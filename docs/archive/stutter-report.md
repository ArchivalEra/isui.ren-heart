# 顿顿现象观测报告（给 Gemini 师傅的运动曲线优化输入）

> 现象：三球运动中存在轻微「顿顿」感（非掉帧——是运动数学层面的速度/方向
> 微跳变）。历经 4 次架构重构（链模型→EulerBlend→回滚→独立球）**始终存在且
> 无本质改善**——已排除架构因素，问题在运动曲线/速度数学层。
> 本报告是观测记录 + 已排除项 + 可疑点，供曲线模板/运动数学优化参考。

## 1. 现象描述

- 观感：球在移动中每隔约 0.5-3 秒出现一次轻微「顿」——像速度突然降一下又恢复，
  或方向轻微折一下。慢速巡航时最明显（高速冲刺被速度掩盖）。
- 蓝绿（跟随/自由球）比粉球明显——粉球较平滑。
- 非渲染问题：拖尾独立采样位置，同样呈现折点（不是 GPU 卡顿）。
- 非帧率问题：60fps 稳定，与浏览器无关（Chrome/Firefox 同现）。

## 2. 历史修复（均未根治，但方向正确）

| 修复 | 效果 |
|---|---|
| 段间速度连续（profile_speed: v_i + (v_next-v_i)×smoothstep(u)） | 消除段边界速度跳变——但顿顿仍在 |
| 智能匀速（跟随者速度 = 队首速度） | 消除跟随者走走停停——部分改善 |
| EMA 时序滤波 α=0.35→0.28（目标点低通） | 「比之前好」但没根治 |
| 曲率差分窗口 0.02→0.06（κ·d 安全衰减平滑化） | 同上 |
| 贴链（位置直接贴链上点，无 spring 追赶） | 消除回弹——顿顿仍在 |
| 前瞻切线（tvel 方向用未来弧长处） | 部分改善 |
| 方向低通 MAX_TURN_RATE=5rad/s | 消除瞬间掉头——顿顿仍在 |

## 3. 已排除（测试/分析证明无关）

- [X] 段间速度跳变（profile_speed 数学连续——测试断言过）
- [X] 队形 gaps 跳变（独立球后已无 gaps）
- [X] 换顺序/排队（已删除）
- [X] 链几何不连续（段间 from=上段 target、切线继承——C1 连续测试）
- [X] 链段出界/收缩（in_bounds 测试全绿）
- [X] 渲染层（拖尾独立采样同样有折点）

## 4. 可疑点（按嫌疑排序）

### 4.1 段边界曲率跳变（最大嫌疑）
- 链 = 25 个曲线模板随机拼接，**段内曲率恒定，段间曲率跳**（相邻档 |Δcurv| 0.10-0.18，贴边强制时可达 0.9+）。
- 几何后果：切线方向 C1 连续但**曲率（切线变化率）不连续**——段边界处"弯度突变"。
- 感知后果：球沿链走，段边界处法向加速度突变 → 视觉"顿"。
- 已尝试：EulerBlend（段内曲率线性渐变）——曲率连续测试 0.0000 通过，但段尾 target 命中破裂（链方向失控）——**全量启用被用户拍板回滚**。教训：曲率连续必须以「段尾精确命中 target + 段中不出圆」为约束。

### 4.2 EMA 追目标残差
- 跟随模式目标 = 粉球链落后点 + Frenet 偏移；EMA α=0.28 平滑——但段边界处
  法线方向跳（曲率跳的连带）→ raw 目标跳 → EMA 追 → 微小顿。
- 已部分缓解（α 0.28 + 曲率窗口 0.06）——未根治。

### 4.3 前瞻切线跨段
- tvel 方向 = 未来 0.45s 弧长处切线——前瞻点跨段时切线方向变化率跳
  （曲率跳的又一次体现）→ 速度方向微折。

### 4.4 调速器（savgol + 钳制）
- velo::tune 对尾部 9 段速度做平滑 + 相邻段差钳制（SEG_V_DELTA=0.6）——
  段级速度档位（0.5-0.65 / 0.72-0.85 / 1.1-1.3）差距本身大（0.55→1.2 翻倍），
  钳制后仍可能感知到。

## 5. 给 Gemini 师傅的方向（模板层可做的）

1. **段内曲率渐变模板**（EulerBlend 的正确版）：单段内曲率从 A 渐变到 B
   （贝塞尔 5 子段曲率线性插值），但**子段 5 直接指向 target**（保证命中）、
   段中经 in_bounds 8 点采样验证（保证不出圆）——当前代码已有
   `make_blend_leg`（sim/chain.rs）被测试覆盖但**默认关闭**（CURVE_PROFILE=Native、
   BLEND_PROB=0）——如果能设计出「曲率渐变 + 段尾命中 + 段中不出圆」三满足的
   模板序列，可以直接启用。
2. **模板序列设计**：现有 25 模板六主题梯队（run 0.0 / stroll±0.10 / breeze±0.20 /
   ripple±0.30 / glide±0.40 / sway±0.52 / loop±0.65 / sweep±0.78 / surge±0.90 /
   drift±1.05 / whirl±1.22 / coil±1.40 / vortex±1.55）——相邻差 0.10-0.18。
   可考虑**更小的段间曲率差**（0.05-0.08）或**消除贴边强制跳档**（near_edge 强制
   中曲率 0.25-0.7 是段边界曲率跳的最大来源）。
3. **速度档位**：三段档（慢 0.5-0.65 / 巡航 0.72-0.85 / 冲刺 1.1-1.3）跨度大——
   冲刺回落两段内（SEG_V_DELTA=0.6）——可考虑档位加密或冲刺档缓降。
