# ADR-0003: 内容快照模式（X/YouTube 静态镜像 + 私域盒子）

- 日期：2026-08-02
- 状态：已接受

## 背景

X / YouTube 对国内用户不可直连；实时反向代理会撞其风控（JS 挑战、验证码），且国内实名设备（盒子）直接转发境外内容有不可逆法律风险。站主方案：VPS 抓取内容生成静态快照，国内盒子只同步/提供快照。

## 决策

- **内容形态**：X/YouTube 内容以**静态快照**提供（HTML 快照 + 图片 + 文本元数据），不做实时反代。
- **抓取**：凤凰城 VPS 运行爬虫（YouTube 用 yt-dlp 抓元数据/缩略图；X 用无头浏览器渲染游客页面），产出静态快照 → Oracle 对象存储。
- **更新**：私域页面「刷新按钮」/访问触发 → 通知 VPS 重爬 → 快照更新到对象存储。
- **分发**：
  - 公开层：EdgeOne（Pages + Edge Functions）提供快照浏览页（x.isui.ren / yt.isui.ren）
  - 私域层：盒子同步快照，CF Tunnel + CF Access 鉴权，仅站主/朋友可访问
- **盒子边界**：只访问自己的服务器（VPS/Oracle）与 CF 边缘，全程不接触境外目标站点；不公开分发（家宽 PCDN 违规），不参与备案（家宽无备案通道）。
- **备案**：暂缓（EdgeOne 国际版全托管零成本）；备案需国内轻量服务器（~50-100 元/年）或公司 IDC 资源，材料备妥后补。

## 为什么（trade-off）

| 方案 | 优点 | 缺点 | 结论 |
|------|------|------|------|
| 实时反代 | 内容最新 | X/YT 风控大概率失败；盒子参与则法律风险不可逆 | 否决 |
| 静态快照 + 按需刷新 | 内容合规可控、盒子零违规访问、实现简单稳定 | 动态有延迟（点刷新才更新） | 采用 |
| 快照公开分发（盒子做 CDN） | 国内体验最好 | 家宽 PCDN 违规、备案制度不允许家宽 | 否决 |

## 后果

- X 的静态快照需无头浏览器渲染（React 页面），VPS 需装 headless chromium；YouTube 用 yt-dlp 即可
- 快照刷新链路：盒子/公开页 → Edge Function → VPS 触发 → 对象存储 → 同步
- 私域访问经 CF Tunnel（cloudflared 已在用），复用现有 CF Access 组织
