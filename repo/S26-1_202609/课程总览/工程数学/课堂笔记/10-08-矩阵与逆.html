10-08-矩阵与逆
这节课在干什么：上周刚把行列式算完，这一节正式进入矩阵。老师先补一串定义（方阵、同型矩阵、零矩阵、主对角线，以及三角、对角、数量、单位四种常见方阵），再讲运算：相等、加法与负矩阵、数乘、乘法、转置。全课的重心和难点是矩阵乘法——先把"行乘列、对应相乘再相加"这条定义讲透，再用一个零元素很多的三阶例子演示分块的省力做法。课末用"两个工厂、两种产品、已知总收入求单价"的引例引出逆矩阵：解 AX=B 需要两边左乘 A⁻¹，所以要知道矩阵的逆；逆的定义、唯一性、伴随矩阵与公式 A⁻¹ = A*/|A| 都在这节课给出。


行政与考核：


    

  • 作业以老师实际布置的为准，不用照着别人拍的照片做（照片糊、看不清）。
    • 

  • 上次作业老师认为可能偏简单，很多同学能拿满分；后面会加针对性的强化练习。
    • 

  • 要求自己把 MATLAB 装好（链接老师这次没发，自己找资源下载也算一种能力），用于把 Excel 里的表格数据读成矩阵后一键计算，替代手算四阶、五阶这类大矩阵。
    • 

  • 预习可扫书上的微课视频（老师提到"微课16"左右）。
    • 



题号条目
例2.3（矩阵加法：9 月、10 月产量相加）
解析：题目给两张表（表2.3、表2.4），行表示车间，列表示 A、B、C 三种产品，表里填的是各车间生产各产品的数量。要算两个月总产量，机械做法只有一步：把两张表各自写成一个同型矩阵，对应位置相加。


设 9 月产量矩阵为 A = (aᵢⱼ)、10 月为 B = (bᵢⱼ)，行列数相同，则总产量



      

        text
        
      

      
A + B = (aᵢⱼ + bᵢⱼ)

    


即第 i 行第 j 列的数就是 A、B 在同一位置两个数之和。依据就是矩阵加法的定义：同型矩阵对应元素相加。前提是两个矩阵行列数完全一致；若不同型，某些位置根本没有对应元素可加，加法就不成立。


这一题在讲什么：这是最直白的一个应用，用来说明"矩阵加法"不是抽象规定，而是"把两张同规格的表逐格相加"这种真实动作的形式化。顺带指出：两个矩阵相加后，行数、列数都不变。


例2.2（矩阵乘法：2×3 乘 3×2，以及反过来乘）
解析：老师先讲按定义逐元素算的"笨办法"，再讲分块省力法。


按定义：C = AB 的第 i 行第 j 列元素，等于 A 的第 i 行与 B 的第 j 列对应元素相乘再求和：



      

        text
        
      

      
cᵢⱼ = aᵢ₁b₁ⱼ + aᵢ₂b₂ⱼ + … + aᵢₛbₛⱼ

    


这一题 A 是 2×3、B 是 3×2，乘出来是 2×2，所以一共要算 4 个元素。老师现场逐个念了这 4 个数（A、B 的原矩阵未在转写中完整念出，按念出的乘加式还原为 A = [[1,0,3],[2,−1,0]]、B = [[1,−1],[2,3],[4,−1]]）：


    

  • 新矩阵第 1 行第 1 列 = A 第 1 行 × B 第 1 列 = 1×1 + 0×2 + 3×4 = 13；
    • 

  • 第 2 行第 1 列 = A 第 2 行 × B 第 1 列 = 2×1 + (−1)×2 + 0×4 = 0；
    • 

  • 第 1 行第 2 列 = A 第 1 行 × B 第 2 列 = 1×(−1) + 0×3 + 3×(−1) = −4；
    • 

  • 第 2 行第 2 列 = A 第 2 行 × B 第 2 列 = 2×(−1) + (−1)×3 + 0×(−1) = −5。
    • 



于是 AB 是 2×2 的矩阵。注意新矩阵的行数 = 前一个矩阵的行数，列数 = 后一个矩阵的列数，中间那个"3"（A 的列数）必须与 B 的行数相等才乘得起来。


反过来算 BA：B 是 3×2、A 是 2×3，乘出来是 3×3，按定义要算 9 个元素、每个元素 2 项乘加，共 9 次运算，比上面麻烦。老师的第二种做法是分块：把这道题里零比较多的部分单独拎出来当"零块"。例如某矩阵有一行全零，就把这整行看成一个零行块（一个全零的行矩阵）；另一矩阵对应的整列若也全零，就看成一个零列块。分块之后按"块 × 块"来乘，凡是与零块相乘的项直接得零，只需算剩下的非零小块相乘。老师把 A 中要用的那部分记作 A₁（1×3 的行块）、B 中要用的那部分记作 B₁（3×1 的列块），这样 BA 里真正要算的只剩一次 B₁ × A₁（行向量乘列向量，对应相乘再相加），把 9 次逐元素运算压到 2 次左右。这段转写极碎（"一传媒""3 乘以 4"等），分块的具体切法无法从转写确定。


这一题在讲什么：一是练"行乘列"这个定义本身；二是说明同一道题换个视角（分块）可以大幅省算——这正是后面分块矩阵这一章的思想预演。老师也借这道题提醒：AB 和 BA 结果不同，矩阵乘法不满足交换律。


例（设 |A| = −1 且 AAᵀ = E，证明 |A + E| = 0）
解析：这是"行列式性质 + 转置性质"的组合题，机械步骤固定。


由条件 AAᵀ = E，把结论里的 E 换掉：|A + E| = |A + AAᵀ|。两个项都含 A，把 A 从左边提出（矩阵乘法对加法满足分配律，注意这里"1"要写成单位矩阵 E，不是数字 1）：|A + E| = |A(E + Aᵀ)|。用行列式性质 |AB| = |A|·|B|，得 |A + E| = |A| · |E + Aᵀ|。


再把 E + Aᵀ 写成转置形式。依据是单位矩阵的转置还是它自己，且和的转置等于转置之和：(E + A)ᵀ = Eᵀ + Aᵀ = E + Aᵀ。所以 |A + E| = |A| · |(E + A)ᵀ|。用转置的行列式性质 |Bᵀ| = |B|（加不加转置不影响行列式的值）去掉转置：



      

        text
        
      

      
|A + E| = |A| · |E + A| = |A| · |A + E|

    


题目给 |A| = −1，代入：|A + E| = −|A + E|  ⟹  2|A + E| = 0  ⟹  |A + E| = 0。（最后一步也可以直接说："一个数等于它自己的相反数，这个数只能是 0"。）


这一题在讲什么：老师用一个数字类比说明这个结论不奇怪——若把行列式当成数，条件相当于 |A| = −1、且要证 |A + 1| = 0，那就只能是 −1 + 1 = 0。同时它把本节课三件工具串起来用了：E = AAᵀ 的替换、提公因子要提单位矩阵、|AB| = |A||B|、|Bᵀ| = |B|。


例2.4（A 反对称、B 对称，证明 AB + BA 是反对称矩阵）
解析：证明"某矩阵是反对称"的唯一机械入口就是对它取转置，看是否等于自己的负矩阵。


设 A 反对称、B 对称，即 Aᵀ = −A、Bᵀ = B。对 AB + BA 取转置：



      

        text
        
      

      
(AB + BA)ᵀ = (AB)ᵀ + (BA)ᵀ            （和的转置 = 转置的和）

    


再用转置的"反序"性质 (XY)ᵀ = YᵀXᵀ：(AB)ᵀ = BᵀAᵀ = B(−A) = −BA，(BA)ᵀ = AᵀBᵀ = (−A)B = −AB。加起来：



      

        text
        
      

      
(AB + BA)ᵀ = −BA − AB = −(AB + BA)

    


由反对称矩阵的定义（Aᵀ = −A）知 AB + BA 是反对称矩阵。


这一题在讲什么：练转置的两条性质（和的转置、乘积转置要反序），并练负号的提取：−BA − AB 中把 −1 当系数提出来，得到 −(AB + BA)。老师强调这类题"直接告诉你矩阵的性质，直接去做题"，属于套性质就能走完的题型。


案例2.2（超市的当日销售额与利润）
解析：表格里是各超市、各商品的销量与单位价格、单位利润。机械关系只有两条：


    

  • 某商品在某超市的销售额 = 该商品在该超市的销量 × 该商品单位售价；
    • 

  • 该商品的利润 = 该商品在该超市的销量 × 该商品单位利润。
    • 



老师不按书上的写法，自己把表格拆开：把表示销量的几行（前三行）看成矩阵 A，把表示单位价格/单位利润的两行看成矩阵 B。要算各超市总销售额，就是把"某超市各商品销量"这一行与"各商品单价"这一列对应相乘再相加——这正是矩阵乘法里"行 × 列"的动作。


这里有个细节：直接按表格行来乘时，需要的单价是竖着的一列，而表里单价是横着的一行，所以要先转置才能严格写成矩阵乘法（把行变成列，让"行 × 列"对得上）。


这一题在讲什么：说明矩阵乘法在经营数据里的用途，并顺势引出工具——与其一个个手算，不如把 Excel 数据用 MATLAB 读成矩阵，一条命令算出全部销售额和利润。老师现场对比：手算四阶、五阶要大半天，软件不到 1 秒出结果。


定义2.9（伴随矩阵）
解析：伴随矩阵 A* 的构造规则是**"各元素的代数余子式，按转置的位置摆放"**：把原矩阵每个元素 aᵢⱼ 换成它的代数余子式 Aᵢⱼ，组成一个新矩阵，再把这个新矩阵转置，就是伴随矩阵。等价说法：原矩阵里"第 i 行"的代数余子式，在伴随矩阵里排成"第 i 列"（原来的行、列位置互换）。


它最重要的性质（老师称"非常经典的公式"）：



      

        text
        
      

      
A A* = A* A = |A| E

    


这一题在讲什么：伴随矩阵本身只是中间产物，它的价值在于由上式立刻得到求逆的公式——把 |A| 移过去：



      

        text
        
      

      
A⁻¹ = A* / |A|      （前提：|A| ≠ 0）

    


这就给出了矩阵求逆的一种通用计算方法。老师用数字类比：中学里 3⁻¹ = 1/3，3⁻¹ × 3 = 1；矩阵里对应的是 A⁻¹ A = A A⁻¹ = E。


逆矩阵引例（书 33–34 页：两工厂两种产品，已知总收入求单价）
解析：甲、乙两个工厂各生产甲、乙两种产品。每天各厂生产两种产品的数量写成一个矩阵，第一行是工厂一，第二行是工厂二。已知工厂一每天总收入 290、工厂二每天总收入 240，求两种产品的单位售价。


设两种产品单价分别为 S₁、S₂（转写里也写作 X₁、X₂，同一意思）。总收入 = 单价 × 数量，按行列出两个方程：



      

        text
        
      

      
5S₁ + 7S₂ = 290
6S₁ + 3S₂ = 240

    


写成矩阵方程：取



      

        text
        
      

      
A = [[5, 7],
     [6, 3]] ,   X = [[S₁],
                      [S₂]] ,   B = [[290],
                                        [240]]

    


则方程组就是 AX = B。


求解不能"两边除以 A"（矩阵没有除法）。正确做法是两边同时左乘 A⁻¹：



      

        text
        
      

      
A⁻¹(AX) = A⁻¹B
(A⁻¹A)X = A⁻¹B        （结合律）
E X = A⁻¹B            （A⁻¹A = E）
X = A⁻¹B              （单位矩阵乘任何矩阵等于它本身）

    


B 是已知的，所以只要知道 A⁻¹，X 就算出来了——这就是为什么要去求矩阵的逆。


这一题在讲什么：老师正面回答了"我们为什么要去计算一个矩阵的逆"。二元一次方程组当然可以用克拉默法则（行列式之比）直接解，但阶数一大（三阶、四阶、五阶，甚至上千阶）克拉默法则就不划算，这时统一用 X = A⁻¹B 更合适；而逆矩阵按上一节 A⁻¹ = A*/|A| 来求。老师也点明：这道引例本身很简单，"你们自己解一个二元一次方程就能出来"，真正的目的是把"解方程组 → 求逆矩阵"这条线拉直。


没编号但讲了的知识点
矩阵与方阵；行列式只对方阵有意义
矩阵是 m 行 n 列的数表。当行数 m 与列数 n 相等（m = n）时，称为 n 阶方阵。


老师在这里带大家回头想行列式：上周算的二阶、三阶、四阶行列式，行数和列数总是相等的（二阶就二行二列，三阶就三行三列）。为什么？回到行列式的定义——它是"取某一行（列）的元素，各自乘以对应代数余子式再求和"，元素的行、列必须够用、能一一对应；如果矩阵是"扁的"（行数 ≠ 列数），行或列就不够，凑不出这种对应。所以行列式只对（方）矩阵有定义，非方阵没有行列式。


行矩阵与列矩阵；矩阵不是数
    

  • 只有一行的矩阵（1×n）叫行矩阵，记作 a₁ₙ 之类；
    • 

  • 只有一列的矩阵（m×1）叫列矩阵。
    • 



这两种在矩阵运算里特别重要，因为"行 × 列"的乘法正是靠它们搭起来的。


老师追问："矩阵是数吗？"不是。只有一种极端情形会退化成数：m = n = 1，此时数表里只剩一个数字，才可以当数看。除此之外矩阵和数是两回事。


同型矩阵
若两个矩阵的行数相等、列数也分别相等，就称它们是同型矩阵。例如 A 是 4×3，B 也必须是 4×3，二者才同型。同型是"矩阵相等""矩阵相加"的前提。


零矩阵
所有元素都是 0 的矩阵叫零矩阵，记作一个粗体的 0（区别于自然数里那个数字 0）。要点：零矩阵的行数、列数也要写清楚——4×3 的零矩阵和 3×4 的零矩阵不是同一个，因为它们不同型。老师特别强调，写 A + (−A) 的结果时不要随手写成数字 0，那是同型的零矩阵。


主对角线
方阵中位于相同行号与列号交叉位置的元素（即 aᵢᵢ）连起来的那条线，称为主对角线。


四种常见方阵
    

  • 三角矩阵：主对角线下方元素全为零的，叫上三角矩阵；主对角线上方元素全为零的，叫下三角矩阵。用下标判断：对 aᵢⱼ，行号 i 大于列号 j 的位置在主对角线以下，若这些位置全为 0 就是上三角；i < j 的位置全为 0 则是下三角。
    • 

  • 对角矩阵：除主对角线外，其余元素全为 0 的方阵，记作 diag(a₁₁, a₂₂, …, aₙₙ)（"diag" 就是英文里"对角线"的那个词）。它同时是上三角也是下三角。
    • 

  • 数量矩阵：主对角线上的元素全都相等（都等于某个数 a）的对角矩阵。它特别好记——只需记住那一个数 a。
    • 

  • 单位矩阵：数量矩阵中那个数 a 取 1 的情形，记作 E。它必须是方阵。单位矩阵在矩阵乘法里的地位相当于数字 1。
    • 



矩阵相等
A = B 需要两个条件同时成立：(1) A、B 同型（行列数一致）；(2) 每个对应位置的元素都相等。


矩阵加法、负矩阵与减法
    

  • 加法：同型矩阵对应元素相加。不同型的矩阵不能相加——某些位置会"没有元素可加"（比如一个矩阵多出一行，另一矩阵这一行是空的）。
    • 

  • 负矩阵：把原矩阵所有元素乘以 −1（即取相反数）得到的新矩阵。
    • 

  • 减法：A − B = A + (−B)，即加上 B 的负矩阵。
    • 



加法的运算律
    

  • 交换律：A + B = B + A；
    • 

  • 结合律：(A + B) + C = A + (B + C)；
    • 

  • A + 0 = A（这里的 0 是同型零矩阵）；
    • 

  • A + (−A) = 0（同样是零矩阵）。
    • 



形式上与数的加法一样，唯一的坑就是那个"0"：它带着行数和列数，不是数字 0。


数乘及其运算律
数 k 与矩阵相乘，就是 k 乘以矩阵里的每一个元素。运算律：


    

  • k(A + B) = kA + kB；
    • 

  • (k + l)A = kA + lA；
    • 

  • k(lA) = (kl)A；
    • 

  • 1·A = A，0·A = 0（零矩阵）。
    • 



这些和数字运算形式一致，按定义走即可。


矩阵乘法（本节难点）
定义：设 A 是 m×s 矩阵，B 是 s×n 矩阵（把两个矩阵里共同的那个 s 圈出来），则 C = AB 是 m×n 矩阵，其中



      

        text
        
      

      
cᵢⱼ = A 的第 i 行 · B 的第 j 列
     = aᵢ₁b₁ⱼ + aᵢ₂b₂ⱼ + … + aᵢₛbₛⱼ

    


三条要记死的规则：


    

  1. 能乘的条件：前一个矩阵的列数必须等于后一个矩阵的行数（都是 s）。只有 s 相等时两个矩阵才能相乘。
    2. 

  2. 乘积的形状：新矩阵的行取前一个矩阵的行，列取后一个矩阵的列（m×n）。
    3. 

  3. 每个元素怎么来：cᵢⱼ = 前一个矩阵第 i 行与后一个矩阵第 j 列对应元素相乘再全部加起来。
    4. 



老师把第 3 条的那句中文（书上 27 页"矩阵 C 的元素是 A 的第 i 行与矩阵 B 的第 j 列对应元素乘积之和"）称为比公式本身更有用的理解抓手：记住"左边挑一行，右边挑一列，对应相乘再相加"，就不会晕。


乘法不满足交换律、不满足消去律
    

  • 不满足交换律：一般 AB ≠ BA。上面例2.2 里 A×B 与 B×A 结果就不一样（形状都不同）。只有当 AB = BA 时才说这两个矩阵可交换。
    • 

  • 不满足消去律：由 AC = BC 且 C ≠ 0，推不出 A = B。不能像数字那样两边约掉同一个因子。
    • 

  • 附带一条：AB = 0（零矩阵）推不出 A 或 B 是零矩阵。
    • 



乘法的运算律与单位矩阵的作用
在运算可行（维数对得上）的前提下，矩阵乘法满足：


    

  • 结合律：(AB)C = A(BC)；
    • 

  • 左分配律、右分配律：A(B + C) = AB + AC，(B + C)A = BA + CA（左右都要写，因为不满足交换律）；
    • 

  • 与数乘的相容：λ(AB) = (λA)B = A(λB)；
    • 

  • 单位矩阵：E 乘任何矩阵仍等于那个矩阵，地位相当于数字里的 1。
    • 



转置及其四条性质
把 m×n 矩阵 A 的行换成相应的列，得到 n×m 矩阵，称为 A 的转置矩阵，记作 Aᵀ（原文简称"A 的转置"）。例如把原矩阵每一行横着抄成新矩阵的一列。


四条性质：


    

  1. (Aᵀ)ᵀ = A（转置的转置还是自己）；
    2. 

  2. (A + B)ᵀ = Aᵀ + Bᵀ（和的转置 = 转置的和）；
    3. 

  3. (λA)ᵀ = λAᵀ（数乘不影响转置，数直接放外面）；
    4. 

  4. (AB)ᵀ = BᵀAᵀ（乘积的转置要交换顺序——这条最经典，也最容易写反）。
    5. 



对称矩阵与反对称矩阵
    

  • 对称矩阵：满足 Aᵀ = A 的方阵。特点是关于主对角线对称（aᵢⱼ = aⱼᵢ）。
    • 

  • 反对称矩阵：满足 Aᵀ = −A 的方阵。特点有两条：主对角线上的元素全是 0（因为 aᵢᵢ = −aᵢᵢ），且关于主对角线对称的元素互为相反数（aᵢⱼ = −aⱼᵢ）。
    • 



行列式的三条性质（本节用到的）
对 n 阶方阵，设 A、B 都是 n 阶方阵，λ 为一个数：


    

  1. |Aᵀ| = |A|：给矩阵加转置，不改变行列式的值。
    2. 

  2. |λA| = λⁿ|A|：数 λ 乘矩阵，等于 A 的每个元素都乘 λ；把每一行的 λ 各提出来一次，共可提出 n 个 λ，所以外面是 λ 的 n 次方（不是 λ 的一次方）。这里用到的依据是行列式"某一行乘 k 可以把 k 提到行列式外面"这条性质。
    3. 

  3. |AB| = |A|·|B|：两个矩阵相乘的行列式，等于这两个矩阵行列式的乘积。老师称之为"非常伟大""非常好用"的性质，后面证明题直接用。数字类比：两个数相乘取绝对值，等于各自绝对值相乘。
    4. 



两个"千万不要搞混"的地方
    

  • AAᵀ 与 AᵀA 一般不一样。这节课的例题里 AAᵀ = E，但不能由此说 AᵀA = E。左乘、右乘是有区别的。
    • 

  • 那么什么时候 AAᵀ = AᵀA = E 三个（含 E）都相等？老师说这是下节课的内容（满足这个条件的方阵有专门名称）。
    • 



逆矩阵的定义与唯一性
对 n 阶方阵 A，若存在同阶方阵 B 使得



      

        text
        
      

      
AB = BA = E

    


则称 A 是可逆矩阵，B 是 A 的逆矩阵，A 与 B 互为可逆阵。由逆矩阵的唯一性，通常把 A 的逆矩阵记作 A⁻¹（右上角写 −1）。可逆的定义要求左右两个方向都成立（AB = E 且 BA = E）。
