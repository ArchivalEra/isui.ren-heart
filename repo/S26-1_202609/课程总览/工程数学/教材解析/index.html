照片与已有资料的关联方式

  • 教材照片按原书结构登记在原始资料索引：目录页 p1–p8、第 1 章正文 p1–p21、书末参考答案页、第 2 章正文 p22–p51，。照片原件不入库，由拍摄者本地保存，仓库只登记文件名与页码。

  • 课堂笔记索引中的两篇行列式笔记仍以原正文保存，并在第 1 章解析中通过链接归入 1.1 节，不复制正文。

  • 教材习题、例题不自动认定为教师正式布置的作业，见作业索引。

  • 资料页零未竟表述（2026-10-12 定案）：解析页只列已抄录、已解析的范围；缺材料、待复核等条目统一归 GitHub issue 跟踪（open = 没补，closed = 补了）。

  • 来源收进气泡、完成边界压缩（2026-10-30 全站定案）：页面顶部的 sources 芯片承载出处 （≤30 字，明细在 原始资料/index.md），正文不再有「来源与边界」一节； 完成边界 压到 ≤150 字，只写已解析／已验证／已知限制各一句，缺什么进 issue。
