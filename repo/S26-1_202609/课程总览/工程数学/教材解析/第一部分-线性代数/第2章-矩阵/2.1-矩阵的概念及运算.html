2.1.1 矩阵的概念（原书 p22–p24）

原书抄录

〔原书 p22〕

矩阵是线性代数的一个重要概念，也是一个重要的数学工具，它被广泛地应用到现代管理科学、自然科学、工程技术等各个领域。本章主要介绍矩阵的概念及运算、矩阵的初等变换及逆矩阵等知识。

引例 2.1（物资调运） 在物资调运中经常要考虑如何决定销地，使物资的总运费最低。如果某个地区的钢材有三个产地 x1​,x2​,x3​，有三个销地 y1​,y2​,y3​，可以用一个数表来表示钢材的调运方案，如表 2.1 所示。

定义 2.1 由 m×n 个数 aij​ (i=1,2,⋯,m; j=1,2,⋯,n) 按一定顺序排成一个 m 行 n 列的数表

A=⎝⎜⎜⎛​a11​a21​⋮am1​​a12​a22​⋮am2​​⋯⋯⋯​a1n​a2n​⋮amn​​⎠⎟⎟⎞​,

称为 m 行 n 列矩阵，简称 m×n 矩阵，记作 A=(aij​)m×n​ 或 A=(aij​) 或 Am×n​。

当 m=n 时，矩阵的行数与列数相等，这时称矩阵为 n 阶方阵。

当 m=1 时，矩阵只有一行，即矩阵 A=(a11​ a12​ ⋯ a1n​)，称为行矩阵。

当 n=1 时，矩阵只有一列，即矩阵 A=⎝⎜⎜⎛​a11​a21​⋮am1​​⎠⎟⎟⎞​，称为列矩阵。

当两个矩阵的行数相等，列数也相等时，就称它们是同型矩阵。

元素都是零的矩阵称为零矩阵，记作 O。不同型的零矩阵是不同的。

从左上角到右下角的直线称作主对角线。主对角线以下的元素全为零的方阵，即

⎝⎜⎜⎛​a11​0⋮0​a12​a22​⋮0​⋯⋯⋯​a1n​a2n​⋮ann​​⎠⎟⎟⎞​,

称为上三角矩阵。主对角线以上的元素全为零的方阵，即

〔原书 p24〕

⎝⎜⎜⎛​a11​a21​⋮an1​​0a22​⋮an2​​⋯⋯⋯​00⋮ann​​⎠⎟⎟⎞​,

称为下三角矩阵。上三角矩阵与下三角矩阵统称为三角矩阵。

主对角线上存在非零元素，其他元素都是 0 的方阵称作对角矩阵，即

A=⎝⎜⎜⎛​a11​0⋮0​0a22​⋮0​⋯⋯⋯​00⋮ann​​⎠⎟⎟⎞​

我们也记作 A=diag(a11​,a22​,⋯,ann​)。显然对角矩阵既是上三角矩阵，也是下三角矩阵。

特别地，主对角线上的元素都是 1，其他元素都是 0 的矩阵称作单位矩阵，记为 En​，简记作 E，即

En​=⎝⎜⎜⎛​10⋮0​01⋮0​⋯⋯⋯​00⋮1​⎠⎟⎟⎞​

解析

矩阵与行列式的区别（整理者补充）：这是本章最容易混的一点。

比较项行列式（第 1 章）矩阵（第 2 章）
外形两侧竖线 ∣⋅∣两侧圆括号
行数与列数必须相等，是 n 阶可以不等，是 m×n
运算结果一个数一个数表本身
相等数值相等同型且对应元素全相等

术语要点：n 阶方阵是行数等于列数的矩阵；行矩阵只有一行、列矩阵只有一列；同型矩阵必须行数、列数都相同，只有同型矩阵才谈得上相等和加减。零矩阵 O 的形状由上下文确定，不同型的零矩阵不是同一个对象。

三角、对角、单位矩阵：上三角（下方全零）、下三角（上方全零）合称三角矩阵；对角矩阵要求主对角线以外全为零，主对角线上允许有零；单位矩阵是对角元全为 1 的对角矩阵，它是矩阵乘法中的"1"（见 2.1.2.3）。

易错点："主对角线上存在非零元素"是对角矩阵的定义措辞，不是"主对角线元素都非零"；单位矩阵 En​ 的阶数必须与同型运算匹配（如 Em​Am×n​ 与 Am×n​En​ 是不同阶的单位矩阵）。

2.1.2 矩阵的运算（原书 p24–p31）

原书抄录

〔原书 p24〕

2.1.2.1 矩阵的加法

首先，给出两个矩阵相等的概念。

如果 A=(aij​) 与 B=(bij​) 是同型矩阵，并且它们的对应元素都相等，即

aij​=bij​,i=1,2,⋯,m; j=1,2,⋯,n,

则称矩阵 A 与 B 相等，记作 A=B。

引例 2.3（产品产量） 某公司有甲、乙两车间生产 A,B,C 三种产品，九月份、十月份两个月的产量如表 2.3、表 2.4 所示。

定义 2.2 设 A=(aij​), B=(bij​) 均为 m×n 矩阵，则矩阵 A 与 B 的和记作 A+B，且

A+B=(aij​+bij​)m×n​

设矩阵 A=(aij​)，记 −A=(−aij​)，−A 称为矩阵 A 的负矩阵。显然 A+(−A)=O。规定，矩阵的减法为 A−B=A+(−B)。

由定义知，只有行数相同、列数也相同的矩阵才能相加减。

矩阵的加法满足以下运算规律：

  1. A+B=B+A；
  2. (A+B)+C=A+(B+C)；
  3. A+O=A；
  4. A+(−A)=O。

其中，A,B,C 都是 m 行 n 列的矩阵。

〔原书 p26〕

2.1.2.2 数与矩阵相乘

定义 2.3 数 λ 与矩阵 A=(aij​) 的乘积记作 λA，规定为 λA=(λaij​)m×n​，即

λA=λ⎝⎜⎜⎛​a11​a21​⋮am1​​a12​a22​⋮am2​​⋯⋯⋯​a1n​a2n​⋮amn​​⎠⎟⎟⎞​=⎝⎜⎜⎛​λa11​λa21​⋮λam1​​λa12​λa22​⋮λam2​​⋯⋯⋯​λa1n​λa2n​⋮λamn​​⎠⎟⎟⎞​

显然，数与矩阵相乘满足下列运算规律：

  1. (λμ)A=λ(μA)；
  2. (λ+μ)A=λA+μA；
  3. λ(A+B)=λA+λB。

其中，A,B 都是 m 行 n 列的矩阵，λ,μ 为任意常数。

【例 2.1】 设 A=⎝⎛​30−1​281​⎠⎞​, B=⎝⎛​123​20−1​⎠⎞​，且 A+2X=3B，求矩阵 X。

解 由 A+2X=3B 知

X=21​(3B−A)=21​×⎣⎡​3⎝⎛​123​20−1​⎠⎞​−⎝⎛​30−1​281​⎠⎞​⎦⎤​
=21​×⎣⎡​⎝⎛​369​60−3​⎠⎞​−⎝⎛​30−1​281​⎠⎞​⎦⎤​=21​×⎝⎛​0610​4−8−4​⎠⎞​=⎝⎛​035​2−4−2​⎠⎞​

2.1.2.3 矩阵与矩阵相乘

引例 2.4（成本和销售额） 设某厂生产甲、乙、丙三种产品，九月份和十月份的产量用矩阵 A 表示，其成本单价和销售单价用矩阵 B 表示，试求九月份和十月份的成本总额和销售总额。

甲乙丙成本单价销售单价成本总额销售总额
b11​b12​c11​c12​
a11​a12​a13​b21​b22​c21​c22​
a21​a22​a23​b31​b32​

A=(a11​a21​​a12​a22​​a13​a23​​),B=⎝⎛​b11​b21​b31​​b12​b22​b32​​⎠⎞​,C=(c11​c21​​c12​c22​​)

用矩阵 C 来表示两个时间段的成本总额和销售总额，则有

九月份三种产品的成本总额为 c11​=a11​b11​+a12​b21​+a13​b31​，

销售总额为 c12​=a11​b12​+a12​b22​+a13​b32​，

〔原书 p27〕

十月份三种产品的成本总额为 c21​=a21​b11​+a22​b21​+a23​b31​，

销售总额为 c22​=a21​b12​+a22​b22​+a23​b32​。

从中可以看出，矩阵 C 的元素 cij​ (i=1,2; j=1,2) 是矩阵 A 的第 i 行元素与矩阵 B 的第 j 列对应元素乘积之和。

定义 2.4 设 A=(aij​) 是一个 m×s 矩阵，B=(bij​) 是一个 s×n 矩阵，那么规定矩阵 A 与矩阵 B 的乘积是一个 m×n 矩阵 C=(cij​)，其中

cij​=ai1​b1j​+ai2​b2j​+⋯+ais​bsj​=k=1∑s​aik​bkj​,i=1,2,⋯,m; j=1,2,⋯,n

记作 C=AB。记号 AB 常读作 A 左乘 B 或 B 右乘 A。

由矩阵乘法的定义知，两个矩阵要能相乘，需满足：A 的列数 =B 的行数。AB 的行数 =A 的行数；AB 的列数 =B 的列数。

A 与 B 的先后次序不能改变。例如，

A=⎝⎛​301​−130​⎠⎞​,B=(10​02​11​−10​),AB=⎝⎛​301​−260​231​−30−1​⎠⎞​

而 BA 无意义。

【例 2.2】 已知 A=(12​0−1​30​), B=⎝⎛​124​−130​⎠⎞​，求 AB 与 BA。

解

AB=(130​−1−5​),BA=⎝⎛​−184​1−30​3612​⎠⎞​

从本例可以看出，有时虽然 AB 与 BA 都有意义，但 AB 不一定等于 BA，即矩阵乘法不满足交换律；

同样，若有两个矩阵 A,B 满足 AB=O，不能得出 A=O 或 B=O 的结论，即矩阵乘法不满足消去律。

例如，设 A=(1−1​−11​), B=(11​22​)，则 AB=(00​00​), BA=(−1−1​11​)。显然，AB=BA；A=O，B=O，但是 AB=O。

但在运算都可行的情况下，矩阵的乘法仍满足下列运算律：

  1. (AB)C=A(BC)；
  2. λ(AB)=(λA)B=A(λB)，其中 λ 为数；
  3. A(B+C)=AB+AC, (B+C)A=BA+CA。

对于单位矩阵 E，易知

〔原书 p28〕

Em​Am×n​=Am×n​,Am×n​En​=Am×n​

可简记为

EA=AE=A

可见在矩阵乘法中单位矩阵 E 类似于"1"在数的乘法中所起的作用。

  1. 完成这些基建任务所需各种主要原材料的数量；

2.1.2.4 矩阵的转置

定义 2.5 设矩阵

A=⎝⎜⎜⎛​a11​a21​⋮am1​​a12​a22​⋮am2​​⋯⋯⋯​a1n​a2n​⋮amn​​⎠⎟⎟⎞​,

矩阵 A 的行与列依次互换所得到的矩阵称作 A 的转置矩阵，记作 AT，即

AT=⎝⎜⎜⎛​a11​a12​⋮a1n​​a21​a22​⋮a2n​​⋯⋯⋯​am1​am2​⋮amn​​⎠⎟⎟⎞​

矩阵的转置运算满足下述运算规律（假设运算都是可行的）：

  1. (AT)T=A；
  2. (A+B)T=AT+BT；
  3. (λA)T=λAT；
  4. (AB)T=BTAT。

定义 2.6 设 A 为 n 阶方阵，如果满足 AT=A，即 aij​=aji​ (i,j=1,2,⋯,n)，则称 A 为对称矩阵。

如果满足 AT=−A，即 aij​=−aji​ (i,j=1,2,⋯,n)，则称 A 为反对称矩阵。

例如：

A=⎝⎛​1261​680​106​⎠⎞​

是 3 阶对称矩阵。

B=⎝⎛​01−2​−10−3​230​⎠⎞​

是 3 阶反对称矩阵。

【例 2.4】 设 A 是 n 阶反对称矩阵，B 是 n 阶对称矩阵，证明：AB+BA 是 n 阶反对称矩阵。

证 因为 AT=−A, BT=B，而

(AB+BA)T=(AB)T+(BA)T=BTAT+ATBT=B(−A)+(−A)B=−(AB+BA),

所以结论成立。

2.1.2.5 方阵的行列式

定义 2.7 由 n 阶方阵 A 的元素构成的行列式（各元素位置不变），称为方阵 A 的行列式，记作 ∣A∣ 或 detA。

设 A,B 为 n 阶方阵，λ 为数，则下列等式成立：

  1. ∣AT∣=∣A∣；
  2. ∣λA∣=λn∣A∣；
  3. ∣AB∣=∣A∣∣B∣。

【例 2.5】 设 A 是 n 阶方阵，满足 AAT=E，且 ∣A∣=−1，求 ∣A+E∣。

解 由于

∣A+E∣=∣A+AAT∣=∣AE+AAT∣=∣A(E+AT)∣=∣A∣∣E+AT∣=∣A∣∣ET+AT∣=−∣(E+A)T∣
=−∣E+A∣=−∣A+E∣,

所以 2∣A+E∣=0，即 ∣A+E∣=0。

解析

加法与数乘的直观：矩阵加法就是"对应位置相加"，所以只有同型矩阵才能相加；数乘 λA 是"每个元素都乘 λ"，与第 1 章的"某一行乘 k"完全不同——后者只乘一行。

矩阵乘法的三条硬规则：

  1. 形状先检查：Am×s​ 乘 Bs×n​ 才有意义，结果 Cm×n​；中间那个 s 必须相同。
  2. 左行右列：cij​ 是 A 的第 i 行与 B 的第 j 列对应元素乘积之和。
  3. 次序不能换：AB 与 BA 可能不同型、可能只一个有定义、可能都有定义但不等。

与数运算的根本差别（整理者补充，务必记牢）：

数矩阵
ab=baAB=BA 不一定成立
ab=0⇒a=0 或 b=0AB=O 推不出 A=O 或 B=O
ax=ay, a=0⇒x=yAX=AY, A=O 推不出 X=Y
(a+b)2=a2+2ab+b2(A+B)2=A2+AB+BA+B2=A2+2AB+B2（除非 AB=BA）
a2−b2=(a+b)(a−b)A2−B2=(A+B)(A−B)（除非 AB=BA）

仍成立的性质：结合律 (AB)C=A(BC)、分配律 A(B+C)=AB+AC、与数乘的相容性 λ(AB)=(λA)B=A(λB)、E 的单位性。

例 2.1 解析：X=21​(3B−A)=⎝⎛​035​2−4−2​⎠⎞​。验算 A+2X=3B：A+2X=⎝⎛​369​60−3​⎠⎞​=3B。

例 2.2 解析：AB=(130​−1−5​) 是 2×2，BA=⎝⎛​−184​1−30​3612​⎠⎞​ 是 3×3，连形状都不同，当然不等。AB=O 的例子（A=(1−1​−11​)）说明消去律失效。

案例 2.1 解析：AB 是"6 栋 A 类、5 栋 B 类、3 栋 C 类"分别乘各类每幢用料后求和，得 (1285,5310,24020,12600)；再乘单价列向量得总金额 5923500。注意 ABC 的结合方式：(AB)C 先算 1×4 再算 1×1，也可以先算 BC（4×1），结果相同——这是结合律。

案例 2.2 解析：要用 ABT 而不是 AB，因为 A 是 2×3（价格/利润 × 商品），B 是 3×3（超市 × 商品），AB 无意义；BT 是商品 × 超市，ABT 得 2×3（价格/利润 × 超市），恰好是每个超市一行销售额一行利润。

转置的四条运算律：(AB)T=BTAT 顺序要反过来，这是最常见的错误。

对称与反对称：对称矩阵 aij​=aji​；反对称矩阵 aij​=−aji​，特别地主对角线元素必须全为 0（因为 aii​=−aii​）。例 2.4 的证明关键是 (AB)T=BTAT 加两个已知条件。

方阵的行列式三条性质：∣AT∣=∣A∣ 来自第 1 章性质 1.1；∣λA∣=λn∣A∣ 是因为 A 的每一行都乘了 λ（对比第 1 章：只有一行乘 k 时提出一个 k）；∣AB∣=∣A∣∣B∣ 说明"乘积的行列式等于行列式的乘积"。例 2.5 用了转置、提取 A、∣AB∣=∣A∣∣B∣ 三条，最后用 ∣X∣=∣XT∣ 与 ∣A+E∣ 自身列方程解出 0。

易错点：把 λA 的行列式写成 λ∣A∣（应为 λn∣A∣）；把 (AB)T 写成 ATBT；由 AB=O 推出 A=O 或 B=O。
