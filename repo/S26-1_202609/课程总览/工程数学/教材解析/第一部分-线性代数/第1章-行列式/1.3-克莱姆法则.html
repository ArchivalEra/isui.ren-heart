1.3-克莱姆法则

本文件同时保存原书抄录与解析，按小节组织。适用前提是方程个数 = 未知量个数 = n 且系数行列式 D=0。

克莱姆法则与证明（原书 p15–p18）

原书抄录

〔原书 p15〕

通过第一节的学习，我们已经知道用二阶、三阶行列式可以分别解含有两个未知量两个方程和含有三个未知量三个方程的线性方程组。下面我们将用 n 阶行列式解含有 n 个未知量 n 个方程的线性方程组。

设含 n 个未知量 n 个方程的线性方程组为

⎩⎨⎧​a11​x1​+a12​x2​+⋯+a1n​xn​=b1​,a21​x1​+a22​x2​+⋯+a2n​xn​=b2​,⋯an1​x1​+an2​x2​+⋯+ann​xn​=bn​.​(1.8)

它的系数组成的 n 阶行列式

〔原书 p16〕

D=​a11​a21​⋮an1​​a12​a22​⋮an2​​⋯⋯⋯​a1n​a2n​⋮ann​​​

称为方程组 (1.8) 的系数行列式。

用常数项 b1​,b2​,⋯,bn​ 代替系数行列式 D 中的第 j 列元素组成的 n 阶行列式记为 Dj​，即

Dj​=​a11​a21​⋮an1​​a12​a22​⋮an2​​⋯⋯⋯​a1,j−1​a2,j−1​⋮an,j−1​​b1​b2​⋮bn​​a1,j+1​a2,j+1​⋮an,j+1​​⋯⋯⋯​a1n​a2n​⋮ann​​​,j=1,2,⋯,n

定理 1.1（克莱姆法则） 若线性方程组 (1.8) 的系数行列式 D=0，则方程组 (1.8) 存在唯一解：

x1​=DD1​​,x2​=DD2​​,⋯,xn​=DDn​​

证 首先证明解的存在性，即 xj​=DDj​​ 是方程组 (1.8) 的解。行列式 Dj​ 按第 j 列展开，

Dj​=b1​A1j​+b2​A2j​+⋯+bn​Anj​,

其中，Aij​ 为系数行列式 D 中元素 aij​ 的代数余子式。将 xj​=DDj​​ 代入方程组 (1.8) 中的第 i 个方程，得

ai1​x1​+ai2​x2​+⋯+ain​xn​=ai1​DD1​​+ai2​DD2​​+⋯+ain​DDn​​
=D1​[ai1​(b1​A11​+b2​A21​+⋯+bn​An1​)+ai2​(b1​A12​+b2​A22​+⋯+bn​An2​)+⋯+ain​(b1​A1n​+b2​A2n​+⋯+bn​Ann​)]
=D1​[b1​(ai1​A11​+ai2​A12​+⋯+ain​A1n​)+b2​(ai1​A21​+ai2​A22​+⋯+ain​A2n​)+⋯+bn​(ai1​An1​+ai2​An2​+⋯+ain​Ann​)],

因为 ai1​Ak1​+ai2​Ak2​+⋯+ain​Akn​=0 (i=k)，ai1​Ai1​+ai2​Ai2​+⋯+ain​Ain​=D，

所以 ai1​x1​+ai2​x2​+⋯+ain​xn​=D1​(bi​D)=bi​, i=1,2,⋯,n。

〔原书 p17〕

因此，xj​=DDj​​ 是方程组 (1.8) 的解。

下面证明唯一性。

用行列式 D 中第 j 列各元素的代数余子式 A1j​,A2j​,⋯,Anj​ 依次乘方程组 (1.8) 的第 1 个、第 2 个、⋯、第 n 个方程，再将等式两端相加，整理得

(k=1∑n​ak1​Akj​)x1​+⋯+(k=1∑n​akj​Akj​)xj​+⋯+(k=1∑n​akn​Akj​)xn​=k=1∑n​bk​Akj​

由第 1.2 节的内容可知，上式中 xj​ 的系数等于 D，而其余 xi​ (i=j) 的系数均为 0；又等式右端即为 Dj​，0⋅x1​+⋯+D⋅xj​+⋯+0⋅xn​=Dj​，即

D⋅xj​=Dj​,j=1,2,⋯,n.(1.9)

由于方程组 (1.9) 是由方程组 (1.8) 经数乘与相加运算而得，故方程组 (1.8) 的解一定是方程组 (1.9) 的解，而方程组 (1.9) 当 D=0 时，仅有一个解

xj​=DDj​​,j=1,2,⋯,n

解析

适用条件：方程个数 = 未知量个数 = n，且 D=0。三者缺一不可；D=0 时法则失效，要继续解方程组需用消元法或秩（第 4 章）。

证明结构（整理者梳理）：

  1. 存在性：Dj​ 按第 j 列展开得 Dj​=∑k​bk​Akj​；把 xj​=Dj​/D 代入第 i 个方程，交换求和次序后，利用异列展开为零、同列展开为 D，得到 bi​。
  2. 唯一性：对任意解，用第 j 列各元素的代数余子式乘第 1,…,n 个方程再相加，异列项消去、同列项剩下 D，得到 Dxj​=Dj​；D=0 时 xj​ 被唯一确定。

整理者补充：Dj​ 换的是列；证明中反复用的是推论 1.4（异行/异列展开为零）和按行（列）展开公式，这两条是 1.2 的直接产物。

例 1.15（原书 p17–p18）

原书抄录

【例 1.15】 解下列线性方程组：

⎩⎨⎧​x1​−x2​+x3​−2x4​=2,2x1​−x3​+4x4​=4,3x1​+2x2​+x3​=−1,−x1​+2x2​−x3​+2x4​=−4.​

解 先计算行列式 D 及 Dj​, j=1,2,3,4，

D=​123−1​−1022​1−11−1​−2402​​−2r1​+r2​−3r1​+r3​r1​+r4​​​​1000​−1251​1−3−20​−2860​​=​251​−3−20​860​​=−2=0,

D1​=​24−1−4​−1022​1−11−1​−2402​​=−2,D2​=​123−1​24−1−4​1−11−1​−2402​​=4,
D3​=​123−1​−1022​24−1−4​−2402​​=0,D4​=​123−1​−1022​1−11−1​24−1−4​​=−1

由克莱姆法则，方程组有唯一解：

〔原书 p18〕

x1​=DD1​​=1,x2​=DD2​​=−2,
x3​=DD3​​=0,x4​=DD4​​=21​

解析

算得 D=−2，(D1​,D2​,D3​,D4​)=(−2,4,0,−1)，所以 (x1​,x2​,x3​,x4​)=(1,−2,0,21​)。

验算四个方程：

  1. 1−(−2)+0−2×21​=2；
  2. 2×1−0+4×21​=4；
  3. 3×1+2×(−2)+0=−1；
  4. −1+2×(−2)−0+2×21​=−4。

提示：D3​=0 不代表 x3​ 无解或可省略，x3​=D3​/D=0 是正常结果；要先把 D 算出来确认非零。

齐次线性方程组（原书 p18–p19）

原书抄录

克莱姆法则也可叙述如下：

定理 1.2 如果线性方程组 (1.8) 的系数行列式 D=0，则方程组 (1.8) 一定有解，且解是唯一的。

它的逆命题如下：

定理 1.3 如果线性方程组 (1.8) 无解或有两个不同的解，则它的系数行列式必为零 (D=0)。

如果方程组 (1.8) 的常数项全部为零，即

⎩⎨⎧​a11​x1​+a12​x2​+⋯+a1n​xn​=0,a21​x1​+a22​x2​+⋯+a2n​xn​=0,⋯an1​x1​+an2​x2​+⋯+ann​xn​=0,​(1.10)

则称为齐次线性方程组。而常数项不全为零的线性方程组 (1.8) 称为非齐次线性方程组。

显然，齐次线性方程组 (1.10) 一定有零解 x1​=x2​=⋯=xn​=0。对于齐次线性方程组除零解外是否还有非零解，可由如下定理判定。

定理 1.4 如果齐次线性方程组 (1.10) 的系数行列式 D=0，则它只有零解，即 x1​=x2​=⋯=xn​=0。

证 因为 D=0，由克莱姆法则，方程组 (1.10) 有唯一解 xj​=DDj​​, j=1,2,⋯,n。由于 Dj​ 中有一列元素全为 0，则 Dj​=0, j=1,2,⋯,n，所以方程组 (1.10) 只有零解 x1​=x2​=⋯=xn​=0。

定理 1.5 齐次线性方程组 (1.10) 存在非零解的充分必要条件是 (1.10) 的系数行列式 D=0。

【例 1.16】 判定齐次线性方程组

⎩⎨⎧​x1​+x2​+2x3​+3x4​=0,x1​+2x2​+3x3​−x4​=0,3x1​−x2​−x3​−2x4​=0,2x1​+3x2​−x3​−x4​=0,​

〔原书 p19〕

是否仅有零解？

解 因为系数行列式

D=​1132​12−13​23−1−1​3−1−2−1​​=−153=0,

所以方程组仅有零解。

【例 1.17】 问 λ 取何值时，齐次线性方程组

⎩⎨⎧​(1−λ)x1​−2x2​+4x3​=0,2x1​+(3−λ)x2​+x3​=0,x1​+x2​+(1−λ)x3​=0,​

有非零解？

解 由定理 1.5 可知，若所给齐次线性方程组有非零解，则它的系数行列式 D=0，而

D=​1−λ21​−23−λ1​411−λ​​
=(1−λ)2(3−λ)+8−2−4(3−λ)+4(1−λ)−(1−λ)
=(3−λ)(λ−2)λ,

由 D=0，解得 λ=0，λ=2 或 λ=3，不难验证，当 λ=0,2 或 3 时，所给齐次线性方程组有非零解。

解析

齐次方程组要点：

  • 常数项全为零，一定有零解。
  • 定理 1.4：D=0 时只有零解。
  • 定理 1.5：有非零解的充要条件是 D=0。
  • 整理者补充：定理 1.5 的充分性（D=0⇒ 有非零解）不能只由定理 1.4 取逆否得到；严格的充分性要在第 4 章用秩说明：D=0 时系数矩阵秩小于 n，齐次方程组存在自由变量。本章只把它作为结论使用。
  • 非齐次方程组 D=0 时不能判定无解还是无穷多解，也不能算 Dj​/D。

例 1.16 解析：只需算 D=−153=0，即可断定只有零解，不必求 Dj​。这是“先看 D”的典型用法。

例 1.17 解析：系数行列式

D=​1−λ21​−23−λ1​411−λ​​=(3−λ)(λ−2)λ

由 D=0 得 λ=0,2,3。补充代入验证：λ=0 时有非零解 (−2,1,1)，λ=2 时有 (2,−1,1)，λ=3 时有 (0,2,1)。

习题 1.3（原书 p19–p20）

原书抄录

  1. 用克莱姆法则求下列线性方程组的解：

(1) ⎩⎨⎧​2x1​−x2​−x3​=4,3x1​+4x2​−2x3​=11,3x1​−2x2​+4x3​=11;​(2) ⎩⎨⎧​2x1​−3x2​+x3​=−1,x1​+x2​+x3​=6,3x1​+x2​−2x3​=−1.​

  1. 问 λ 取何值时，齐次线性方程组

⎩⎨⎧​(5−λ)x1​+2x2​+2x3​=0,2x1​+(6−λ)x2​=0,2x1​+(4−λ)x3​=0,​

有非零解？

〔原书 p20〕

  1. k 取何值时，下列齐次线性方程组有非零解：

(1) ⎩⎨⎧​x1​+x2​+kx3​=0,−x1​+kx2​+x3​=0,x1​−x2​+2x3​=0;​(2) ⎩⎨⎧​kx1​+x2​+x3​=0,x1​+kx2​+x3​=0,3x1​−x2​+x3​=0.​

解析

书末参考答案页给出：第 1 题 (1) x1​=3,x2​=1,x3​=1，(2) x1​=1,x2​=2,x3​=3；第 2 题 λ=2 或 5 或 8；第 3 题 (1) k=4 或 −1，(2) k=1。

  1. (1) D=60，(D1​,D2​,D3​)=(180,60,60)，解 (3,1,1)；(2) D=−23，(D1​,D2​,D3​)=(−23,−46,−69)，解 (1,2,3)。
  2. 系数行列式为 −(λ−2)(λ−5)(λ−8)，故 λ=2,5,8。
  3. (1) D=−(k−4)(k+1)，故 k=4 或 −1；(2) D=(k−1)2，故 k=1。重根只对应一个参数值。

易错点：Dj​ 换的是列；D=0 时不要写 Dj​/D；齐次方程组不要漏掉“零解总是存在”这一半；参数行列式分解后要回代验证。
