1.0-通关攻略

这是什么：一条从零开始、走完就能掌握本章的学习路线。不要求你读过教材或本仓的任何解析文件——每个概念在需要时当场讲清楚。

怎么用：先看「前置检查」和「知识地图」→ 按顺序点开「逐节通关」的四节，每节先记「你要会的事」，再做「过关题」→ 最后用「通关自测」验收。全部独立完成 = 本章通关。

1.0 不是教材的小节：教材第 1 章只有 1.1–1.4 四节，这一页是给整章做的导航与验收页，放在 1.1 前面只是为了让它排在最前面。

开始之前：前置检查

本章是全书第一部分的第一章，不依赖本书任何其他章节。需要的基础只有初中代数：

  • 合并同类项、提公因式
  • 完全平方公式、平方差公式（例 1.5 要解 x2−5x+6=0，用到十字相乘）
  • 二元、三元一次方程组的加减消元法（1.1 节用它引入行列式，1.3 节克莱姆法则就是它的打包版）

不需要提前学：矩阵、向量、排列组合。1.2 节的 n 阶定义走的是「按行展开」的递归路线，不涉及排列与逆序数（这一点与多数教材不同，别被其他书吓到）。

但符号要专门认一遍：aij​、r2​−3r1​、detA 这些记号教材默认你已经认识、不作任何解释——教材不教，我们教。开动前先扫一遍符号入门，不必背；整份攻略里出现的记号本身都可点（气泡就地解释，「详细 ↗」直达符号入门对应位置），读到哪卡到哪就点到哪。

预计用时：初学 4–6 小时（含做题）。

本章知识地图：四节连成一条线

节你学到的是它为什么存在
1.1二阶、三阶行列式怎么算先有具体印象：行列式就是一个「按规则算出来的数」
1.2n 阶的定义 + 六条性质三阶的对角线法则到四阶就失效了，必须换正式定义；六条性质是让计算变简单的工具箱
1.3克莱姆法则行列式的第一个应用：解线性方程组，并回答「什么时候有非零解」
1.4MATLAB 的 det实际计算交给机器，但要懂它的浮点陷阱

一条主线记住它：定义（是什么）→ 性质（怎么变简单）→ 应用（能干什么）→ 机器（谁来做）。

逐节通关要点

1.1 二阶、三阶行列式（原书 p1–p5）

跟着算一遍：用对角线法则算三阶行列式（教材例 1.3）

题目：计算 D=​1−2−3​224​−41−2​​。

第一步：先写下主对角线方向的三项（都取正）。 主对角线方向指「左上到右下」平行的那三条斜线：

  • 主对角线：1×2×(−2)=−4；
  • 上移一条：2×1×(−3)=−6；
  • 下移一条：(−4)×(−2)×4=32。

第二步：再写副对角线方向的三项（都取负）。 「右上到左下」平行的那三条斜线：

  • 副对角线：(−4)×2×(−3)=−24；
  • 上移一条：2×(−2)×(−2)=8；
  • 下移一条：1×1×4=4。

第三步：正三项之和减负三项之和。

D=(−4)+(−6)+32−[(−24)+8+4]=22−(−12)=−14

答案：D=−14。

沙路法则（把前两列抄到右边、画六条斜线）得到的是完全相同的六项，只是把斜线画在纸上更省事—— 两种画法不必都记，记住「三条主斜线取正、三条副斜线取负」就行。

要点

  1. 二阶：主对角线之积减去副对角线之积。
    ​a11​a21​​a12​a22​​​=a11​a22​−a12​a21​
  2. 三阶：对角线法则，共六项——主对角线方向三项取正，副对角线方向三项取负。
    ​a11​a21​a31​​a12​a22​a32​​a13​a23​a33​​​=a11​a22​a33​+a12​a23​a31​+a13​a21​a32​−a11​a23​a32​−a12​a21​a33​−a13​a22​a31​
  3. 沙路法则：把前两列抄写到右侧，三条主斜线取正、三条副斜线取负——与对角线法则得到完全相同的六项，是同一件事的两种画法。

最容易错的点

  • 三阶是六项的代数和，不是三项；漏掉的三项往往恰好决定正负。
  • 副对角线方向的每一项都取负，不是只给最后一个负号。
  • 行列式是一个数，不是矩阵、也不是「可能等于什么」——算完要有确定的值。
  • 四阶拿沙路法则硬套——四阶没有沙路法则，要用定义（按行展开）或性质化简（1.2 节）。

过关题（答案与书末参考答案页一致：习题 1.1 六小题分别为 0, 1, −1, 28, 0, 2）

  • 习题 1.1(4)：​231​1−24​3−13​​=28——用对角线法则，六项一项不能少。
  • 习题 1.1(1)：​a2ab​abb2​​=0——先直算：a2b2−(ab)(ab)=0。 再做一步任何人都可复制的检查：两列一比，第二列恰好是第一列的 ab​ 倍（a=0）。 「成比例为什么必得 0」此刻还答不了——1.2 节性质 1.4 会揭晓，先把「两列一比」这个动作记住。
1.2 n 阶行列式（原书 p6–p15）

跟着算一遍（一）：代数余子式里的 (−1)i+j 到底是什么（教材例 1.6）

先解决最常卡人的一个符号：教材写 Aij​=(−1)i+jMij​ 时，i+j 是两个下标相加—— i 是元素所在的行号、j 是列号。别把它当成「i 加 j 这个变量」，它是查一个棋盘格。

第一步：先看 (−1)i+j 的正负长什么样——它就是一张棋盘。

行列式每个位置 (i,j) 都有一个固定符号。把 i+j 是偶数的位置记 +、奇数的记 −， 三阶、四阶排出来就是（从左上角开始是 +，然后上下左右交替）：

第 1 列第 2 列第 3 列第 4 列
第 1 行+−+−
第 2 行−+−+
第 3 行+−+−
第 4 行−+−+

查法：要算 A34​，就看第 3 行第 4 列那一格 → 表上是 −，所以 A34​ 前面带负号。 这不需要背：从 (1,1) 的 + 出发，向右或向下走一步就翻一次号。

第二步：认识「余子式 Mij​」——把该元素所在的行和列划掉，剩下的行列式。

题目（教材例 1.6）：D4​=​402−3​3−140​1561​2370​​，写出 a34​ 的余子式与代数余子式。

  • a34​ 是第 3 行第 4 列的元素，值是 7；
  • 划掉第 3 行、第 4 列，剩下三行三列原样照抄：

M34​=​40−3​3−10​151​​

第三步：代数余子式 = 余子式再乘棋盘符号。

A34​=(−1)3+4M34​=(−1)7M34​=−M34​=−​40−3​3−10​151​​

（3+4=7 是奇数 → (−1)7=−1 → 前面是负号。这就是「为什么有的带负号有的不带」的全部道理。）

跟着算一遍（二）：按一行展开算四阶（教材例 1.7）

题目：用定义计算 D4​=​3−41−3​0150​−2072​0204​​。

第一步：挑展开的行——挑「零最多」的那一行。 第 1 行是 (3, 0, −2, 0)，有两个 0；第 3 行也是两个 0。取第 1 行。

为什么挑零多的：按第 i 行展开是 D=ai1​Ai1​+ai2​Ai2​+ai3​Ai3​+ai4​Ai4​—— 四个三阶行列式相加。某个 aij​=0 时，那一项整个是 0，对应的三阶行列式根本不用算。 第 1 行有两个 0 → 四个三阶只需算两个。

第二步：把第 1 行四个位置逐个写出来（a1j​ 乘它的代数余子式，四个相加）：

D4​=a11​A11​+a12​A12​+a13​A13​+a14​A14​

逐项查棋盘格（第 1 行：+,−,+,−）并划行划列：

  • a11​=3，符号 (−1)1+1=+ → +3​150​072​204​​；
  • a12​=0 → 这一项是 0，不用管；
  • a13​=−2，符号 (−1)1+3=+ → +(−2)​−41−3​150​204​​；
  • a14​=0 → 这一项是 0，不用管。

第三步：算那两个三阶行列式（用 1.1 的对角线法则：三条主斜线取正、三条副斜线取负）。

第一个（主斜线三项 1⋅7⋅4=28、0⋅0⋅0=0、2⋅5⋅2=20；副斜线三项都含 0）：

​150​072​204​​=28+0+20−0−0−0=48

第二个（主斜线三项：(−4)⋅5⋅4=−80、1⋅0⋅(−3)=0、2⋅1⋅0=0； 副斜线三项：2⋅5⋅(−3)=−30、(−4)⋅0⋅0=0、1⋅1⋅4=4，取负后是 +30、0、−4）：

​−41−3​150​204​​=(−80)+0+0+30+0+(−4)=−54

第四步：合起来。

D4​=3×48+(−2)×(−54)=144+108=252

（与教材例 1.7 的答案 252 一致。）

要点

  1. n 阶的定义（定义 1.1）：n=1,2 直接给；n>2 时按任一行展开为低一阶的代数和 Dn​=∑k=1n​aik​Aik​，其中 Aik​ 是代数余子式（划去所在行列后乘 (−1)i+k）。 这个定义是递归的——四阶靠三个三阶算出来，三阶再靠二阶。
  2. 上三角行列式 = 主对角线之积（例 1.8）：反复按第一行展开即可证明，这条让后面很多题变轻松。
  3. 六条性质（1.2.2 的全部，速查如下）——它们不是用来背的，是用来把难算的变成好算的。
性质内容最常用的场合
1.1D=DT行的性质对列自动成立
1.2互换两行（列）变号调整行的位置；两行相同则为 0（推论 1.1）
1.3某行（列）乘 k，行列式乘 k公因子可提出（推论 1.2）；全零行则为 0（推论 1.3）
1.4两行（列）成比例则为 0看到 a2,ab,b2 这类结构先想它
1.5某行（列）是两组数之和可拆分只拆这一行（列）
1.6某行（列）的 k 倍加到另一行（列），值不变化简主力：造零全靠它

动手前的三秒侦察（按顺序问三句，问到了就用性质白拿结果）： ① 有相同或成比例的行（列）吗——性质 1.4 直接归零； ② 有全 1（全常数）的行（列）吗——拿它去消别的行（列），别的行（列）每个元素减/加同一个数； ③ 有首元相同的两行（列）吗——直接相减必出零行（列）。 都没有，才走化简的主力组合：用性质 1.6 造零，消到某行（列）只剩一个非零元就展开，或化成上三角直接取对角线之积。

最容易错的点

  • det(kA)=kndetA（n 阶时是 k 的 n 次方），不是 kdetA——性质 1.3 是对一行乘 k。
  • 互换两行要变号，倍加不变——这两个别记反。
  • 对角线法则 / 沙路法则只适用于二阶、三阶；四阶以上必须用定义或性质（这是本仓解析里反复强调的易错点）。
  • 异行展开为零（推论 1.4）：某行元素乘另一行的代数余子式之和恒为零——它是克莱姆法则唯一性证明的关键，别与按行展开混为一谈。

例 1.9：化三角形法——把「算行列式」变成「消元」

题面：

D=​3−521​110−5​−1313​2−4−1−3​​

思路是怎么来的：三句话，每一步都是判据不是眼力

  1. 先问「什么形状的值是白拿的」：上三角 = 对角线之积（例 1.8），某行（列）只剩一个非零元 = 按它展开降一阶。四阶没有别的捷径（沙路法则四阶失效），所以把目标定成上三角。
  2. 再问「哪两个动作不破坏已知信息」：倍加（性质 1.6）值不变，交换（性质 1.2）值变号。于是路线只有一条——用倍加把对角线以下全清成 0，一路上每交换一次记一个负号。
  3. 最后问「谁当主元」：主元取 ±1 时所有乘数都是整数，分数一步都不出现。所以先看第 1 行有没有 ±1——本题第 1 行第 2 列就是 1，一次列交换 c1​↔c2​ 就把它挪到 (1,1)（性质 1.1：行能做的列也能做；1 若在别的行，改用行交换，代价同样是一个负号）。

照着走的六步（中间矩阵的抄录见 1.2 解析 的例 1.9）：

步动作依据 / 为什么这么走符号账
①c1​↔c2​，把第 1 行的 1 挪到 (1,1)主元取 1，后面乘数全是整数负号 ×1
②−r1​+r2​、5r1​+r4​倍加：第 1 列 (1,1,0,−5) 中主元以下的元清成 0不变
③r2​↔r3​子矩阵首列是 −8,2,16：取绝对值最小的 2，它整除 8 与 16，仍不出分数负号 ×1（与①抵消）
④4r2​+r3​、−8r2​+r4​倍加清第 2 列不变
⑤45​r3​+r4​收到 2×2 子矩阵已无处可躲，全程只此一处分数不变
⑥D=(−1)2×1×2×8×25​=40上三角取对角之积；两次交换 → 系数 +1—

三条可复用的判断

  • 符号记账的写法：交换次数整理成因子 (−1)交换次数 乘在最后，倍加永不改号。本题交换两次 → 系数 +1；只交换一次就是 −1。怕记错就把次数标在式子边上，最后统一乘。
  • 主元的机械判据：当前子矩阵里取绝对值最小的非零元，首选 ±1（乘数全整数），次选能整除同行同列系数的（本题的 2）。这不是手感：本题若硬拿 (1,1) 上的 3 起手，乘数立刻变成 35​、32​，全程分数。
  • 与降阶法的分工：有 ±1、或某行（列）零很多 → 化三角形一路做到上三角（本题）；某行（列）只剩一个非零元 → 就地展开降一阶（例 1.10）。两者都是「倍加造零」，只有收尾方式不同。

过关题（习题 1.2 第 1 题四小题答案：−3, 0, −102, 0；第 2 题(3)：x2y2）

  • 习题 1.2 第 1 题(2)：D=0——存在列关系 c4​+2c1​−2c2​−5c3​=0，倍加造出零列。这个组合不是瞪眼凑出来的：机械找法（0 最多的行先列方程）见作业1 第三题。
  • 习题 1.2 第 1 题(3)：D=−102——造零降阶进行到三阶时，基准行不必是第一行： 第一列变成 −4,1,1，第 1 行当基准会逼出分数（r2​+41​r1​）， 换首元为 1 的第 2 行当基准——r1​+4r2​、r3​−r2​ 消净第一列，分数从头到尾没出现。
  • 习题 1.2 第 2 题(3)：证明四阶行列式 =x2y2——按列拆分（性质 1.5）后逐项归零，注意这个证明不需要除以 x 或 y，所以也覆盖它们为零的情况。
1.3 克莱姆法则（原书 p15–p20）

跟着算一遍：D_j 到底换哪一列（教材例 1.15 的构造）

题目（教材例 1.15，四元方程组）：

⎩⎨⎧​x1​−x2​+x3​−2x4​=2,2x1​−x3​+4x4​=4,3x1​+2x2​+x3​=−1,−x1​+2x2​−x3​+2x4​=−4.​

第一步：写出系数行列式 D（把每个方程的系数按列排，右端常数项不进 D）：

D=​123−1​−1022​1−11−1​−2402​​=−2=0

第二步：构造 Dj​——把 D 的第 j 列换成常数项 (2,4,−1,−4)T，其余列原样。 这一步是克莱姆法则唯一容易错的地方，换的是列、不是行：

  • D1​：第 1 列换成常数项 → ​24−1−4​−1022​1−11−1​−2402​​=−2；
  • D2​：第 2 列换成常数项 → 4；D3​：第 3 列换成常数项 → 0；D4​：第 4 列换成常数项 → −1。

第三步：每个解 = 对应的 Dj​÷D：

x1​=DD1​​=1,x2​=DD2​​=−2,x3​=DD3​​=0,x4​=DD4​​=21​

验算（代回第 1 个方程）：1−(−2)+0−2×21​=2 ✓。

D3​=0 不代表 x3​ 无解——x3​=D3​/D=0 是正常结果（只是这一元恰好等于 0）， 前提是 D=0。别看到某个 Dj​=0 就慌。

要点

  1. 定理 1.1（克莱姆法则）：系数行列式 D=0 时，方程组有唯一解，且 xj​=DDj​​。
  2. Dj​ 怎么构造：换的是「列」，不是「行」——把 D 的第 j 列换成方程组右端的常数项，其余列不动。 （作业里做了一张 D,D1​,D2​,D3​ 的列替换对照表，就在作业1的第六题。）
  3. 齐次方程组的判定（定理 1.4、1.5）：D=0 时只有零解；存在非零解 ⟺ D=0。

最容易错的点

  • Dj​ 换成行——错。换的是第 j 列。
  • D=0 时说「方程组无解」——错。D=0 只能说克莱姆法则不适用；齐次方程组此时恰有非零解（定理 1.5）， 而非齐次方程组可能无解也可能有无穷多解，要到第 4 章才能完整回答。
  • 算出解不验算——代回原方程组 30 秒就能发现符号错误。

过关题（书末答案：习题 1.3 第 1 题(1) x1​=3,x2​=1,x3​=1；第 3 题(2) k=1）

  • 习题 1.3 第 1 题(1)：用克莱姆法则解三元方程组，解为 (3,1,1)，其中 D=60、D1​=180、D2​=D3​=60。
  • 习题 1.3 第 3 题(2)：齐次方程组有非零解的条件，答案是 k=1——依据是定理 1.5（D=0）。 注意 k=1 是二重根，但重根也只对应这一个 k 的取值。
1.4 用 MATLAB 计算行列式（原书 p20–p21）

跟着算一遍：浮点残差不是零（教材例 1.20 的教训）

题目：教材例 1.20 给一个三行线性相关的行列式（精确值为 0），在 MATLAB 里跑 det(A)。

你会看到：输出不是 0，而是 −9.5162×10−16 这样的小数； 本机 Octave 实测甚至得到 +6.6613×10−16——连符号都相反。

读法：这个数毫无意义。它的来源是「精确奇异（真值 0）+ 浮点运算」—— 计算机用二进制近似小数，加减乘除各带一点舍入误差，累加起来就是这团 10−16 的噪声。

所以：

  • 不要用 det(A)==0 判断奇异（浮点几乎不会正好等于 0）；
  • 不要相信残差本身的正负与大小（连符号都可能反过来）；
  • 判奇异要用秩（rank）或条件数（cond）。

要点

  1. D = det(A)——A 必须是方阵。
  2. 浮点陷阱（例 1.20 的教训）：教材的例 1.20 是三行线性相关的行列式（精确值为 0）， MATLAB 输出 −9.5162×10−16 这样的浮点残差；本机 Octave 实测甚至得到 +6.6613×10−16——连符号都相反。 所以：不要用 det(A)==0 判断奇异，也不要相信残差本身的正负与大小。

本节不设硬性通关题，但例 1.20 的结论要记住：确定的算确定的，随机的标随机—— 本仓对教材 1.4、2.5 两节 MATLAB 输出的复现记录见分部索引的复现状态表。
