1.4-MATLAB-行列式

本文件同时保存原书抄录与解析。教材输出按书页登记；书页数值已在本机用 GNU Octave 11.3.0 复跑对照（见文末「本机复现」），但 Octave 不等于 MATLAB 原程序，差异逐条列明。

原书抄录

〔原书 p20〕

采用 det 函数来求行列式的值，一般格式为：D=det(A)，其中 A 为 n×n 个数按一定顺序排成的一个 n 行 n 列的数表。

【例 1.18】 求行列式

​1−51​−220​403​​

的值。

解

matlab 
>> A=[1 -2 4;-5 2 0;1 0 3]
A=
     1    -2     4
    -5     2     0
     1     0     3
>> D=det(A)
D=
   -32

【例 1.19】 求行列式

​1114​2203​3011​2−522​​

解

>> A=[1 2 3 2;1 2 0 -5;1 0 1 2;4 3 1 2]
A=
     1     2     3     2
     1     2     0    -5
     1     0     1     2
     4     3     1     2
>> D=det(A)
D=
   -48

〔原书 p21〕

【例 1.20】 求行列式

​147​258​369​​

解

matlab 
>> A=[1 2 3;4 5 6;7 8 9]
A=
     1     2     3

D=
   -9.5162e-16

解析

教材用法：D=det(A)，A 为方阵；同一行元素用空格或逗号分隔，分号分隔行。

例 1.18–1.19：教材输出分别与整数精确值 −32、−48 一致。例 1.19 就是 1.2 节例 1.10 的同一行列式，手工降阶法与 det 互相印证。

例 1.20（浮点残差）：

matlab 
A=[1 2 3;4 5 6;7 8 9];
D=det(A)      % 教材输出 -9.5162e-16

精确值为 0，因为 r3​=2r2​−r1​，三行线性相关（第 3 行 = 第 2 行的 2 倍减第 1 行）。教材输出的是一个极小的浮点残差，不是数学上的非零值；不同 MATLAB 版本或计算环境可能给出不同的微小残差或零。

整理者补充的数值实践：

  • 不要用 det(A)==0 判断奇异；浮点下几乎永远不恰好为零。
  • 也不要用不考虑矩阵尺度的固定阈值；一般需结合奇异值、条件数或带容差的判据。
  • 数值求解线性方程组一般用 A\b，而不是重复算行列式再做除法；克莱姆法则主要用于理论推导和小规模精确计算。
  • 若要判断例 1.20 这类行列式，直接看行（列）之间的线性关系比看浮点输出更可靠。

本机复现（GNU Octave 11.3.0）

复现脚本：工具/教材复现/工程数学MATLAB复现.m（一条命令跑完全部三例并与书页对照）。 环境：Debian sid，GNU Octave 11.3.0（MATLAB 语法兼容的开源实现，非 MATLAB 本身）。

例书页输出本机实得结论
1.18D = -32-32一致
1.19D = -48-48.000000000000007显示值一致；浮点差 7.1×10−15
1.20D = -9.5162e-166.6613e-16不一致：残差实现相关，连符号都相反

例 1.19 的浮点细节：−48.000000000000007 就是精确值 −48 偏移 1 个 ULP（间隔 7.105×10−15）。书页上的 -48 是显示层四舍五入的结果，不是精确整数取值。这说明 det 是浮点计算，"看起来是整数"的输出也可能带 1 ULP 误差。

例 1.20 的残差为什么不一样：det 走 LU 分解，残差的正负与量级取决于主元选取顺序、BLAS 实现与 MATLAB 版本。本机得到 +6.6613×10−16（十六进制 3cc8000000000000），书页是 −9.5162×10−16。两者都不是数学值；本机同时验证了精确值为 0（r3​−(2r2​−r1​)=[0 0 0]）与 rankA=2。

由此加固的结论：书页那一行 -9.5162e-16 属于「不可跨环境复现」的输出，登记时应标注，不能当作该行列式的值。
