1.1.1 二阶行列式（原书 p1–p2）

原书抄录

〔原书 p1〕

本章在二阶、三阶行列式的基础上，引出 n 阶行列式的概念，讨论 n 阶行列式的性质，以及行列式的计算方法，最后应用 n 阶行列式解 n 个方程 n 个未知数的线性方程组。

设二元一次线性方程组为

{a11​x1​+a12​x2​=b1​,a21​x1​+a22​x2​=b2​.​(1.1)(1.2)​

式 (1.1)×a22​ + 式 (1.2)×(−a12​)，得

(a11​a22​−a12​a21​)x1​=a22​b1​−a12​b2​.(1.3)

式 (1.2)×a11​ + 式 (1.1)×(−a21​)，得

(a11​a22​−a12​a21​)x2​=a11​b2​−a21​b1​.(1.4)

当 a11​a22​−a12​a21​=0 时，可用消元法求得解为

⎩⎨⎧​x1​=a11​a22​−a12​a21​b1​a22​−a12​b2​​,[2mm]x2​=a11​a22​−a12​a21​a11​b2​−a21​b1​​.​(1.5)

由上可见，方程组的解完全可由方程组中的未知数系数 a11​,a12​,a21​,a22​ 以及常数项 b1​,b2​ 表示出来。为了方便记忆，引入记号

〔原书 p2〕

D=​a11​a21​​a12​a22​​​=a11​a22​−a12​a21​,(1.6)

把式 (1.6) 称为二阶行列式。D 中横写的称为行，竖写的称为列；数 aij​ (i,j=1,2) 称为行列式的元素，它的第一个下标 i 称为行标，第二个下标 j 称为列标，表明该元素位于第 i 行第 j 列。 把行列式从左上角到右下角的连线称为主对角线，从右上角到左下角的连线称为副对角线。二阶行列式的值就是主对角线上的两元素之积减去副对角线上的两元素之积。

记

D1​=​b1​b2​​a12​a22​​​=b1​a22​−a12​b2​,D2​=​a11​a21​​b1​b2​​​=a11​b2​−a21​b1​,

则有 x1​=DD1​​, x2​=DD2​​。即当 D=0 时，二元一次线性方程组的解可表示为

x1​=DD1​​,x2​=DD2​​

【例 1.1】 解二元一次线性方程组

{3x1​−2x2​=12,2x1​+x2​=1.​

解 由于

D=​32​−21​​=3−(−4)=7=0,
D1​=​121​−21​​=12−(−2)=14,D2​=​32​121​​=3−24=−21,

因此

x1​=DD1​​=714​=2,x2​=DD2​​=7−21​=−3

【例 1.2】 计算下列行列式的值：

(1) ​25​−86​​;(2) ​sinα−cosα​cosαsinα​​;(3) ​−10​02​​;(4) ​20​−13​​

解

(1) ​25​−86​​=2×6−5×(−8)=52
(2) ​sinα−cosα​cosαsinα​​=sin2α+cos2α=1
(3) ​−10​02​​=−1×2−0×0=−2
(4) ​20​−13​​=2×3−(−1)×0=6

解析

消元法的实质（整理者补充）：式 (1.1)×a22​ + 式 (1.2)×(−a12​) 消去 x2​，式 (1.2)×a11​ + 式 (1.1)×(−a21​) 消去 x1​。 两式左边出现同一个结构 a11​a22​−a12​a21​，这就是二阶行列式 D；把 x1​,x2​ 的分子也写成同样的结构，就得到“解=DDj​​”的记法。行列式不是新发明的运算，而是消元结果的记忆工具。

成立条件：D=0。这是除以 D 的前提，不是移项条件；D=0 时两个消元式都退化成 0= 某个常数，必须另行讨论，不能继续用 Dj​/D。

Dj​ 的记忆法：Dj​ 是把 D 的第 j 列换成常数列 (b1​,b2​)T，其余列不动；换的是列不是行。x1​ 对应第 1 列，x2​ 对应第 2 列。

例 1.1 解析：D=7=0，D1​=14，D2​=−21，所以 (x1​,x2​)=(2,−3)。验算：3×2−2×(−3)=12，2×2+(−3)=1，两个方程都成立。

例 1.2 解析：

  • (1) 2×6−5×(−8)=12+40=52，副对角线是“减去 5×(−8)”，负负得正。
  • (2) sinα⋅sinα−cosα⋅(−cosα)=sin2α+cos2α=1，中间步 −(−cos2α) 不要跳。
  • (3) (−1)×2−0×0=−2。
  • (4) 2×3−(−1)×0=6，含 0 的项也要写清符号。

易错点：D1​,D2​ 的位置写反；把“减副对角线乘积”写成“加”；D=0 时继续套公式。

1.1.2 三阶行列式（原书 p3–p5）

原书抄录

〔原书 p3〕

类似地，对三元一次线性方程组

⎩⎨⎧​a11​x1​+a12​x2​+a13​x3​=b1​,a21​x1​+a22​x2​+a23​x3​=b2​,a31​x1​+a32​x2​+a33​x3​=b3​.​(1.7)​

用消元法，可以解出 x1​,x2​,x3​。记

D=​a11​a21​a31​​a12​a22​a32​​a13​a23​a33​​​=a11​a22​a33​+a12​a23​a31​+a13​a21​a32​−a11​a23​a32​−a12​a21​a33​−a13​a22​a31​

由于 D 共有三行三列，故把它称为三阶行列式。当 D=0 时，用消元法容易算出方程组 (1.7) 的唯一解

x1​=DD1​​,x2​=DD2​​,x3​=DD3​​,

其中 Dj​ (j=1,2,3) 分别是将 D 中第 j 列的元素换成方程组 (1.7) 右端的常数项 b1​,b2​,b3​ 得到的。

三阶行列式是六项的代数和，其中每一项都是 D 中不同行、不同列的三个元素的乘积，并冠以正负号，为了便于记忆，可写成图 1.1 的形式。

（1）对角线法则：实线上三个元素的乘积项带正号，虚线上三个元素的乘积项带负号，这种方式称为三阶行列式的对角线法则。

（2）沙路法则：具体见图 1.2（沙路法则）。

〔原书 p4〕

【例 1.3】 计算下列三阶行列式的值：

D=​1−2−3​224​−41−2​​

解 由三阶行列式的对角线法则，得

D=1×2×(−2)+2×1×(−3)+(−4)×(−2)×4−(−4)×2×(−3)−2×(−2)×(−2)−1×1×4
=−4−6+32−24−8−4=−14

【例 1.4】 解方程组

⎩⎨⎧​x1​−x2​+2x3​=13,x1​+x2​+x3​=10,2x1​+3x2​−x3​=1.​

解 D=​112​−113​21−1​​=−1−2+6−4−3−1=−5=0,

〔原书 p5〕

D1​=​13101​−113​21−1​​=−13−1+60−39−10−2=−5,
D2​=​112​13101​21−1​​=−10+26+2−1+13−40=−10,
D3​=​112​−113​13101​​=1−20+39−30+1−26=−35

因此

x1​=DD1​​=1,x2​=DD2​​=2,x3​=DD3​​=7

【例 1.5】 求方程

​124​139​1xx2​​=0

的解。

解 方程左端的三阶行列式

D=3x2+4x+18−9x−2x2−12=x2−5x+6

令 x2−5x+6=0，解得：x=2 或 x=3。

解析

六项结构（整理者补充）：三阶行列式的六项 = 从每行每列各取一个元素的全部 3!=6 种取法，正负号由排列的逆序数决定。对角线法则和沙路法则是同一组六项的两种画法。

关键限制：对角线法则/沙路法则只适用于二阶、三阶；四阶及以上没有这种画法，n≥4 必须用定义展开或行列式性质。把沙路法则套到四阶是常见错误。

Dj​ 的含义：把 D 的第 j 列换成常数项 (b1​,b2​,b3​)T；当 D=0 时 xj​=Dj​/D。

例 1.3 解析：先写出六个连乘式再算数，不要边心算边加减：

D=1⋅2⋅(−2)+2⋅1⋅(−3)+(−4)⋅(−2)⋅4−(−4)⋅2⋅(−3)−2⋅(−2)⋅(−2)−1⋅1⋅4

前三项 −4−6+32=22，后三项 −24−8−4=−36，合计 −14。最后三个负项容易漏负号。

例 1.4 解析：D=−5=0，D1​=−5，D2​=−10，D3​=−35，所以 (x1​,x2​,x3​)=(1,2,7)。验算第 3 个方程：2×1+3×2−7=1。

例 1.5 解析：左端按对角线法则展开：

D=3x2+4x+18−9x−2x2−12=x2−5x+6

这是含 x 的方程，不是数值行列式；令 x2−5x+6=0 得 x=2 或 x=3。

易错点：把三阶的六项写成四项；漏掉负项；解含参方程时把 x 当作行列式元素之外的常数。

习题 1.1（原书 p5）

原书抄录

  1. 计算下列二、三阶行列式：

(1) ​a2ab​abb2​​;(2) ​cosαsinα​−sinαcosα​​;(3) ​x−11​x3x2+x+1​​
(4) ​231​1−24​3−13​​;(5) ​0b0​a0d​0c0​​;(6) ​231​−12−2​111​​

解析

书末参考答案页（IMG20260917200901.jpg）给出六个小题的答案：0,1,−1,28,0,2。逐题说明：

  1. ​a2ab​abb2​​=a2b2−(ab)(ab)=0。
  2. ​cosαsinα​−sinαcosα​​=cos2α+sin2α=1。
  3. ​x−11​x3x2+x+1​​=(x−1)(x2+x+1)−x3=(x3−1)−x3=−1。用立方差恒等式化简，不要展开多项式。
  4. ​231​1−24​3−13​​=28。题面已从局部照片逐项核对；旧稿抄成两行相同的行列式，不能用于验算。照片上的手写末尾为 26，与学生草稿涂改一起出现，不是正确答案。
  5. ​0b0​a0d​0c0​​=0，也可由第 1 行展开立即看出。
  6. ​231​−12−2​111​​=2。

六个标准结果均与书末答案一致。本题单不代表教师正式布置的作业。
