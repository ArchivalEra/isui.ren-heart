3.0-通关攻略

这是什么：一条从零开始、走完就能掌握本章的学习路线。不要求你读过教材或本仓的任何解析文件——每个概念在需要时当场讲清楚。

怎么用：每个面板的写法是 「跟着算一遍」→「要点」→「最容易错的点」→「过关题」。 先把「跟着算一遍」那道例题从题面到答案走一遍（每步都写了依据），再回头看要点，最后自己做过关题。 全部独立完成 = 本章通关。

3.0 不是教材的小节：教材第 3 章只有 3.1–3.5 五节，这一页是给整章做的导航与验收页。

开始之前：前置检查

本章依赖第 1、2 章——不是泛泛的「先学完」，而是具体三条：

  • 会算行列式（第 1 章）：定理 3.2 判线性相关，判据就是「n 阶行列式是否为 0」。 不会算行列式，这个判据用不了。先过掉第 1 章通关攻略。
  • 会用初等行变换（2.3 节）：本章求秩、求极大无关组、求坐标，全部靠行变换。 这是本章唯一的重型工具。不熟就先过掉2.3 节攻略。
  • 会求矩阵的秩（2.4 节）：3.3 节的秩是「向量组的秩」，与矩阵的秩是同一个数（定理 3.3）。

本章相对独立的一点：3.1、3.2 两节的运算都很轻（只有加法、数乘）， 即使第 2 章学得不好也能跟上；难点集中在 3.3 节——秩的算法。

预计用时：初学 4–6 小时（含做题）。

本章知识地图：五节连成一条线

节你学到的是它为什么存在
3.1n 维向量与线性运算（原书 p52–p53）把「向量」从箭头换成「一串有序的数」；加法和数乘都是逐分量做
3.2向量组的线性相关性（原书 p54–p57）判「一组向量里有没有多余的」；判据是「齐次方程组有没有非零解」
3.3向量组的秩（原书 p58–p60）量出「有几个真正独立的」；算法是拼矩阵数非零行
3.4向量空间 · 基 · 坐标（原书 p61–p62）把 3.3 的结论装进「空间」这个壳；坐标 = 在指定基下的表示系数
3.5MATLAB 向量运算（原书 p63–p64）rank / rref / A\B 全是前三节的机器版

一条主线记住它：对象（一串数）→ 关系（能不能互相表示）→ 度量（秩）→ 坐标系（基与坐标）→ 机器（MATLAB）。

逐节通关要点

3.1 n 维向量（原书 p52–p53）

跟着算一遍：解 α+3γ=β（教材例 3.1）

已知 α=(−3,3,6,0)，β=(9,6,−3,18)，求 γ。

第 1 步：把未知量孤立到一边。 由 α+3γ=β，两边同减 α：

3γ=β−α
这一步用的是「等式两边可以同加同一个向量」——来自 3.1 节性质 (3)(4)：α+(−α)=0。

第 2 步：右边做减法（逐分量）。

β−α=(9−(−3), 6−3, −3−6, 18−0)=(12,3,−9,18)

第 3 步：除以系数（数乘的逆运算，逐分量）。

γ=31​(12,3,−9,18)=(4,1,−3,6)

验算：代回原式 α+3γ=(−3,3,6,0)+(12,3,−9,18)=(9,6,−3,18)=β ✓

要点

  • 一切运算都是逐分量的：加法、数乘、相等判定，全部按位置一个一个做。
  • 行向量 ≠ 列向量：(1,2,3) 与 (1,2,3)T 在本课程里是两种不同对象，不能相加。做题先看题面写的是哪种。
  • 「向量 = 特殊矩阵」是工具不是修辞：后面求秩、求坐标，都是把向量当列拼成矩阵来算。

最容易错的点

  • 把未知量留在两边就代数字。像例 3.2 那样 β 在等式两边都出现时，必须先归并（按普通代数整理），再代数字。一上来就代数字会让中间步骤全乱。
  • 忽略系数：求出的 3γ 要再除以 3，别忘了。

过关题

教材习题 3.1 第 1 题：α1​=(1,2,−1)、α2​=(2,5,3)、α3​=(1,3,4)，求 (3α1​−2α2​)+4α3​。 （答案见3.1 节解析）

3.2 向量组的线性相关性（原书 p54–p57）

跟着算一遍：判三个向量是否线性相关（教材例 3.6）

已知 α1​=(1,1,0)T、α2​=(−1,1,2)T、α3​=(1,3,2)T，讨论其线性相关性。

第 1 步：按定义设出线性关系。 设 k1​α1​+k2​α2​+k3​α3​=0。 这一步不是形式主义——定义 3.6 说的就是这句话：能找出不全为零的 ki​ 就相关。

第 2 步：把三个向量当列拼成矩阵。

A=(α1​,α2​,α3​)=⎝⎛​110​−112​132​⎠⎞​
为什么能这么做：k1​α1​+k2​α2​+k3​α3​=A⎝⎛​k1​k2​k3​​⎠⎞​， 所以「组合等于零」等价于「齐次方程组 Ak=0 有非零解」。

第 3 步：算行列式（或化行阶梯形）。 化行阶梯形：

Ar2​−r1​​⎝⎛​100​−122​122​⎠⎞​r3​−r2​​⎝⎛​100​−120​120​⎠⎞​
出现全零行 ⇒ detA=0。

第 4 步：按定理 3.2 下结论。 detA=0 ⟺ 线性相关。故 α1​,α2​,α3​ 线性相关。

验算：detA=0 ✓、rank(A)=2<3 ✓（Octave 复核）。

要点

  • 判据只有一条：设 k1​α1​+⋯=0，看齐次方程组有没有非零解。
  • 两条捷径（背下来能省很多时间）：
    • n 个 n 维向量 → 算行列式（定理 3.2）：det=0 相关、det=0 无关。
    • 向量个数 > 维数 → 直接判相关（定理 3.1），不用算。
  • 相关 = 有冗余 = 有的向量能被其余的表示；无关 = 谁都不能被表示。

最容易错的点

  • 把「个数 ≠ 维数」的情形套定理 3.2。3 个 4 维向量没有 3×3 行列式可算，只能解方程组或用秩。
  • 把 D=0 直接说成「不能表示」（这条在 3.2 节的例 3.3 那一类题里最容易犯）。D=0 只说明「不唯一或无解」，要判到底哪种，得比较系数矩阵与增广矩阵的秩。
  • 证明题不换成已知无关的那组。像例 3.5 那种「已知 α 组无关，证 β 组无关」，必须把 β 的关系式翻译成 α 的关系式才能用上已知条件。

过关题

教材习题 3.2 第 2 题：判断 α1​=(1,1,1)、α2​=(1,0,2)、α3​=(1,−1,1)、α4​=(1,3,6) 的线性相关性。 （4 个 3 维向量 → 个数 > 维数 → 由定理 3.1 直接判相关；也可化行阶梯形确认 rank≤3）

3.3 向量组的秩（原书 p58–p60）

跟着算一遍：求秩与极大无关组（教材例 3.7 第 (1) 小题）

已知 α1​=(1,1,0,0)、α2​=(1,0,1,1)、α3​=(2,−1,3,3)，求秩与一个极大无关组。

第 1 步：竖着当列拼矩阵。（不是横着当行！）

A=⎝⎜⎜⎛​1100​1011​2−133​⎠⎟⎟⎞​
每个向量 4 维 → 4 行；3 个向量 → 3 列。

第 2 步：化行最简形（不是行阶梯形——要读表示系数必须最简形）。 书上用四步行变换，最终得到

⎝⎜⎜⎛​1000​0100​−1300​⎠⎟⎟⎞​

第 3 步：数非零行 = 秩。 2 个非零行 ⇒ R=2。

第 4 步：主元列 → 极大无关组。 主元在第 1、2 列 ⇒ α1​,α2​ 是一组极大无关组。

第 5 步：读非主元列得表示系数。 第 3 列是 (−13​) ⇒ α3​=−α1​+3α2​。

验算：−α1​+3α2​=−(1,1,0,0)+3(1,0,1,1)=(2,−1,3,3)=α3​ ✓

要点

  • 一个动作管三种问法：求秩、求极大无关组、其余向量用其表示——全在行最简形里。
  • 秩 = 非零行数 = 极大无关组的向量个数。
  • 主元列（行最简形里每行首个非零元所在的列）对应原矩阵的同号列，那几个原向量构成一组极大无关组。
  • 非主元列的数 = 表示系数，这是行最简形独有的信息，行阶梯形读不出来。

最容易错的点

  • 横着拼。横着拼也能算出秩（行秩=列秩），但读不出哪几个原向量构成极大无关组，也读不出表示系数。
  • 只化到行阶梯形就停。行阶梯形能数秩，但不能读系数。
  • 读系数时读错列。非主元列的数是「作为主元列的那些向量的组合系数」，顺序按主元列从左到右排。
  • 应用题忘了检查「系数不能为负」（例 3.9 调味品配制就是这个坑）：行最简形给出的表示可能有负系数，实际题里要换成等价的非负表示。

过关题

教材习题 3.3 第 1 题 (1)：求 α1​=(2,1,1)、α2​=(1,2,−1)、α3​=(−2,3,0) 的秩与一个极大无关组。

3.4 向量空间（原书 p61–p62）

跟着算一遍：验证是基并求坐标（教材例 3.14）

验证 α1​=(1,−1,0)、α2​=(2,1,3)、α3​=(3,1,2) 为 R3 的基，并把 β1​=(5,0,7)、β2​=(−9,−8,−13) 用这个基表示。

第 1 步：验证是基。 三个 3 维向量 → 拼成 3×3 矩阵算行列式：

det⎝⎛​1−10​213​312​⎠⎞​=−6=0
非零 ⇒ 线性无关 ⇒ 是基（3 个无关向量在 3 维空间里必是基）。

第 2 步：设出表示式。 B=AX，其中 B=(β1​,β2​)、A=(α1​,α2​,α3​)、X 是待求坐标矩阵（3×2）。

第 3 步：拼增广矩阵 (A∣B) 做行变换，把左边化成单位阵：

(A∣B)→⋯→⎝⎜⎜⎜⎜⎛​100​010​001​23−1​3−3−2​⎠⎟⎟⎟⎟⎞​
右边剩下的就是 X。

第 4 步：读答案。

X=⎝⎛​23−1​3−3−2​⎠⎞​
即 β1​=2α1​+3α2​−α3​、β2​=3α1​−3α2​−2α3​。

验算：2(1,−1,0)+3(2,1,3)−(3,1,2)=(2+6−3, −2+3−1, 0+9−2)=(5,0,7) ✓

要点

  • 查「是不是向量空间」只查两条：非空 + 对加法封闭 + 对数乘封闭。不用验 10 条性质（自动继承）。 最快的否证：集合里没有零向量 ⇒ 一定不是（因为取 k=0 必有零向量）。
  • 基 = 极大无关组，维数 = 秩。3.3 的算法原样搬过来。
  • 验证「是基」只需证无关（维数已知时）：r 个无关向量在 r 维空间里自动构成基。
  • 坐标依赖基：同一个向量换一组基，坐标就变。答题必须写「在哪个基下的坐标」。

最容易错的点

  • 把「坐标」当成「分量」。只有标准基下坐标才等于分量。
  • 行变换时右边忘了同步做。(A∣B) 是一个整体，左边怎么变右边也要怎么变。
  • 验证封闭性时只举一个例子。要任取一般元素（带约束条件写出来）来验证，或举出一个明确的反例来否证。

过关题

教材习题 3.4 第 1 题：集合 V1​={(x1​,…,xn​)∣x1​+⋯+xn​=0} 是否构成向量空间？为什么？ （提示：任取两个元素带约束相加，看和的分量总和是否为 0；再取 k 倍看是否仍为 0）

3.5 用 MATLAB 进行向量运算（原书 p63–p64）

跟着算一遍：用三条命令完成本章全部核心动作

>> A = [1 1 2; 1 0 -1; 0 1 3; 0 1 3]    % 三个向量竖着当列
>> rank(A)                                % 秩 = 2
>> [R, jb] = rref(A)                      % R 是行最简形，jb 是主元列号 [1 2]

jb 给出主元列号 ⇒ 对应原矩阵第 1、2 列 ⇒ α1​,α2​ 构成极大无关组。

求坐标：

>> A = [1 2 3; -1 1 1; 0 3 2];            % 基向量当列
>> B = [5 -9; 0 -8; 7 -13];               % 待表示向量当列
>> X = A \ B                              % 坐标矩阵
X =
     2   3
     3  -3
    -1  -2

要点

  • a:step:b — 等差数列，终点是上界不保证取到（1:2:7 与 1:2:8 结果相同）
  • linspace(a,b,n) — 从 a 到 b 共 n 个点（n 是点数不是步长，两端都含）
  • logspace(a,b,n) — 从 10a 到 10b 共 n 个点的等比数组
  • rank(A) / rref(A) / A\B — 秩 / 行最简形 / 解矩阵方程
  • 行向量 [1 2 3]，列向量 [1;2;3] 或 [1 2 3]'

最容易错的点

  • linspace 的第三个参数当步长用。它是点数。
  • 行列向量搞混。3×1 乘 3×1 不合法，会直接报错。
  • 以为 1:2:8 能取到 8。它只到 7。

过关题

用 MATLAB（或手算模拟）求出习题 3.3 第 2 题 (1) 的秩与极大无关组，并写出一行命令完成它。

#动作判据
1给两个向量，求它们的线性组合逐分量算，不重不漏
2给一个 β 和一组向量，判能否表示并求出系数设 ki​ → 解方程组 → 写出表达式 → 代回验算
3给一组向量，判线性相关性个数=维数算行列式；否则解方程组
4给一组向量，求秩与极大无关组竖着拼 → 行最简形 → 数非零行 + 读主元列
