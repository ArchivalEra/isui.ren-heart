4.4-用MATLAB求解

本节是第 4 章的 MATLAB 收尾：把 4.1–4.3 的手算流程翻译成两条语句—— 消元过程用循环 + 左除 X=A\B，通解用 format rat 的有理数输出 + 符号参数合成。 书页命令与输出按原样登记，已在本机用 GNU Octave 11.3.0 复跑对照。

解析

一、例 4.8：消元法 = 循环消列 + 左除收尾

书上代码做的事，逐行对应 4.1 节的手算步骤：

MATLAB 语句对应的手算动作
A(i,:)=A(i,:)-A(i,1)/A(1,1)*A(1,:)用第 1 行消第 1 列（ri​−a11​ai1​​r1​）
k=find(A(2:3,2)); k=k(1)+1; … 交换两行若主元为 0 则换行（初等变换第二类）
B=A(:,4); A=A(:,1:3);把常数列拆出来，系数矩阵归位
X=A\B左除：等价于「化上三角后回代」一条龙

题面下标的数值判定：转写时第三式有两个候选读法——x1​+2x2​+4x3​=6 与 x1​+2x3​+4x3​=6。用两种读法分别跑 A\B：前者得 X=(−10,4,2)T，与书页输出逐项一致；后者得 (−4,2,1)，不符。故题面取 2x2​、4x3​。

Octave 复核：按书上代码逐句跑（Octave 与 MATLAB 在这几句上语法一致），输出 X=(−10, 4, 2)T；rref([A B]) 给 ​100​010​001​−1042​​；代回原方程组三式残差全 0。

为什么最后用左除而不是继续手写回代：A\B 内部做的正是「高斯消元 + 回代」，与手算等价；书把它放在消元循环之后，是为了让读者看到「中间矩阵」与「最终解」两个阶段。实践中一句 X=A\B 就够，循环是教学用的展开。

二、例 4.9：通解 = 左除的特解 + 手工拼的基础解系

方程组与 4.3 节例 4.7 相同（R(A)=R(A∗)=2<5，自由量 x3​,x4​,x5​）。代码分三段：

  1. 消元与换行（for 循环 + find + 行交换）——与例 4.8 同一套；
  2. 有理化：format rat 让输出显示分数（730​ 而不是 4.2857）；r=1/A(2,2)*A(2,:) 把第 2 行归一，t=-A(1,2)*A(2,:)+A(1,:) 消去第 1 行的第 2 列——这是把消元做到行最简形的两句；
  3. 拼通解：x=A(:,6) 取常数列当特解 η∗（自由量取 0——正是 4.3 节解析五的「最省事取法」）；y1,y2,y3 用 -A(1,2:*) 取行最简形自由列的负值，再与单位块拼成基础解系；syms k1 k2 k3 后合成符号通解。

输出与 4.3 节例 4.7 的手算通解逐项一致：

x1​=730​−723​k1​−723​k2​−710​k3​,x2​=−73​+710​k1​+73​k2​−76​k3​,x3​=k1​, x4​=k2​, x5​=k3​

Octave 复核：消元主循环跑出的中间矩阵与 4.3 节例 4.7 的书上行变换一致；format rat 在 Octave 中同样可用；特解 (730​,−73​,0,0,0)T 与基础解系三个向量代回各自方程组残差全 0（见 4.3 节验证记录）。符号合成段用到 Symbolic 工具箱（syms），Octave 侧用 syms 包等价复现，输出形状一致。

三、与 4.3 节手算的分工

任务手算（4.3 节）MATLAB（本节）
判有没有解比 R(A) 与 R(A∗)代码里没有显式判断——直接 A\B，无解时结果不可信，判别仍要人做
特解行最简形常数列直接读x=A(:,6)（同一动作）
基础解系自由列取单位向量-A(1,2:*) 拼块（同一动作的机器版）
通解合成手写 k1​ξ1​+⋯syms 符号相加

机器接手的是算术，没接手的是判别：rank 检查（R(A)=R(A∗)?）本节代码里没有，套用模板前必须自己先看——这正是 4.2 节判别定理仍然是主角的原因。

四、四个卡点

  1. A\B 之前先判秩。 左除对无解/不定解的方程组会给出「最小二乘意义下」或「其中一个解」的结果而不警告——判别是读者的责任。
  2. 拆列要趁早（B=A(:,n+1); A=A(:,1:n);）。带着常数列做消元会让 A\B 的对象错位——书上专门拆列再左除，就是这个原因。
  3. format rat 只改显示不改存储。底层仍是浮点；要精确有理数得用 Symbolic（syms/sym）。书上的 730​ 是「显示成有理数」，不是「算出有理数」。
  4. 书上用字母 O 当零向量。照抄时保留原样；自己写代码时用 zeros(n,1) 或 0 更稳（O 在 MATLAB 里是合法变量名，容易和 0 看混）。
