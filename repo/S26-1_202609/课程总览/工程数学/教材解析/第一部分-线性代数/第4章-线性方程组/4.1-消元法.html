4.1-消元法


本节把「解方程组」拆成三个固定动作：写增广矩阵 → 只对行做三类初等变换化成三角（阶梯）形 → 从最后一个方程往上回代。
唯一的依据是定理 4.1：三类初等变换都可逆，所以解集一格不变。
全节不许出现的操作是列变换——它换的是未知量的位置，不是方程。




4.1 线性方程组的消元法（原书 p65–p67）
原书抄录
〔原书 p65〕


第 4 章　线性方程组


解线性方程组是线性代数最主要的任务之一，在科学技术与经济管理许多领域中，我们面对更多的是方程的个数与未知数的个数不相等的情形，或者说当方程的个数与未知数的个数相等、方程组的系数行列式不为零时，等等。为了解决这一大类问题，我们需要从更加普遍的角度来讨论线性方程组的一般理论。


4.1　线性方程组的消元法


线性方程组最常用的方法就是消元法，其步骤是逐步消除线性方程的未知数，把原方程组化为等价的三角方程组，再利用代回求解此等方程的方法，从而得出原方程组的解。


【例 4.1】 线性方程组


⎩⎨⎧​2x1​+2x2​+3x3​=3,−2x1​+4x2​+5x3​=−7,4x1​+7x2​+7x3​=1.​


解　将第一个方程加到第二个方程上，再将第一个方程以 −2 加到第三个方程上，得到与原方程组同解的线性方程组：


⎩⎨⎧​2x1​+2x2​+3x3​=3,6x2​+8x3​=−4,3x2​+x3​=−5.​


在上述中交换第二个和第三个方程，然后把第二个方程乘以 −2 加到第三个方程上，得到与原方程组同解的三角方程组：


⎩⎨⎧​2x1​+2x2​+3x3​=3,3x2​+x3​=−5,6x3​=6.​


再回代，得 x3​=1，x2​=−2，x1​=2。


我们对方程施行了三种变换：


〔原书 p66〕


（1）交换两个方程的位置；


（2）用一个不等于 0 的数乘某个方程；


（3）用一个数乘一个方程后加到另一个方程上。


这三种变换称为线性方程组的初等变换，也称为初等变换。


这三种变换与线性方程组的解的关系如下：


定理 4.1　初等变换是可逆的线性变换，它保持方程组的解集不变。


线性方程组有解以及有（无）解的情况，完全取决于它的系数和常数项。


因此我们讨论线性方程组时，主要研究它的系数和常数项。


设线性方程组：


⎩⎨⎧​a11​x1​+a12​x2​+⋯+a1n​xn​=b1​,a21​x1​+a22​x2​+⋯+a2n​xn​=b2​,⋮⋮an1​x1​+an2​x2​+⋯+ann​xn​=bn​,​(4.1)


令


A=​a11​a21​⋮an1​​a12​a22​⋮an2​​⋯⋯⋯​a1n​a2n​⋮ann​​​,x=​x1​x2​⋮xn​​​,b=​b1​b2​⋮bn​​​


则线性方程组（4.1）可以写矩阵形式：Ax=b。


我们分别称 A，x 和 b 是线性方程组（4.1）的系数矩阵、未知量矩阵和常数项矩阵。


同时我们称


A∗=(A∣b)=​a11​a21​⋮an1​​a12​a22​⋮an2​​⋯⋯⋯​a1n​a2n​⋮ann​​b1​b2​⋮bn​​​


是线性方程组（4.1）的增广矩阵。


若常数项 b1​,b2​,⋯,bn​ 不全为零，则称（4.1）式为非齐次线性方程组；若常数项 b1​,b2​,⋯,bn​ 全为零，则称（4.1）式为齐次线性方程组。


满足式（4.1）的一个 n 元有序数组称为 n 元线性方程组（4.1）的一个解，一般用列向量形式 ξ=(x1​,x2​,⋯,xn​)T 表示，因此也称 ξ 是方程组（4.1）的一个解向量。


当线性方程组有无穷多个解时，其所有解的集合称为方程组的解或解集。对于一个方程组施行消元法求解，即对方程组施行了（初等变换），（对）线性方程组相当于用初等行变换化简它的增广矩阵。这样讨论起来比较方便，而且能够给予我们一种方法，即利用一个线性


〔原书 p67〕


方程组的增广矩阵来解这个线性方程组，而不必每次把未知量写出。


【例 4.2】 线性方程组


⎩⎨⎧​21​x1​+31​x2​+x3​=1,x1​+35​x2​+2x3​=5,2x1​+34​x2​+5x3​=2.​


解　其增广矩阵是


A∗=​21​12​31​35​34​​125​152​​


交换矩阵第一行与第二行后，把第一行分别乘以 −21​ 和 −2 加到第二行和第三行上，再把第二行乘以 −2，得


A1∗​=​100​35​1−2​201​53−8​​


在 A1∗​ 中将第二行乘以 2 加到第三行上，得


A2∗​=​100​35​10​201​53−2​​


最后的行阶梯矩阵对应的三角型（阶梯型）方程组为


⎩⎨⎧​x1​+35​x2​+2x3​=5,x2​=3,x3​=−2.​


回代，得 x1​=4，x2​=3，x3​=−2。


从上面的例子我们看到，用消元法解线性方程组的过程，实际上就是对（改）方程组的增广矩阵作初等行变换化为行阶梯形矩阵的过程。在解线性方程组时，只写出方程组的增广矩阵的变换过程即可。




⚠ 三处按上下文补读（原文残缺处已用括号标出）：
p66「这三种变换称为线性方程组的初等变换，也称为初等变换」末句可能为「也称为初等行变换」；
p66 末段「即对方程组施行了（初等变换），（对）线性方程组相当于……」被版式断开、字形不清；
p67「实际上就是对（改）方程组的增广矩阵作初等行变换」一字不清。
依据：p67 开头「方程组的增广矩阵来解这个线性方程组」承 p66 末句，且全节只用行变换，故三处均按行变换读。




解析
一、消元法的三个动作（全节可执行内核）
教科书那句话拆开就是三步，顺序不能换：


    

  1. 写增广矩阵：把 n 个方程的系数按列排成 A，常数项单列一列接在右边，得 A∗=(A∣b)。
从此不再写 x1​,x2​,⋯ 这些符号——未知量在第 j 列的位置就是它的身份。
    2. 

  2. 初等行变换化三角形：只用三类行变换，把 A∗ 的下三角（严格说：主元以下的元素）全部打成 0，
得到行阶梯形（n 个方程 n 个未知数且系数行列式不为 0 时，就是上三角）。
    3. 

  3. 回代：从最后一个非零行解出一个未知量，逐行往上代入。
    4. 



「消元」两个字对应的正是第 2 步：逐个消掉未知量。第 1 步只是把这件事搬到矩阵上，
第 3 步是把三角方程组翻回具体的数。


二、为什么只允许动行，不允许动列
初等变换三类（定理 4.1 的前提）：






变换具体做法可逆性（逆操作是什么）


换位交换第 i、j 两个方程再交换一次即还原


倍乘第 i 个方程两边同乘 k=0再乘 1/k 即还原


消元第 j 个方程加上第 i 个方程的 k 倍再减去第 i 个方程的 k 倍即还原






三条都是「方程两边同时做同一件事」，所以解集不变；三条的逆操作都还在这个集合里，
所以这条链可以往回走——这是「同解」的依据，也是为什么化完的矩阵还能反推原方程组。


两类不该做的操作：


    

  • 列变换：交换两列等于把 x1​ 和 x2​ 的位置对调，系数矩阵变了、增广列的位置也错了，
算出来的数对不上原来的未知量。增广矩阵只做行变换。
    • 

  • 乘 0：k=0 这个条件不是装饰。第 i 个方程乘 0 会把它变成 0=0，
丢掉一个约束，解集从「一个点」放大成「一条线」，不可逆。
    • 



三、例 4.1 的机械路径（附 Octave 复核）
原方程组


⎩⎨⎧​2x1​+2x2​+3x3​=3−2x1​+4x2​+5x3​=−74x1​+7x2​+7x3​=1​


第 1 列的主元取第 1 行的 2，用它把下面两行的 x1​ 消掉。写成矩阵就是：


​2−24​247​357​3−71​​ r2​+r1​  r3​−2r1​ ​​200​263​381​3−4−5​​


逐格核对第 2 行：−2+2=0，4+2=6，5+3=8，−7+3=−4；第 3 行：4−2⋅2=0，
7−2⋅2=3，7−2⋅3=1，1−2⋅3=−5。


第 2 列现在是 (6,3)T，主元 6 不整除下面的 3，先把两行换位，让主元变成 3，
再用它消掉 6：


 r2​↔r3​ ​​200​236​318​3−5−4​​ r3​−2r2​ ​​200​230​316​3−56​​


第 3 行 6x3​=6 直接给 x3​=1。回代：


    

  • 第 2 行：3x2​+x3​=−5⇒3x2​=−5−1=−6⇒x2​=−2；
    • 

  • 第 1 行：2x1​+2x2​+3x3​=3⇒2x1​=3−2(−2)−3(1)=4⇒x1​=2。
    • 



Octave 复核：det(A)=−36=0（说明解唯一），rref(A∣b) 的第 4 列是 (2,−2,1)T，
A\b 给出 (2.000,−2.000,1.000)，与回代结果逐位一致；上面三次行变换逐行重算也一致。
注意 det(A)=−36 只是「唯一解」的旁证，求值仍要靠消元回代。


四、例 4.2 的机械路径（分数系数怎么处理）
原方程组带 21​,31​,35​,34​ 一类分数系数，直接写增广矩阵、直接做行变换，
不先去分母——去分母要给每一行乘不同的数，多一道容易出错的手续。


​21​12​31​35​34​​125​152​​ r1​↔r2​ ​​121​2​35​31​34​​215​512​​


先换位是因为整数行当主元行更好算。接着 r2​−21​r1​、r3​−2r1​：


​100​35​−21​−2​201​5−23​−8​​


第 2 行主元是 −21​，乘 −2 把它变成 1（书上「再把第二行乘以 −2」）：


​100​35​1−2​201​53−8​​


再用 r3​+2r2​ 消掉 −2：


​100​35​10​201​53−2​​


已为上三角，回代：x3​=−2、x2​=3、x1​=5−35​⋅3−2⋅(−2)=5−5+4=4。


Octave 复核：det(A)=0.5，rref(A∣b) 末列为 (4,3,−2)T，A\b 给出 (4,3,−2)；
中间矩阵 A1∗​ 的三行为 (1,35​,2,5)、(0,1,0,3)、(0,−2,1,−8)，A2∗​ 第三行为 (0,0,1,−2)，
与书上印字逐项相同。


五、五个卡点（做错通常错在这几处）
    

  1. 回代从最后一行开始。取第一个方程先解 x1​ 会带进两个未知量，解不动。
三角形状的意义就是「最后一行只含 xn​」。
    2. 

  2. 消元方向是从上往下。第 k 步用第 k 行（主元行）去消它下面的行；反过来消上面，
会把已经消干净的 0 又弄脏。
    3. 

  3. 主元不能是 0。第 k 列第 k 行位置是 0 时，必须与下面某个该列非零的行交换；
若整列下方都为 0，这一列没有主元，主元位置右移到下一列（这时方程个数与未知数个数不再够用，
解的情况要交给 4.2 节的秩判别）。
    4. 

  4. 分数只在必要时消。像例 4.2 那样一路保留分数反而稳；把某行乘一个公倍数虽然也能算，
但每行乘的数不同，容易漏乘常数项那一列。
    5. 

  5. 算完代回原方程组抽查。把 (2,−2,1) 代回例 4.1 第三式：4⋅2+7⋅(−2)+7⋅1=8−14+7=1 ✓；
把 (4,3,−2) 代回例 4.2 第一式：2+31​⋅3−2=1 ✓。这一步用原式验，不用化简后的式子验。
    6. 





本节小结（三条可执行判据）




情形用什么判判据


拿到 n 个方程 n 个未知数，想先知道解的大致情况算 det(A)det(A)=0 ⇒ 唯一解，放心消元回代（也可用克莱姆法则）；det(A)=0 ⇒ 三种可能，不能预先断定


消元第 k 步，第 k 列主元位置是 0看该列下方有没有非零元有 ⇒ 把那一行换上来当主元行；整列下方全 0 ⇒ 主元右移一列，跳过该未知量


化到行阶梯形后求解从最后一个非零行往上回代每行只解出一个新未知量，代入它上面所有行；结束时把解代回原方程组抽查

例 4.2（det(A)=0.5、rref 末列 (4,3,−2)T、A\b =(4,3,−2)、A1∗​ 与 A2∗​ 各元素逐项一致）均经 Octave 独立复核。
