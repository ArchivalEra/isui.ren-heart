3.2.1异步电动机运行分析
1. 依赖
题量与状态：学习通「3.2.1 异步电动机的运行分析（客观题）」共 4 道题（单选 3 题 + 多选 1 题，限时未提交任务）。第 1、4 题含 7 张公式图片，已逐张超分核对并转写为标准 LaTeX；平台对选项做了乱序，下表按屏幕显示顺序抄录并注明原始位（orichoice）。






题号用到的知识与机械判据前置锚点（如有）


第 1 题定转子旋转磁动势相对静止：定子磁动势 F˙1​ 转速为 n1​；转子转速 n 时转子电流频率 f2​=sf1​，转子磁动势 F˙2​ 相对转子转速 n2​=sn1​=n1​−n，相对定子合成转速恒为 n+n2​=n1​（任何稳态运行状态均同向同速、空间相对静止）同步速与转差率定义见 11-12 笔记；气隙合成规律见本节 1.1


第 2 题功率流与附加电阻：气隙电磁功率 PM​=m1​I2′2​sr2′​​，转子铜耗 pCu2​=m1​I2′2​r2′​=sPM​，附加电阻 s1−s​r2′​ 消耗的有功功率为 (1−s)PM​=PM​−pCu2​=Pi​（转轴上总机械功率）负载与等效电路思路同 10-15 笔记；频率折算与功率拆分见本节 1.2


第 3 题转子频率计算：先由 p=极数/2 求同步速 n1​=p60f1​​，再求转差率 s=n1​n1​−n​，最后算转子感应电流频率 f2​=sf1​11-12 笔记（n1​=60f/p、s=(n1​−n)/n1​）；转子频率 f2​=sf1​ 见本节 1.1


第 4 题转子绕组归算三变比：用 (m1​,N1​,kw1​) 的假想绕组替代实际转子 (m2​,N2​,kw2​)，保持磁动势不变与总功率不变；由此得 Ki​=m2​N2​kw2​m1​N1​kw1​​、Ke​=N2​kw2​N1​kw1​​、Kz​=Ke​Ki​=m2​m1​​(N2​kw2​N1​kw1​​)2归算两条不变原理同 10-15 笔记；相电势含 kw​ 见 11-19 笔记；一般 m 相磁动势与三变比推导见本节 1.3






1.1 气隙磁场相对静止与转子频率
以下按交流定子旋转磁场（n1​=p60f1​​=0）讨论。定子通入频率为 f1​ 的对称三相电流，建立转速为 n1​ 的定子旋转磁动势 F˙1​。当转子以机械转速 n 旋转时，转差率 s=n1​n1​−n​，转子绕组感应电动势及电流频率为


f2​=sf1​


该转子电流在气隙中产生转子旋转磁动势 F˙2​，其相对转子的转速为


n2​=p60f2​​=p60sf1​​=sn1​=n1​−n


因此 F˙2​ 相对定子空间的绝对转速恒为


n+n2​=n+(n1​−n)=n1​


无论是电动机（0<s<1）、发电机（s<0，相序反转使 n2​<0）还是反接电磁制动（s>1，n<0 使 n2​>n1​），F˙2​ 与 F˙1​ 始终同向同速、空间相对静止。（若为定子通直流的能耗制动，n1​=0，不再代入 s=(n1​−n)/n1​，转子切割静止磁场产生的 F˙2​ 同样在空间上与定子直流磁场保持相对静止。）


1.2 异步电动机等效电路与功率拆分
对频率为 f2​=sf1​ 的转子电路作频率折算（分子分母同除 s）：


I˙2​=r2​+jsx2σ​sE˙2​​=sr2​​+jx2σ​E˙2​​


再经绕组归算到定子侧后，每相转子等效电路的总串联电阻为 sr2′​​，拆成两段：


sr2′​​=r2′​+s1−s​r2′​


因正常运行时 f2​=sf1​ 很小（如 1–3 Hz），转子铁耗可忽略不计，于是气隙电磁功率 PM​ 全部按下列路径分配：


    

  • 气隙传向转子的电磁功率：PM​=m1​I2′2​sr2′​​；
    • 

  • 转子铜耗：pCu2​=m1​I2′2​r2′​=sPM​；
    • 

  • 附加电阻 s1−s​r2′​ 消耗的功率：m1​I2′2​s1−s​r2′​=(1−s)PM​=PM​−pCu2​=Pi​（转轴上的总机械功率）；
    • 

  • 扣除机械损耗 pmec​ 与附加损耗 pΔ​ 后，才是轴上输出功率：P2​=Pi​−pmec​−pΔ​。
    • 



1.3 转子绕组归算与变比推导
将实际转子 (m2​,N2​,kw2​) 折算为参数 (m1​,N1​,kw1​) 与定子相同的假想绕组，遵循「磁动势不变」与「总功率（有功损耗与无功）不变」两项原则（下式中 Φm​ 即 11-19 笔记 所写的每极主磁通 Φ）：


    

  • 由一般 m 相绕组基波旋转磁动势幅值 Fm​=2m​⋅π22​​pNkw​I​=π2​​pmNkw​I​≈0.45pmNkw​I​ 相等：m1​N1​kw1​I2′​=m2​N2​kw2​I2​⟹Ki​=I2′​I2​​=m2​N2​kw2​m1​N1​kw1​​；
    • 

  • 由相同气隙主磁通与基准频率 f1​ 下相电动势 E=4.44f1​Nkw​Φm​（不含相数 m）且 E2′​=E1​：Ke​=E2​E1​​=E2​E2′​​=N2​kw2​N1​kw1​​；
    • 

  • 由总功率不变 m1​I2′2​Z2′​=m2​I22​Z2​：Kz​=Z2​Z2′​​=m1​m2​​Ki2​=m2​m1​​(N2​kw2​N1​kw1​​)2=Ke​Ki​。
    • 





2. 单选题（第 1–3 题）
第 1 题
关于异步电机定、转子旋转磁场描述正确的是（ ）。






显示位原始位选项


AD不论进入什么运行状态，其转子磁势 F˙2​ 与定子磁势 F˙1​ 总是同向同速旋转，在空间上保持相对静止。


BC进入电制动运行状态时，转子磁势 F˙2​ 与定子磁势 F˙1​ 旋转方向相反。


CA进入电动机运行状态时，转子磁势 F˙2​ 与定子磁势 F˙1​ 旋转方向相同、转速略小。


DB进入发电机运行状态时，转子磁势 F˙2​ 与定子磁势 F˙1​ 旋转方向相同、转速略大。







提示
把「转子机械转速 n」和「转子磁势相对定子的转速 n+n2​」严格分开：先算 F˙2​ 相对转子的转速 n2​=sn1​=n1​−n，再叠加转子机械转速 n，看结果是否还依赖运行状态。



完整解答
第一步：计算转子磁动势 F˙2​ 相对定子的转速。
设同步转速为 n1​=p60f1​​，转子机械转速为 n，则转差率 s=n1​n1​−n​，转子感应电流频率 f2​=sf1​。
由旋转磁动势转速公式，F˙2​ 相对转子的转速为

n2​=p60f2​​=sn1​=n1​−n

将转子本身的机械转速 n 叠加上去，F˙2​ 相对定子空间的转速为

n+n2​=n+(n1​−n)=n1​


第二步：逐项检验运行状态。


    

  • A（原始位 D）正确：不论处于电动机（0<s<1）、发电机（s<0）还是电制动（s>1）状态，定转子磁动势相对定子的转速始终同为 n1​，同向同速、空间相对静止（这也是产生稳定平均电磁转矩的前提）。
    • 

  • B（原始位 C）错误：反接电制动时是转子机械转向与 n1​ 相反（n<0），此时 s>1、n2​=n1​−n>n1​，叠加后 F˙2​ 对定子仍以 n1​ 同向旋转（能耗制动时定子通直流 n1​=0，双方仍相对静止）。
    • 

  • C（原始位 A）错误：电动机运行时「略小于 n1​」的是转子机械转速 n，不是转子磁动势 F˙2​ 的空间转速。
    • 

  • D（原始位 B）错误：发电机运行时「略大于 n1​」的是转子机械转速 n（此时 s<0，转子电流相序反转使 n2​=n1​−n<0，F˙2​ 相对定子仍为 n1​）。
    • 



答案：A（原始位 D）



复盘
    

  • 核心陷阱：B、C、D 全部把「转子的机械转速 n」偷换成了「转子磁动势 F˙2​ 的空间转速」。记住口诀：转子无论怎么转（快一点、慢一点、倒着转），转差频率 f2​=sf1​ 会自动把缺少或多余的那部分速度补平，使 F˙2​ 永远卡死在同步速 n1​ 上与 F˙1​ 相对静止。
    • 

  • 乱序提醒：本作答页显示位 A 对应原始位 D，提交时按当前页面字母（A）或文字核对，不要照抄未对照的原始字母。
    • 



第 2 题
异步电动机等效电路图中的附加电阻所消耗的有功功率应等于（ ）。






显示位原始位选项


AB空载损耗功率 p0​


BA气隙电磁功率 PM​


CC转轴上总的机械功率 Pi​


DD转轴上输出的机械功率 P2​







提示
把转子等效总电阻 sr2′​​ 拆成 r2′​+s1−s​r2′​：总电阻吃掉的是气隙传过来的电磁功率 PM​，实际铜电阻 r2′​ 吃掉的是转子铜耗 pCu2​，剩下的「附加电阻」就是两者的差，对照功率流程图里的名称。



完整解答
第一步：列出转子回路功率关系。
在归算并频率折算后的等效电路中，转子支路总电阻为 sr2′​​，拆分为实际转子电阻与附加模拟电阻两项：

sr2′​​=r2′​+s1−s​r2′​

其中：


    

  • 气隙电磁功率：PM​=m1​I2′2​sr2′​​；
    • 

  • 转子铜耗：pCu2​=m1​I2′2​r2′​=sPM​；
    • 

  • 附加电阻消耗的有功功率：

    m1​I2′2​s1−s​r2′​=(1−s)PM​=PM​−pCu2​=Pi​
    • 



第二步：逐项排错。


    

  • A（原始位 B）错误：空载损耗 p0​ 包括铁耗（对应励磁电阻 rm​）和空载机械损耗，与附加电阻无关。
    • 

  • B（原始位 A）错误：气隙电磁功率 PM​ 对应转子支路总电阻 sr2′​​ 消耗的功率（即 PM​=pCu2​+Pi​）。
    • 

  • C（原始位 C）正确：附加电阻将实际不存在于转子绕组发热中的机电能量转换部分等效出来，其功率等于转轴上产生的总机械功率 Pi​（有时也记作 PΩ​）。
    • 

  • D（原始位 D）错误：轴上输出机械功率 P2​=Pi​−pmec​−pΔ​ 还需从 Pi​ 中扣除机械损耗和附加损耗，等效电路里的附加电阻尚未扣除这两项损耗。
    • 



答案：C（原始位 C）



复盘
    

  • 易混边界：最容易误选 B（PM​）或 D（P2​）。区分三者只需一条线：sr2′​​ → PM​；r2′​ → pCu2​；s1−s​r2′​ → Pi​；最后再从 Pi​ 减去机械与杂散损耗才得到轴输出 P2​。
    • 



第 3 题
一台三相 4 极异步电动机额定运行时，转子转速为 1470 r/min，如果电源频率为 50 Hz，则在转子绕组中产生的感应电流的频率为（ ）。






显示位原始位选项


AA1 Hz


BC30 Hz


CB4 Hz


DD50 Hz







提示
按三步依次代数字：① 4 极对应极对数 p=4/2=2，先求同步速 n1​=p60f1​​；② 代入 n=1470 r/min 求转差率 s=n1​n1​−n​；③ 计算 f2​=sf1​。



完整解答
第一步：求极对数与同步转速。
已知磁极数 2p=4，故极对数 p=2；电源频率 f1​=50 Hz：

n1​=p60f1​​=260×50​=1500 r/min


第二步：求转差率 s。
额定运行时 n=1470 r/min，因此

s=n1​n1​−n​=15001500−1470​=150030​=0.02


第三步：求转子感应电流频率 f2​。

f2​=sf1​=0.02×50=1 Hz

（亦可直接用转速差算：f2​=60p(n1​−n)​=602×30​=1 Hz。）


第四步：排错与自检。
B（30 Hz）误把转速差 n1​−n=30 r/min 当成频率；D（50 Hz）是堵转（s=1,n=0）时的频率；C（4 Hz）数值误算。


答案：A（原始位 A）



复盘
    

  • 秒检规律：50 Hz 4 极电机同步速永远是 1500 r/min，每 1% 转差对应 0.01×50=0.5 Hz（等价于转差每少 15 r/min 对应 0.5 Hz）；本题少 30 r/min ⇒ 直接得 1 Hz。
    • 

  • 数值验算：Octave 已独立复核 n1=1500, s=0.02, f2=1 ✓。
    • 



3. 多选题（第 4 题）
第 4 题
下列关于异步电动机绕组归算的说法正确的有（ ）。






显示位原始位选项


AA用一个相数、每相串联匝数以及绕组因数和定子绕组相同的假想绕组替代实际的转子绕组，而且应保持归算前后转子磁动势和转子总的功率不变。


BC电流比 Ki​=I2′​I2​​=m2​N2​kw2​m1​N1​kw1​​


CB电势比 Ke​=E2​E1​​=E2​E2′​​=N2​kw2​N1​kw1​​


DD阻抗变比 Ke​Ki​=m2​m1​​(N2​kw2​N1​kw1​​)2







提示
先把变压器归算的两个「不许动」扩写到旋转电机（多出相数 m1​/m2​ 与绕组因数 kw1​/kw2​）：① 写旋转电机基波磁动势幅值比例式 m1​N1​kw1​I2′​=m2​N2​kw2​I2​ 反解 I2​/I2′​；② 用相电势式 E=4.44f1​Nkw​Φm​ 写 E1​/E2​；③ 用有功/无功功率不变 m1​I2′2​Z2′​=m2​I22​Z2​ 推 Z2′​/Z2​ 并核对它是否正好等于 Ke​Ki​。



完整解答
逐项推导与核对：


    

  1. 选项 A（原始位 A）：正确。
异步电动机定子与转子不仅每相匝数、绕组因数不同，相数也可能不同（例如笼型转子 m2​=3）。转子绕组归算就是用一个相数 m1​、每相串联匝数 N1​、绕组因数 kw1​ 均与定子相同的假想绕组代替实际转子 (m2​,N2​,kw2​)，且必须保持归算前后转子磁动势不变与转子总功率（有功损耗与无功功率）不变。
    

    2. 

  2. 选项 B（原始位 C）：正确。
由转子基波旋转磁动势幅值不变（F2m′​=F2m​，其余常数如 p0.45​ 或 πp2​​ 两侧相同约去）：

    m1​N1​kw1​I2′​=m2​N2​kw2​I2​⟹Ki​=I2′​I2​​=m2​N2​kw2​m1​N1​kw1​​
    

    3. 

  3. 选项 C（原始位 B）：正确。
对同一气隙主磁通 Φm​（即 11-19 中的 Φ）与同一基准频率 f1​（频率折算后转子基准电势记为 E2​，归算后满足 E2′​=E1​），相电动势 E=4.44f1​Nkw​Φm​ 与相数 m 无关，因此：

    Ke​=E2​E1​​=E2​E2′​​=N2​kw2​N1​kw1​​
    

    4. 

  4. 选项 D（原始位 D）：正确。
由转子总功率（含铜耗与漏抗无功）不变，m1​I2′2​Z2′​=m2​I22​Z2​，得阻抗归算系数：

    Kz​=Z2​Z2′​​=m1​m2​​(I2′​I2​​)2=m1​m2​​Ki2​=m1​m2​​(m2​N2​kw2​m1​N1​kw1​​)2=m2​m1​​(N2​kw2​N1​kw1​​)2
    
另一方面直接相乘：

    Ke​Ki​=N2​kw2​N1​kw1​​⋅m2​N2​kw2​m1​N1​kw1​​=m2​m1​​(N2​kw2​N1​kw1​​)2
    
二者完全一致。
    

    5. 



答案：A、B、C、D



复盘
    

  • 和变压器归算的联系与区别：变压器里 m1​=m2​=1（或同为三相）、kw1​=kw2​=1，所以退化为 Ke​=Ki​=k=N1​/N2​、Kz​=k2。异步电动机因为 m1​=m2​ 且存在绕组因数 kw1​,kw2​，所以 Ki​ 带 m2​m1​​，而 Ke​ 不带 m2​m1​​，于是阻抗变比 Ke​Ki​ 里正好留下一次方 m2​m1​​。
    • 

  • 做题常见错觉：多选题看到四个全对常怀疑是不是少看了一个细节，只要核对「相电势公式不含 m、磁动势含 m、总功率为 mI2Z」三件事，就能把 Ke​、Ki​、Ke​Ki​ 里的 m2​m1​​ 次幂当场验死。
    •
