符号入门

这本书自己带了一张「主要符号表」（在目录之后、正文之前，两页），第一章开头就直接用其中的符号，而且一个都不解释——教材默认你已经认识。这一页把那张表整张录入：每个符号都能点出气泡，气泡里是它的含义。

  • 公式内全量取词：符号表里的符号，只要在公式里出现，就自动变成可点符号——不必手写令牌。 例如 S、Φ、μ、Br​、pFe​ 都直接可点。
  • 正文与公式都默认全量取词：符号表里的符号在正文里裸写、在公式里出现，都自动变成可点符号——不必手写令牌。 例如 S、Φ、μ、Br​、pFe​ 都直接可点；拉丁单字母（T、S、A、H、W…）也一并覆盖， 宁可在少数撞车的页面上显式收窄。
  • 撞车就显式排除：拉丁单字母与单位、缩写、选项标号撞车的地方（「单位 T（特斯拉）」里的 T 是特斯拉不是转矩、 「10000 MVA」里的 M 只是量级、作业页的「答案：C、F」是选项），在该页 frontmatter 里写 符号排除: [sym-T, sym-M]（只禁正文）或 符号排除公式: [sym-A]（只禁公式），两个都写 = 完全禁自动取词。 手写令牌 [T]{#sym-T} 永远照常——排除只收窄自动取词，显式总是优先。行内代码（反引号）里的字母一律不取词。
  • 词典与自动取词都来自教材那页「主要符号表」，新增符号照表补一行即可，不用改代码。
  • 气泡里的公式是真公式：词条的标题与释义都在构建期渲染，$…$ 出真分式（\frac）， 不必拿斜杠或 unicode 上下标凑；那张表本身整张列在本页末尾（见「符号总表」）。
  • 单位与量纲跟着符号走：B 用 T，Φ 用 Wb，H 用 A/m，μ 用 H/m，F 与 UM​ 用 A，L、M 用 H，e 用 V，T 用 N·m。

一族一族的记法

磁场的三个基本量：B、H、μ
  • B 是磁通密度（磁感应强度），描述"磁有多强"，矢量；H 是磁场强度，描述"外界激励有多强"；两者由 μ 联系：B=μH。
  • H 只看电流（激励），B 还要乘介质磁导率——同一个电流在铁心里的 B 比空气里大几千倍。这条在第一章反复考。
磁通与磁链：Φ、Ψ
  • Φ 是磁通（穿过面积的磁感应线根数，标量，Wb）；Ψ 是磁链（Ψ=NΦ）。Φ 是"几根线"，Ψ 是"几根线 × 几圈"。
  • 教材符号表区分三种磁通：Φ 有效值、Φm​ 最大值、φ 瞬时值。
磁路三件套：F、UM​、Rm​、Λ
  • F 磁动势（NI，单位 A）；UM​ 磁压（∫Hdl，单位 A）；Rm​ 磁阻（l/(μS)）；Λ 磁导（1/Rm​）。
  • 与电路一一对应：磁动势↔电动势、磁通↔电流、磁压↔电压降、磁阻↔电阻（第一章整张类比表在小结页）。
电路与机电转换：L、M、e、Fe​、T
  • L 电感、M 互感、e 感应电动势、Fe 电磁力、T 转矩。
  • 三个定则分工：右手螺旋（电流→磁场）、右手定则（运动→电动势）、左手定则（电流＋磁场→受力）。
材料与损耗：Br、Hc、pF​e
  • Br 剩磁、Hc 矫顽力；铁耗 = 磁滞损耗 + 涡流损耗。
  • 记忆钩子：回线越胖磁滞损耗越大；片子越薄、电阻率越高，涡流损耗越小。
下标与上标
  • 下标约定、上标约定 是本书的语法，读公式前先认号。
运算符（教材同样不作解释）
  • 第一章反复出现三种「算总账」的符号：∫ 是沿一条线/一个面累加（如 Φ=∫S​BcosθdS 就是把整个面上各点的磁通加起来）； ∮ 是沿闭合回路走一圈（全电流定律 ∮l​Hdl=NI 就是它）；Σ 是离散地求和（各段磁压相加 ∑UM​=∑F）。
  • d 是微分号（dΨ/dt 表示"磁链对时间的变化率"）；∂ 是偏导（多元函数里对某一个变量求导）；∞ 是无穷大。
  • ∝ 是正比（ph​∝fBmn​ 表示磁滞损耗与频率、磁通密度成正比）；× 与 ⋅ 都是乘号（× 常用于数与数、矢量叉乘；· 表示点乘，如能量密度 21​BH 里的相乘）。

符号总表

下面这张表就是教材「主要符号表」那张表（前置页两页）按序录入——族面板讲的是怎么记，总表管的是查得到，两者互为索引。 每个符号在表里都有自己的锚点，所以正文或公式里点出气泡后，气泡下方「详细 ↗」落到的那一行就是它的位置。

符号含义
A：A 相；线负荷三相里的 A 相（小写 a 是 a 相）；也用作线负荷——沿圆周单位长度上的安匝数。
B：磁通密度（磁感应强度）描述磁场强弱的矢量，单位 T（特斯拉）。穿过垂直于它的单位面积的磁感应线根数就是它的大小，所以又叫磁通密度。B=μH——与介质有关：同一个电流在铁心里的 B 比空气里大几千倍。
Br​：剩余磁通密度（剩磁）极限磁滞回线与纵轴（H=0）的交点，表示撤去外磁场后材料里还剩的磁通密度。剩磁大 → 适合做永磁体。
a：a 相三相绕组里的 a 相（大写 A 是 A 相，也作线负荷）；下标记号里 Ha​、Ba​ 表示曲线上某一点的量。
b：宽度一个几何尺寸记号（如槽宽、导条宽）。
c：c 相三相绕组里的 c 相（大写 C 是 C 相，也作并联支路数、电容、比热）。
d：直径；轴线几何尺寸记号（轴径、导线直径）；坐标里是直轴（d 轴，与 q 轴正交）。
g：气隙长度定子与转子之间的空气隙长度（Bg​、Hg​、Fg​ 都是气隙里的量）。旋转电机的磁场能量主要储存在气隙中。
m：相数；质量绕组相数（三相 m=3，定子相数也写 m1​）；也算质量（材料用量）。
r：半径；电阻；相对值几何里是半径；电路里是电阻（R 的瞬时/小写用法）；下标记号里 μr​、xr​ 是相对值与转子量。
Y：星形接法三相绕组的一种连接方式（另一端接中性点）；与三角形接法 △ 相对——星形下线电压是相电压的 3​ 倍。
z：槽数电机定子或转子的槽数（Z 的同义小写；每极每相槽数 q=2pm1​Z​）。
bm​：电纳交流电路里的电纳（导纳的虚部）。
C：C 相；并联支路数；电容；比热按上下文取一个：C 相（小写 c）、绕组并联支路数、电容、比热。
Ce​：电动势常数电机转速—电动势关系里的常数（E∝Ce​nΦ）。
CT​：转矩常数转矩—电流关系里的常数（T∝CT​ΦI）。
Ct​：修正系数异步电机计算中的修正系数。
D：定子内径定子内圆的直径，算极距、槽距角时用。
E：电动势（有效值）交流电动势的有效值；直流用大写，瞬时值用小写 e。
Eph​：相电动势每相绕组的电动势。
Ec​：线圈电动势单个线圈的感应电动势。
Eq​：q 个线圈合成电动势一个线圈组（q 个线圈）的合成电动势。
e：电动势瞬时值瞬时值；由磁链变化产生，e=−dΨ/dt（正方向按右手螺旋与磁通一致）。
F：磁动势；力磁路里是磁动势（安匝数 NI，单位 A）；力学里是力。永磁体也可以当磁动势源。
Fe​：电磁力磁场对载流导体的作用力，Fe​=Bli（B、l、i 互相垂直），单位 N，方向用左手定则。
Fd1​：线圈磁动势的基波振幅单只线圈磁动势的基波（直轴分量）振幅。
Fq1​：线圈组磁动势的基波振幅线圈组磁动势的基波（交轴分量）振幅。
Fm1​：磁动势的基波振幅磁动势的基波振幅，谐波分析时用。
G：重量电机部件的重量（算材料与成本时用）。
gm​：电导电阻的倒数。
H：磁场强度描述磁场"激励"的矢量，单位 A/m。只看电流和几何（长直导线 H=2πrI​、螺线管 H=lNI​），与介质无关；介质的影响全部由 B=μH 里的 μ 承担。
Hc​：矫顽磁力（矫顽力）极限磁滞回线与横轴（B=0）的交点，表示要把磁通密度降到零所需的反向磁场。Hc​ 小、回线窄 → 软磁（做铁芯）；Hc​ 大、回线宽 → 硬磁（做永磁）。
Iμ​：励磁电流中的磁化电流励磁电流里用于建立磁场（磁化）的分量，与铁耗电流 IFe​ 合成励磁电流。
IFe​：励磁电流中的铁耗电流励磁电流里对应铁芯损耗的分量。
IN​：额定电流铭牌上长期运行允许的电流（由发热与散热平衡定）：单相 IN​=SN​/UN​，三相 IN​=3​UN​SN​​。分侧写 I1N​／I2N​。
i：电流瞬时值瞬时值；直流电路用大写 I，交流电路用电流的瞬时或有效值。
J：转动惯量机械过渡过程（加速转矩 Tj​）里用。
j：电流密度单位截面积上的电流（A/mm²）。
K：换向器片数直流电机换向器的片数。
Kd​：分布因数分布绕组相对集中绕组的电动势折减系数。
Kp​：节距因数短距绕组相对整距绕组的折减系数。
KN​：绕组因数KN​=Kd​Kp​，绕组折算成"等效集中整距"的系数。
Km​：过载能力最大转矩与额定转矩之比。
kv​：电压波形正弦畸变率衡量电压波形偏离正弦的程度。
k：电压变比变压器一次、二次电压之比。
kk​：短路比同步电机参数（空载额定电压时的励磁电流与短路额定电流时的励磁电流之比）。
kA​：自耦变压器变比自耦变压器的变比。
L：电感（自感）单位电流在线圈里产生的磁链，L=Ψ/I=ΛN2=N2/Rm​，单位 H。只与匝数和磁路介质有关，与所加电压、电流、频率无关。
l：长度导体或磁路段的长度（算 e=Blv、磁阻 Rm​=μSl​ 时用）。
M：互感一个回路的电流在另一个回路里造出的磁链与之比，M21​=Ψ21​/I1​，单位 H。两个回路的互感相等：M12​=M21​。
m1​：定子相数定子绕组的相数（三相电机 m1​=3）。
N：串联匝数线圈或绕组的串联匝数（磁动势 F=NI 里的 N）。
Nc​：线圈的匝数单只线圈的匝数。
n：转速旋转速度（r/min）；与同步转速 n1​ 比较可判断运行状态。
n1​：同步转速n1​=p60f​，由频率与极对数决定。
P1​：输入功率电机从电源（或机械端）吸收的功率。
P2​：输出功率电机送出的功率。
Pi​：机械功率机械端传递的功率。
PM​：电磁功率通过气隙磁场传递的功率（PM​ 是机电能量转换的枢纽）。
p：损耗；极对数损耗（如 pCu​、pFe​）或极对数（n1​=p60f​），按上下文取。
pCu​：铜损耗绕组电阻上的损耗（I2R）。
pFe​：铁芯损耗（铁耗）交变磁化时铁心里的能量损耗，pFe​=ph​+pe​：磁滞损耗 ph​=kh​fVBmn​（正比于回线面积，n 约 1.5～2）+ 涡流损耗 pe​=ke​Vf2τ2Bm2​（正比于频率平方、片厚平方）。工程上按材料的比损耗（W/kg）乘重量算。
pad​：附加损耗除铜耗、铁耗、机械损耗之外的杂散损耗。
pmec​：机械损耗轴承摩擦、通风等机械损耗。
q：每极每相槽数q=2pm1​Z​，绕组分布与磁动势波形都由它决定。
R：电阻绕组或回路的电阻（R=Sρl​）。
Rm​：磁阻；励磁电阻磁路里是磁阻 Rm​=ΦUM​​=μSl​（单位 H⁻¹ 或 A/Wb）；直流电机里也指励磁绕组电阻。
rΔ​：附加电阻附加（外接或折算的）电阻。
s：转差率；秒异步电机转差率 s=n1​n1​−n​；也作时间单位秒。
sk​：最大转矩时的转差率异步电机最大转矩对应的转差率，也称临界转差率。
T：转矩；时间常数；周期电磁转矩 T=Blir（单位 N·m）；也用作时间常数或周期。
T1​：输入转矩机械端的输入转矩。
T2​：输出转矩机械端的输出转矩。
Tj​：加速转矩使转子加速的剩余转矩（Tj​=T−TL​）。
Tpu​：牵入转矩同步电动机能牵入同步的最大负载转矩。
Ta3​：非周期电流衰减时间常数短路电流非周期分量的衰减时间常数。
Td3′​：瞬变电流衰减时间常数短路电流瞬变分量的衰减时间常数。
Td3′′​：超瞬变电流衰减时间常数短路电流超瞬变分量的衰减时间常数。
Td0​：定子开路时励磁绕组自由分量时间常数定子开路条件下励磁绕组电流自由分量的衰减时间常数。
Tc​：换向周期直流电机一个换向片经历换向的时间。
t：时间时间变量（瞬时值、过渡过程的横坐标）。
SN​：额定容量铭牌上的视在功率（kVA／MVA）：单相 SN​=UN​IN​，三相 SN​=3​UN​IN​（UN​、IN​ 取线值）。容量上限由发热与散热平衡决定。
UN​：额定电压铭牌规定的电压：变压器一次侧是额定分接头下的电压，二次侧是一次加额定电压、二次空载时的空载电压。分侧写 U1N​／U2N​。
Uph​：相电压每相绕组的电压。
UM​：磁位差（磁压）磁场强度沿一段路径的线积分 UM​=∫Hdl，单位 A。闭合磁路的全部磁压之和等于全部磁动势之和（全电流定律）。
u：电压瞬时值瞬时值；与电流 i 类似，交流用瞬时或有效值。
ΔU：电压变化率；电刷接触电压降变压器里是电压变化率；直流电机里是电刷的接触电压降。
W：功；能功与能量（输入功、输出功、损耗能量）。
Wm​：磁场储能磁场里储存的能量，是能量密度 wm​=21​BH 的体积分，线性介质下 wm​=2μB2​。旋转电机的气隙 μ 小、储能集中，气隙储能的大小直接决定电机能转换多大功率。
X：电抗交流电路里的电抗（X=ωL 或 ωC1​）。
Xs​：同步电抗同步电机稳态分析的核心参数（电枢反应电抗与漏抗之和）。
xp​：保梯电抗用保梯图法求励磁电动势时替代漏抗的电抗。
Ym​：导纳阻抗的倒数。
y：绕组合成节距线圈两边的合成节距（y=y1​−y2​ 等）。
y1​：第一节距线圈两边沿电枢表面的距离（用槽数表示）。
y2​：第二节距相邻两线圈之间的节距。
ZL​：负载阻抗外接负载的阻抗。
α：槽距角相邻两槽之间的电角度（α=Z360∘p​）。
β：短距角；负载系数线圈节距比整距短的电角度；也用作负载系数。
δ：功率角；气隙同步电机里是功率角（功角）；结构里是气隙长度。
θ：功率因数角；温升功率因数角（电压与电流的相位差）；也用作温升。
Ψ：磁链与线圈各匝相链的磁通之和，Ψ=NΦ，单位 Wb（也写 Wb·匝）。电机里论"变化"用 Ψ（e=−dΨ/dt）。
ψ：内功率因数角同步电机里励磁电动势与电枢电流的夹角。
Λ：磁导磁阻的倒数，Λ=Rm​1​=lμS​，单位 H 或 Wb/A。用电感表达就是 L=ΛN2——电感与磁导成正比、与匝数平方成正比。
μ：磁导率（μ0​、μr​）B=μH 里的比例系数，单位 H/m，由介质决定。真空磁导率 μ0​=4π×10−7 H/m；相对磁导率 μr​=μ0​μ​，空气、铜、铝都近似取 1，铁磁材料可达 102∼105 倍。
σ：电导率材料的导电能力（电阻率 ρ 的倒数）。
η：效率输出功率与输入功率之比 η=P2​/P1​。
Φ：磁通（有效值）穿过某一面积的磁感应线根数，标量，单位 Wb。均匀磁场且磁感应线与面正交时 Φ=BS。教材符号表区分：Φ 有效值、Φm​ 最大值、φ 瞬时值。注意它是有向的，进出要相减。
Φm​：磁通最大值交变磁通的最大值（算铁耗、感应电动势幅值时用）。
Ω：机械角速度机械角速度（rad/s），与电角频率 ω 的关系是 ω=pΩ。
磁滞回线与磁化曲线反复磁化时上升与下降曲线不重合，围成的封闭曲线叫磁滞回线；充分饱和后最大的一条叫极限磁滞回线。软磁材料工程上用连接各回线顶点的曲线（基本磁化曲线）代表它的 B-H 关系，手册上查的就是这条。
下标约定本书语法：1 = 定子侧／一次侧／基波；2 = 转子侧／二次侧／二次谐波（3、4…类推）；+／−／0 = 正序／负序／零序及空载；∗ = 标幺值；a = 电枢；d／q = 直轴／交轴；f／m = 直流／交流励磁；k = 短路、换向极；N = 额定；st = 起动；av = 平均；v = v 次谐波；σ = 漏；max／min = 最大／最小。
上标约定′ = 归算值或瞬态值；′′ = 超瞬态值；⋅（点）= 相量（矢量）值。读带撇的公式前先确认它是"归算过来"还是"瞬态"。
∫：积分号沿一条线（或一个面）把各点的量累加。∫S​BcosθdS 就是把整个面上各点的磁通加起来；单重积分表示沿一条路径。
∮：环路积分沿闭合路径走一圈的积分。全电流定律 ∮l​Hdl=∑I=NI：磁场强度沿闭合回路的积分等于所匝链的电流。
Σ：求和号把离散的若干项相加。∑UM​=∑F：各段磁压之和等于各段磁动势之和（闭合磁路）。Σ 下标写从哪里加到哪里。
d：微分号表示"对某个量求变化率"：dΨ/dt 是磁链对时间的变化率；dB、dl、dS 分别是磁通密度、长度、面积上的微小量。它不是变量 d，而是运算记号。
∂：偏导号多元函数里只对某一个变量求导（其余暂时当常数）：∂B/∂t 是磁通密度对时间的变化率。
∞：无穷大极限记号，如"时间趋于无穷"。
∝：正比于表示两个量成比例（差一个常数因子）：ph​∝fBmn​ 说磁滞损耗与频率、最大磁通密度成正比。
→：趋于极限／趋向记号，如 t→∞、ui​→0。
×：乘号（叉乘）数乘或矢量叉乘：4π×10−7、F=Il×B。
⋅：点乘矢量点乘（结果为标量），也用作相乘记号：B⋅dS、21​B⋅H。
