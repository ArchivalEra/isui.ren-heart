命名与写作规则

  • 一节一个文件，放在 第NN章-章名/ 下，命名为 <节号>-<节名>.md（如 1.2-电机的磁路和磁路定律.md）；章级资料页用 第NN章-<名称>.md（如小结与习题）。
  • 每个文件内部固定：先「原书抄录」（按印书页码逐段抄印刷正文与原编号，公式用 LaTeX）再「解析」（机械做法、易错点、验算、与后续内容的接口），抄录与解析分开标注，文末写「本节完成边界」。
  • 验算独立：教材例题必须用精确算术重算（fractions.Fraction），差异逐项列出；书上没给答案的习题只登记题面与方法。
  • 图不复刻：教材的图只记图题与可辨标注（本仓不做图片线）。
  • 标题里不写 $…$（2026-09-24 踩坑）：右侧目录是从渲染后的标题取文本的，KaTeX 会把同一个符号吐三遍 （符号本体 + 原始 TeX + 渲染结果），目录里就会冒出 HHH、pFep_{Fe}pFe 这种重复。标题里的符号一律写平文 （H、μ、Φ、p_Fe）。
  • 符号气泡（2026-09-28 重构为环境包络模型）：正文里把记号写成 [B]{#sym-B} 令牌；词条在 0.0 符号入门 的 :::glossary-dict 围栏里维护。词条标题与释义都写 LaTeX （$B_r$、$\frac{60f}{p}$、$\mu_0$）——构建期渲染成真公式，不要再用 unicode 上下标（B_r、μ₀） 或斜杠分数（P₂/P₁）凑。词条按「符号包」组织（包注册表与课程环境表在 站点/符号环境.mjs）： 本页是「电机学:符号」包，词条 id 在包内唯一；别的课程要用这里的符号，把它的课程环境变量指到本包 （整包复用）或写 […]{#电机学:sym-B} 包限定令牌（强制锚定单个符号）。解析零回退——被锚定的 包里没有的 id 原样保留并给构建期警告。「详细 ↗」落到本页符号总表里该词条那一行。
  • 符号总表（2026-09-24）：本页围栏写成 :::glossary-dict table，构建期就在围栏位置渲染出一张 122 行的表（每行 id="<词条id>"），气泡的「详细 ↗」才有个逐符号的落点。族的折叠面板讲「怎么记」， 总表管「查得到」。
    新增符号＝照教材符号表补一行，表与气泡同时生效，不用改代码。
  • 自动取词（2026-09-24 加）：同一个文件里再用一个 :::glossary-match 围栏声明写法—— id | 正文形式（、分隔） | TeX 形式（、分隔，可省），声明过的符号在正文里裸写、在公式里出现都会自动可点， 不必手写令牌。TeX 形式还可以写成 /…/ 正则（模式原子，2026-09-28 加）——一族记号（如行列记号 $r_1$、正负号 (−1)i+j）一条声明全覆盖。没声明的词条仍要手写令牌（自动取词只在内容侧点过名时 发生，不会把每个字母都上色）。正文侧不碰代码、公式、链接、标题与已有令牌，并跳过「B 级绝缘」「B 图」这类场合。 只声明形式、没有词条内容的 id 不参与取词（构建期会警告）。
  • 禁止反人类解析：解析里不出现「试探／凑／巧妙看出」这类没写完的步骤；教材本身的「试探法」一律翻译成两点线性插值的机械步骤（见 1.2 节与小结页）。
