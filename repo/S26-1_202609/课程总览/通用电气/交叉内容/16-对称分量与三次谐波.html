16-对称分量与三次谐波
依赖
本篇打通「相量复数旋转算子 a=ej120∘」到《电机学》三相非对称与饱和非线性畸变分析：先用对称分量法把任意不对称三相向量拆成正/负/零序三套单相电路，再顺着 3×120∘=360∘ 的零序同相本质，一次讲透铁芯饱和、尖顶/平顶波互逆、组式 vs 心式（芯式）分岔与「三次谐波三道防线」。






上游模块锚点（点击直达）本篇取用内容


励磁饱和与波形互逆10-15 励磁电流波形 / 2.3.1 #2-3磁通正弦 ↔ 电流尖顶；电流被迫正弦 ↔ 磁通平顶 → 电动势尖顶


三次谐波与心/组式分岔10-29 四·磁路系统 / 七·Y 接无中性线 / 2.3.1 #2-1 / #2-4组式磁路独立（45%∼60% 过电压禁用 Yy）；心式（芯式）磁路相关且 ≤1800 kVA 可用


三道防线与对称分量法11-05 二·三道防线 / 五·对称分量法一次侧 → 二次侧 → 心式结构三道防线；a=ej120∘ 拆解正序/负序/零序








跨页用字与数值口径统一注记：课堂笔记 10-29 与 11-05 口述写作「心式」，教材与 2.3.1 作业 写作「芯式」，二者为同一结构同义词；组式采用 Yy 时二次侧三次谐波电势占比，10-29 与 2.3.1 写 45%∼60%（11-05 笔记口述作 45%∼65%），两处一并登记。




一、对称分量法：a=ej120∘ 把不对称化回三套单相
当三相电源、变压器或负载不对称时，15 篇 依赖对称性的单相等效电路失效。引入复数单位旋转算子 a=ej120∘=−21​+j23​​（满足 a2=ej240∘、a3=1、1+a+a2=0），任意一组不对称三相相量 (A˙,B˙,C˙) 可唯一分解为三组对称分量之和（11-05 五·对称分量法）：


A˙=A˙1​+A˙2​+A˙0​,B˙=a2A˙1​+aA˙2​+A˙0​,C˙=aA˙1​+a2A˙2​+A˙0​


反解 A 相三序分量（B、C 相按各序相序推得）：






序分量相序特征各序提取公式现场/后续继保对应


正序（下标 1）A1​→B1​→C1​ 依次滞后 120∘A˙1​=31​(A˙+aB˙+a2C˙)正常对称运行工况


负序（下标 2）A2​→C2​→B2​ 反序（B2​ 超前 A2​）A˙2​=31​(A˙+a2B˙+aC˙)两相短路等不对称故障分量


零序（下标 0）三相等幅值、严格同相位A˙0​=31​(A˙+B˙+C˙)=B˙0​=C˙0​CT 并联取 3I˙0​、PT 开口三角形取 3U˙0​






二、为什么三次谐波天然变成「同相零序」，引发铁芯畸变
    

  1. 相位倍频规则（2.3.1 #2-2）：基波三相互差 120∘，则 3 次谐波频率与电角度翻 3 倍，三相三次谐波相角差变为 3×120∘=360∘≡0∘。因此三相三次谐波严格同相（天然就是零序分量）。
    2. 

  2. 因果链与波形互逆（2.3.1 #2-4）：
      

    • 正弦磁通需要励磁电流在饱和 B-H 曲线上呈尖顶波（含 3 次谐波）；
      • 

    • 一旦 Y 接无中性线堵死了同相三次谐波电流的通路（I03​=0），励磁电流被迫变成正弦波 ⟹ 饱和曲线将其压成含 3 次谐波的平顶主磁通 ⟹ 求导后感应出尖顶形二次相电动势（务必咬准因果：电流被迫正弦在先，磁通平顶在后！）。
      • 

    

    3. 



三、组式 vs 心式（芯式）分岔与「三次谐波三道防线」
面对三次谐波磁通/电动势威胁，工程判定永远只有一条主线：三次谐波电流有没有闭合回路，依次过 11-05 二·三道防线：


    

  1. 第一道防线（一次侧接线）：一次侧选用 单相独立、YN（带中性线） 或 D（三角形环内闭流） ⟹ 三次谐波电流在一次侧自行流通，磁通直接保持正弦，问题根除；若一次侧选了无中性线 Y，失守。
    2. 

  2. 第二道防线（二次侧接线）：一次失守时，二次侧选用 d（三角形环流）、yn（注意不可空载运行，必须带负荷才有通路） 或专门加装不对外供电的平衡三角形绕组 ⟹ 靠全电流定律由二次侧补齐三次谐波磁动势，主磁通仍保正弦；若二次侧又选 y（即 Yy 接线），两道防线全失守。
    3. 

  3. 第三道防线（铁心磁路结构）：Yy 接线无三次谐波电流通道，后果由磁路结构决定：
      

    • 组式（三台单相独立铁心）：三次谐波磁通顺利在低磁阻主铁心内闭合，谐波磁通极大 ⟹ 二次相电动势三次谐波高达基波的 45%∼60%（11-05 笔记口述作 45%∼65%），造成① 相电动势波形严重畸变 与 ② 过电压危及绝缘 ⟹ 组式严禁用 Yy（思考题 3-3 第一问两条缺一不可）。
      • 

    • 心式 / 芯式（三铁心柱磁路相关）：三相三次谐波磁通同相零序，在铁心柱间互相顶住借不了道，只能被迫穿出铁心经绝缘油、空气、油箱壁闭合，路径磁阻极大 ⟹ 谐波磁通被压得很小、电动势接近正弦；代价是油箱壁等铸铁未叠片构件产生 9 倍频（∝f2）涡流局部过热，加速绝缘老化 ⟹ 心式（芯式）可用 Yy，但容量必须限制在 ≤1800 kVA、低电压配电变压器（思考题 3-3 第二问）。
