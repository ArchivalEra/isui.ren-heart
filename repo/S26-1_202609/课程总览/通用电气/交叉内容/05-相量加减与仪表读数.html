一、同频相量加减铁律：乘除走极坐标，加减回直角坐标

由高数复数代数可知，两个极坐标复数 A˙1​=A1​∠ψ1​ 与 A˙2​=A2​∠ψ2​ 不能直接把模相加、把角相加（即 ∣A˙1​+A˙2​∣=A1​+A2​，arg(A˙1​+A˙2​)=ψ1​+ψ2​）。按 11-09 笔记，固定四步走：

  1. 极坐标拆直角坐标：A˙k​=Ak​cosψk​+jAk​sinψk​=ak​+jbk​；
  2. 实虚各加各：A˙=(a1​+a2​)+j(b1​+b2​)（求差 A˙1​−A˙2​ 则作 A˙1​+(−A˙2​)，实虚部分别相减）；
  3. 重算模与象限角：∣A˙∣=(a1​+a2​)2+(b1​+b2​)2​，按 03 篇四象限表定 ψ；
  4. 图形校验（平行四边形定则）：把 A˙1​,A˙2​ 从原点画出，邻边平行四边形对角线即为 A˙1​+A˙2​；做减法 A˙1​−A˙2​ 时将 A˙2​ 反向旋转 180∘ 再合成。

二、为什么电压表与电流表读数不能直接加减

交流电压表与电流表测量的是周期交变信号的有效值模长（U=∣U˙∣、I=∣I˙∣），丢掉了相位角信息：

  • 瞬时值 u(t),i(t) 与相量 U˙,I˙ 在同频条件下严格满足 KCL 和 KVL：∑I˙k​=0、∑U˙k​=0；
  • 有效值 Uk​,Ik​ 是标量模长，一般不满足 KCL/KVL，只能满足三角不等式 ​∣A1​∣−∣A2​∣​≤∣A˙1​+A˙2​∣≤∣A1​∣+∣A2​∣。

具体退化规律只需盯紧三个夹角（设两分相量夹角为 Δψ）：

两分相量关系元件属性判断合成有效值公式题库典型样题
同相（Δψ=0∘）两支路/元件性质完全相同（如同为纯电阻）A=A1​+A2​（唯一可直接相加）选 18：3 A+4 A=7 A⟹Z2​ 为纯阻
正交（Δψ=±90∘）纯电阻 R 配纯电抗（L 或 C）A=A12​+A22​​（勾股定理）选 3、选 11、选 26
反相（Δψ=180∘）纯电感 L 配纯电容 CA=∣A1​−A2​∣（直接相减抵消）11-16 例题二：UL​,UC​ 抵消

三、相量图参考量选法：串联找电流，并联找电压，混联从最远端倒推

画相量图前不要凭空乱画，先看电路结构选定唯一的「参考基准（固定放在 0∘ 水平右向）」：

  1. 纯串联（串联相量图）：各元件电流相同，选电流 I˙ 为参考：U˙R​ 与 I˙ 同相（水平）、U˙L​ 超前 90∘（竖直向上）、U˙C​ 滞后 90∘（竖直向下），合成得总电压三角形 U=UR2​+(UL​−UC​)2​。
  2. 纯并联（并联相量图）：各支路电压相同，选端口电压 U˙ 为参考：I˙R​ 与 U˙ 同相（水平）、I˙C​ 超前 90∘（竖直向上）、I˙L​ 滞后 90∘（竖直向下），合成得总电流三角形 I=IR2​+(IC​−IL​)2​。
  3. 混联（先并后串，如 计 10）：若用总电源电压当基准往往算不出，必须从并联子块电压 U˙p​ 起步！先用 U˙p​=Up​∠0∘ 画出各并联支路电流并合成为干路电流 I˙，再往回画干路阻抗压降 RI˙ 与 U˙p​ 相加得到电源总电压 U˙。

四、真题演算（对齐《习题册第五章》）

  1. 正交仪表三角形知二求一（选 3、选 11、选 26）：
    • 选 3（习题册第五章#选-3-图-5-2）：R 与 C 并联，干路读数 I=10 A、R 支路 I1​=6 A。因 I˙C​ 超前 U˙ 90∘ 而 I˙R​ 同相，二者正交 ⟹I2​=I2−I12​​=102−62​=8 A（不能错选 10−6=4 A 或加和 traps）。
    • 选 11（习题册第五章#选-11）：R 与 L 串联，总电压 U=30 V、UL​=18 V。正交得 UR​=302−182​=24 V。
    • 选 26（习题册第五章#选-26-图-5-10）：R 串 jXL​，UR​=3 V、UL​=4 V⟹U=32+42​=5 V。
  2. 有效值直接相加反推同相元件（选 18）：
    • 选 18（习题册第五章#选-18-图-5-7）：两支路并联，Z1​=R 支路 A1​=3 A、Z2​ 支路 A2​=4 A，干路读数恰好 A0​=7 A=3+4。说明 I˙2​ 与 I˙1​ 相角差 Δψ=0∘（同相），因此 Z2​ 只能也是纯电阻（若为电感或电容则会算出 32+42​=5 A）。
  3. 混联相量图参考量倒推（计 10）：
    • 计 10（习题册第五章#计-10-图-5-31）：干路电阻 R=5 Ω 串联并联块「−jXC​ 并（R2​ 串 jXL​）」，已知总电压有效值 U=200 V、I1​=10 A、I2​=102​ A、R2​=XL​，求 I,XC​,XL​,R2​。
    • 第一步定参考量：设并联块电压 U˙p​=Up​∠0∘ 为基准。
    • 第二步画并联电流：容性支路超前 90∘，得 I˙1​=10∠90∘=j10 A；感性支路因 R2​=XL​，阻抗角 φ2​=arctan(XL​/R2​)=45∘，电流滞后电压 45∘，得 I˙2​=102​∠−45∘=10−j10 A。
    • 第三步 KCL 合成干路电流：
      I˙=I˙1​+I˙2​=j10+(10−j10)=10+j0=10∠0∘ A
      恰与 U˙p​ 同相（电路等效成纯阻串联，几何上两个虚部 +j10 与 −j10 恰好抵消）。
    • 第四步反推电压与参数（Octave 复核 I=10, Up=150, XC=15, R2=XL=7.5）：干路电阻压降 U˙R​=IR=10×5=50∠0∘ V，因 U˙R​ 与 U˙p​ 同相 ⟹Up​=U−UR​=200−50=150 V。从而：
      XC​=I1​Up​​=10150​=15 Ω,∣Z2​∣=I2​Up​​=102​150​ Ω⟹R2​=XL​=2​∣Z2​∣​=7.5 Ω
