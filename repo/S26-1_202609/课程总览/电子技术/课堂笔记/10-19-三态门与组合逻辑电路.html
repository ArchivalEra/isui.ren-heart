10-19-三态门与组合逻辑电路

这节课在干什么：上次课讲到三态门（转写读作「三扇门」「三太门」）没讲完就下课了，本讲先把它收完，再进第七章的后半段——组合逻辑电路怎么分析、怎么设计。要会五件事： ① 三态门的第三种状态从哪来（二极管钳位把输出管全部关断 → 悬空）； ② 三态门的两个用途（总线分时传输、双向传输）； ③ 冗余输入端的两种接法； ④ 组合电路分析的四步（写式 → 化简 → 状态表 → 归纳功能），三个例题各对应一类考点； ⑤ 组合电路设计的三原则与流程（逻辑抽象 → 状态表 → 最小项式 → 卡诺图 → 门电路），两个例题。收尾讲实验一怎么测。

行政与考核

  • 考试：分析或设计"肯定有一道大题要考"，样式就是本次三个分析例题、两个设计例题，具体电路会换。
  • 实验：周三第 8–9 节，电子技术实验室二（转写对实验室门牌有 302／304／306 三种读数，不择一断言）；全程 6 个实验，一个实验两节课；现场验收，完成得又快又好的平时成绩高；每人每个实验交一份电子版报告，上传学习通；实验指导书也在学习通上（口述为第九章）。
  • 报告要求：模板里的红字要删；逻辑图、表达式、测试方法自己写；不许互相抄袭、不许 AI 直接生成（教师说生成式文本的排版痕迹一眼看得出来）；AI 可以做描述、总结、归纳的辅助。

题号条目

分析例一：四个与非门拼成的电路

题面（教师逐门报的连线，四只二输入与非门）：

门输入输出
G1​A、BY1​=AB
G2​A、Y1​Y2​=AY1​​
G3​B、Y1​Y3​=BY1​​
G4​Y2​、Y3​Y=Y2​Y3​​

解析（教师口径：每一步都必不可少）：

  1. 逐门标变量、写逻辑式。先给每只门的输出起名（Y1​、Y2​、Y3​，末级叫 Y），再按门的类型逐个写式——非门直接取非，与非门／或非门就把输入相与（相或）后整体取非。
  2. 化简。末级 Y=Y2​Y3​​：先用德摩根把最外面那条最长的反号拆开，与非变与或——Y2​Y3​​=Y2​​+Y3​​。而 Y2​​ 正好是 Y2​ 反号里包着的东西，也就是 AY1​；Y3​​=BY1​。于是
    Y=AY1​+BY1​=Y1​(A+B)
    代回 Y1​=AB=A+B，用德摩根展开：
    Y=(A+B)(A+B)=AB+AB
  3. 列状态表：A、B 相同取 0，相异取 1。
  4. 归纳功能：这就是异或——符号是方框里写 =1，表达式写作 A⊕B（圆圈里一个加号）。

这一题在讲什么：这是"给电路求功能"的标准走法——每只门一个中间变量，式子里就不会串错。教师强调这一条是防错的关键：不分中间变量、一步把式子写到底，几乎必错。异或门是与后面加法器（半加器、全加器）直接相关的底子。

以真值表复核：Y 在 (0,1)、(1,0) 取 1，其余取 0，与异或一致。

分析例二：两只非门加三只与非门

题面：G2​、G3​ 分别是 A、B 的反相器（输出 A、B）；G1​ 输入 A、B，输出 Y1​=AB；G4​ 输入 A、B，输出 Y2​=A⋅B；末级 Y=Y1​Y2​​。

⚠ 转写把 G4​ 的两路输入读成"A 跟 B 非"，含糊；按"两只非门 + 三只与非门"的门数，两只非门的输出 A、B 正好喂给 G4​，且只有这样接才得出教师给的同或结果。

解析：

  1. 逐门写式：G2​、G3​ 各是一只非门，输出 A、B（两只非门正好喂 G4​ 的两路输入）；Y1​=AB，Y2​=A⋅B=A+B，末级
    Y=Y1​Y2​​=AB⋅(A+B)​=AB+A+B​=AB+AB
  2. 化简只走德摩根定律一条线：逐层拆反号、逐步合并，最后只剩 AB+AB——两项，两项都是二变量与项。
  3. 列状态表：相同取 1、相异取 0。
  4. 归纳功能：同或（转写读作"囤货""同货"）。同或的符号是在异或符号外面再加一个小圆圈——也就是说同或就是异或取反，两个运算永远相反。
  5. 教师给的用途名：判一致电路。判断两个变量是否一致，一致输出 1、不一致输出 0，数字系统里常用。

这一题在讲什么：与例一配成一对——同一种"逐门写式 → 化简 → 状态表 → 归纳"，结果落在同或上。教师在这里顺手纠了一个看图习惯：异或符号没有输出小圆圈，同或有，两个符号只差这一个圈，考试看错就全错。

分析例三：给 A、B 波形，加一个控制端 C

题面：C 经一只非门 G2​ 得 C；G1​=A⋅C；G3​=B⋅C；末级 Y=G1​G3​​。

解析（教师先抓"哪只门受 C 管"，分两种状态讨论）：

  • C=1：G1​ 的输入 C 为 1，它处于打开（有效）状态，输出 A；G2​ 输出 C=0，G3​ 的输入含 0，被封锁，输出恒为 1。末级 A⋅1=A——电路只传 A。
  • C=0：G1​ 的输入含 0 → 被封锁，输出恒 1；G2​ 输出 C=1 → G3​ 打开，输出 B。末级 1⋅B=B——电路只传 B。

合起来写成一条式子：

Y=AC⋅BC=AC+BC

这一题在讲什么：这是数据选择器的原理——一个控制端在原信号与另一信号之间二选一。教师把它挂在"波形题"上考：给了 A、B 的波形和 C 的状态，输出波形就是把 C=1 的时段截 A、C=0 的时段截 B 拼起来。三只与非门加一只非门就是最小规模的选择器。

以真值表复核：C=1 时 Y=A、C=0 时 Y=B，与 AC+BC 一致。

设计例题一：三人表决器

题面（功能描述）：三人各投一票，多数通过——三人中 2 票及以上同意则表决通过，否则不通过。用门电路实现。

解析（设计比分析多一步"逻辑抽象"，教师把它比作数学建模）：

  1. 逻辑抽象：三个人 → 三个输入变量 A、B、C；同意取 1、不同意取 0。输出 Y：通过取 1、不通过取 0。"多数有效"落到数字上就是输入里 1 的个数 ≥ 2。
  2. 列状态表：1 的个数 ≤ 1 的行全取 0（000、001、010、100），≥ 2 的行取 1（011、101、110、111）。
  3. 写最小项式：把取 1 的行提出来相或——
    Y=ABC+ABC+ABC+ABC=∑m(3,5,6,7)
  4. 卡诺图化简（设计里默认用卡诺图，比公式法快）：四个 1 两两成对圈三组——红色圈消去 C 留 AB、绿色圈消去 A 留 BC、另一组消去 B 留 AC，三圈用或号相连：
    Y=AB+BC+AC
  5. 画电路：三只与门 + 一只三输入或门。
  6. 换成单一门型：对 Y=AB+BC+AC 取两次反，再用德摩根把大反号推成与非-与非：
    Y=AB⋅BC⋅AC
    三只二输入与非门 + 一只三输入与非门，共 4 只，只用一种门。教师判它优于与或实现——同一块芯片就能装下。

这一题在讲什么：这是"从功能到电路"的完整一遍，也是**"最简与或式不是终点"**的示范：功能一样、器件更省，才是好实现。教师顺带给做题口径——题目没点名要哪种门，画与或实现就算对；点名"用与非门实现"就必须化简到与非-与非形式。他还说这条在日后工作中同样成立：手头有什么器件，就往那种器件的形式上化。

以真值表复核：与非-与非实现与"1 的个数 ≥ 2"逐行一致。

设计例题二：十字路口交通灯故障报警电路

题面（功能描述）：红、黄、绿三盏灯，正常是任一时刻恰有一盏亮；故障是全灭、或两盏以上同时亮。要求故障时报警输出 F=1，正常时 F=0。

解析：

  1. 逻辑抽象：三盏灯 → R、Y、G 三个变量，亮取 1、灭取 0；输出 F：有故障取 1、无故障取 0。据此正常态只有三种：001、010、100。
  2. 列状态表：
RYGF说明
R">0Y">0G">0F">1全灭
R">0Y">0G">1F">0正常（绿）
R">0Y">1G">0F">0正常（黄）
R">0Y">1G">1F">1黄绿同亮
R">1Y">0G">0F">0正常（红）
R">1Y">0G">1F">1红绿同亮
R">1Y">1G">0F">1红黄同亮
R">1Y">1G">1F">1三灯全亮
  1. 写最小项式：F=∑m(0,3,5,6,7)=RYG+RYG+RYG+RYG+RYG。
  2. 卡诺图圈 1：m3​ 与 m7​ 成对 → YG；m5​ 与 m7​ 成对 → RG；m6​ 与 m7​ 成对 → RY；m0​ 是孤零零的一格，没有伙伴，只能单独圈 → RYG。
    F=RYG+RY+RG+YG
    教师专门点了这一处：孤立的那一格最容易被漏掉（漏掉就等于把"全灭"判成正常，报警就失效了）。
  3. 一次实现的代价：上式要三只非门 + 四只与门（其中一只三输入）+ 一只四输入或门，门的种类和数量都多，电路繁杂。
  4. 换思路圈 0：0 只有三格（m1​、m2​、m4​），圈 0 更省。
    F=RYG+RYG+RYG
    这三格两两都差两位，谁也不能合并，所以是三个三变量与项。圈 0 得到的是 F，返回时要再取一次非——教师特别强调这个非号不能丢：
    F=RYG+RYG+RYG​
    三只非门 + 一只与或非门，共 4 只门，比第 5 步少了一大半。

这一题在讲什么：三件事一次讲完——①圈 0 与圈 1 是对称的两条路，1 多圈 1、0 多圈 0，但圈 0 得到的是反函数，返回必须再取非；②孤立格不能漏；③同一个逻辑功能有不同形式的函数式，就有不同形式的电路，选门型时要照着"器件少、种类少"去挑。教师收尾说要尽量用同一集成器件实现。

以真值表复核：F=RYG+RY+RG+YG 与"恰有一盏亮则 0、否则 1"逐行一致。

没编号但讲了的知识点

三态门的第三种状态从哪来

普通 TTL 与非门只有高、低两种输出。三态输出与非门（简称 TS 门，转写读作"三扇门""三太门""三块门"）在普通 TTL 与非门上加了一只二极管和一只非门：

  • 控制端 EN（转写读作"enc""enco""dn"）先过一个反相器，反相器的输出接到普通 TTL 与非门内部那一路输入（教师称这一路为 C 输入）；
  • 一只反接的二极管，阳极接 T2​ 的集电极（也就是 T3​ 的基极），阴极接反相器输出；
  • 于是控制端能通过这只二极管把 T3​ 的基极钳位到低电平（转写读作"前卫"）。

两种状态分开看：

控制端 EN反相器输出二极管内部输出
EN">0（低电平有效）1截止（阴极是高电平，不足以导通）这条支路相当于断开，对后面没有影响；原来那一路 C 输入被保持为 1与普通 TTL 与非门相同，两变量与非 Y=AB
EN">10导通T3​ 基极被钳到低电平T3​、T4​ 截止（两管串联要 1.4 V 以上才导通），T5​ 也截止

T3​、T4​、T5​ 全截止时，输出端既不接电源也不接地，是悬空的——对地呈现很高的电阻，这就是高阻态（转写读作"高组织""高姿态""高稳态"）。高阻就是第三种状态，三态门因此得名。

符号怎么认：与非门符号的侧面多一个倒三角，那是三态输出的标记；控制端在本体上，控制端上带小圆圈 = 低电平有效（EN 取 0 时是普通与非功能、取 1 时高阻），不带小圆圈 = 高电平有效（反过来）。两种符号除这个圈以外完全一样。

功能表（教师把这个控制引脚记作 C，讲的是高电平有效的那只符号）：

C输出
C">0高阻（输出悬空）
C">1正常的与非门工作状态：Y=ABC（C 取 1 后就是两变量的 AB）

教师强调 C 与 EN 恰好反相——同一只门换成另一个符号，有效电平就反过来；读图先看控制端上有没有小圆圈。

用途一：一根总线分时传多路数据

把 8 只三态门同时挂在同一根总线上，控制端分时段使能：同一时段内有且只有一只三态门的控制信号有效（教师原话"有且一个"），只有它把前面的输入送到总线；其余 7 只全部处于无效（高阻）状态，输出悬空，挂不到总线上、不干扰总线。

  • 好处：一根线代替八根线，省硬件资源；CPU 引脚不够、没法并行时就用这个办法；
  • 工作方式：固定周期内轮流打开、轮流扫描，扫到的状态存进寄存器，再由控制器内部的 CPU 计算；
  • 对应的现实系统：计算机内部总线（各种设备都挂在总线上按时序传输）、PLC 的轮询采样——教师点明"你们后面学 PLC 就是这个方式"。

用途二：控制传输方向（双向传输）

两只三态门背靠背接在同一对端点 A、B 之间，控制端记作 E：一路直接接到 G1​ 的 EN，另一路经一只非门接到 G2​ 的 EN——所以两只永远只有一只使能：

控制端 EG1​ 的 ENG2​ 的 EN结果
E">0G1​ 的 EN">0 → 使能G2​ 的 EN">经非门得 1 → 高阻信号 A→B
E">1G1​ 的 EN">1 → 高阻G2​ 的 EN">经非门得 0 → 使能信号 B→A

教师把链路一步步点过：E=0 时 A 先经三态门反相成 A、再经后一级非门反相回 A，送到 B；E=1 时反过来，B 经两处反相回到原值送到 A。级联里两次反相互相抵消，因此传过去的是原信号。

只要拨一下控制端的电平，就能决定数据往哪个方向走。这就是三态双向缓冲器的原理；总线上既能发又能收，靠的就是它。

多余输入端的处理

集成与非门常有四个输入端，实际只用一两个时，其余的不能随便留：

门型多余输入端接到依据
与门、与非门高电平 1A⋅1=A，不改变输出
或门、或非门低电平 0（接地）A+0=A，不改变输出
  • 另一种做法：把多余输入端并联到正在使用的输入端上（悬空的几路全并过去）——前提是前级输出端驱动能力足够（电流、电压都够）；
  • 教师提醒两种门型的接法正好相反，接错就把功能改了，这是实验里最容易犯的错之一。

组合逻辑电路与时序逻辑电路

数字逻辑电路整体分两块，判据是有没有记忆元件：

组合逻辑电路时序逻辑电路
记忆元件无，只有与、或、非、与非、或非这些基本门有——触发器（第八章讲），状态能保存
输出只由当时的输入决定，与原有状态无关；输入一变输出跟着变除当时的输入，还与原状态有关；原状态影响下一个状态
典型电路加法器、编码器、译码器、比较器、数据选择器、数据分配器寄存器、计数器、脉冲分配器
  • 系统框图：多输入、多输出，输入端与输出端之间有逻辑函数关系，框里没有储存元件；可以多输入单输出，也可以多输入多输出。
  • 转写把"编码器"读成"解码器"，把"时序"读成"持续"——这两个词后面还要用，先记住正确写法。

分析的四步（教师口称"五步"，把"已知电路"也算作一步）

已知电路 → 求功能，与分析互逆的是设计。

  1. 写逻辑式：给每只门的输出标一个中间变量（Y1​、Y2​……），逐门写出表达式，推到最终输出；
  2. 化简：公式法（德摩根为主）或卡诺图法，二选一；
  3. 列状态表：把输入的全部组合与对应输出列全；
  4. 归纳功能：从状态表看出输入输出的规律，用一句话说出来（如"相同为零、相异为一"）。

教师的话：每一步都不能省，只有列出状态表才能看出规律；直接由式子猜功能容易猜错。写式子时"每只门一个变量"是防错的关键，一步一步推到总输出，"这样写出的逻辑式肯定不会错"。

设计的三原则与流程

已知功能 → 求电路，比分析多一步逻辑抽象。

流程：逻辑抽象（建模：定输入输出变量、定 0/1 的含义）→ 列状态表 → 写最小项式 → 卡诺图化简（设计里通常用卡诺图）→ 按选定门型画电路。

三原则（判"哪个实现更好"的标准）：

  1. 器件最少：能用一只不用两只，能用两只不用三只；
  2. 器件种类最少：能用一种门实现就绝不用两种——好处是同一块芯片就能装下，不必几块芯片互连；
  3. 连线最少：布线简洁，线与线之间干扰少，可靠性高。

三原则里第 2 条是本讲反复用到的判据：三人表决器的与非-与非实现一种门搞定，交通灯的圈 0 实现把 8 只门压到 4 只。

实验一：集成门电路的测试（周三做）

  • 器件：74LS00 一类 14 脚双列直插芯片，含与非门、或非门、三态门、OC 门；
  • 认引脚：靠芯片上的缺口定向——缺口上方一端是 14 脚 = 电源 VCC​（+5 V）、7 脚 = 地。实验箱上有 +5 V、+15 V、−15 V、±5 V 多路电源，接反芯片就烧；
  • 一组门的引脚：如 12、13 是输入、11 是输出；只测其中一组即可，自己记牢用的是哪一组；
  • 测法：万用表电压档，红笔接输出脚、黑笔接地，读出电压值；先记高低电平的 0/1 状态，再填电压值。输入信号由滑动变阻器的中间端引出；
  • 电压传输特性曲线：横坐标输入电压、纵坐标输出电压，一条线——不是把每个分布点连成折线，这是最容易画错的地方；
  • 三态门：额外测一次高阻态下输出端的电压；
  • OC 门：输出端必须先接一只上拉电阻再接到 +5 V。集电极开路，不接上拉时高电平状态下输出电流极小，测出来的电压很低，不是标准高电平；
  • 报告：模板里的红字删掉，逻辑图、表达式、测试方法自己写（测试方法照指导书那段改写、换芯片型号），结果表填实测值，再写分析。

转写与术语

本次转写的同音错误密集在器件名与门的类型上，照原文抄会抄错：

  • 「TCL／tdl」→ TTL（晶体管-晶体管逻辑）。
  • 「3派分之2／ts分成二」「三开门／三扇门／三太门」→ 三态门（TS 门），三态 = 高电平、低电平、高阻。
  • 「高组织／高姿态／高稳态」→ 高阻态（输出悬空）。
  • 「Enco／enc／emc／EE非／一推」→ EN／EN（三态门的控制端）。
  • 「飞门／飞轮／反向器」→ 非门（反相器）。
  • 「前卫的低电平」→ 钳位到低电平（T3​ 基极被二极管钳住）。
  • 「集液极／阶级／积极」→ 集电极／基极。
  • 「铝货门／与飞门」→ 与非门；「部门／余非」→ 与门／与非。
  • 「囤货／同货」→ 同或；「易货」→ 异或。
  • 「卡路图／卡波图／卡通图／看到图」→ 卡诺图。
  • 「解码器」→ 编码器（组合电路的一类）；「持续逻辑电路」→ 时序逻辑电路；「记忆文件／记忆邮件」→ 记忆元件。
  • 「看一致电路」→ 判一致电路（同或的用途名）。
  • 「放大电阻／商家电阻」→ 上拉电阻（OC 门输出端用）。
  • 「括号相连」→ 或号相连（各圈／各项之间用或）。
  • 「或与非式／过于黑市」→ 或非-或非式（交通灯那一步的口述，指把表达式化成或非形式；门数读不清，本页不落数字）。
  • 教师把分析说成"总共五步"，五步是：已有逻辑电路 → 写逻辑式 → 化简 → 列状态表 → 归纳功能（第一步是题目已给的条件，所以动作只有四个）。
