11-09-555定时器与共射放大
这节课在干什么：一晚跨两半。前半（00:00–23:29）收尾数字电路：555 定时器的内部结构（两个比较器 C1/C2、三等值电阻分压、基本 RS 触发器、放电管 T）、引脚 2/5/6/7 的功能与比较判据，并用它搭单稳态触发器（外接 R₁C 充放电、脉宽 TP​≈1.1RC）。后半（24:15 起）开模电：共发射极放大电路——交直流分离的思路、放大电路三大指标（放大倍数、输入电阻、输出电阻）、直流通路与静态工作点 Q 的估算法与图解法、微变等效电路法（r_be 公式与受控源），动态三指标 Au​、ri​、ro​ 全部推出。末尾（1:22:20）下课，其后是学生闲聊。


行政与考核
    

  • 555 不进期末大题（22:47）：「555 不考，但是作业题里头是有的……就是一个概念」，TP​ 的计算「可能会有一个填空或者选择题」；并反问学生「大题考什么」——即 555 相关内容按概念与 TP​ 口算准备，不为大题。
    • 

  • 模电复习范围（24:15–26:20）：「回归到模电这一部分」——重点共发射极放大电路，顺带梳理共集电极、多级放大、差分放大、功率放大；考试重点也是共发射极，有计算题。要求掌握：静态工作点估算、微变等效电路分析法，了解输入电阻/输出电阻/多级放大/频率特性、互补功率放大与差动放大工作原理；差分部分要会共模/差模信号的概念与互换公式（两个输入信号求共模与差模）；场效应管非重点、公式了解即可。
    • 

  • 实验安排（23:57–24:09）：下周一（11-16）「如果没有其他课程安排」继续做实验三。
    • 

  • 课间在 39:04–42:38(下一讲内容从 42:38 开始)。课末有一段与学生关于班务的对话，不复录。

题号条目
例题：单稳态触发器（555 外接 R₁C）
题面（教师口述）:555 的 2 引脚接触发脉冲,6 与 7 引脚并联后接电容 C,电容另一端接地;C 的上端再经电阻 R₁ 接电源 U_CC。


解析(完整链条,条件齐全,可逐步复核):


    

  1. 稳态(无触发):2 引脚无脉冲时为高电平,高于 31​UCC​ ⇒ C2 输出 1。上电后电源经 R₁ 给 C 充电，uC​ 升过 32​UCC​ ⇒ C1 输出 0 ⇒ 触发器复位 Q=0、Q​=1 ⇒ 放电管 T 导通 ⇒ C 经 T 放电到 0 并保持——两个比较器输出 1、1,触发器保持,电路稳定在 uO​=0 的稳态。教师话里说的「D非应该是零,所以它应该是一开始是零状态」即此处 Q​=1 → T 导通 → uC​=0。
    2. 

  2. 触发翻转(暂稳态开始):2 引脚来一个低电平脉冲,低于 31​UCC​ ⇒ C2 输出 0 ⇒ 触发器置 1(Q=1、Q​=0) ⇒ T 截止 ⇒ C 停止放电,电源经 R₁ 给 C 兄电，uC​ 从 0 上升。此时 uO​=Q=1，输出高电平——电路进入暂稳态。
    3. 

  3. 自动返回:脉冲过去后 2 引脚回到高电平,C2 回 1；C 充到 32​UCC​ 时 C1 输出 0 ⇒ 复位 Q=0 ⇒ T 导通 ⇒ C 放电回 0 ⇒ 回到稳态。教师原话:「加了一个脉冲以后,我们的电路由稳定的状态翻转为暂稳的状态……停留一段时间以后……它又会自动返回到这个稳定的状态」(14:16)。
    4. 

  4. 脉宽公式:暂稳态持续时间由充电到 32​UCC​ 决定:

    TP​=RCln3≈1.1RC
    
教师原话「2C乘以log3啊乘以log3,那么约等于 1.1 的 R C」——「2C」即 RC 的口误/转写失真,公式为 TP​=RCln3≈1.1RC。暂稳态的宽度和「选取的这个 RC」有关。
    5. 

  5. 走廊照明灯应用(20:47–22:30):把开关接在 2 引脚。未按时 uI​ 高电平(>⅓U_CC)电路处稳态、灯灭;按下瞬间 2 引脚为低电平,触发暂稳态,输出高电平驱动照明灯;RC 数值设置好,「过个 10 秒……自动熄灭掉了,那也就不用你再去跑回来去关灯了」;亮灯时间即 TP​=1.1RC。设置好 R、C 的数值就设置好了 TP​。
    6. 



这一题在「讲什么」:教师挑这一题是要把 555 的四个引脚功能(2 触发、6 阈值、7 攏电,5 控制电压)在一道应用题里全部用到:2 引脚的低脉冲「点火」,6 引脚的⅔U_CC 上阈「刹车」,7 引脚的放电管「归零」。教师另说「考试 555 不考、但作业有」、TP​ 可能有填空或选择——这条应用链条(触发→充电→上阈复位→放电回稳态)就是作业里 TP​=1.1RC 的推导背景。教师另说「考试 555 555 不考」与「作业里头是有的」两句并列,不择一断言。


这一题在讲什么:555 单稳态是「RC 充电 × RS 触发器」的合体应用:RS 触发器在 555 里管输出 Q,RC 链条管「什么时候复位」。要会两件事:① 逐段追踪「脉冲→C2→触发器→Q/T→电容充放电」的信号链;② 暂稳态宽度的来源——充电到 ⅔U_CC 所需时间,只由 R、C 决定,与脉冲宽度本身无关。

555 定时器内部结构与引脚
四个关键引脚(00:00–00:49):

放电管与 Q̄ 的联动(05:37–08:02):触发器输出 Q​ 经电阻接放电管 T 的基极。输出 uO​=Q;当 555 输出高电平(Q=1)⇒ Q​=0 ⇒ T 截止,放电端(7)悬空;当 Q=0 ⇒ Q​=1 ⇒ T 导通,7 引脚外接电容经 T 对地放电。Q=0、Q=1 与 T 的截止/导通一一对应;RD​、SD​ 同为 1 时保持,T「原来是截止的还是截止,原来是导通的还是导通」(07:37)。复述中把基极说成「积极」「发射机/发射极」混用,见转写与术语。


555 应用电路的三个用途(08:02):外接元器件可构成单稳态触发器、多谐振荡器(波形振荡器)、施密特触发器;本讲只讲了第一种,后两种没讲。


555 单稳态:上电与触发的完整链条
见题号条目。补充两个教师口述细节:


    

  • 上电保持段:「两比较器输出都是高电平……还是保持原来的不变」(09:57)——稳态时 RD​=SD​=1 (11 组合),触发器保持,Q 保持 0。
    • 

  • 触发段的触发器组合:低脉冲期间 C2 出 0、C1 出 1 ⇒ 01 组合(置 1)——教师讲「低电平有效是置一」(12:16)。
    • 



交直流分离的分析思想(模电开篇)
电路里的两类源(交流/直流),图上的记号约定:大写 U 表示直流电压源 UCC​,小写 uₛ + 电源符号表示交流电压源信号;RS​ 是信号源内阻(26:40)。电路中同时存在交流成分与直流成分的信号,输出端是两种信号叠加而成(27:48–28:20)。分析时人为把两部分信号分离:「交流的管交流的,直流的管直流的」,最后输出叠加(28:22–28:41)。


u_BE 波形的「叠加」读图(29:09):输入正弦信号是「在直流分量上叠加了交流的电压信号」——uBE​ 以直流基准线为中线正弦波动;电流波形同理。两个关键结论:


    

  • iC​ 与 iB​ 同相、成放大倍数关系(β 倍)(29:42–30:15)。
    • 

  • uCE​ 与 iC​ 反相——从回路 uCE​=UCC​−iC​RC​ 直接读出: iC​ 涨 ⇒ 管压降反而降。教师说「出现一个反向的效果」(30:46)。输出电压取自 uCE​ 经隔直电容,「把直流部分给它割掉了」,得纯交流输出(31:09–31:45)。
    • 



放大电路的三大指标
电压放大倍数 Au​(33:29–36:29):把放大电路看成一个二端网络:输入侧等效为「理想信号源 + 内阻 RS​」供 ui​;输出侧等效为「受控电压源 uo′​ + 输出电阻 ro​」给负载 RL​ 供电。Au​=uo​/ui​。考虑信号源时的源电压放大倍数 Aus​:信号源电压按 RS​ 与 ri​ 串联分压分给放大电路,故 Aus​=Au​⋅RS​+ri​ri​​。要源放大倍数大 ⇒ 希望 ri​ 越大越好:「ri​→∞ 时就接近放大电路本身的放大倍数」,且有效输入信号大、减轻信号源负担(36:54–37:50)。


输入电阻 ri​=ui​/ii​(37:16):定义即输入电压除以输入电流。


输出电阻 ro​(post-break 42:38 起):输出侧从负载往里看,等效为「受控电压源 uo′​ 串联 ro​」给负载供电。测量(计算)方法四步(43:20–44:54):① 信号源置零(uₛ=0);② 负载断开(RL​=∞,输出开路);③ 输出端口加压;④ 加多少电压、测出多少电流,ro​=uo​/io​。注意前提:信号源为零 + 负载开路下加压测流。ro​ 象征带负载能力:45:14 起「同样的输出电压下,ro​ 越小输出电流越大……带负载的能力越强」⇒ 希望 ro​ 越小越好。


频率特性与通频带(46:05–48:06):幅频特性上,当放大倍数幅值降到最大值的 2​1​(≈0.707)时,信号衰减已厉害、失真严重,「不能用了」——该处对应两个频率:低频截止频率(低频侧)与高频截止频率(高频侧);其间为通频带。在截止频率处相位差 90°(教师说「就差了 90 度」);「通常要让放大电路都在这(通频带)工作」。


直流通路、静态工作点 Q 与估算法
分析框架:静态分析 = 交流信号为零、只留直流,求 IB​、UBE​、IC​、UCE​ 四个量(32:19、52:12);动态分析 = 针对交流维度,分析电压放大倍数、输入电阻、输出电阻,用微变等效电路法(32:45、1:06:45)。


画直流通路的两条规矩(53:38–54:16):电容对直流开路 ⇒ C1、C2 断开;电容断开后,只剩两条支路:① UCC​→RB​→ 发射结(UBE) → 地;② UCC​→RC​→ 集电结 → 地。


为什么先算 Q:波形以 Q 为中心上下波动;Q 太靠饱和点 ⇒ 波形上部削平(饱和失真);太靠截止点 ⇒ 下部失真(49:20–50:28)。估算法的前提:UBE 电压基本稳定(PN 结导通压降),「如果这个电压不恒定,估算法就没法算了——少了个未知数,再多了一个未知数」(1:02:40)。UBE 取值:硅管 0.7 V;题目特别说明 0.6 就用 0.6(57:30):「如果说题目有特别说明,说是 0.6 的,那就按照 0.6,没有说明按 0.7」。IC≈βI_B(IE「是很小的」,忽略)(58:01)。


例题(58:27–59:56):UCC​=12 V, RC​=4 kΩ, RB​=300 kΩ(转写写「300欧」,从单位逻辑上应为 kΩ),β=37.5(转写写「放大倍数,贝塔等于3000U V」,数值转写含糊),UBE​=0.6 V(题面特别说明用 0.6,不用 0.7)。求 Q 点四参数:


    

  1. IB​=(UCC​−UBE​)/RB​=(12−0.6)/300k=38 μA;
    2. 

  2. IC​=βIB​=37.5×38μA=1.425 mA;
    3. 

  3. UCE​=UCC​−IC​RC​=12−1.425×4=6.3 V。
    4. 



这一题在讲什么:教师挑一道最裸的例题演示估算法的四步:先定 UBE(0.6 还是 0.7 按题面)、再 IB​、β 倍得 IC​、代回路方程得 UCE​。教师另提两点:① 单位与数量级——IB​ 一般是微安级、IC​ 毫安级,「这 2 个电流值算出来这个单位……一般是一个微安的,1 个是毫安的」(59:26);② 这四个量在输入/输出特性曲线上各定一个点,这就是「静态工作点」名字的几何来处(52:12–53:02)。


思考题:发射极加电阻 R_E 后 Q 点怎么变
题面(1:00:00–1:02:13):在发射极接一只 R_E,其他不变,算 Q 点、看 IB​/IC​ 怎么变。


解析:


    

  1. 左回路电压方程变成 UCC​=IB​RB​+UBE​+IE​RE​,用 IE​=(1+β)IB​ 替换:

    IB​=RB​+(1+β)RE​UCC​−UBE​​
    
教师口述含一次自我纠错:先说「IE 是不是可以写成一加 Ace 的 ie」(即 IE​=(1+β)IB​),中途说「这里是错了的……是 IE 乘以 ib」,最终落点仍是 IE​=(1+β)IB​。正文按 (1+β)IB​ 写,详见条件备注。
    2. 

  2. 分母从 RB​ 变成 RB​+(1+β)RE​,分子不变 ⇒ IB​ 变小 ⇒ IC​=βIB​ 变小 ⇒ Q 点整体下移,「跟原来不加电阻的肯定变小」(1:01:47–1:02:13)。教师说「IB 提取一下……IB 是不是变小了」。
    3. 

  3. UCE​ 同理多减一项 IE​RE​: UCE​=UCC​−IC​RC​−IE​RE​(1:00:23)。
    4. 



这一题在讲估算法的边界:分母多出的 (1+β)RE​ 正是发射极电阻把输入回路电阻放大 (1+β) 增——这正是微变等效电路里 rbe​=200+(1+β)IE​26​ 公式中 (1+β)IE​26​ 项的电路来源之一,教师在后面讲 r_be 公式时呼应了它(1:16:45)。


图解法:直流负载线与 Q 点
题面/方法(1:03:09–1:05:24):不用估算法,改用图解法确定 Q 点。


解析:


    

  1. 先估 IB​(图解法第一步仍是估算 IB​):IB​=(UCC​−UBE​)/RB​。
    2. 

  2. 画直流负载线:输出回路方程 UCE​=UCC​−IC​RC​ 取两个极限点:
      

    • IC​=0 ⇒ UCE​=UCC​ (横轴交点 (UCC​,0));
      • 

    • UCE​=0 ⇒ IC​=UCC​/RC​ (纵轴交点 (0,UCC​/RC​));
两点连线即直流负载线。
      • 

    

    3. 

  3. 找交点:算出的 IB​ 决定是哪一条输出特性曲线(IB​ 是曲线族的下标):「对应的不同的 ib 是不是有横向的……你得通过 ib 来确定我是这一条曲线,而不是这一条」(1:04:33)。该曲线与直流负载线的交点即 Q 点,读出 IC​、UCE​。
    4. 

  4. 输入回路 Q 点: UBE​、IB​ 已由估算法给出,在输入特性曲线上同样定出一个点(1:输出 1:05:24)。教师:「输入曲线上静态工作点,我们是不是前面的 UBE 和 ib 是不是都算出来了,所以这个点也能确定的」。
    5. 

  5. 指出动态分析下一步就是以 Q 为中心、沿负载线摆动的交流分析(1:05:44 起转入动态分析)。
    6. 



这一题在讲什么:图解法回答「估算法算不动时怎么办」——估算法靠 UBE 恒定这个前提,图解法靠输出特性曲线族 + 负载线。IB​ 在图解法里的真正身份是选曲线的下标:不用它你就不知道该用曲线族里的哪一条。输入/输出两张特性曲线图各定一个点,这就是 Q 点的几何身份。


为什么叫「共发射极」:输入输出回路的公共端
1:11:27–1:12:52:输入信号加在 B–E 之间(输入回路经发射极),输出信号取自 C–E 两端(输出回路也经发射极)——输入、输出两个回路共用发射极 E ⇒ 「共发射极放大电路」。教师原话:「输入回路和输出回路……公用一个发射极」,并预告共集电极、共基极两种组态(本课只讲共集电极:「在我们这个课里头,我就讲一下供给电机的电路」),三种组态教材里都要熟悉,课时有限只讲共射与共集。
「供给电机的电路」为转写失真 = 共集电极电路,见转写与术语。


微变等效电路法
「微变」的名字来处(1:13:50–1:15:58):Q 点附近信号幅度小,输出特性曲线在 Q 附近可用切线近似直线——「信号足够小的时候,我们就忽略曲线的曲度变化」,取切线斜率作等效参量(教师点了一句「高中的时候都学过那个极限的概念」)。输入侧:rbe​ = Q 点上 uBE​/iB​ 的切线斜率,即晶体管的输入电阻。


r_be 经典公式(1:15:58–1:16:45):本教材用 200 Ω 基值(「其他教材也有用 300 欧」的,与管子特性有关),要求记忆:

rbe​=200Ω+(1+β)IE​26 mV​

方向:B–E 之间等效为一个电阻 rbe​;C–E 之间等效为受控电流源 iC​=βiB​——因为 iC​ 的数值由 β 与输入电流 iB​ 决定,「ib 确定了 IC 就确定了它是成贝塔倍的关系」(1:18:01)。参考方向:受控源电流方向由 C 指向 E(教师:参考方向「等一下计算的时候是要用的」)。


画微变等效电路的接缝整理(1:08:02–1:11:27):先画交流通路,再替管子。


    

  • 交流通路规矩(1:07:44–1:08:43):电容用导线替代(短路);直流电压源对交流相当于接地——「你不接上(地)这个电路肯定画错了」(1:08:43)。验证方法:逐节点整理——同一节点连着哪些元器件、每个元件两端各连哪些节点(「发挥自己的空间想象力」,1:09:25)。
    • 

  • 共射交流通路的样子:信号源 us​–RS​ 在 B–E 之间;RB​ 一端接 B、另一端接 U_CC = 地 ⇒ R_B 接在 B–地之间;RC​ 一端接 C、另一端接 U_CC = 地 ⇒ R_C 接在 C–地之间;RL​ 从 C 引出经负载回地 ⇒ R_C ∥ R_L 并在 C–地之间;发射极无电阻直接接地。教师点名易错点:R_B 的上端「接着 C,接着这个 RC 这里出来了,接着 UCC 的出来」——即 R_B 上端接的是 U_CC(交流地),不是 C 点(转写这段含糊,见条件备注)。
    • 

  • 微变等效电路:管子 B–E 间换 rbe​,C–E 间换受控源 βi_B;R_B 在 B–地、R_C∥R_L 在 C–地,R_B 与 r_be 在输入端并联、R_C∥R_L 与受控源构成输出回路。
    • 



动态三指标的计算(共射)
电压放大倍数(1:19:46–1:22:03):


    

  1. ui​:R_B 与 r_be 并联,取 r_be 上电压即可, ui​=iB​rbe​。
    2. 

  2. uo​:两条支路(R_C 与 R_L)汇集电流 iC​,等效负载 RL​′=RC​∥RL​, uo​=−iC​RL​′——负号的来处:电流参考方向「往这边走」而负载电压上正下负,方向相反,「前面要加一个负号」(1:21:23–1:21:45)。
    3. 

  3. 相除, iB​ 消掉:

    Au​=ui​uo​​=−βrbe​RC​∥RL​​
    
其中 RL​′=RC​∥RL​。
    4. 

  4. 源电压放大倍数: Aus​=Au​⋅RS​+ri​ri​​,与前面指标定义呼应。
    5. 



这一题在讲什么:动态三指标的推导链在课上是一口气串下来的:先画交流通路(电容短路 + 电源接地),管子换微变模型(r_be + 受控源),再按定义逐个算 Au​、ri​、ro​。教师最后说「动态分析的所有的三个量都求出来了」(1:22:10)但课上只推出了 Au​ 的公式;ri​、ro​ 只给了定义与求法,共射电路下具体的表达式(如 ri​=RB​∥rbe​、ro​≈RC​)**课上没有推出——这是本篇笔记能力边界:这三条表达式是整理者补充,教师课上未给,复习时以课堂 PPT/教材为准。
