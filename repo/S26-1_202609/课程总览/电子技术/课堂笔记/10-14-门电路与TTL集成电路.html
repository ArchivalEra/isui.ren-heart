10-14-门电路与TTL集成电路
这节课在干什么：前两次课把逻辑函数化简成了最简式，这节课把最简式落到硬件上——用逻辑门电路去实现它。第七章从三类基本门开篇，再叠成复合门，最后进集成门电路（TTL 门、OC 门、TS 门三类）。要会六件事：
① 与、或、非三种基本门的电路实现，以及各自的判断口诀；
② 复合门（与非、或非、与或非）的构成与口诀；
③ 给定门电路和输入波形画输出波形的方法（分段 + 虚线对齐）；
④ TTL 与非门的内部三级结构（输入级／倒相级／输出级）与两种输入状态下的电平走向；
⑤ TTL 的电气指标：高电平典型 3.6 V（合格 ≥ 2.4 V）、低电平典型 0.3 V（合格 ≤ 0.4 V），以及扇出系数；
⑥ OC 门的两个用法：电平转换与线与。


行政与考核


    

  • 作业（两条，教师当场布置）：① 给定逻辑门电路和输入信号的波形，画出输出波形；② 思考题——列出与或非门的逻辑状态表，四个输入变量、一个输出变量，把每个状态列成 0000 到 1111 共 16 种，列全对应输出，课后自己画，再从这个状态表反推它的逻辑功能。
    • 

  • 实验预告：教师说后面安排实验时用 74LS00 测它的输入输出引脚，以及不同输入组合下输出的电平电位。
    • 



题号条目
思考题一：列出与或非门的逻辑状态表（4 个输入变量、16 种状态）
题面（教师原话）：思考题，请大家列出与或非门的逻辑状态表。四个变量、四个输入变量、一个输出变量，把每个状态列成 0000 到 1111 共 16 种，全列出来对应的输出是什么；画完再从状态表推它的逻辑功能。


解析（与或非门的表达式由教师当场给出，所以这张表不需要另找条件）：


与或非门的结构是「两组与门 → 或门 → 输出端加小圆圈」，两组各带两个变量，逻辑式是


Y=AB+CD​


列表的机械做法：逐行算出两个与项 AB、CD，两个或起来再整体取反。十六行照抄下表：






ABCDABCDY


0000001


0001001


0010001


0011010


0100001


0101001


0110001


0111010


1000001


1001001


1010001


1011010


1100100


1101100


1110100


1111110






再对一遍口诀：教师给的功能是「一组全 1 出 0，两组各有 0 出 1」。


    

  • Y=0 的七行（0011、0111、1011、1100、1101、1110、1111）全部满足「至少有一组的两个变量全为 1」——1100 到 1111 是 AB 全 1，0011、0111、1011 是 CD 全 1；
    • 

  • 剩下九行每组都至少含一个 0，两个与项都是 0，Y=0+0​=1。
    • 



两条判定正好互补：Y=0 当且仅当某一组全 1，Y=1 当且仅当每一组都至少有一个 0。


这一题在讲什么：复合门的状态表不是新东西——它是「与项 → 或 → 取反」这条结构链的直接展开，把结构翻译成十六行数字。顺带用上 10-10 讲过的「n 个输入变量有 2n 种组合」：四个输入变量正好 24=16 行，一行不多。真正要记住的是判据反过来用：不要逐行背表，要能看着式子说出「哪几行出 0」。


思考题二：两个普通 TTL 门的输出能不能用一根线直接连起来
题面（教师提出时让学生带着问题听下一段）：普通 TTL 门也能完成 Y1​ 和 Y2​，直接用一根线把它们连起来，这样的电路能不能正常工作？如果 Y1​ 输出是高电平、Y2​ 输出是低电平，这两个输出端能不能直接并到一根线上？


解析：不能。教师讲完 OC 门之后回到这道题，给的理由是回路与电流：


    

  1. Y1​ 出高电平、Y2​ 出低电平时，两个输出端并在一起就构成一条通路：电源经 Y1​ 的输出管一路灌到 Y2​ 的 T5​（饱和导通），再到地。
    2. 

  2. 这条通路中间几乎没有电阻（教师原话大意：中间几乎没有电阻，电阻很小），所以流过去的电流很大。
    3. 

  3. 电流大到会损坏器件，因此普通 TTL 的输出端不能这样并用；换成 OC 门才可以（见下文「OC 门用法二」）。
    4. 



这一题在讲什么：这是 OC 门存在的理由。普通 TTL 的输出级是「互补输出级」，任何时刻总有一边把输出端压在确定的电平上，两个输出端硬并起来就是两个电压源打架；OC 门的输出级只有下管、上拉电阻在外，所以多路并联是允许的。问「两个输出端能不能并」是集成门电路每讲一个新器件都会问一遍的问题，答法固定：看这个器件的输出级能不能承受"别的器件往这条线上灌电流"。


没编号但讲了的知识点
与逻辑与二极管与门电路
开关电路：A、B 各代表一个开关，两个开关串联再与一盏灯、一个电源串成回路。开关闭合记 1、断开记 0。只有两个开关同时闭合才形成有效回路、灯才亮——这就是与逻辑，Y=A⋅B。


二极管与门电路（教师画在黑板上，本页只记结构与电平走向）：






元件接法


电源5 V 经电阻 R 接到三个二极管的共阳端


二极管三个并联，阳极接在共阳端，阴极各接一个输入端


输出从共阳端引出，记 Y






电平分析（教师逐步走的）：


    

  • 任一输入为低电平（教师取 0.3 V 为例）：这个输入对应的二极管正向导通，把共阳端的电位钳在低电平（教师给的算式是输入的低电平 0.3 V 再加上二极管的导通压降 0.7 V）；B、C 两个输入同理——只要三个输入里出现一个 0，输出 Y 就是 0。
    • 

  • 三个输入全为高电平：各二极管截止（阳极电位与输入高电平之差不足以使它正向导通），输出端经电阻 R 直接接电源，Y 为高电平。
    • 



由此得与门的口诀：有 0 出 0，全 1 出 1。教师解释这两句的意思：「有 0」指输入变量里有 0，输出就是 0；「全 1 出 1」指输入变量全部是 1 的时候，输出才是一。


逻辑符号：方框内写 AND（转写作 &）。


学门电路的五步（教师反复强调要熟练）：


    

  1. 最基本的与逻辑电路（开关串并联那种）；
    2. 

  2. 二极管的逻辑门电路；
    3. 

  3. 列对应的状态表；
    4. 

  4. 由状态表推出逻辑功能（口诀）；
    5. 

  5. 记住逻辑符号。
    6. 



再收成三件事的一一对应：不管哪一种门，逻辑表达式 ↔ 逻辑功能 ↔ 逻辑符号要能互推，教师要学生把这三者建成一张映射表。


或逻辑与二极管或门电路
开关电路：A、B 各代表一组并联的开关，控制同一盏灯。只要有一个开关闭合就形成有效回路；只有两个都断开时灯才灭——这就是或逻辑，Y=A+B。


二极管或门电路：与前面的与门电路正好反过来——二极管的方向反了，参考电源的极性也反了（教师原话：二极管的方向也反过来了，参考电压源的极性也是反过来的）。电平分析：


    

  • 任一输入为高电平：这个输入对应的二极管正向导通，把输出端钳位在那个输入的高电平上，Y 为高电平；
    • 

  • 全部输入为低电平：各二极管截止（两端电位差不足以导通），输出端经电阻 R 接到低电平的参考电源（教师口播为「负 U」那一端），Y 为低电平。
    • 



或门的口诀：有 1 出 1，全 0 出 0。教师指出这正好是与门口诀把 0 和 1 互换。


逻辑符号：方框内写 ≥ 1。


非逻辑与晶体管非门电路
开关电路：在灯的两端并联一个开关。开关闭合等于把这盏灯短路，灯灭；开关断开时灯亮。所以「开关断开 = 1、闭合 = 0」，得到的是反变量。


晶体管（三极管）非门电路（教师板书，本页记接法与电平）：






元件接法


输入经电阻 RK​ 接三极管基极


基极另经一只电阻接负电源 −UBB​（电阻符号转写不清，见条件备注）


输出从集电极直接引出


集电极经 RC​ 接电源 UCC​






电平分析：


    

  • 输入为低电平（0）：基极电位为低，发射结不正向导通，晶体管截止；此时集电极与发射极相当于断开，输出端经 RC​ 接 UCC​，输出为高电平。
    • 

  • 输入为高电平：管子工作在饱和状态，管压降约 0.3 V，输出端电位约 0.3 V，输出为低电平。
    • 



非门的口诀：有 0 出 1，有 1 出 0——就是一个反相器。


符号上最容易错的地方（教师专门点出）：方框里标一个 1 还不够，输出端必须加一个小圆圈，加上去才是非门；漏掉小圆圈，功能就反了。


为什么基极还要接 −UBB​：为了保证输入是低电平时晶体管可靠截止——只靠输入把基极拉低不够，还要加一个负电压把发射结反偏得更彻底。


与逻辑的现实场景
教师举了两个日常例子，说明与门不是纸上的东西：


    

  • 保险箱：要输入正确密码，箱内还要有正确的机械钥匙；两样都对才能打开。
    • 

  • 银行卡：要拿正确的卡，还要输入这张卡的正确密码，才能对账户操作（取款还是存款另说）。
    • 



两例都是「两件事同时成立才继续」，即与逻辑。


与非门、或非门、与或非门
三者的做法是同一套：先掌握基本门的逻辑功能，再在基本门的输出端加一只非门。






门构成输出表达式口诀符号


与非门与门 + 非门（与门输出端加小圆圈）Y=ABC有 0 出 1，全 1 出 0与门符号加小圆圈


或非门或门 + 非门（或门输出端加小圆圈）Y=A+B+C​有 1 出 0，全 0 出 1或门符号加小圆圈


与或非门两组与门 → 或门 → 输出端加小圆圈Y=AB+CD​一组全 1 出 0，两组各有 0 出 1与、或、非三种符号叠加






与非门：三输入。原来的与门是「有 0 出 0，全 1 出 1」，后面再接一只非门整体取反，就成了「有 0 出 1，全 1 出 0」。教师提醒：逻辑式里那个长横杠不能丢，它是与非门的标志。


或非门：原来的或门是「有 1 出 1，全 0 出 0」，后面接非门取反，成了「有 1 出 0，全 0 出 1」。教师强调读符号时要看清有没有小圆圈：有圈结果就整个反过来。


与或非门：既有与门、又有或门、还有非门，三种电路组合在一起。结构是「两个与项相或以后，整体取非」，所以口诀是「一组全 1 出 0，两组各有 0 出 1」。教师是逐层推出来的：


    

  1. 前面一组（比如 A、B）全为 1 时，这一组的与项就是 1，1 或上任何变量都得 1，再整体取非 → 输出 0；
    2. 

  2. 若这一组里有一个 0，与完就是 0；若另一组（C、D）里也有一个 0，则两组相或得 0，再取非 → 输出 1。
    3. 



教师给这道题的完整状态表作业见上文「思考题一」。

这是本讲反复强调的实际题型，也是当天作业的主体：告诉你逻辑门电路，再给你输入信号的波形，让你画出这个电路输出的波形。


画法三步（教师现场分析 Y1​（与门）与 Y2​（或门）时走的）：


    

  1. 分段：把输入波形按变化时刻切成一段一段，每段内输入取值不变，用该门的逻辑功能口诀定这一段的输出；
    2. 

  2. 用虚线对齐：把输入波形的变化时刻用虚线向下拉，与输出波形的时刻一一对上；
    3.

    4.

TTL 与非门：三级结构
把晶体管逻辑门电路做进一整块芯片，就叫 TTL 电路（教师原话：把晶体管这个逻辑门电路叫做 TTL 电路）。典型 TTL 与非门分三级：






级组成作用

倒相级R2​、T2​、R3​把 T1​ 集电极的输出经 T2​ 变成集电极与发射极两个相位相反的信号，用来驱动输出级

T1​ 的等效：多发射极三极管可以展开成三个共阳极并联的二极管（每个发射极—基极结各是一个二极管），集电极—基极结又构成一个二极管。教师指出：这样一来，输入级与前面讲的二极管与门电路是同一回事，只不过把二极管集成进去了。


TTL 与非门：两种输入状态下的电平走向
情形一：三个输入里有一个是低电平（教师假设 C 为低电平，输入低电平取 0.3 V）


    

  1. T1​ 的这个发射极正向导通（导通电压 0.7 V），于是 T1​ 基极电位 VB1​=0.3+0.7=1 V；
    2. 

  2. 要让 T2​、T5​ 的发射结都正偏，这个点电位需要大于 2.1 V（三个 0.7 V 结串起来）；1 V 达不到，所以 T2​、T5​ 截止，这一组相当于断开；
    3. 

  3. T3​、T4​ 这组复合管则导通（T3​ 集电极经 R2​ 直接接电源，5 V 足够让两个结正偏）；
    4. 

  4. 输出电位 = 5−0.7−0.7=3.6 V → 输出高电平。
    5. 



情形二：三个输入全为高电平（取 3.6 V）


    

  1. 计算值 3.6+0.7=4.3 V 大于 2.1 V，三个结都正偏，T1​ 基极电位被钳在 2.1 V；
    2. 

  2. T2​、T5​ 都正向偏置并饱和导通，这一段电位为 0.7 V，再加饱和导通的管压降约 0.3 V → 该点为 1 V；
    3. 

  3. T3​、T4​ 这只复合管要两个结都正偏，至少要 1.4 V；1 V 不够，所以 T3​、T4​ 截止；
    4. 

  4. 输出从 T5​ 的集电极引出，T5​ 饱和导通，UCE5​ 约 0.3 V → 输出低电平。
    5. 



所以 TTL 与非门的功能仍是有 0 出 1，全 1 出 0，与门电路一致。

电压传输特性与两个电平门限
TTL 门的输入电压不是从高电平一下跳到低电平，中间有一个变化过程（电压传输特性）。但实际使用时只认两个稳定状态——输出高电平区与输出低电平区。教师给出的两个门限：






电平典型值实测合格判据


高电平3.6 V≥ 2.4 V 才算合格


低电平0.3 V≤ 0.4 V 才算合格






由此得出一条抗干扰判据：高电平越高、低电平越低，抗干扰能力越强（信号离门限越远，干扰越不容易把它拉过门限）。电压传输特性曲线怎么测、怎么画，见 10-21 实验一常用逻辑门电路。


扇出系数
TTL 的另一个参数叫扇出系数，教师给的定义是：与非门最大的输出电流与负载之间的比值；这个比值越大，带负载的能力越强。


OC 门：省掉输出级的复合管
OC = Open CollectOR，全称集电极开路 TTL。做法很直接：在普通 TTL 与非门的电路上，把 T3​、T4​ 这一部分连同 R4​ 一起省掉，直接从 T5​ 的集电极引出输出端——T5​ 集电极开路，所以叫集电极开路。






项普通 TTL 与非门OC 门

输出高电平怎么来输出级自己供高电平（3.6 V）必须外接上拉电阻接电源正极


符号与非门符号与非门符号上再加一个菱形加一杠






工作状态：


    

  • T5​ 饱和导通时，输出直接接地，电位约 0.3 V → 输出低电平；

OC 门用法一：电平转换
OC 门的输出端是悬空的（开路）状态，通过上拉电阻可以接不同的电源电压。教师给的例子：


    

  • 输入信号的电平范围是 0.3 V 到 3.6 V（TTL 的两个电平）；
    • 

  • 把上拉电阻接到 15 V 电源，输出的电平信号就在 0.3 V 到 15 V 之间。
    • 



于是「输入信号是低电平范围、输出被抬高到另一电压范围」这件事就实现了，这叫电平转换。教师指出：普通 TTL 做不到——它的输出级直接跟 5 V 电源通过 T3​、T5​ 的互补电路连着，电平被钉死在 0.3 V 与 3.6 V。


OC 门用法二：线与
线与是把多个 OC 门的输出端直接用导线并联（再各自经同一个上拉电阻接电源），使总输出等于各路输出的逻辑与。教师的做法是三组 OC 与非门并联：


    

  1. 某一路的 T5​ 饱和导通时，把公共输出节点拉到 0.3 V（低电平）。电流回路是：电源正极 → 上拉电阻 RL​ → 该路的输出节点 → T5​ 饱和导通 → 地；
    2. 

  2. 其余各路的 T5​ 都截止，输出端悬空——它没有跟任何东西相连，对后面的逻辑门电路来说就是高电平；
    3. 

  3. 于是公共输出 Y 就是各路输出的与：
    4. 



Y=Y1​⋅Y2​⋅Y3​


其中每一路是一个三输入与非门的输出（Y1​=ABC，另两路同构）。教师口播的等效展开是「ABC 整体取非，然后与上（另两组各自取非），再相与」，即


Y=ABC⋅DEF⋅GHI


（按德摩根展开，等价于 ABC+DEF+GHI​——三组与项相或再整体取非。第二、三组的变量字母转写糊连，按上下文读作 DEF、GHI，见条件备注。）


教师点出这个结论的来源：正因为高电平那几路是悬空的（不拉电流），它们并上去才不会互相干扰——这正是普通 TTL 做不到、而 OC 门可以的原因（见上文「思考题二」）。
