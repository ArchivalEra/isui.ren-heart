11-02-时序分析与设计
这节课在干什么：这一晚是连堂两段：18:00 起讲「怎么分析」，讲到 37:17；18:39 接上讲「怎么设计」，讲到 42:27。两段合起来是时序逻辑电路的一套完整方法论：


① 时序电路与组合电路的分界——输出除了取决于当下的输入，还取决于电路原来的状态，记忆功能由触发器承担；
② 分析：写四个方程 → 列状态转换真值表 → 画状态图与时序图 → 判断逻辑功能（含自启动的判据）；
③ 设计：逻辑抽象 → 状态图与状态转移表 → 状态化简 → 状态分配与编码 → 选触发器类型 → 求输出方程与状态方程 → 与特性方程比较反推驱动方程 → 画逻辑电路图 → 检查能否自启动；
④ 两类例子各走一遍：教材例题一（同步六进制加法计数器，分析）与例题一（同步三位二进制加法计数器，设计）；末尾的例题二（同步五进制）没讲完。


行政与考核


    

  • 作业上的提问：上次作业有人问 JK 触发器的波形（05:23）。教师借此讲教材约定：JK 触发器的 J、K 端单独悬空时，一般默认接高电平；要接 0，教材上会标一个 0 的符号，或者直接把它接地。
    • 

  • 课后自查：教师指出课件上设计步骤的顺序反了（39:18），并要求学生回去自己对照验证一遍推导过程（40:22）——即按「先得状态方程 → 与触发器特性方程比较 → 反推驱动方程」这条顺序重走一次。
    • 



题号条目
例一（分析）：同步六进制加法计数器（教材例题一）
题面（教师口述与板书）：三个 JK 触发器 FF0、FF1、FF2 组成，CP 端接同一路时钟脉冲；输出 Y 由 Q2​ 与 Q0​ 经一只与门产生；各触发器的 J、K 端按驱动方程接线。


⚠ 这一题的驱动方程那一行转写失真（语音识别把上下标与取反号全部听丢）。正文给出的驱动方程是按教师自己报出的状态序列与自启动路径反解得到的，解法步骤全部写出、可以逐步复核；板书原件不在手上，文字符号以推导结果为准，详见文末「条件备注」。


解析（分析步骤逐条走，每一步的依据写在旁边）：


    

  1. 先判同步还是异步：三个触发器的 CP 都接在同一路时钟脉冲上 ⇒ 同步时序电路。这一句必须写出来（10:15）。同步电路的时钟方程可以省略，也可以统一写成 CP0​=CP1​=CP2​=CP（04:26）；异步电路则要逐个分析每个 CP 由哪几个信号组合而成。
    

    2. 

  2. 写输出方程：Y 是一只与门的输出，两个输入是 Q2​ 和 Q0​ ⇒ Y=Q2​Q0​。
    

    3. 

  3. 写驱动方程：JK 的特性方程是 Qn+1​=JQn​​+KQn​（教师要求背下来，12:05：「这个式子不会给你的，你要自己去记住」）。教师报出的状态序列是 000→001→⋯→101→000，无效状态路径是 110→111→010。据此列出各位的变化表：
    

    

    

    现态Q0​ 的变化Q1​ 的变化Q2​ 的变化
    

    0000→1 置位0→0 保持0→0 保持
    

    0011→0 复位0→1 置位0→0 保持
    

    0100→1 置位1→1 保持0→0 保持
    

    0111→0 复位1→0 复位0→1 置位
    

    1000→1 置位0→0 保持1→1 保持
    

    1011→0 复位0→0 保持1→0 复位
    

    1100→1 置位1→1 保持1→1 保持
    

    1111→0 复位1→1 保持1→0 复位
    

    

    

    再用特性方程逐格解出 J、K，规则是固定的四句：现态为 0 而次态为 1 ⇒ 该格 J=1；现态为 1 而次态为 0 ⇒ 该格 K=1；现态为 0 而次态为 0 ⇒ 该格 J=0；现态为 1 而次态为 1 ⇒ 该格 K=0。按触发器分开整理：
    

      

    • FF0（Q0​）：八个状态全部翻转 ⇒ J0​=K0​=1。
      • 

    • FF1（Q1​）：只在 001、011 两格翻转 ⇒ 这两格 J1​=K1​=1，其余为 0；这两格的共同特征是「Q0​=1 且 Q2​=0」⇒ J1​=K1​=Q0​Q2​​。
      • 

    • FF2（Q2​）：J2​ 需在 011（置位）为 1、在 000、001、010（保持）为 0、在 101、110、111 处因现态为 1 而无关 ⇒ J2​=Q0​Q1​；K2​ 需在 101、111（复位）为 1、在 100、110（保持）为 0、在 000∼011 处因现态为 0 而无关 ⇒ K2​=Q0​。
      • 

    

    于是驱动方程为
    

    J0​=K0​=1,J1​=K1​=Q0​Q2​​,J2​=Q0​Q1​,K2​=Q0​
    

    4. 

  4. 写状态方程：把驱动方程代入 JK 特性方程 Qn+1​=JQn​​+KQn​：
    

    Q0​(n+1)=Q0​​
    

    Q1​(n+1)=Q0​Q2​​Q1​​+(Q0​​+Q2​)Q1​
    

    Q2​(n+1)=Q0​Q1​Q2​​+Q0​​Q2​
    

    5. 

  5. 列状态转换真值表：把现态、次态、输出列成一张表（07:17 起教师讲的列法：现态列 Q2​(n),Q1​(n),Q0​(n)，次态列 Q2​(n+1),Q1​(n+1),Q0​(n+1)，一行行的次态就是下一行的现态）：
    

    

    

    现态 Q2​Q1​Q0​次态 Q2​(n+1)Q1​(n+1)Q0​(n+1)输出 Y
    

    0000010
    

    0010100
    

    0100110
    

    0111000
    

    1001010
    

    1010001
    

    1101110
    

    1110101
    

    

    

    表里 Y 只有 101 与 111 两行为 1，与教师口述一致（14:59：「101 刚好 Q2​ 与 Q0​ 等于 1」，主循环里其余各状态 Y 全为 0）。
    

    6. 

  6. 画状态图与时序图：
    

      

    • 状态图：每个状态画一个圈，圈里写三位状态码，箭头从现态指向次态，输出标在转移箭头上。000→001、001→010、010→011、011→100、100→101 这五条箭头标输出 0，101→000 标输出 1（18:14）。输出只挂在状态转移上，所以这个电路是 Moore 型的输出形式。
      • 

    • 时序图：一个 CP 来一个下降沿，Q0​ 翻一次；再来一个下降沿，Q0​ 与 Q1​ 同时翻，Q2​ 因为不满足翻转条件不动；再往下依此类推（16:40）。
      • 

    

    7. 

  7. 判断逻辑功能：环上有 000∼101 六个状态，按递增规律从 0 数到 5，数满六个又回到 000 ⇒ 同步六进制加法计数器（教师原话 15:49：「从零计数到 5……总共记了六个数，记完六个数以后他又回头回到零重新记了」）。
    

    8. 

  8. 检查能否自启动：三位触发器共 8 个状态，主循环只用了 6 个，剩下 110 与 111 是无效状态。把它们代入状态方程：110→111→010，010 已经在主循环里 ⇒ 经过有限个 CP 能自动回到有效循环 ⇒ 能自启动。
教师给的判据原话是 20:53：「经过若干个有限的 CP，它能够自动的返回有效状态……这个叫做这个电路是能够实现自启动的」；反过来，若无效状态只在它们自己之间循环、进不了主循环，就叫不能自启动，那说明这个电路设计得有问题（21:48）。
    

    9. 



这一题在讲什么：这一题把「分析」的四步从头到尾走了一遍，示范的是顺序而不是结论：先判同步/异步，再写四个方程，然后列表、画图，最后才下功能判断。四个方程一个都不能省（06:38：「记住要写四个方程啊，对步骤不能省略」），因为后面每一步都靠它——驱动方程代进特性方程才出状态方程，状态方程才列得出转换真值表，转换真值表才画得出状态图，状态图才判得出功能与自启动。


这一题还有一层用意：自启动是设计的验收项，不是可选项。功能判断只说明「正常情况下它是六进制计数器」，自启动判断才说明「上电瞬间进了无效状态也能自己爬回来」。教师把这两件事分开讲，是为了让你在设计完电路后还能回头验一遍。


例一（设计）：同步三位二进制加法计数器
题面（教师口述，12:39）：设计一个同步的三位二进制加法计数器。


解析（按设计步骤逐条走）：


    

  1. 逻辑抽象（12:59）：三位二进制加法计数器 ⇒ 状态是 000∼111，共 8 个状态；初态取 000；每来一个 CP 加 1；计到 111 时输出一个进位信号 Y，并同时返回 000。要表示三位二进制，至少要 3 个触发器（22=4<8≤23=8）。
    

    2. 

  2. 画状态图 / 状态转移表（13:59 起）：八个状态全部用上，000→001→⋯→110 每一步都没有进位，只有 111→000 这一步产生进位。
    

    3. 

  3. 状态化简（14:32）：八个状态两两不同——每个状态的输入相同、输出也各不相同，没有可以合并的等价状态，所以不需要化简。
    

    4. 

  4. 状态分配与编码（14:55）：用三位二进制码给八个状态编码，000∼111 依次对应。
    

    5. 

  5. 求输出方程（16:51）：教师在这里专门强调一条规矩——输出方程用现态描述（原话：「注意是不是描述现态方程……是由现态来组成的」）。Y=1 只有 111 这一行，三个现态全为 1 ⇒

    Y=Q2​Q1​Q0​
    
电路上一只三输入与门即可。
    

    6. 

  6. 求状态方程（18:05 起）：把现态与次态列在同一张表里，取次态的每一个变量当作输出变量，把该输出变量取 1 的那些行圈起来，用卡诺图化简成关于现态 Q2​,Q1​,Q0​ 的表达式，得到
    

    Q0​(n+1)=Q0​​
    

    Q1​(n+1)=Q0​Q1​​+Q0​​Q1​
    

    Q2​(n+1)=Q2​​Q1​Q0​+(Q1​​+Q0​​)Q2​
    

    7. 

  7. 选触发器类型 + 反推驱动方程（19:16 起）：选 JK 触发器，特性方程 Qn+1​=JQn​​+KQn​。把它与上面三条状态方程逐条比较，反推 J、K：
    

      

    • Q0​(n+1)=Q0​​：每次都翻转 ⇒ J0​=K0​=1（教师原话 22:40：「J0​，K0​ 应该等于什么？等于 1……每来一个时钟，我这个 Q0​ 要翻转一次」）。
      • 

    • Q1​(n+1)=Q0​Q1​​+Q0​​Q1​：Q0​=1 时翻转、Q0​=0 时保持 ⇒ J1​=K1​=Q0​（23:53）。
      • 

    • Q2​(n+1)=Q2​​Q1​Q0​+(Q1​​+Q0​​)Q2​：Q1​Q0​=1 时翻转、否则保持 ⇒ J2​=K2​=Q1​Q0​（24:11）。
      • 

    

    这一步就是教师指出来「课件顺序反了」的地方：正确的次序是先得状态方程，再与特性方程比较，反推驱动方程（39:18）。
    

    8. 

  8. 画逻辑电路图（25:02 起）：
    

      

    • 3 个 JK 触发器，CP 端全部接到同一路时钟（同步）；
      • 

    • 清零端置高，让它不起作用（「你让他那个什么就是要给他置高点……要置高一点你就让他不要清零」）；
      • 

    • J0​、K0​ 悬空（悬空默认就是 1），也可以把两个端连在一起、再标一个「1」表示高电平接进这两个端（26:02）；
      • 

    • J1​、K1​ 两个端都接 Q0​；J2​、K2​ 两个端都接 Q1​ 与 Q0​ 的与门输出（26:39、26:55）；
      •

例一（设计）的另一种做法：不画卡诺图，直接从状态转移表找规律
题面（28:39 起）：同样的同步三位二进制加法计数器，换一条路做。


解析（这条路教师称为「直接分析状态转移的规律」，32:03）：


    

  1. 先把状态转移表列清楚：现态一行、次态一行，上面那行的次态就是下面那行的现态（29:11）。
    2. 

  2. 看每一位什么时候翻转：
      

    • FF0：每来一个 CP 就翻转一次 ⇒ 接成 T 触发器（J0​=K0​=1），教师说这里用的是 JK 触发器接成的 T 触发器（31:01、32:03）。
      • 

    • FF1：Q0​=1 时再来一个 CP 就翻转一次 ⇒ J1​=K1​=Q0​，效果等价于「Q0​ 决定这个 T 触发器能不能翻」（31:36、33:07）。
      • 

    • FF2：Q0​ 与 Q1​ 都等于 1 时再来一个 CP 就翻转一次 ⇒ J2​=K2​=Q0​Q1​，输入信号是前两个信号相与的结果（33:45）。
      • 

    

    3. 

  3. 画电路与波形，并说明它与前面卡诺图那条路接出来的电路形式不同但功能一样（34:31：「三个二进制的一个分布加的电路画出来电路是不一样的」）。
    4. 

  4. 工作过程（35:16 起）：同步计数器的特点是每来一个时钟都要同步判断——在这个时钟到来的同时，要一起看 Q0​、Q1​、Q2​ 的状态对下一时刻的影响。第 2 个 CP（状态 001→010）时 Q0​ 与 Q1​ 同时翻转；第 4 个 CP（状态 011→100）时 Q0​、Q1​ 翻转，同时 Q0​Q1​=1 满足了 Q2​ 的翻转条件，于是三个触发器在同一时刻同步翻转——这就是「同步加法计数器」这个名字的来处。
    5. 



这一题在讲什么：这一题的价值在于同一道题有两条路，而两条路给出同一个答案。前面那条路是标准的卡诺图化简法（先列状态转移表 → 化简出状态方程 → 比较特性方程反推驱动方程），这条是「读懂状态转移表里每一位的翻转规律」。教师把两条路并排摆出来，是为了让你在做设计时能自己选：功能简单、状态少的时候直接找规律更快；状态一多，卡诺图才是靠得住的。


两条路得到同一组驱动方程（J0​=K0​=1、J1​=K1​=Q0​、J2​=K2​=Q0​Q1​），这一点本身就是对两条路的交叉验证。


十进制计数器：10 个有效状态，6 个无效状态
题面（36:58 起）：设计一个十进制计数器。


解析：


    

  1. 定状态数与位数：十进制计数器有 10 个状态（0∼9）；23=8<10≤24=16 ⇒ 至少 4 个触发器。四个触发器有 16 个状态，取其中 10 个当有效状态 ⇒ 6 个是无效状态。
    2. 

  2. 列状态图与状态转移表（37:25）：10 个有效状态依次 0→1→…→9，每个 CP 加 1；计到 9 之后回到 0，同时产生进位。课件上用红框把这 6 个无效状态框了出来（37:48）。
    3. 

  3. 同步设计：CP 端全部接在同一端（37:48：「他是用同步的，所以我们同步的时空方程都是接在同一端，CD 端」）。
    4. 

  4. 求方程：状态方程仍然用卡诺图求——把次态的每个变量当输出变量，把该变量取 1 的那些行圈起来，化简成关于四个现态变量的表达式（38:21）。
    5. 

  5. 检查自启动：把这 6 个无效状态分别代入状态方程，看能不能回到有效状态（41:13：「启动之前，我就把剩余的六种状态分别带入到状态方程」）。
    6. 



这一题在讲什么：十进制计数器和二进制计数器在方法上没有任何区别，差别只在状态数与无效状态的数量。而无效状态数量的由来是纯算术：位数向上取整，多出来的组合全是无效状态，要逐个代入状态方程验一遍能不能回来——这就是「设计完必须回头验自启动」这条规矩的用武之地。

什么叫时序逻辑电路：功能与两类描述方式
时序逻辑电路的特点：任何时刻的电路输出，不仅与当下的输入有关，还取决于电路原来的状态（00:06）。这个「原来的状态」由有记忆功能的触发器记录——它把原始状态存下来，与当下的输入一起决定输出。

计数器的特点、分类与作用
作用（22:53 起，27:27 复述）：在自动化生产线里应用非常广泛。对时钟脉冲 CP 计数——来一个脉冲记一个数；产生节拍脉冲与脉冲序列；定时；进行数字运算。组成单元是触发器。


分频是它的副产品（23:26 起）：每一位输出的频率不同，Q0​ 是 CP 的 1/2，Q1​ 是 1/4，Q2​ 是 1/8……把高频率信号通过分频电路变成低频率信号，所以计数器也叫做分频器（37:04）。


两种分类口径（25:06 起）：






分类依据类别


进制二进制计数器、十进制计数器、任意 N 进制计数器


计数方式加法计数器、减法计数器、可逆计数器


触发器翻转是否同时同步计数器、异步计数器






状态数的算术（26:21 起）：选 N 位（N 个触发器）时，状态数大于等于 2N−1、小于等于 2N；多出来的那些就是无效状态。无效状态代入状态方程后能回到有效状态，就是能自启动；否则不能自启动，说明电路设计有问题。


三位二进制异步加法计数器
题面（27:52 起）：三位二进制异步加法计数器。


解析：


    

  1. 接线与判定：FF0 的时钟是 CP，FF1 的时钟是 Q0​，FF2 的时钟是 Q1​。三个触发器的时钟信号各不相同 ⇒ 这是异步电路（28:30）。
    2. 

  2. 逐拍分析（29:09 起）：
      

    • 来一个 CP 的下降沿 ⇒ Q0​ 先翻转（0→1）。此时 Q1​、Q2​ 不动——它们的时钟是 Q0​、Q1​，而 Q0​ 这次是上升沿，没有下降沿。
      • 

    • 再来一个 CP ⇒ Q0​ 由 1 变 0，这个下降沿就是 FF1 的有效触发信号 ⇒ Q1​ 翻转。
      • 

    • Q1​ 翻转后，它自己由 1 变 0 的那个下降沿又去触发 FF2 ⇒ Q2​ 翻转。
      • 

    • 到 111 再来一个下降沿时，Q2​、Q1​、Q0​ 三个同时翻转，回到 000。
      • 

    • 归纳成一句：Q0​ 出现下降沿，Q1​ 翻转；Q1​ 出现下降沿，Q2​ 翻转（31:59）。这就是「CP 管 Q0​、Q0​ 管 Q1​、Q1​ 管 Q2​」的级联关系。
      • 

    

    3. 

  3. 触发器接法：把 J、K 悬空（默认高电平），即 J0​=K0​=J1​=K1​=J2​=K2​=1，相当于用 JK 触发器接成 T′ 触发器，下降沿触发（33:18）。
    4. 

  4. 另一种接法（34:25 起）：把后面两级的时钟信号换成 Q1​​、Q0​​，就得到上升沿触发的版本。功能完全相同，只是一个下降沿有效、一个上升沿有效。教师说如果需要接成上升沿，就用后一级接 Q​ 的那种接法。
    5. 

  5. 对比同步与异步（35:35 起）：异步计数器每一步的翻转都不是同时进行的，只有最后一个状态 111→000 是三个同时翻转。同步计数器则是各位在同一 CP 时刻同步翻转。
    6. 



这一题在讲什么：异步计数器的价值在于电路最省——后级的时钟直接用前级的输出，不额外引入时钟；而它的代价就是各位不在同一时刻更新。**"翻转为同步还是异步"**这件事的分界线，落在「各触发器的 CP 是不是都接同一路」这一条上，看图先看时钟端。
