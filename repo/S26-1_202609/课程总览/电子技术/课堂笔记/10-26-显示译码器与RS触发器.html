10-26-显示译码器与RS触发器
这节课在干什么：这一晚是连堂两段——18:01 起的那段在「上节课没讲完的显示译码器」处收尾，讲到基本 RS 触发器的电路结构就断在一个问句上；18:32 起的那段直接给答案，接着讲完基本 RS、钟控 RS，最后停在「空翻怎么解决，下一节课来讲」。两段合起来是一条完整的线，要会六件事：


① 把七段译码显示器的段码表收完——七段的排列、0/1/2/6/9 各点亮哪几段、74LS47 的低电平有效与 LTC／RBI／BI 三个控制端；
② 第八章的范围：重点是 RS、JK、D 三种触发器的逻辑功能、特性方程与状态转移关系，8.05–8.07 只作了解；
③ 触发器的定义与三个特点——记一位二进制信息、两个稳定状态、输入消失后状态被保存；
④ 按功能分的三大类：双稳态、单稳态、无稳态（多谐振荡器）；
⑤ 基本 RS 触发器：两个与非门交叉耦合的电路结构、SD​／RD​ 的四种输入组合，以及描述它的四种方式（状态转移真值表 → 特性方程 → 状态转移图 → 工作波形图）；
⑥ 钟控（可控）RS 触发器与它的两个固有缺陷，其中空翻现象只点到现象，解法留给下一节课。


行政与考核


    

  • 第八章要求（17:26–18:52）：重点掌握 RS 触发器、JK 触发器、D 触发器的逻辑功能、特性方程和状态转移关系；
在此基础上理解寄存器、移位寄存器、二进制计数器、十进制计数器的逻辑功能和工作原理；
掌握时序逻辑电路的分析方法，了解其设计方法。
综合应用里还讲了集成计数器、寄存器（左移／右移／双向移动）、单稳态与无稳态触发器。教材的 8.05、8.06、8.07 作了解性知识。
    • 

  • 作业预告（34:54）：从这节课开始会有大量时序图作业，要画 RD​、SD​、R、S、Q 各种状态下的波形。
    • 

  • 实验衔接（10:30）：实验箱左上角那台数码管显示与一块七段译码显示器芯片配对使用，下一次做计数器实验时可以顺手把它做一遍。
    • 



没编号但讲了的知识点
显示译码器：把运算结果变成看得见的十进制数字
链路（00:50–01:44）：BCD 编码（二-十进制代码）→ 译码器 → 驱动器 → 显示器。数字仪表、计算机的数字系统都是靠这条链路把运算结果用十进制数显示出来。


数码管的两种接法（01:44–03:04）：七段发光二极管排成"日"字形。






接法公共端接法各段另一端译码输出的有效电平


共阴极所有阴极接在一起接地各阳极接译码信号高电平有效（输出高 → 该段亮）


共阳极所有阳极接在一起接电源正极各阴极接译码信号低电平有效（输出低 → 该段亮）






两种接法的段码排列完全一样，不一样的是输出极性，所以译码器与数码管必须配对使用，配错就整片显示乱码。


段的排布（03:04–03:58）：最上面那一横记 a，然后顺时针方向 b、c、d、e、f，中间那一横是 g。


⚠ 教师报出「共阴极时第 8 个引脚和第 3 个引脚都接地，共阳极时 3 和 8 接电源正极」，但转写里没有交代这是数码管模块的公共端脚号还是 74LS47 的控制端脚号，两处引号编号的口径见文末条件备注。段码表本身不受这一条影响。


七段码：每位数字点哪几段
规则只有一条：某位数字需要哪几段亮，就是那几位取有效电平。


    

  • 显示 1：只要点亮 b、c 两段（04:13）。共阴极接法下这两端给高电平 → 导通点亮。按教师采用的 "G 到 A"读法（g、f、e、d、c、b、a 依次），段码是 0000110（05:22）。
    • 

  • 显示 2：要点亮 a、b、d、e、g 五段（05:35），其余两段不亮。
    • 

  • 0000 → 显示 0：a、b、c、d、e、f 六段高电平点亮，只有中间那一横 g 低电平熄灭（08:38–09:03）。
    • 

  • 1001 → 显示 9：只要 e 这一段不亮，其余都亮（07:34）。
    • 



把码字与点亮段合成一张表（就是教师说的"七段译码显示器这个状态表"，11:49）：






BCD 码显示数码点亮的段熄灭的段段码（G→A，高电平有效）


00000a,b,c,d,e,fg0111111


00011b,ca,d,e,f,g0000110（教师当场报出）


01106a,c,d,e,f,gb1111101


10019a,b,c,d,f,ge1101111






教师当场报出的段码只有数字 1 那一格；其余各行的段码按同一条读法排出——读法是 G→A，亮的段记 1、灭的段记 0。


⚠ 0110 这一行：教师在 09:18 把 0110 说成「编码二」并给出数字 2 的段码（c、f 不亮），在 11:01 又以「0110 只要 b 一段不亮」为例——那是数字 6 的段码（b 灭、其余亮）。两处口述互斥；按 BCD 编码 0110 就是 6，上表取后者（b 灭），差异见文末条件备注。


表怎么用：输入端接四位 BCD 码，译码器输出直接接数码管的七段（07:07）。教师让同学把码字与段码的关系"捋顺"——把七段按数码管的形状摆好，亮的那几格拼起来就该是那个数字（11:26）。


74LS47：低电平有效与三个控制端
芯片（11:59）：七段译码显示器做成一块集成芯片 74LS47。四个 BCD 输入端接码字，输出是七段，外加一个控制端。


⚠ 教师报出四个 BCD 输入端对应的引脚号，转写作「1、2、1、2、6」，读法含糊，不能确定每个脚对应码字的哪一位；本页只写"四个输入端分别接 BCD 码的四位 A3​、A2​、A1​、A0​"，脚号口径见文末条件备注。


输出极性（12:28–13:13）：输出端符号上标了非号，即直接输出低电平有效。由此定下配对规则：


    

  • 低电平有效 → 配共阳极接法。教师原话："你的阳极已经是接高电平了……你只要你的阴极出现低电平，它就亮了。"
    • 

  • 高电平有效 → 配共阴极接法。
    • 



所以同一张段码表，搬到 74LS47（配共阳极）上时亮的段输出 0、灭的段输出 1，与上表正好相反。


三个控制端（14:03–15:11）：






控制端作用教师的原话口径


LTC（灯测试）=1 时译码器正常译码工作"当 LTC 等于 1 的时候，译码器是属于正常译码工作状态"


BI（灭灯）=0 时各输出为低电平 → 灭灯输出低电平有效，所以灭灯对应的是低电平而不是高电平


RBI把数码管显示的零熄灭"将数码管显示的零熄灭"






三个信号组合起来，就能控制哪一段按要求显示、哪一段灭灯。


实验接法（15:34）：前面的四个 BCD 编码输入端接好，输出端通过电阻接数码管。


进入第八章：范围与要求
为什么换章（16:33–17:26）：前面讲的都是组合逻辑电路，它没有记忆元件（没有触发器这类记忆元件），输出只跟着当时的输入变，与前一时刻的状态无关。第八章讲有记忆的电路——输出除了取决于输入，还取决于电路原来的状态。


本章内容（17:26–18:52）：


    

  • 双稳态触发器 + 时序逻辑电路的分析与设计；
    • 

  • 综合应用里：集成计数器（各种进制的）、寄存器（左移、右移、双向移动）、单稳态触发器、无稳态触发器；
    • 

  • 教材的 8.05、8.06、8.07 作了解性知识；
    • 

  • 重点掌握前面四种触发器：RS 触发器、JK 触发器、D 触发器的逻辑功能、特性方程和状态转移关系（教师原话"它的逻辑功能、特征方程和状态转移关系"）；
    • 

  • 在此基础上理解寄存器、移位寄存器、二进制计数器、十进制计数器的逻辑功能和工作原理；
    • 

  • 掌握时序逻辑电路的分析方法，了解其设计方法。
    • 



触发器的定义与三个特点
定义（19:24）：能够储存或者记忆一位二进制信息的基本逻辑单元。


三个特点（19:24–22:06）：


    

  1. 两个稳定状态：一位二进制信息就是 0 和 1，所以触发器有状态 0 与状态 1 两个稳定状态。
    2. 

  2. 可以被输入控制：通过不同的输入可以对输出状态进行控制——可以置 0，也可以置 1；这两种状态能通过改变输入互相改变。
    3. 

  3. 输入消失后状态被保存（教师说"第三点特别重要"）：输入信号消失之后，输出的 0 或 1 被保存下来，不变化——这就是记忆功能。
    4. 



与组合逻辑电路的分界（21:14–22:06）：组合逻辑电路的输出随着输入状态的改变而改变，与前一时刻的状态没有任何关系；触发器则下一时刻的状态跟现在的状态有关系——它不只跟输入有关，还跟当下的状态有关，当下的状态可以对下一刻的状态产生影响。


按功能分三大类
三类（22:14–22:55）：






类别包含什么


双稳态触发器接下来重点学的 RS 触发器，以及下节课的 JK 触发器、D 触发器、T 触发器


单稳态触发器—


无稳态触发器又名多谐振荡器






教师强调"三大类，大家要记住"。双稳态触发器是最基本的一类，其中最基本的就是基本 RS 触发器。


基本 RS 触发器的电路结构
组成（23:12–24:45）：两个与非门 G1​、G2​，输出互为对方的输入（交叉耦合）。


    

  • G1​ 的输出记作 Q，Q 是 G2​ 的一个输入信号；Q 与 RD​ 共同组成 G2​ 的两个输入。
    • 

  • G2​ 的输出记作 Q​，Q​ 反过来作为 G1​ 的输入信号。
    • 

  • 所以 G1​ 与 G2​ 的两个输出是互补关系。
    • 



电路结构（两只交叉耦合的与非门，Q 与 Q​ 互补）：



      

        text
        
      

      
        ┌───────┐
  S̄_D ─┤       │
        │  G1   ├──── Q ─────┐
  Q̄ ───┤  与非  │            │
        └───────┘            │
                             ▼
        ┌───────┐         ┌───────┐
        │       │◄────────┤       │
  R̄_D ─┤  G2   │         │  G1   │
        │  与非  ├──── Q̄ ─┤  与非  │
        └───────┘         └───────┘

    


输入端 SD​、RD​ 带非号，是低电平有效——这一条决定了下面四种组合的一切。


基本 RS 的四种输入组合

第 3 种（保持）怎么推出来的（00:33–01:17）：设原状态 Q=0。G2​ 的输入是 Q 与 RD​，即 0 与 1 相与得 0，取反得 1，所以 Q​=1；G1​ 的输入是 Q​=1 与 SD​=1，相与得 1，取反得 0，所以 Q 仍为 0。原状态是 0 就保持 0；原状态是 1 就保持 1——两个状态各自"往复循环"，输出不变。


第 4 种（不确定）到底怎么来的（01:17–03:40）：

钟控（可控）RS 触发器
电路（39:25–40:30）：在基本 RS 触发器的基础上再加两只与非门 G3​、G4​。这两只门有一个共同的输入 C（时钟脉冲信号）。C 作为 G1​、G2​ 的一个输入信号的控制信号——它加入了这个导引电路和控制端 C。


工作分析（40:30–42:41）：


    

  • C=0：G3​、G4​ 的输出都是 1。与非门有一个输入是 1 时，输出不受另一个输入影响（"1 作为与门……与开头的那个门，你就影响不了输出结果"），所以 G1​、G2​ 的输入不变，触发器状态不改变。
    • 

  • C=1：G3​、G4​ 才开始起作用。G3​ 的输出由 S 决定、G4​ 的输出由 R 决定，再由这两个输出去决定 G1​、G2​ 的输入，从而决定 Q。

    4.

空翻现象
现象（51:47–52:16）：钟控 RS 触发器的 Q 只在 CP 的高电平窗口内才可能变化。
当 CP 的高电平脉冲持续时间过长时——"在这个过程当中，我的 S 跟 R 它已经发生了好多次的翻转了"——
而每一次翻转都落在 CP 高电平的有效范围之内，于是 Q 在一个时钟脉冲期间翻转多次。
教师原话："那就会发生这个 Q 会发生空翻，就我不希望它翻转，它翻转了啊，这个我们就叫空翻。"


后果：输出在不该翻转的时候翻转，信号受干扰，抗干扰能力下降。


解法：教师一句"那么怎么解决，我们下一节课来讲"（52:40）收束本讲。

  • 基本 RS 特性方程里两个非号的位置（本篇最要紧的一处转写歧义）：教师口述的式子（21:07）是「Qn+1​ 应该等于 SD​​ 加上 RD​​ 乘以 Qn​」，转写为「S B 加 R T C 乘以 Q N」——两个非号分别在第几项上都读不出来。
正文取 Qn+1​=S+R⋅Qn​（S、R 是逻辑有效信号，不是引脚电压），依据有两条：
① 教师在 19:15 解释绿色圈时说的是「本来是 SD​ 非再取反，所以就是 SD​」——第一项是引脚 SD​ 取反后的逻辑置位信号；
② 红色圈取的是「RD​​ 乘以 Qn​」，对应"RD​=1（R 无效）时次态跟着 Qn​ 走"，即第二项用的是引脚 RD​ 本身。
机械复核判据：把四种输入组合逐行代入，必须与状态表一致。已逐行验过——按逻辑信号写，6 行全部一致（置 1 得 1、置 0 得 0、保持两行得 Qn​）；若把两个非号都读成"直接对引脚电压取反"，则 6 行里 5 行对不上（置 1 那一行会算出 0）。双签时应重跑这一条。
⚠ 同一条也解释了教师在钟控 RS 那段说的"基本 RS 和可控 RS 的特征方程形式一致"（48:28）：两者的 S、R 都是逻辑有效信号，所以式子形状相同，区别只在基本 RS 的两个信号要各取一次反。

  • 基本 RS 触发器的电路图：教师在课件与黑板上画了两只与非门交叉耦合（23:12–24:45），转写里没有图。本页正文里的 ASCII 简图是按教师口述的连接关系（G1 输出 = Q 接 G2 输入、G2 输出 = Q​ 接 G1 输入、RD​ 与 Q 构成 G2 的两个输入）画的，不复现课件图面，如与原图有出入以原图为准。

  • 时序图例题：教师给的是课件上的一段波形（29:41–34:01），波形图本身不在转写里。正文表里列的七个时刻是按教师逐段口述的顺序还原的（置 1 → 保持 → 置 1 → 置 0 → 置 1 → 同时为 0 的"一态" → 同时由低翻高的不可控段），波形形状与时间刻度本页未复现。

  • 钟控 RS 的 G3​、G4​ 接法：教师口述"G3​ 的状态跟 S 有关、G4​ 的状态跟 R 有关"（41:51），
并由四种组合逐一推出 G3​／G4​ 的输出（43:47–47:15）。
本页正文表格按这四次口播反推：S=0,R=1 时 G4​ 输出 0（推 Q=0）、S=1,R=0 时 G3​ 输出 0（推 Q=1）——与 G3​ 管 S、G4​ 管 R 一致。
⚠ 但**S 接 G3​ 的哪一个输入端、R 接 G4​ 的哪一个输入端**（各门的两个输入中哪个是 C、哪个是 S／R），转写未逐一报出，正文也未断言，复核时以课件图为准。

  • 钟控 RS 特性方程的极性：教师口述「它等于 S 加上 R 可以（取反）乘以 qn​」（47:54–48:28），转写里"可以"是否带非号读不出，

双签
2026-11-04，独立子代理只拿题面重做全部题号（Octave 电路级仿真复核）：一致 13 项、不一致 0 项、条件不自足 3 项。


特别核：特性方程四个候选——在「S、R 为逻辑有效信号」约定下，
只有候选 ① Qn+1​=S+R⋅Qn​ 能让 6 行全对；
② S+RQn​ 错 5/6、③ S+RQn​ 错 2/6、④ S+RQn​ 错 4/6。正文取法正确。


约定问题：S、R 是逻辑有效信号（S=SD​​、R=RD​​），
三条依据：转写 19:15「本来是 sd 非再取反，所以就是 sd」；
19:51 红圈取 RD​⋅Qn​；
48:28–49:01「基本 rs 和可控 rs 的特征方程形式是一致的，你不要去记反了」
——钟控 RS 的 S、R 本就是高电平有效的逻辑有效信号，两者形式一致就要求基本 RS 同解。
「引脚电压直读」那一支与三条口播均不相容。


段码核对：独立算出与正文全部一致（2 = 1011011、6 = 1111101、1 = 0000110、0 = 0111111、9 = 1101111；
74LS47 低电平有效取反码亦复现）。


条件不自足 3 项：① 0110 那一行转写两处口播互斥（09:18「编码二」与 11:01「只要 b 不亮」），
正文取数字 6（BCD 中 0110 = 6）并已披露；② 74LS47 四个 BCD 输入端的引脚号转写含糊（「一、2、1、2、6」），未落脚号；
③ 数码管引脚号 3/8 的归属口径（模块公共端还是 74LS47 的脚）转写未交代。三项均未补造。


双签另核过且一致：6 行状态表、基本/钟控 RS 状态图各 4 条边、时序图 7 个时刻、钟控 RS 四组合与三条硬约束、
空翻现象、三个控制端（均 Octave 电路级仿真复现）。
