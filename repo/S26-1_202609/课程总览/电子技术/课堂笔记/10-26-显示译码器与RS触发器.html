10-26-显示译码器与RS触发器

这节课在干什么：这一晚是连堂两段——18:01 起的那段在「上节课没讲完的显示译码器」处收尾，讲到基本 RS 触发器的电路结构就断在一个问句上；18:32 起的那段直接给答案，接着讲完基本 RS、钟控 RS，最后停在「空翻怎么解决，下一节课来讲」。两段合起来是一条完整的线，要会六件事：

① 把七段译码显示器的段码表收完——七段的排列、0/1/2/6/9 各点亮哪几段、74LS47 的低电平有效与 LTC／RBI／BI 三个控制端； ② 第八章的范围：重点是 RS、JK、D 三种触发器的逻辑功能、特性方程与状态转移关系，8.05–8.07 只作了解； ③ 触发器的定义与三个特点——记一位二进制信息、两个稳定状态、输入消失后状态被保存； ④ 按功能分的三大类：双稳态、单稳态、无稳态（多谐振荡器）； ⑤ 基本 RS 触发器：两个与非门交叉耦合的电路结构、SD​／RD​ 的四种输入组合，以及描述它的四种方式（状态转移真值表 → 特性方程 → 状态转移图 → 工作波形图）； ⑥ 钟控（可控）RS 触发器与它的两个固有缺陷，其中空翻现象只点到现象，解法留给下一节课。

行政与考核

  • 第八章要求（17:26–18:52）：重点掌握 RS 触发器、JK 触发器、D 触发器的逻辑功能、特性方程和状态转移关系； 在此基础上理解寄存器、移位寄存器、二进制计数器、十进制计数器的逻辑功能和工作原理； 掌握时序逻辑电路的分析方法，了解其设计方法。 综合应用里还讲了集成计数器、寄存器（左移／右移／双向移动）、单稳态与无稳态触发器。教材的 8.05、8.06、8.07 作了解性知识。
  • 作业预告（34:54）：从这节课开始会有大量时序图作业，要画 RD​、SD​、R、S、Q 各种状态下的波形。
  • 实验衔接（10:30）：实验箱左上角那台数码管显示与一块七段译码显示器芯片配对使用，下一次做计数器实验时可以顺手把它做一遍。

没编号但讲了的知识点

显示译码器：把运算结果变成看得见的十进制数字

链路（00:50–01:44）：BCD 编码（二-十进制代码）→ 译码器 → 驱动器 → 显示器。数字仪表、计算机的数字系统都是靠这条链路把运算结果用十进制数显示出来。

数码管的两种接法（01:44–03:04）：七段发光二极管排成"日"字形。

接法公共端接法各段另一端译码输出的有效电平
共阴极所有阴极接在一起接地各阳极接译码信号高电平有效（输出高 → 该段亮）
共阳极所有阳极接在一起接电源正极各阴极接译码信号低电平有效（输出低 → 该段亮）

两种接法的段码排列完全一样，不一样的是输出极性，所以译码器与数码管必须配对使用，配错就整片显示乱码。

段的排布（03:04–03:58）：最上面那一横记 a，然后顺时针方向 b、c、d、e、f，中间那一横是 g。

⚠ 教师报出「共阴极时第 8 个引脚和第 3 个引脚都接地，共阳极时 3 和 8 接电源正极」，但转写里没有交代这是数码管模块的公共端脚号还是 74LS47 的控制端脚号，两处引号编号的口径见文末完成边界。段码表本身不受这一条影响。

芯片（11:59）：七段译码显示器做成一块集成芯片 74LS47。四个 BCD 输入端接码字，输出是七段，外加一个控制端。

  • 低电平有效 → 配共阳极接法。教师原话："你的阳极已经是接高电平了……你只要你的阴极出现低电平，它就亮了。"
  • 高电平有效 → 配共阴极接法。

所以同一张段码表，搬到 74LS47（配共阳极）上时亮的段输出 0、灭的段输出 1，与上表正好相反。

进入第八章：范围与要求

为什么换章（16:33–17:26）：前面讲的都是组合逻辑电路，它没有记忆元件（没有触发器这类记忆元件），输出只跟着当时的输入变，与前一时刻的状态无关。第八章讲有记忆的电路——输出除了取决于输入，还取决于电路原来的状态。

本章内容（17:26–18:52）：

  • 双稳态触发器 + 时序逻辑电路的分析与设计；
  • 综合应用里：集成计数器（各种进制的）、寄存器（左移、右移、双向移动）、单稳态触发器、无稳态触发器；
  • 教材的 8.05、8.06、8.07 作了解性知识；
  • 重点掌握前面四种触发器：RS 触发器、JK 触发器、D 触发器的逻辑功能、特性方程和状态转移关系（教师原话"它的逻辑功能、特征方程和状态转移关系"）；
  • 在此基础上理解寄存器、移位寄存器、二进制计数器、十进制计数器的逻辑功能和工作原理；
  • 掌握时序逻辑电路的分析方法，了解其设计方法。

触发器的定义与三个特点

定义（19:24）：能够储存或者记忆一位二进制信息的基本逻辑单元。

三个特点（19:24–22:06）：

  1. 两个稳定状态：一位二进制信息就是 0 和 1，所以触发器有状态 0 与状态 1 两个稳定状态。
  2. 可以被输入控制：通过不同的输入可以对输出状态进行控制——可以置 0，也可以置 1；这两种状态能通过改变输入互相改变。
  3. 输入消失后状态被保存（教师说"第三点特别重要"）：输入信号消失之后，输出的 0 或 1 被保存下来，不变化——这就是记忆功能。

与组合逻辑电路的分界（21:14–22:06）：组合逻辑电路的输出随着输入状态的改变而改变，与前一时刻的状态没有任何关系；触发器则下一时刻的状态跟现在的状态有关系——它不只跟输入有关，还跟当下的状态有关，当下的状态可以对下一刻的状态产生影响。

类别包含什么

单稳态触发器—

教师强调"三大类，大家要记住"。双稳态触发器是最基本的一类，其中最基本的就是基本 RS 触发器。

基本 RS 触发器的电路结构

组成（23:12–24:45）：两个与非门 G1​、G2​，输出互为对方的输入（交叉耦合）。

  • G1​ 的输出记作 Q，Q 是 G2​ 的一个输入信号；Q 与 RD​ 共同组成 G2​ 的两个输入。
  • G2​ 的输出记作 Q​，Q​ 反过来作为 G1​ 的输入信号。
  • 所以 G1​ 与 G2​ 的两个输出是互补关系。

电路结构（两只交叉耦合的与非门，Q 与 Q​ 互补）：

text 
        ┌───────┐
  S̄_D ─┤       │
        │  G1   ├──── Q ─────┐
  Q̄ ───┤  与非  │            │
        └───────┘            │
                             ▼
        ┌───────┐         ┌───────┐
        │       │◄────────┤       │
  R̄_D ─┤  G2   │         │  G1   │
        │  与非  ├──── Q̄ ─┤  与非  │
        └───────┘         └───────┘

输入端 SD​、RD​ 带非号，是低电平有效——这一条决定了下面四种组合的一切。

基本 RS 的四种输入组合

教师在第一段末尾停在问句"假设 SD​ 和 RD​ 都不起作用的时候，那应该是什么？"（25:06），第二段开头直接给答案并接讲第三种情况。两种接法要分清：基本 RS 的 SD​、RD​ 是低电平有效（带非号）；钟控 RS 的 S、R 是高电平有效（不带非号）——两者极性相反。

#SD​RD​谁有效Qn+1​功能教师原话依据
110R 有效0（不管 Qn​）置 005:17
201S 有效1（不管 Qn​）置 105:57
311都无效Qn​保持00:17–01:17
400都有效不确定不允许出现01:17–03:40

第 3 种（保持）怎么推出来的（00:33–01:17）：设原状态 Q=0。G2​ 的输入是 Q 与 RD​，即 0 与 1 相与得 0，取反得 1，所以 Q​=1；G1​ 的输入是 Q​=1 与 SD​=1，相与得 1，取反得 0，所以 Q 仍为 0。原状态是 0 就保持 0；原状态是 1 就保持 1——两个状态各自"往复循环"，输出不变。

第 4 种（不确定）到底怎么来的（01:17–03:40）：

  • 两个输入同时为 0 时，G1​ 与 G2​ 的输入里各有一个 0，两个输出都是 1（Q=1，Q​=1）——这一瞬间的状态是确定的。
  • 但在这个状态下两个输入一起由 0 变 1 时，要看这两个与非门谁先翻转；谁先谁后无法确定，于是次态不可控。
  • 所以"同时为零"这一刻有确定值，"同时由低翻高"这一段才是不定状态。

教师在第二段末尾特别把这条澄清了一遍（36:21–37:23）："注意这个不确定是不是说同时出现零的时候是确定的啊……同时是零的时候，状态是确定的，Q 等于 1，Q​ 也等于 1……如果只翻转一个呢，是确定的……你两个同时由低电平往高电平去翻的时候，那就出现状态不可控了。"

结论：正确使用时不允许 SD​ 与 RD​ 同时为 0。

记忆法：S 是 set，R 是 reset

教师专门教了一套记法（13:21–14:41）：

  • S 管置 1，对应的英文单词是 set（设置）；
  • R 管置 0，对应的英文单词是 reset（复位）；
  • 两个同时无效 → 保持不变；
  • S、R 上面有没有非号，决定它是高电平有效还是低电平有效——有一个非号就是低电平有效，没有就是高电平有效。基本 RS 的两个输入都带非号，所以是低电平有效；等下讲钟控 RS 时，S、R 没有非号，是高电平有效，两者正好相反（45:53："注意这里是 S 是没有戴帽子的"）。

描述触发器功能的四种方式

教师说"再去看第 3 块的内容"（03:55），把描述一个触发器的逻辑功能分成四种方式。先把两个记号立起来：

  • 次态 Qn+1​：下一个时刻的状态；
  • 现态 Qn​：现在的状态。

按教师自己的编号（07:11"第二种描述触发器功能的叫做特征方程"、21:21"第三种……状态转移图"、28:27"第四种……也叫时序图"），四种方式是：状态转移真值表（状态表）→ 特性方程 → 状态转移图 → 工作波形图（时序图）。 逻辑符号是第一种（状态表）里附带的画法，画图时用来认器件。下面按讲的先后逐个展开。

① 状态转移真值表（状态表）

列法：把四种输入组合逐条列成表，写清每一种下 Qn+1​ 是什么。

SD​RD​Qn​Qn+1​功能
1000置 0
1010置 0
0101置 1
0111置 1
1100保持（Qn+1​=Qn​）
1111保持（Qn+1​=Qn​）
000不确定不允许出现
001不确定不允许出现

教师说这张表"组合怎么这么复杂"（13:06），于是给了上面那套 set／reset 记忆法——记住 S 管置 1、R 管置 0、两个都无效就保持，表就不用死记。

逻辑符号（画图时认它）

（06:38–07:11）一个方框，两个输入、两个输出：

  • 方框里写 S 和 R；
  • 两个输入端都加小圆圈——因为是低电平有效；
  • 输出是 Q 和 Q​，互补。

② 特性方程（状态方程）

写法：像组合逻辑电路写逻辑表达式那样，把次态写成次态 + 输入条件的逻辑式。

先把两组信号分清（这是本讲最容易记反的地方）：

记号含义有效电平
SD​、RD​引脚上的电平（方框里画的就是这两个带非号的输入端）低电平有效：SD​=0 才表示置 1 有效，RD​=0 才表示置 0 有效
S、R逻辑有效信号：S=1 表示置 1，R=1 表示置 0由引脚各取一次反得到：S=SD​​、R=RD​​

怎么列（15:23–19:00）：

  1. 列输入信号：一共三个——现态 Qn​，以及两个输入端。
  2. 画卡诺图（按前面的状态表）。
  3. 处理约束项：SD​ 与 RD​ 同时等于 0 的那两格是无关项，用约束项表示——因为那是不确定的状态。
  4. 圈组化简（教师在课件上用绿、红两个圈标出来）：
    • 绿色圈：圈住"置 1 有效"的那两格（SD​=0，Qn​ 取 0 或 1）与两格约束项。这一列全是 1 或无关项，保留 1 得到的那一项就是逻辑置位信号 S——教师原话"当 SD​=0 也就是 SD​=1……本来是 SD​ 非再取反，所以就是 SD​"。
    • 红色圈：圈住"R 无效且 Qn​=1"那两格，保留的那一项是 R⋅Qn​——教师原话"保留相同量……R 非乘以 Qn​"。
  5. 得结果：

Qn+1​=S+R⋅Qn​

换回引脚写，就是

Qn+1​=SD​​+RD​⋅Qn​

（第一项那个双重取反不能省：它表示"引脚 SD​ 取反后才是逻辑置位信号"。）

约束条件（20:26–20:43）：S 与 R 不能同时为 1，也就是引脚 SD​ 与 RD​ 不能同时等于 0——这正是四种组合里第 4 种不允许出现的那个条件，写在方程旁边作为限制。

自查办法只有一条：把四种输入组合逐行代入这个式子，结果必须与状态表一致（置 1 得 1、置 0 得 0、保持得 Qn​）。方程与状态表对不上时，以状态表为准——推导过程与这句话见文末完成边界。

③ 状态转移图（状态图）

画法（21:21–22:36）：

  • 用两个圆圈代表 0 和 1 两种状态；
  • 用箭头从一个圆圈指向另一个圆圈，表示状态转移的方向；
  • 在箭头旁标注转移条件。

四条边逐条推（23:05–26:28）：

转移条件依据
0 → 1SD​=0、RD​=1（置 1）置 1 过程
0 → 0RD​=X（任意 0 或 1），但 SD​ 必须为 1只要 SD​ 无效，就不会是置 1；此时要么保持、要么置 0，末态仍是 0
1 → 0RD​=0、SD​=1（置 0）置 0 过程
1 → 1RD​=1（不能为 0），SD​ 可 0 可 1RD​ 有效就会变 0；RD​ 无效时要么置 1、要么保持，末态仍是 1

教师专门提醒："这个不变是很关键的，这个不变很容易让我们漏掉……在状态转移的过程当中，就是我 SD​ 和 RD​ 都等于 1 的情况下，我的次态和现态是……这个状态你别忘了"（26:28）。画状态图时保持那两条边必须画出来。

为什么要画（27:08–28:27）：后面学计数器时，状态转移图是重要分析工具——比如从 0000 → 0001 → 0010 依次转移，每来一个时钟状态转移一次，"每一个时钟过后，你的每一个输出端输出的状态到底是怎么样的"，到集成计数器那一章时，状态转移图就是分析它的标准工具。

④ 工作波形图（时序图）

给什么（28:27–29:41）：通常给输入信号随时间变化的波形图，再加上一段状态图；然后按特性方程、状态转移图或状态表判断次态。

推法：Q 与 Q​ 是由 RD​、SD​ 的变化 + 之前的状态共同决定的——不是只看当前输入。

基本 RS 的时序图例题

教师把一段波形逐段推过去（29:41–34:01）：

时刻输入条件Qn+1​说明
1SD​=0、RD​=1高电平置 1，Q​ 相应为低电平
2RD​=1、SD​ 也变为 1保持高电平查状态表：保持不变，Qn+1​=Qn​
3SD​=0、RD​=1仍高电平仍是置 1 的条件
4SD​=1、RD​=0由高变低R 有效 → 置 0
5RD​=1、SD​=0由低变高满足置 1 的条件 → 置 1
6两个同时为 0Q=1、Q​=1都是 1，是"一态"
7两个同时由低翻高不可控虚线段画成"无序混乱"：谁翻得快，结果就不一样

这一段要记住的分辨（36:21–37:23）：

  • 同时为 0 的那一段：状态是确定的——Q=1，Q​=1；
  • 只翻转一个：状态也是确定的——要么置 1 有效，要么置 0 有效；
  • 两个同时由低电平往高电平翻：才进入不定状态，Q 不再由输入信号确定，而是由"谁翻得快、谁翻得慢"的偶然因素决定。

所以使用中不允许让两个输入同时为低电平有效。

基本 RS 触发器的两个固有缺陷

（37:55–39:25）教师点出两条，作为下一讲铺垫：

  1. 状态只由两个控制信号决定，与时间无关——"你的这 2 个输入状态是什么样的，就确定了是什么样的状态，包括它原来的这个状态……它跟时间就没有任何关系"。所以做不了计时器。
  2. 实际电路里两个输入无法完全控制——输入状态控制不住，就有可能出现不定状态。

钟控（可控）RS 触发器

电路（39:25–40:30）：在基本 RS 触发器的基础上再加两只与非门 G3​、G4​。这两只门有一个共同的输入 C（时钟脉冲信号）。C 作为 G1​、G2​ 的一个输入信号的控制信号——它加入了这个导引电路和控制端 C。

工作分析（40:30–42:41）：

  • C=0：G3​、G4​ 的输出都是 1。与非门有一个输入是 1 时，输出不受另一个输入影响（"1 作为与门……与开头的那个门，你就影响不了输出结果"），所以 G1​、G2​ 的输入不变，触发器状态不改变。
  • C=1：G3​、G4​ 才开始起作用。G3​ 的输出由 S 决定、G4​ 的输出由 R 决定，再由这两个输出去决定 G1​、G2​ 的输入，从而决定 Q。

四种输入组合（43:47–47:15）：

SRG3​、G4​ 的输出Qn+1​功能
00都为 1Qn​保持不变
01G4​ 输出 00置 0
10G3​ 输出 01置 1
11都为 0—出现"一态"，随后进入不稳定状态

第 2 行的推法（44:40）：R=1 与 C=1 相与再取反得 0，G4​ 输出 0 → G2​ 的输入里有一个 0 → G2​ 输出 1 → Q=0，置 0。第 4 行：S、R 都为 1 时 G3​、G4​ 输出都是 0，G1​、G2​ 的输入端同时出现 0 → 出现"一态"，同时翻转后又进入不稳定状态。

与基本 RS 的三点对照（45:53–50:04）——这是本讲最容易记反的地方：

  1. 有效电平相反：基本 RS 的 SD​、RD​ 是低电平有效（带非号）；钟控 RS 的 S、R 没有非号，是高电平有效（教师原话"注意这里是 S 是没有戴帽子的"）。虽然记法反了，功能对应关系却一致——S 有效仍置 1、R 有效仍置 0。

  2. 特性方程形式一致：钟控 RS 同样是

    Qn+1​=S+R⋅Qn​

    教师强调"你不要去记反了"（48:28–49:01）——它与基本 RS 的 Qn+1​=S+R⋅Qn​ 形式一致：两边的 S、R 都是逻辑有效信号（S=1 置 1、R=1 置 0），所以式子形状相同，区别只在基本 RS 的两个信号要各取一次反（SD​ 的反是 S，RD​ 的反是 R）。约束条件也不变（S、R 不能同时为 1）。

  3. 状态表与状态图必须括注 CP=1 才有效："你画这个 RS 触发器的时候，状态表记住这里必须括弧，要有一个 CP 等于 1 的时候，这个只有它等于 1 的时候有效啊……这个状态图也是一样的，也要标一个 CP=1，这个不标不行"（49:10–49:57）。

状态图的对照（50:04–51:09）：0 → 1 只在 S=1、R=0（置 1）；1 → 0 只在 R=1、S=0（置 0）；0 → 0 只要不出现 S=1，R 是什么都行；1 → 1 只要满足 R=0，S 是 0（保持）还是 1（置 1）都不影响末态仍是 1。

空翻现象

现象（51:47–52:16）：钟控 RS 触发器的 Q 只在 CP 的高电平窗口内才可能变化。 当 CP 的高电平脉冲持续时间过长时——"在这个过程当中，我的 S 跟 R 它已经发生了好多次的翻转了"—— 而每一次翻转都落在 CP 高电平的有效范围之内，于是 Q 在一个时钟脉冲期间翻转多次。 教师原话："那就会发生这个 Q 会发生空翻，就我不希望它翻转，它翻转了啊，这个我们就叫空翻。"

后果：输出在不该翻转的时候翻转，信号受干扰，抗干扰能力下降。

解法：教师一句"那么怎么解决，我们下一节课来讲"（52:40）收束本讲。

转写与术语

本次转写的同音误识别集中在触发器型号与输入端名、"特征/特性"与"姿态/线态"这组词、以及**"增值表"**上，照原文抄会抄错意思：

  • 「基本 is 触发器／基本负担／基本 rs 触发器」→ 基本 RS 触发器。
  • 「解 K 触发器／K 触发器」→ JK 触发器。
  • 「孵化器」→ 触发器（"这个孵化器只能记一位二进制信息"＝触发器）。
  • 「Sdc／Sdv／SDK／SDV／sdc」→ SD​（S 端，异步置位，低电平有效）；「Rdc／rdc／rdv／RDK／RDV」→ RD​（R 端，异步复位，低电平有效）。
  • 「Sdc 等于 1」这类说法里的"等于 1"要连着"低电平有效"一起看——SD​=1 表示 S 端无效，SD​=0 才表示置 1 有效。教师在 $S$ 有效 = 置 1、$R$ 有效 = 置 0 这条对应上是清楚的。
  • 「特征方程／特定方程／对应方程／姿态方程」→ 特性方程（同句里也出现过正确的"特征方程"，两种写法指同一个东西）。
  • 「姿态／线态／磁带／后跟」→ 现态；「4派／4K」→ 次态。
  • 「状态转移增值表／增值表／状态转移分子表」→ 状态转换真值表（状态表）（转写里"状态表"本身也出现过，属正确写法）。
  • 「状态反应图／状态转换图」→ 状态转移图（状态图）。
  • 「工作波形图」→ 时序图（教师两个说法都用，本页统一写"工作波形图（时序图）"）。
  • 「卡路图／卡路／长度图」→ 卡诺图。
  • 「保留相同项／保留相同量」→ 卡诺图圈组化简时的保留 1／保留 0（含无关项的圈）。
  • 「约束项／无关项」→ 约束项（无关项），指 SD​ 与 RD​ 同时为 0 的那两格。
  • 「引导电路／导引电路」→ 引导电路（本讲钟控 RS 里 G3​、G4​ 那一组，10-28 那篇的 D 触发器也用这个词，两篇一致）。
  • 「一态／异态／遗憾」→ 一态（Q 与 Q​ 同时为 1）。
  • 「不定状态／不确定的状态／无序混乱的状态」→ 不确定（不定）状态。
  • 「空翻」→ 空翻现象（转写里"空翻"两字本身正确，与 10-28 那篇同词）。
  • 「戴帽子／C 这个符号／没有 C」→ 讲输入端有没有非号（S 上方那个横杠）——"戴帽子"指那个非号。
  • 「741S2 4 7」→ 74LS47；「LTC／ltc」→ LTC；「rbi／rbic」→ RBI；「bic」→ BI。
  • 「供阳极／供阴极／中心级／共进级」→ 共阳极／共阴极。
  • 「八字形／日字形」→ 七段数码管的**"日"字形**排列（教师口述"八字形"，是同一个形状）。
  • 「筹码／数码版」→ 数码管；「七块一码显示器／七码显示器」→ 七段译码显示器。

  • 「低液体状态」→ 低电平状态；「清灯／灭灯」→ 灭灯。
