2026-10-12作业

1. 来源与边界

  • 来源：学习通上的作业，平台页眉（任务名）逐字为「2026-10-12作业」；共 1 题，平台小节写作「简答题」——即教材习题 7.4。
  • 题面来源：用户提供的 1 张答题页截图；截图原件不入库，文件名与 SHA-256 登记在原始资料索引。题面与图 7.01 已与教材第 7 章章末习题 7.4 逐字核对一致（该章原文档已归档，图 7.01 取自原文档内的图片对象）。
  • 题型：画波形——已知输入 A、B、C、D 的波形，画出 (b)~(g) 六个门电路的输出波形。
  • 配图：题面有图（图 7.01(a) 输入波形 + (b)~(g) 六个门电路），已按「题面必须完整」把输入波形与六个门电路一并画在题面里（下方两图）；六个门的输出波形是本作业的答案，在解答层给出。

2. 依赖

做之前先过掉（点击直达）到那里你该已经会了
基本逻辑门与复合逻辑门的符号读门三步：门体符号（&/AND 与、≥1 或、=1 异或、1 非）；输入端接信号还是常数；输出端小圆圈＝对该门输出取反。含与非/或非/与或非/异或/同或的表达式与口诀
基本定律（五组）与常用公式与、或、非的运算规则；A⋅1=A、A⋅0=0（门的一端接常数时用这两条看穿）

怎么用这份作业：先自己按输入波形把六个门的输出画出来，再逐题展开「提示 → 完整解答 → 复盘」对照。 本类题的三步套路：① 写表达式——把每个门（含输入端的常数 0/1、输出端的取反泡）写成逻辑式； ② 化简——接常数的门往往直接退化（如 A⋅1=A、C⋅0=0）；③ 照表达式画波形——逐段把输入的高低电平代进去。

三、逐门解析

(b) 与门（A、1）取反

提示

与门一个输入接常数 1，先化简再想取反泡 ① A⋅1=A，所以这就是把 A 取反；② 输出端的小圆圈再做一次取反，合起来就是 A。

完整解答

表达式：Yb​=A⋅1=A。 波形：A 的反相——A 为高时 Yb​ 低、A 为低时 Yb​ 高；A 有 10 个脉冲，Yb​ 就有 10 个互补脉冲。

复盘

接常数 1 的与门是「透明门」：A⋅1=A，它不改变信号，输出端有没有取反泡才决定波形是 A 还是 A。 这类门考的就是「常数 + 取反泡」两层都别漏。

(c) 与门（C、0）取反

提示

与门一个输入接常数 0，先把乘积算出来 ① 任何数与 0 相与都是 0；② 输出端取反泡把 0 变成 1——于是输出与 C 无关。

完整解答

表达式：Yc​=C⋅0=0=1。 波形：恒为高电平的一条直线（全时段为 1），C 的波形完全不影响输出。

复盘

接常数 0 的与门是「死门」：输出恒 0，再加取反泡就是恒 1。 与 (b) 对照——同样是「与门 + 取反泡」，一个接 1 得到 A、一个接 0 得到恒 1，常数是谁直接决定结果。

(d) 三输入与门（A、B、C）取反

提示

三个输入同时为 1 时输出才被拉低 Yd​=ABC：只有 A、B、C 同时为 1 时 ABC=1、Yd​=0；其余时刻 Yd​=1。

完整解答

表达式：Yd​=ABC。 波形：大部分时间为高，只在 A、B、C 三者重叠为高的少数时段出现低电平。 本题里 C 只有 2 个宽脉冲，ABC=1 只可能落在 C 的两个脉冲内、且 A、B 同时为高处——所以 Yd​ 的低电平是两段短凹口。

复盘

三输入与门取反 = 与非门。「三者同时为 1」在波形上就是三条高电平的重叠区——先把 C 的两个宽脉冲找出来， 再在其中挑出 A、B 也同时为高的段，凹口就定位了。

(e) 或门（B、D）取反

提示

或门取反 = 或非：两个输入都为 0 时才输出 1 Ye​=B+D​：只要 B 或 D 有一个为 1，输出就是 0；只有 B、D 同时为 0 时才为 1。

完整解答

表达式：Ye​=B+D​。 波形：大部分时间为低（B 的 5 个脉冲、D 的 1 个宽脉冲都把它压低），只在 B 与 D 同时为低的几段出现高电平。

复盘

或非门的输出高电平 = 两条输入都低的交集。D 的宽脉冲横跨中部，把 (e) 的中段整段压低；只在 D 之外、B 也为低处才有高电平。

(f) 异或门（A、D）取反

提示

异或门（=1）再带取反泡 = 同或：两输入相同时输出 1 Yf​=A⊕D​=A⊙D：A 与 D 相同（同为 0 或同为 1）时 Yf​=1，不同时为 0。

完整解答

表达式：Yf​=A⊕D​=A⊙D。 波形：A 与 D 的电平相同处为高。D 为低的前段，Yf​ 跟随 A（与 A 相反）；D 为高的中段，Yf​ 跟随 A（与 A 相同）。

复盘

「异或门符号 =1 + 输出取反泡」是本题最容易看错的一处：=1 本身是异或，加泡才是同或。 记法：异或「不同为 1」，同或「相同为 1」——波形上就是「A、D 相同则高」。

(g) 与或非门

提示

两个与门先各算一项，或门相加，最后取反 ① 上支路 A⋅B、下支路 C⋅D；② 或门把两项相加 AB+CD；③ 输出取反得 AB+CD​。

完整解答

表达式：Yg​=AB+CD​。 波形：只要 AB=1 或 CD=1 就输出低，两项都为 0 时输出高。

  • AB=1：A、B 同时为高（A 的窄脉冲落在 B 的宽脉冲内时）；
  • CD=1：C、D 同时为高（C 的宽脉冲与 D 的宽脉冲重叠的那一段）。 两处都会把 Yg​ 拉低。
复盘

与或非（AOI）门是复合门：读图时先把它拆成「两个与门 + 一个或门 + 一个取反」四块， 分别写出中间量再合并，就不会把结构看错。它与 (d) 的区别是：(d) 是「三个输入全与」，(g) 是「两项之或」。

小结：这份作业要带走的东西

  1. 常数输入先化简：与门接 1 → 透明（等于另一个输入）；接 0 → 死门（恒 0）。取反泡再翻一次。
  2. 取反泡只在输出端：读门时先看门体符号（&/≥1/=1），再看输出端有没有小圆圈——有泡就把整个结果取反。
  3. 或非 / 与非 / 同或：分别是「或门 + 泡」「与门 + 泡」「异或门（=1）+ 泡」；=1 加泡 = 同或，别看成异或。
  4. 画波形三步：写表达式 → 化简 → 逐段代入。多输入门就找「高电平重叠区」。
  5. 复合门拆开读：像 (g) 这种与或非门，拆成「与门 → 或门 → 取反」再逐块写式子。

  • 已知限制：原书图系手绘，相位为近似值；波形按原图数字化的相位关系在干净时间网格上重画，只保留逻辑关系与脉冲数（A=10、B=5、C=2、D=1 个脉冲），输出波形形状只依赖六个表达式、不依赖具体相位。

条件备注

  • (g) 的结构（上与门 A⋅B、下与门 C⋅D → 或门 → 取反）经两名读图员确认；六个门输出端均带取反泡。
