2026-11-23作业

1. 依赖

判断正弦波振荡电路能否起振，核心是检查直流偏置是否正常以及**起振条件（相位平衡 φA​+φF​=2nπ 与幅度条件 ∣AF∣>1）**是否同时成立。对具体电路可按下列机械步骤逐项核查：

核查项目机械步骤（照做）判据与依据
1. 直流偏置与组态识别① 沿直流路径检查 RB1​、RB2​、RE​ 等偏置元件是否被电感或导线直流短路；② 看基极与发射极对地有无旁路电容 CB​、CE​，或经偏置电阻接交流地，结合输入／输出端定出共基／共射组态三极管须先能稳定工作在放大区；交流通路里 B 为交流地则是共基（同相），E 为交流地则是共射（反相）
2. 瞬时极性法判反馈极性① 设放大级交流输入端电位瞬时升高（记为 +）；② 按组态推出集电极 C 电位极性（共基同相为 +，共射反相为 −）；③ 依变压器同名端或电容／电感分压，推出反馈网络输出端极性；④ 将反馈极性与原假设极性对比反馈信号增强净输入（同向变化）⇒ 正反馈（满足 φA​+φF​=2nπ）；削弱净输入（反向变化）⇒ 负反馈（不能起振），见 正反馈与负反馈
3. LC 三点式「射同余异」复核① 画出交流通路（+UCC​ 与旁路电容视作交流地）；② 分别列出 B-E、C-E、B-C 之间的电抗性质（感性 X>0 或容性 X<0）；③ 核对 Xbe​ 与 Xce​ 是否同性质、Xbc​ 是否异性质只有「射同余异」（Xbe​、Xce​ 同性质，Xbc​ 异性质）才满足正反馈相位条件
4. RC 网络相移核对① 确定基本放大级相移 φA​（单级共射为 180∘）；② 确定 RC 选频网络相移范围 φF​（RC 串并联网络在 (−90∘,+90∘) 内，选频点 ω0​ 处为 0∘）；③ 检查 φA​+φF​ 能否达到 0∘/360∘若总相移始终达不到 2nπ，则相位平衡条件不成立，不能起振
5. 幅度起振条件 ∣AF∣>1相位条件成立后，在 三个环节的三个式子 给出的 A、F 定义基础上，按本页起振条件核查环路增益 ∣AF∣（尤其注意无 CB​ 时 RB​ 会拉低等效跨导）正反馈只是必要条件；只有同时满足 ∣AF∣>1（如 RB​ 不致过大）电路才能起振

怎么用：四幅电路各设一组「提示 → 完整解答 → 复盘」折叠块，默认收起——先按上表自己推一遍极性与组态，再逐层展开核对。

(a) 变压器耦合电路

提示

先看清两个黑点（同名端）都在哪一端：L 的同名端在下（集电极 C），L1​ 的同名端也在下（接地端）。同时注意 B 端有 CB​ 交流接地，且 L1​ 直接跨在 E 与地之间。

已收录旁注（不接管步骤）：正反馈与负反馈给出了「净输入被增强或削弱」的极性判据。

完整解答

第一步：直流通路与交流组态。

  1. 直流偏置异常：副边线圈 L1​ 下端直接接地、上端直接接发射极 E。由于电感线圈对直流近似短路，L1​ 将发射极电阻 RE​ 直流短路，使发射极静态电位被强行拉至地电位，无法利用 RE​ 稳定静态工作点。
  2. 交流组态：基极接有旁路电容 CB​ 至地，对交流信号而言 B 处于交流地电位；反馈信号由 L1​ 上端送入发射极 E，输出取自集电极 C ⇒ 电路按共基极组态工作。

第二步：瞬时极性法判反馈极性。 假设在某一瞬间，发射极电位 ue​ 相对交流地升高，记为 +：

  1. 因为基极 B 经 CB​ 交流接地（ub​=0），净输入 ube​=ub​−ue​=−ue​ 减小，导致 ib​、ic​ 减小；
  2. 集电极电流 ic​ 减小，集电极电位 uc​ 升高，即 C 端为 +（共基极从 E 到 C 同相）；
  3. 对原边线圈 L：上端接 +UCC​（交流地），下端（同名端）接 C（+），因此 L 上同名端（下端）电位高于非同名端（上端），记 L 同名端为 +；
  4. 由互感同名端同极性可知，副边线圈 L1​ 的同名端（下端）相对其非同名端（上端）也为 +；
  5. 因为 L1​ 的下端（同名端）直接接地（交流地），所以 L1​ 的上端（非同名端）相对地必为 −；
  6. L1​ 上端接回发射极 E，送回的反馈极性为 −，与原假设的 ue​(+) 相反。

第三步：结论。 反馈信号削弱原输入变化，电路引入的是交流负反馈（且 L1​ 将 RE​ 直流短路），不满足相位平衡条件（φA​+φF​=180∘=2nπ），因此不能产生振荡。

复盘
  • 最易看错的点：原边 L 与副边 L1​ 表面上都是「下端标点」，看似同名端对齐，但 L 的下端接输出 C、上端接交流地，而 L1​ 的下端恰恰接了地、上端接输入 E——相当于一侧「点接信号、非点接地」，另一侧「点接地、非点接信号」，正好反了一次相。
  • 改动方向：若要把极性翻回正反馈（同时消除 RE​ 被直流短路的问题），需将 L1​ 同名端改在接 E 的一端，并在反馈支路中串入隔直耦合电容。

(b) 抽头电感电路

提示

先判组态：E 端有旁路电容 CE​ 接地，所以是共发射极。再从 B 加 +，推 C 极性，然后看 L1​、L2​ 抽头是落在 +UCC​（交流地）和 C 之间的哪一侧；也可以用「射同余异」核对 B、C、E 之间的三个电抗元件。

已收录旁注（不接管步骤）：正反馈与负反馈给出了净输入增减与正／负反馈的对应关系。

完整解答

第一步：交流组态识别。 发射极接有大容量旁路电容 CE​ 并联 RE​ 接地，交流信号经 CE​ 旁路至地，E 为交流地；信号由抽头经耦合电容 CB​ 送入基极 B，输出取自集电极 C ⇒ 电路为共发射极组态。

第二步：瞬时极性法判反馈极性。 假设基极电位 ub​ 瞬时升高，记为 +：

  1. 在共发射极组态中，B 与 C 反相，ub​ 升高使 ib​、ic​ 增大，集电极电位 uc​ 降低，记为 −；
  2. 在谐振回路中，电感 L1​ 上端接 +UCC​（交流地，电位为 0），L2​ 下端接集电极 C（电位为 −），L1​ 与 L2​ 同向绕制（同名端均在各绕组上端）；
  3. 因此从上端（交流地 0）到下端（集电极 −），线圈上各点对交流地的电位逐段降低，L1​-L2​ 抽头处的交流电位必然为 −；
  4. 该 − 信号经隔直电容 CB​ 加回基极 B，与原假设的 ub​(+) 相反 ⇒ 反馈为负反馈。

第三步：LC 三点式「射同余异」复核。 在交流通路中（+UCC​ 与 E 均为交流地，抽头接 B，L2​ 下端接 C）：

  • B 与 E 之间：Xbe​=XL1​（感性）；
  • B 与 C 之间：Xbc​=XL2​（感性）；
  • C 与 E 之间：Xce​=XC​（容性）。

可见 Xbe​（感性）与 Xce​（容性）性质相反，而 Xbe​ 与 Xbc​ 同为感性，不满足「射同余异」原则，与瞬时极性法结论一致。

第四步：结论。 电路引入的是负反馈，相位条件不成立，不能产生振荡。

复盘
  • 错误根源：图 (b) 把电感抽头接到了基极 B，而把交流地（E）接在了 L1​ 顶端，相当于把标准电感三点式振荡器中发射极 E 与基极 B 的接点对调了，破坏了「射同余异」。
  • 记忆口径：三点式电路判相位时，先把交流地找准（哪一极有旁路电容就以哪一极接地），再看接在 E 两旁的电抗是否同性质；把 B 错放在中间抽头必然得到负反馈。

(c) RC 串并联电路

提示

单级共射放大器本身的相移是 180∘，而 RC 串并联选频网络的相移范围严格落在 (−90∘,+90∘)（在中心频率 ω0​ 处为 0∘）。把两者的相移范围相加，看能不能达到 0∘ 或 360∘。

已收录旁注（不接管步骤）：三个环节的三个式子说明闭环工作由前向放大与反馈系数共同决定。

完整解答

第一步：识别放大级与反馈网络。

  1. 放大级：由单个 NPN 三极管构成的单级共发射极放大电路（B 端输入，C 端输出，无旁路电容），在工作频段内输出 uc​ 与输入 ub​ 反相，即基本放大电路相移为
    φA​=180∘
  2. 反馈网络：由串联支路（R 串 C）与并联支路（C 并 RC​）组成的 RC 串并联选频网络，从集电极 C 取电压信号送回基极 B。

第二步：核算 RC 串并联网络的相移范围。 设串联支路阻抗为 Z1​=R+jωC1​，并联支路导纳为 Y2​=RC​1​+jωC，则反馈系数为

F˙(jω)=1+Z1​Y2​1​=(1+RC​R​+1)+j(ωRC−ωRC​C1​)1​
分母实部 2+RC​R​>0 恒成立，因此对于任意有限频率 0<ω<∞，RC 串并联网络的相移严格满足：
−90∘<φF​<+90∘
在选频中心角频率 ω0​=CRRC​​1​ 处，φF​=0∘（若进一步计入基极输入电阻 Ri​ 与 RC​ 并联，等效并联电阻 Rp​=RC​∥Ri​>0，分母实部 2+Rp​R​>0 依然恒成立，相移范围仍严格在 (−90∘,+90∘) 内）。

第三步：检验环路相位平衡条件。 环路总相移为

φA​+φF​∈(180∘−90∘,180∘+90∘)=(90∘,270∘)
该区间不包含 0∘ 或 360∘（2nπ）；特别地在 ω=ω0​（φF​=0∘）时，总相移为 180∘，反馈回到 B 端为负反馈。

第四步：结论。 相位平衡条件 φA​+φF​=2nπ 无法满足，不能产生振荡。

复盘
  • 为什么配不起来：RC 串并联网络（文氏电桥）在谐振点是 0∘ 相移，要求与之配合的放大器必须是同相放大器（0∘ 相移，例如同相比例运放或两级共射放大）；若强行配单级共射（180∘），只会在选频点得到最强的负反馈。
  • 与 RC 移相网络区分：若要把单级共射（180∘）与 RC 网络配成振荡器，反馈网络必须用能产生 180∘ 相移的三节 RC 移相网络，而不是 RC 串并联网络。

(d) 电容三点式电路

提示

先用「射同余异」或瞬时极性法检查相位：反馈从 C1​-C2​ 抽头接回 E，输出取自 C。接着务必检查基极 B——它不像 (a) 那样接了旁路电容 CB​，而是经 RB1​∥RB2​ 接交流地，再看这对等效跨导和起振幅度条件有什么影响。

已收录旁注（不接管步骤）：三个环节的三个式子定义了前向放大 A 与反馈系数 F 的闭环分解关系（本页据此进一步核查环路增益 ∣AF∣>1）。

完整解答

第一步：交流组态与接线核对。

  • 集电极 C 接 L 下端与 C2​ 下端；L 上端与 C1​ 上端接 +UCC​（交流地）；C1​-C2​ 中间抽头直接接回发射极 E（无 CE​），电路为共基极组态电容三点式结构。
  • 关键接线特征：基极 B 通过 RB1​ 接 +UCC​、RB2​ 接地，基极无旁路电容 CB​，因此基极并非直接交流接地，而是通过分压电阻并联值 RB​=RB1​∥RB2​ 接至交流地。

第二步：相位条件核查（正反馈）。

  1. 瞬时极性法：假设发射极电位 ue​ 相对交流地瞬时升高（+）。尽管基极存在未旁路电阻 RB​，由 Δub​=−Δib​RB​ 与 Δube​=Δib​rbe​ 可得
    Δue​=Δub​−Δube​=−Δib​(RB​+rbe​)
    故当 Δue​>0 时必有 Δib​<0，从而 Δub​=RB​+rbe​RB​​Δue​<Δue​，净输入 Δube​=−RB​+rbe​rbe​​Δue​<0 仍严格减小，导致 ic​ 减小、集电极电位 uc​ 升高（+）。在电容分压支路 C1​-C2​ 上，上端为交流地（0）、下端为 uc​(+)，故 C1​-C2​ 抽头对交流地电位必为 +，反馈回 E 与原假设 ue​(+) 同相 ⇒ 相位满足正反馈。
  2. 「射同余异」复核：C1​∥RE​ 与 L 上端均接于交流地，B 经纯电阻 RB​ 接交流地（纯电阻不改变支路电抗的容／感性符号）。交流通路中三端之间的电抗性质为：
    • B 与 E 之间：Xbe​=XC1​（容性，与 RE​ 并联）；
    • C 与 E 之间：Xce​=XC2​（容性）；
    • B 与 C 之间：Xbc​=XL​（感性）。 Xbe​ 与 Xce​ 同为容性，Xbc​ 为感性，满足「射同余异」原则，相位平衡条件成立。

第三步：无旁路电容 CB​ 对幅度条件的影响。 由于基极没有接旁路电容 CB​，RB​=RB1​∥RB2​ 串入了基极-发射极交流输入回路。对共基极交流输入信号 ue​（相对交流地）有：

Δue​≈−Δib​(RB​+rbe​),Δic​=βΔib​≈−RB​+rbe​β​Δue​
与有 CB​ 旁路（等效跨导 gm​=rbe​β​）相比，无 CB​ 时电路的等效跨导降至
gm′​=RB​+rbe​β​
从而使开环电压增益 A 与环路增益 ∣AF∣ 相应下降。

第四步：结论。 该电路相位条件严格满足正反馈；在基极无旁路电容 CB​ 的前提下，只要 RB​=RB1​∥RB2​ 不致过大，使得电路仍能满足起振幅度条件 ∣AF∣>1（且 RE​、RB​ 分流后的回路品质因数足够），该电路能产生振荡（若 RB​ 过大导致 ∣AF∣<1，则不能起振）。

复盘
  • 为什么必须点出无 CB​：很多解题直接套「电容三点式 + 射同余异 ⇒ 能振荡」，漏掉了对比 (a) 和 (d) 基极处的差异——(a) 画了 CB​ 而 (d) 没画 CB​。无 CB​ 不改相位极性（仍为正反馈），但会通过 gm′​=RB​+rbe​β​ 直接压缩环路增益 ∣AF∣。
  • 工程补充：实际设计共基极电容三点式振荡器时，通常会在基极与地之间并联一只高频旁路电容 CB​，把基极真正接到交流地，从而将等效跨导恢复为 rbe​β​，增大环路增益裕量，确保稳定起振。

四幅电路结论汇总：

子图电路类型与交流组态相位／偏置判据结果能否产生振荡关键原因
(a)变压器耦合（共基极）负反馈（且 RE​ 被 L1​ 直流短路）不能L 同名端在 C 端、L1​ 同名端在接地端，反馈回 E 的信号与原输入反相
(b)抽头电感（共发射极）负反馈（不满足「射同余异」）不能抽头接回 B、E 接 L1​ 顶端，Xbe​ 与 Xce​ 异性质，瞬时极性得负反馈
(c)RC 串并联（单级共射）相位平衡不成立不能单级共射 180∘ 配 RC 串并联（相移在 (−90∘,+90∘)、ω0​ 处 0∘），总相移达不到 0∘/360∘
(d)电容三点式（共基极，无 CB​）正反馈（满足「射同余异」）能（当 ∣AF∣>1 时）相位满足正反馈；因基极无 CB​，等效跨导降为 RB​+rbe​β​，在 RB​ 不致过大且满足 ∣AF∣>1 时能起振
