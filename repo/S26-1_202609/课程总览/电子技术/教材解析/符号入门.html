符号入门

这一课从第一章起就满纸 VC​、UCE​、ICM​、U(BR)CEO​ 这类记号——没人解释。 这一页是自撰工具页：把本课实际用到的记号逐个立词条，全站（按构建期环境锚定）都能点出气泡。

  • 环境锚定：本页是「电子技术:符号」符号包。电子技术的页面默认锚定 通用+电子技术 （通用包管 U/I/R/P 这些跨课共用的量，本页只管本课特有的器件与参数记号）。
  • 下标是族语言：三极管记号几乎全靠下标区分——大写小写、单双下标各有约定（见下「三极管记号族」）。
  • 词典与释义是本课自撰：以作业题面、课堂笔记口径为准，不照抄任何教材符号表。
  • 气泡里的公式是真公式：标题与释义都在构建期渲染，$…$ 出真分式。

依赖：读本课内容之前该认识的记号

下标的大小写约定

大写下标多是直流/平均值（IC​、VB​），小写是交流瞬时量（ic​、ui​）；UCE​ 双下标中第一个字母是「+」端。

三个电极

三极管 E（发射极）、B（基极）、C（集电极）；场效应管 G（栅极）、S（源极）、D（漏极）。UCE​ 就是集电极对发射极的电压。

极限参数

手册里带「CM」「(BR)」的都是不许超过的界限值：PCM​ 最大耗散功率、ICM​ 最大集电极电流、U(BR)CEO​ 击穿电压。

符号总表

本章用到的记号按族录入；每个符号在表里都有自己的锚点，气泡「详细 ↗」落到对应行。

符号含义
IB​：基极电流流入基极的电流（直流/平均值用大写 IB​，瞬时值写 ib​）。
IC​：集电极电流集电极电流；与 IB​ 的关系是 IC​=βIB​（放大区），β 是共射电流放大系数。
IE​：发射极电流三极管三个电流满足 IE​=IB​+IC​（KCL 在管子内部）。
UCE​：集-射电压集电极对发射极的电压（双下标：第一个字母是「+」端）。它决定管子工作在放大/饱和/截止哪个区。
UBE​：基-射电压基极对发射极的电压；硅管导通时约 0.7 V（锗管约 0.2∼0.3 V），是「发射结是否导通」的判据。
ui​：输入电压放大电路输入端的交流信号（小写 ui​ 表示瞬时量，有效值写 Ui​）。
uO​：输出电压放大电路输出端的交流信号；与 ui​ 之比就是电压放大倍数。
UCC​：集电极电源双字母下标是电源的记号（CC = 集电极电源、BB = 基极电源、EE = 发射极电源）。
PCM​：最大耗散功率三极管允许的最大集电极耗散功率（CM = maximum），超过就烧管——三个极限参数之一。
ICM​：最大集电极电流集电极电流的上限，超过则 β 急剧下降——三个极限参数之一。
U(BR)CEO​：击穿电压基极开路时集-射间的反向击穿电压（BR = breakdown，CEO = C-E with base open）——三个极限参数之一。
Uz​：稳压电压稳压二极管的反向击穿电压，正常工作时它两端的电压基本不变。
IZ​：稳压管工作电流稳压管正常稳压时的电流；IZ(min)​<IZ​<IZ(max)​ 才稳压。
IZM​：最大稳压电流稳压管允许的最大工作电流（超过会热击穿）。
UGS​：栅-源电压场效应管栅极对源极的电压，它控制沟道导电能力（对应三极管的 UBE​）。
UGS(th)​：开启电压增强型场效应管形成导电沟道所需的最小 UGS​（th = threshold）。
UD​：二极管电压二极管两端的电压（正偏导通、反偏截止）。
ID​：二极管电流流过二极管的电流；正偏时有 ID​=(UD​−Uth​)/R 之类的近似式（死区电压硅管约 0.5 V）。
β：共射电流放大系数β=IC​/IB​（放大区），也写 hfe​；同一型号管子的 β 分散性很大。
α：共基电流放大系数α=IC​/IE​，与 β 的关系 β=α/(1−α)。
VCE​：管子压降（限流题）限幅/开关电路题里常问「管子两端剩多少伏」——理想模型取 0、恒压降模型取 0.7 V（硅）。
二极管符号三角形指向的那一端是阳极（+），竖线一端是阴极（−）；箭头方向 = 正偏导通时的电流方向。
三极管符号带箭头的电极是发射极——箭头朝外是 NPN、朝里是 PNP；箭头方向就是发射结正偏时的电流方向。
VB​：基极电位各电极对地（或参考点）的电位——判管型与工作状态就用它：VE​>VB​>VC​ 是 PNP、VC​>VB​>VE​ 是 NPN。与 UBE​（极间电压）不同：电位是「对地」，电压是「两点之差」。
VC​：集电极电位集电极对参考点的电位；三极管三个电位排序决定它工作在放大/饱和/截止哪个区（NPN 硅管放大区约 VC​>VB​>VE​ 且 UBE​≈0.7 V）。
VE​：发射极电位发射极对参考点的电位；NPN 里它通常最低（接地时 VE​=0）。
RC​：集电极电阻三极管放大电路里接在集电极的负载电阻，把电流变化转成电压变化：uO​=UCC​−iC​RC​。
RB​：基极偏置电阻接在基极的电阻，给发射结提供正偏电流：IB​=(UCC​−UBE​)/RB​。
RE​：发射极电阻接在发射极的电阻（射极偏置），有稳定工作点的作用。
U1​：输入电压（有效值）放大电路输入信号的有效值；瞬时值写 u1​、直流电源写 UCC​——三者按大小写与下标区分。
U2​：输出电压（有效值）输出信号的有效值；与 U1​ 之比就是电压放大倍数 Au​=U2​/U1​。
u1​：瞬时输入信号输入交流信号的瞬时值：u1​=ui​−uO​（叠加在静态工作点上的小信号）。
IR​：电阻上的电流限流电阻（或稳压电路里的串联电阻）流过的电流；稳压管电路里 IZ​=IR​−IL​。
Uab​：a、b 两点间电压双下标记法 Uab​=φa​−φb​（第一个下标在前、第二个在后）——和电路原理同一套写法；含二极管电路里常用于「求 Uab​」。
∑m(⋯)：最小项和卡诺图与真值表的记号：mi​ 是把输入组合写成二进制后等于 i 的最小项，∑m(2,4,8) 就是「2、4、8 号格填 1」。编号从 0 起、A 是最高位。
RD​：直接置 0 端基本/钟控 RS 触发器的直接复位端，低电平有效：RD​=0 时 Q 强制为 0，与 CP 无关。上划线就是「低有效」的记号。
SD​：直接置 1 端基本/钟控 RS 触发器的直接置位端，低电平有效：SD​=0 时 Q 强制为 1。与 RD​ 同时为 0 是禁用态。
CP：时钟脉冲钟控触发器的同步信号。CP 为高电平的时段里 S、R 才起作用；CP 为 0 时无论 S、R 怎么变，输出一律保持。
⊕：异或A⊕B：两输入不同时为 1。真值表 0,1,1,0。
⊙：同或A⊙B=A⊕B​：两输入相同时为 1。真值表 1,0,0,1；两地控制照明灯的函数就是它。

形式声明（自动取词）
