2026-09-20 ｜ 课程定位、安全稳定概念群

考点：为什么必须用智能分析（数据链论证）

要会：把这条链条讲出来。

链条：电力系统规模大、状态量多 → 传统方法算不过来 → 所以要把数据变成可用于决策的信息 → 用智能分析。 教师强调这是全课的动机，第一讲、第二讲、第三讲各出现一次，答题时先写它。

容易记混：这条是动机不是方法——别和后面「四个评估方法」答成一回事。

笔记原文 ↗

考点：稳定的判据是特征值

要会：一句话判据。

  • 系统状态由特征值实部判：实部 < 0 稳定（实部 = 0 临界，实部 > 0 失稳）。
  • 与之配套的两个概念：平衡态（系统稳定运行的点）、扰动（打破平衡的外来作用）。

容易记混：判据看的是实部（不是模、不是虚部）——虚部只管振荡频率。

笔记原文 ↗

考点：安全域与安全裕度

要会：两个定义各一句。

  • 安全域：状态空间里**「安全的那些点」构成的区域**。
  • 安全裕度：当前运行点离安全域边界的距离。
  • 细分：静态安全域（看潮流约束）与动态安全域（看暂态约束）。

容易记混：安全域是「区域」，裕度是「距离」——一个是集合、一个是数，别答反。

2026-09-22 ｜ 暂态稳定评估方法与紧急控制

本讲最容易混的地方：有两组方法，一组 4 个（评估）、一组 3 个（控制），别答串。

考点：评估的四个方法（按出现顺序）

要会：四个方法的名字 + 每个的一句话特征 + 为什么被淘汰/保留。

#方法一句话关键点
1时域仿真法建全元件模型、解微分代数方程组、看功角曲线精度最高（其他方法的标准），但不能在线
2直接法（能量函数/李雅普诺夫）构造能量函数判稳，不求特征根充分非必要——找不到函数不能说系统不稳
3基于故障后响应直接用故障后实际轨迹判（如故障电流衰减/发散）靠 WAMS/PMU 实测，可与前两种结合
4数据挖掘与机器学习离线仿真建库 → 训练模型 → 在线评估当前研究热点；AI 是近似计算、可能算错、要筛选

AI 方法（第 4 类）单独记一句：它是近似计算、可能算错、还要筛选——不能盲信。 教师把基于数据挖掘的方法划为当前研究热点，前三种都是经典方法。

容易记混：前三类叫经典方法，第 4 类才是热点；时域仿真「不能在线」是本讲反复出现的理由—— 数据中心、并行计算、AI 全是为了解决它。

笔记原文 ↗

考点：时域仿真法的两条提速路线

要会：说出两条路线，以及并行计算的三个研究方向。

  • 路线一：用简化模型换速度——但不能一味求简（差太远就「没有指导意义」）。
  • 路线二：分布式并行计算（最高形式是云计算）。三个研究方向（教师要求记住）：
    1. 时间并行算法——微分方程差分化后与代数方程联立求解；
    2. 空间并行算法——大系统按物理分布分成子网各自算；
    3. 波形松弛算法——拆小系统、子系统间交替迭代。

关键数字：判稳通常看扰动结束后 3–5 秒；有潜在区间震荡模式的大系统可延长到 15–20 秒。

容易记混：微分方程描述动态＝目标，代数方程描述平衡态＝约束——两类合起来才构成求解问题。

笔记原文 ↗

考点：直接法（能量函数）的三个要点

要会：充分非必要、两个定理的差别、为什么发展不下去。

  • 充分非必要（教师强调三遍）：找到能量函数可证明稳定；找不到不能说明不稳定。
  • 两个定理的差别：李雅普诺夫定理要求函数正定（系数都 > 0，条件更保守）； 拉萨尔（LaSalle）定理只要求非负定（≥ 0，是放宽）。
  • 发展不下去的原因：能量函数没有统一构造方法，只能用于较简单系统； 每加一个新模型（HVDC、三级发电机、负荷动态）就要重造一个能量函数 → 又回到「发展 AI 与云计算是必由之路」。

容易记混：正定＝能量逐渐增大（发散）；负定＝总能量减少（耗散，稳定系统该有的样子）。

笔记原文 ↗

考点：紧急控制的三个方法（与评估组分开记）

要会：三个方法的名字 + 各自做法要点。

#方法做法要点
1启发式方法用少量仿真找方案，靠指标排序（如切机切负荷有效性指标）降复杂度
2基于响应的方法直接用 PMU 量测；判不稳时把系统等效为两机模型，用加速/减速面积算切机切负荷量
3基于安全域/稳定域用切机切负荷改变稳定边界，把运行点从域外移回域内；边界移动可近似线性叠加

关键概念：灵敏度 = 参数的一阶导（如电流对负载电阻的灵敏度）。用灵敏度建优化模型， 计算量与备选措施数量无关——只需两次积分/仿真。

容易记混：切机＝切除发电机，切负荷＝摘掉负荷，本质都是调频手段。 三个方法各自的局限：启发式靠少量仿真、响应法依赖「简化等值」、安全域法依赖「域描述准不准」。

2026-09-29 ｜ 电力大数据特点与人工智能算法

本讲教师按考试题型讲，条条对着考点——下面是逐条。

考点：大数据 4V 特点（判断题陷阱）

要会：四个 V 的中英文 + Value 的正确含义。

V中文含义
Volume规模大发输变配用调度各环节长期积累，且爆炸式增长
Variety多样性结构化 / 半结构化 / 非结构化三类并存
Velocity速度快实时系统，异常要立即切除，响应要快
Value价值潜在价值巨大，但价值密度低、藏在海量数据中，需要挖掘

关键数字：数据量 GB → TB → PB → EB → ZB → YB，每级差 3 个数量级（103 倍）。

容易记混：value 不能简单译成「价值高」——正确含义是价值密度低、潜在应用价值巨大。 这是判断题专门设的坑。

考点：人工智能的三个发展阶段

要会：三级各一句（教师补充：书上只讲到第三代，这三级分类「不考」——了解即可）。

  2. 强人工智能——类人机器人，能绘画、能诊断。

考点：决策树算法（期末计算题 20 分）

要会：教师明确点名这是期末考试的一道计算题（20 分）。10-13 第二次点名时把期末范围收窄到： 教材第 28 页第 7 个算法 = 启发式搜索算法（决策树/搜索树的一种典型），并说总复习时会当例题讲一遍、考试考原题。

  • 启发式搜索 = 深度优先搜索之上再加「记忆」功能的智能化搜索，比普通搜索更优（复杂度更小）。
  • 决策树分分类树（叶节点是类别标识）与回归树（叶节点是输出值的常数/方程）； 通常是二叉树，也可能多叉树。
  • 过拟合：拟合曲线虽满足目标函数最小、却没有样本点落在曲线上 → 对策是修剪。

容易记混：另有一道大题也是人工智能算法（两道大题都围绕 AI）；口径是**「书上有的才考，书上没有的不考」** ——生成式对抗网络（GAN）教材未收 → 不考，教师口头提到但教材没有的算法都不列入。

考点：人工智能常用算法地图（10-13 新增）

要会：每种算法是什么、属于哪一类、用在什么场合（教师本讲只讲这三样，不展开流程原理）。

算法一句话定位关键点
支持向量机 SVM优化计算方法映射到高维空间找间隔最大的线性超平面；本质是全局最优化（目标函数 + 约束，约束常为不等式）

容易记混：异或门式的「同一符号两种身份」——GBDT 与 LightGBM：GBDT 不能用于海量数据， LightGBM 就是为大数据改进的；记「轻量级 = 大数据」。

考点：两类常用算法（SVM 与集成学习）

要会：各解决什么问题、在算法谱系里的位置。

  • 支持向量机（SVM）：监督学习算法；用映射函数把样本映射到高维空间， 找一个间隔最大的线性超平面做分类。电力系统里用于稳定评估（输出 +1 稳定／−1 不稳定）。
  • 集成学习：按策略训练多个「弱监督模型」，组合成一个强监督模型，性能大幅提升。 为什么会有弱学习器：理论上「各方面都好」的模型几乎不存在。

容易记混：教师说 AI 有**「九种」算法**，但当堂只讲了 SVM 与集成学习两类—— 答题写这两类即可，别硬凑九个（其余没念出来的名字不要编）。

2026-10-20 ｜ 聚类方法与神经网络

考点：为什么先讲「不智能」的方法

要会：神经网络是基于距离的聚类方法的继承者——教师原话「神经网络算法它这个最基础的，它的基础是基于……聚类方法」。 先讲 K 平均这类自动化但不智能的方法，是为了看清它们错在哪，才说得出神经网络智能在哪、代价是什么。

笔记原文 ↗

考点：聚类的五大类方法（期末 5 分简答）

要会背五类名字与各自一句话思路：

类别基本思路
划分把样本切成 k 堆，迭代优化到「堆内够紧、堆间够开」
层次凝聚（自下而上合并）或分裂（自上而下拆分），形成一棵树
基于密度邻域内点数够多就连成一簇，能找出任意形状、能识别噪声
基于网格把对象空间量化为有限单元形成网格，一切操作在网格上做
基于模型先假定一个模型，再找最贴合该模型的那一族数据

考点：K 平均法（k-means）

要会步骤：随机选 k 个初始中心 → 按最近距离归类 → 用每类均值更新中心 → 迭代到不动。

缺点（简答要写）：对初始值敏感、对离群点敏感、k 要人为定。隐含假定簇是凸的、大小相近的一团。

笔记原文 ↗

考点：K 中心点法（k-medoids）

与 K 平均只差一处：代表每类的不是均值，而是「类内实际存在的一个点」（medoid）。

取舍：对离群点更稳（均值会被离群点拽走，实际点不会），代价是计算量更大。

考点：密度聚类的基本思想

要会：「密度」在 DBSCAN 里的定义是某点给定半径的邻域内数据点的个数（教师重复两遍，是要背的）， 不是空间意义上的密度。邻域密度超过阈值就连成一簇；高密度区域被低密度区域分割。

2026-11-03 ｜ 一次调频性能评价

本讲的链条是：先给七项指标体系，再给基于 WAMS 的评价算法，最后说六个关键时间点怎么搜。

考点：一次调频分静态与动态两套指标

要会：这两套的分界不是一句定性话，而是方程的类型。

用什么方程描述归到哪套指标
静态分析代数方程（没有微分方程，也不是参数方程）调差系数（式 4-1）：按调节前后的稳态值算，反映一次调频的有差调节特性
动态分析微分方程／微分方程组，或差分方程／差分方程组响应过程（滞后时间与稳定时间，第 7 项）
  • 调频死区与调差系数同为调速系统控制环节里的一环，是七项里另一个关键项。
  • 本课不要求计算：调差系数与动态分析的计算留到后边专业课；动态（暂态）分析两年制不展开。

容易记混：判「静态还是动态」看靠哪种方程描述，不是看这个量好不好算。

笔记原文 ↗

考点：一次调频的七项指标（两个关键项 + 五个主要指标）

要会：简答题原话「一次调频的指标体系包括哪几个指标」——答七个； 七项指标里两个是关键项（调差系数、调频死区），其余五项是主要指标，各有教材算式号。

#指标性质口径 / 算式号
1调差系数静态关键项；按调节前后稳态值算，反映有差调节；式 4-1
2调频死区关键项调速系统控制环节的一环；火电 0.033 Hz 以内、水电 0.05 Hz 以内
3一次调频贡献电量积分量计算原理 4-6；积分时间长度取 120 秒
4一次调频贡献率比率计算原理 4-7、4-8；多数电网拿它当考核标准
5一次调频正确动作率单机长期统计阈值一般取 0，也可取 −0.1 以识别反调；按月计量
6一次调频投运率长期统计投切信号经远程终端 RTU 送省调
7一次调频滞后时间和稳定时间动态特性衡量响应速度；时间常数取 L/R

关键数字：火电死区 0.033 Hz 以内、水电 0.05 Hz 以内（教师点名「考选择题」）； 贡献电量积分 120 秒；贡献率的调差系数考核值 ΔFset​ 一般取 5%。

容易记混：贡献率 = 实际贡献电量 ÷ 理论贡献电量——实际值直接测，理论值要积分算（涉及时间段与长度系数）， 所以它才「对采样率和精度要求不高」、能被多数电网用作考核标准。 贡献率与贡献电量是两个指标，别答成一个。

笔记原文 ↗

考点：基于 WAMS 的性能评价算法三步

要会：三步的顺序与每一步的做法，以及「只在频率大幅变化时才计算」这条前提。

  1. 坏数据剔除（判据 4-13）：要用的是电网频率与发电机有功功率两个基础数据， 而测量、采集、传输、存储各环节都会出错，所以先辨识、修正。 判据：实测频率对基准值的变化超过基准值频率量的 50% ⇒ 判为异常数据； 修正办法是利用频率特性曲线的连续性，用前一时刻的数据代替。
  2. 平滑处理：用平均值方法把固定时间周期内的所有数据取平均、以均值代替这段全部数据，消除单点测量偏差。 平滑周期取 0.1 秒：周期越长越平滑但丢的信息越多，越短则扰动大（拿一个人的分数代表全班不成立，样本越大个别干扰越弱）。
  3. 二次调频影响剔除：大扰动时一次调频与二次调频耦合，要用 AGC 指令（矢量，有方向也有幅值）剔掉二次调频的作用—— 先定方向（上升／下降速率与总功率改变量），再定量值，拟合成一条 AGC 响应指令曲线，整体剔除后才剩纯一次调频效应。

大／小扰动的判据（判据由分析加仿真验证定出，因为电力系统不能做实验）：

判据说明
大扰动频率对基准值变化超过 ΔF1​=0.033 Hz，且持续 T1​=0.3 s两条均满足才算大扰动
小扰动只取频率阈值，时间阈值取 T1​=8 s不再要求 0.3 s

取哪个频率：不能只看单台机组的频率——机组启停时测点频率会大幅变化； 做法是取分布在电网不同地理位置的几个大型变电站的频率求平均，用它作判断依据。

容易记混：0.033 Hz + 0.3 s 是大扰动，8 s 是小扰动的时间阈值——两个判据的频率门槛都取 0.033 Hz， 差别只在持续时间；0.033 Hz 这个数与火电死区数值一致（火电响应要求更快）。 ⚠ 大扰动的 0.033 Hz、0.3 s 是教师当场更正后的数值（口播先说成 0.003 Hz、10 s，随即更正）。

笔记原文 ↗

考点：关键时间点 T1​∼T6​ 与方差比较法

要会：六个时间点的含义、T1​ 怎么取，以及方差比较法的机械步骤与判据 4-14。

难点在哪儿：从单机的三个指标看，指标计算的难点就是找调节开始和结束的关键时间点。

时间点含义
T1​频率超过阈值的时间点
T2​频率回到阈值内（回到误差带内）的时间点
T3​频率开始变化的时间点
T4​有功功率开始变化的时间点
T5​频率稳定的时间点
T6​有功功率稳定的时间点
  • T1​ 的直接取法：判断「频率超过阈值持续一定时间」时，记下频率超过阈值的第一个点，该点对应的时间就是 T1​。
  • T5​ 的口径：稳定不是精确值，而是与基准值的误差在允许范围内；这段时间可取 3 秒，带宽取 0.005 Hz。
  • T6​：教师只要求「了解一下」，没有给判据数值。

方差比较法（图 4-7，教材由清华大学教授提出）——利用频率突变点的数学特征，机械步骤：

  1. 对频率超过阈值前的 1 个数据窗进行扫描；
  2. 对每个数据点，比较它前 1 秒频率序列的方差与后 1 秒频率序列的方差之差；
  3. 前后方差变化最大的点即为频率突变点。
  • 图 4-7 的例子：突变点就是曲线上的冲击位置，坐标为 X=8.5、Y=50.1。
  • 降计算量的关键：只需要搜索到之前已经搜索出的时间点——因为频率突变的点一定在频率超过阈值之前。
  • 方法评价：经仿真验证可行、有效；简单直观、便于编程。

判据 4-14（认定「一次调频没有动作」）：为准确评估、要避开机电暂态过程对有功功率曲线的影响，两条条件：

① 突变前 1 秒的功率模值大于 0.4% 的基本功率（基本功率＝有功功率的基准值）； ② ΔP 与 ΔF 反方向变化（两者都取该点之前 1 秒的变化量：ΔP>0 则 ΔF<0，反之亦然）。

两条都满足 ⇒ 认为一次调频没有动作。

⚠ 判据 4-14 的两条条件与结论都照教材记；其方向语义与式 4-1 推出的「一次调频正常动作方向」相同， 需按教材判据 4-14 本身的口径理解（这一处口径冲突归档于 issue #31）。

2026-11-10 ｜ 二次调频与无功电压

考点：一次调频有差、二次调频无差

  • 一次调频靠调速器自动按调差系数分摊，有差调节（动作完频率回不到额定值）。
  • 二次调频靠 AGC 把频率拉回额定，无差调节；机组按中枢点指令增减出力。
  • 答题一句话：一次管「快而不准」、二次管「准」，两者是分工不是替代。

考点：二次调频的两套指标（运行区域 vs AGC 机组）

  • 时间尺度分分钟／小时／全天三级；火电机组按指令周期分段评价。

考点：AVR 与 PSS、一次与二次设备

  • AVR（自动电压调节器）：调励磁电流，维持机端电压。
  • PSS（电力系统稳定器）：在 AVR 上加阻尼转矩，压低频振荡。

考点：过滤式与封装式（按「是否独立于学习算法」分）

类别判据代价
过滤式 filter只看数据本身的统计量（距离、一致性、相关性、信息论）快，但可能与后续学习器不匹配
封装式 wrapper用学习器的表现给特征子集打分准，但每评一次都要训练，很贵
  • 封装式在样本量少时会因反复训练而性能不稳，这是它的短板。
