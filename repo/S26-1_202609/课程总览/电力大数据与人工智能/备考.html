考试形式（只记与答题有关的）

  • 开卷，只允许带教材；教室内不得使用手机，带手机按作弊处理。
  • 成绩 = 平时 50% + 卷面 50%；平时含课堂表现（旷课一次扣 20 分；旷课四次取消全部平时成绩；旷课五次取消考试资格）。
  • 没有期中；第 17 周上完课当天考试；最后两节课总复习并练计算题；教师说不考原题。

2026-09-20 ｜ 课程定位、安全稳定概念群

考点：为什么必须用智能分析（数据链论证）

要会：把这条链条讲出来。

链条：电力系统规模大、状态量多 → 传统方法算不过来 → 所以要把数据变成可用于决策的信息 → 用智能分析。 教师强调这是全课的动机，第一讲、第二讲、第三讲各出现一次，答题时先写它。

容易记混：这条是动机不是方法——别和后面「四个评估方法」答成一回事。

笔记原文 ↗

考点：稳定的判据是特征值

要会：一句话判据。

  • 系统状态由特征值实部判：实部 < 0 稳定（实部 = 0 临界，实部 > 0 失稳）。
  • 与之配套的两个概念：平衡态（系统稳定运行的点）、扰动（打破平衡的外来作用）。

容易记混：判据看的是实部（不是模、不是虚部）——虚部只管振荡频率。

笔记原文 ↗

考点：安全域与安全裕度

要会：两个定义各一句。

  • 安全域：状态空间里**「安全的那些点」构成的区域**。
  • 安全裕度：当前运行点离安全域边界的距离。
  • 细分：静态安全域（看潮流约束）与动态安全域（看暂态约束）。

容易记混：安全域是「区域」，裕度是「距离」——一个是集合、一个是数，别答反。

笔记原文 ↗

考点：名词解释（本课术语来源）

要会：名词解释题就从这些术语里出。第一讲列的名词表见笔记；复习时先记住每个词在课本哪一页（开卷要靠它翻）。

容易记混：名词解释按「三处现状」集中出题（见上「考试形式」）——把三处「现状」的名词拎出来单独背。

2026-09-22 ｜ 暂态稳定评估方法与紧急控制

本讲最容易混的地方：有两组方法，一组 4 个（评估）、一组 3 个（控制），别答串。

考点：评估的四个方法（按出现顺序）

要会：四个方法的名字 + 每个的一句话特征 + 为什么被淘汰/保留。

#方法一句话关键点
1时域仿真法建全元件模型、解微分代数方程组、看功角曲线精度最高（其他方法的标准），但不能在线
2直接法（能量函数/李雅普诺夫）构造能量函数判稳，不求特征根充分非必要——找不到函数不能说系统不稳
3基于故障后响应直接用故障后实际轨迹判（如故障电流衰减/发散）靠 WAMS/PMU 实测，可与前两种结合
4数据挖掘与机器学习离线仿真建库 → 训练模型 → 在线评估当前研究热点；AI 是近似计算、可能算错、要筛选

AI 方法（第 4 类）单独记一句：它是近似计算、可能算错、还要筛选——不能盲信。 教师把基于数据挖掘的方法划为当前研究热点，前三种都是经典方法。

容易记混：前三类叫经典方法，第 4 类才是热点；时域仿真「不能在线」是本讲反复出现的理由—— 数据中心、并行计算、AI 全是为了解决它。

笔记原文 ↗

考点：时域仿真法的两条提速路线

要会：说出两条路线，以及并行计算的三个研究方向。

  • 路线一：用简化模型换速度——但不能一味求简（差太远就「没有指导意义」）。
  • 路线二：分布式并行计算（最高形式是云计算）。三个研究方向（教师要求记住）：
    1. 时间并行算法——微分方程差分化后与代数方程联立求解；
    2. 空间并行算法——大系统按物理分布分成子网各自算；
    3. 波形松弛算法——拆小系统、子系统间交替迭代。

关键数字：判稳通常看扰动结束后 3–5 秒；有潜在区间震荡模式的大系统可延长到 15–20 秒。

容易记混：微分方程描述动态＝目标，代数方程描述平衡态＝约束——两类合起来才构成求解问题。

笔记原文 ↗

考点：直接法（能量函数）的三个要点

要会：充分非必要、两个定理的差别、为什么发展不下去。

  • 充分非必要（教师强调三遍）：找到能量函数可证明稳定；找不到不能说明不稳定。
  • 两个定理的差别：李雅普诺夫定理要求函数正定（系数都 > 0，条件更保守）； 拉萨尔（LaSalle）定理只要求非负定（≥ 0，是放宽）。
  • 发展不下去的原因：能量函数没有统一构造方法，只能用于较简单系统； 每加一个新模型（HVDC、三级发电机、负荷动态）就要重造一个能量函数 → 又回到「发展 AI 与云计算是必由之路」。

容易记混：正定＝能量逐渐增大（发散）；负定＝总能量减少（耗散，稳定系统该有的样子）。

笔记原文 ↗

考点：紧急控制的三个方法（与评估组分开记）

要会：三个方法的名字 + 各自做法要点。

#方法做法要点
1启发式方法用少量仿真找方案，靠指标排序（如切机切负荷有效性指标）降复杂度
2基于响应的方法直接用 PMU 量测；判不稳时把系统等效为两机模型，用加速/减速面积算切机切负荷量
3基于安全域/稳定域用切机切负荷改变稳定边界，把运行点从域外移回域内；边界移动可近似线性叠加

关键概念：灵敏度 = 参数的一阶导（如电流对负载电阻的灵敏度）。用灵敏度建优化模型， 计算量与备选措施数量无关——只需两次积分/仿真。

容易记混：切机＝切除发电机，切负荷＝摘掉负荷，本质都是调频手段。 三个方法各自的局限：启发式靠少量仿真、响应法依赖「简化等值」、安全域法依赖「域描述准不准」。

笔记原文 ↗

2026-09-29 ｜ 电力大数据特点与人工智能算法

本讲教师按考试题型讲，条条对着考点——下面是逐条。

考点：大数据 4V 特点（判断题陷阱）

要会：四个 V 的中英文 + Value 的正确含义。

V中文含义
Volume规模大发输变配用调度各环节长期积累，且爆炸式增长
Variety多样性结构化 / 半结构化 / 非结构化三类并存
Velocity速度快实时系统，异常要立即切除，响应要快
Value价值潜在价值巨大，但价值密度低、藏在海量数据中，需要挖掘

关键数字：数据量 GB → TB → PB → EB → ZB → YB，每级差 3 个数量级（103 倍）。

容易记混：value 不能简单译成「价值高」——正确含义是价值密度低、潜在应用价值巨大。 这是判断题专门设的坑。

笔记原文 ↗

考点：数据结构的三种类型（选择题）

要会：三种结构类型各举一例。

  • 结构化：能装进关系数据库表格的（如电表读数表）。
  • 半结构化：有标签但不严格（如 XML、JSON 报文）。
  • 非结构化：图片、视频、音频、文本等。

容易记混：教师说按结构类型分是三种（书上有五种分法，本课只按这三种考）。

笔记原文 ↗

考点：两类数据来源（电网分析计算，选择题）

要会：两类来源 + 各自的存储/建模形式（这才是选择题的区分点）。

来源存储/建模形式
离线形成的计算数据文件（仿真软件输出）母线支路模型
能源管理系统（EMS）提供的实时数据（通常在内存）节点开关模型

容易记混：选择题考的是**「母线支路模型 vs 节点开关模型」这个对应关系**—— 不是「离线/实时」这两个词本身；别和「数据结构三类型」答混。

笔记原文 ↗

考点：电力系统运行状态分几类（5 分简答题）

要会：五类，按顺序写。

  1. 正常 2. 警戒 3. 紧急 4. 测试 5. 恢复

为什么重要：状态一旦确定，对应状态该做的操作就发给操作员；大数据技术有助于状态分类与物理过程识别。

容易记混：五个（不是三、四个）；顺序按「正常→警戒→紧急→测试→恢复」。

笔记原文 ↗

考点：人工智能的定位与沿革

要会：一句话定位 + 几个关键年份。

  • 定位：人工智能是计算机科学的分支，也是交叉学科。
  • 沿革：1956 年达特茅斯会议立为独立学科（约 70 年）→ 几经兴衰 → 2006 年 Hinton 深度学习网络使神经网络崛起 → 现在是第三次 AI 阶段（深度学习阶段）。

容易记混：1956（学科成立） 与 2006（深度学习崛起） 两个年份别搞反。

笔记原文 ↗

考点：人工智能的两个技术范式（多选题）

要会：两个范式的名字 + 各自对应哪一代。

  • 符号主义——对应第一代的知识驱动方法。
  • 连接主义——对应第二代的数据驱动方法。
  • 结论：靠单个范式推不动人工智能，知识与数据融合是必经之路。

容易记混：符号主义↔知识驱动、连接主义↔数据驱动，两个别配反。

笔记原文 ↗

考点：人工智能的三个发展阶段

要会：三级各一句（教师补充：书上只讲到第三代，这三级分类「不考」——了解即可）。

  1. 弱人工智能——智能汽车、无人机等（现在）。
  2. 强人工智能——类人机器人，能绘画、能诊断。
  3. 超人工智能——超过人类智慧边界，会自学习自我迭代，人类无法控制（中美好标准严防的就是它）。

关键年份（可能考）：1956 年达特茅斯会议把 AI 立为独立学科（距今约 70 年）； 2006 年 Hinton 提出深度学习网络，神经网络再次崛起（当前是第三次 AI 阶段）； 1997 年深蓝胜国际象棋、2016 年 AlphaGo 胜围棋。

笔记原文 ↗

考点：决策树算法（期末计算题 20 分）

要会：教师明确点名这是期末考试的一道计算题（20 分）。10-13 第二次点名时把期末范围收窄到： 教材第 28 页第 7 个算法 = 启发式搜索算法（决策树/搜索树的一种典型），并说总复习时会当例题讲一遍、考试考原题。

  • 启发式搜索 = 深度优先搜索之上再加「记忆」功能的智能化搜索，比普通搜索更优（复杂度更小）。
  • 决策树分分类树（叶节点是类别标识）与回归树（叶节点是输出值的常数/方程）； 通常是二叉树，也可能多叉树。
  • 过拟合：拟合曲线虽满足目标函数最小、却没有样本点落在曲线上 → 对策是修剪。

容易记混：另有一道大题也是人工智能算法（两道大题都围绕 AI）；口径是**「书上有的才考，书上没有的不考」** ——生成式对抗网络（GAN）教材未收 → 不考，教师口头提到但教材没有的算法都不列入。

笔记原文 ↗ ｜ 旧记录 ↗

考点：人工智能常用算法地图（10-13 新增）

要会：每种算法是什么、属于哪一类、用在什么场合（教师本讲只讲这三样，不展开流程原理）。

算法一句话定位关键点
支持向量机 SVM优化计算方法映射到高维空间找间隔最大的线性超平面；本质是全局最优化（目标函数 + 约束，约束常为不等式）
集成学习多个弱监督模型 → 一个强监督模型原理简单、精度较高、应用广
决策树 / 二叉树分类树 / 回归树叶节点 = 一次运算 = 一个数据样本（数据列表）；过拟合要修剪
启发式搜索深度优先 + 记忆功能期末大题（第 28 页第 7 个算法）
GBDT 梯度提升决策树集成学习中应用最广以回归树为子模型迭代叠加、损失函数递减；预排序选分裂点，精度高但耗内存、不适合海量数据
LightGBM 轻量级梯度提升GBDT 的大数据版（2017）按叶子分裂（带最大深度）；直方图 + 单边梯度采样（GOSS）+ 互斥特征绑定；适合大规模/云数据
深度信念网络 DBN深层次模型若干**受限玻尔兹曼机（RBM）**堆叠；逐层无监督贪婪训练
堆栈自动编码器深层次模型多个自动编码器堆叠；编码（输入→隐含层）/ 解码（隐含层→输出层）
卷积神经网络 CNN有监督学习卷积层（特征提取）+ 池化层（降维、鲁棒性）+ 全连接层；图像/机器视觉
循环神经网络 RNN / LSTM处理序列数据有记忆（前一时刻输入也进当前计算）；LSTM 加门控，解决长期依赖、避免梯度消失

容易记混：异或门式的「同一符号两种身份」——GBDT 与 LightGBM：GBDT 不能用于海量数据， LightGBM 就是为大数据改进的；记「轻量级 = 大数据」。

考点：为什么电力系统要上 AI（10-13 新增）

要会：新能源（风、光）高比例接入 → 电力电子设备占比升高 → 系统惯性变小 （旋转设备惯性大、电力电子设备惯性小）→ 更敏感、易波动、稳定性差 → 靠更智能化的控制快速跟踪。 AI 擅长应对高维、时变、非线性、强耦合问题。

容易记混：惯性大小别搞反——旋转设备（电机、变压器）惯性大，电力电子设备惯性小。

考点：AI 在电力系统的三个发展阶段（10-13 新增）

要会：三阶段按「技术 → 应用」对应记： ① 专家系统 / 人工神经网络 → 故障诊断、安全评估、负荷预测； ② 机器学习（贝叶斯分类、SVM 等） → 动态安全评估、暂态预测、优化运行； ③ 深度学习 / 强化学习 / 群体智能 → 故障诊断、稳定性判断、调度控制。

容易记混：这是「AI 在电力系统的应用阶段」，与 09-29 讲的「人工智能本身的三个发展阶段」 是两件事，别混（后者见上表前的 09-29 考点）。

考点：第三章数据预处理（10-13 开篇）

考点：两类常用算法（SVM 与集成学习）

要会：各解决什么问题、在算法谱系里的位置。

  • 支持向量机（SVM）：监督学习算法；用映射函数把样本映射到高维空间， 找一个间隔最大的线性超平面做分类。电力系统里用于稳定评估（输出 +1 稳定／−1 不稳定）。
  • 集成学习：按策略训练多个「弱监督模型」，组合成一个强监督模型，性能大幅提升。 为什么会有弱学习器：理论上「各方面都好」的模型几乎不存在。

容易记混：教师说 AI 有**「九种」算法**，但当堂只讲了 SVM 与集成学习两类—— 答题写这两类即可，别硬凑九个（其余没念出来的名字不要编）。
