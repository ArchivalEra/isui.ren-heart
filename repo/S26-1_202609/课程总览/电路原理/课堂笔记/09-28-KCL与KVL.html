09-28-KCL与KVL

这节课在干什么：先复习上周的电路模型、参考方向和功率，然后正式讲基尔霍夫定律，电流定律（KCL）和电压定律（KVL）这一节全部讲完，包括它们的推广形式。最后进入 1.4 无源元件，讲了电阻元件、欧姆定律、电导、功率，以及开路和短路的判断。要会三件事：数清支路/节点/回路/网孔，会列 KCL 和 KVL 方程（含广义节点、假想回路），会用欧姆定律和功率公式求电阻类元件的电压、电流、功率。

行政与考核：老师说考试第一个大题一般就是这种 KCL/KVL 求解，即使一眼能看出答案也要按步骤写。以"求 U"为例，标准的给分点是：先写绕行方向（或在图上画出绕行方向）1 分，由 KVL 列方程 1 分，式子本身 2 分，最后结果 1 分，共 5 分。作业目前是发下来的预习题册，没带的可以先做课本 30 页的习题（第一个到第四个，不分析的可以自己算一算、画一画）。国庆节后再补印。

题号条目

随堂例题：两节点电路求 I₁、I₂

解析：电路有左右两个节点。对左边节点，设流出的电流为正，把各支路电流按参考方向代入：

  • 节点 A：4 − 7 − I₁ = 0，解得 I₁ = −3。（4 和 7 都按流入记为负号前的减项，整理即"流入的等于流出的"：7 + I₁ = 4。）
  • 节点 B：−10 + 12 + I₁ + I₂ = 0，代入 I₁ = −3，得 I₂ = 1。

注意 I₁ = −3 表示该支路电流的参考方向与实际方向相反；若把参考方向反过来画，数值就是 +3。这里老师顺带强调：写 KCL 时"流入的等于流出的"最省事，不用去纠结正负号。

这一题在讲什么：这是最简单的节点应用，目的是把"参考方向定了才能列方程、列出来的正负号代表参考方向与实际方向的关系"这件事钉死。它对应 KCL 的机械流程：认节点 → 定参考方向 → 流入等于流出。以后凡是看到只给几条支路电流、让你求某一条的题，第一步都是找节点。

例题 1.3.1（教材 P11，与随堂例题同型）

解析：与上面那道两节点题完全同型，就是课本把它写成标准解题过程。老师要求：即使一眼能看出答案，也要写出"对哪个节点、由 KCL 得什么式子"的完整过程，因为考试这是大题。

这一题在讲什么：教材把 KCL 的规范书写方式固定下来——先指明节点，再列方程。这是考试答题格式的样板。

随堂例题：广义节点求 I₁、I₂

解析：先求好求的那条支路：节点上 I₂ + 2 = 7（2 与 I₂ 都是流入，7 是流出），得 I₂ = 5。

再求 I₁。I₁ 所在的两条支路电流都不知道，逐节点列不出来，于是用广义节点：把中间一整块电路用一个假想闭合面圈起来，整个闭合面当成一个"大节点"。对这个大节点列 KCL，把穿过闭合面的各支路电流按流出（或流入）统一取号，代数和为零，即可一步解出 I₁。

转写里报出的结果是 I₁ = −7；老师同时给了一种逐节点的等价做法（先由节点推出中间支路电流为 0，再由流入 7 反推），两种做法结论一致。

这一题在讲什么：讲广义节点的用处——当某个元件或某块电路内部结构不清楚、但只关心它与外界交换的电流时，把它整体看成一个节点，可以少列好几个方程。以后遇到"电路中间画了个三角形/方块、只给外部支路"的题，就该想到广义节点。

例题 1.3.2（教材 P12）

解析：已知 U₁、U₂、U₃，求 U₅、U₄、U。做法是逐个回路套 KVL：

  1. 先选右边一个回路列 KVL，求出其中一个未知电压；
  2. 再选第二个回路，求出 U₅；
  3. 最后选最外圈的大回路（绕行路径经过各元件），把剩下的未知量求出来。

每列一次都要先定绕行方向（顺时针或逆时针），电压参考方向与绕行方向一致取正、相反取负。

这一题在讲什么：练习"同一组未知量可以用不同回路分别求"，也说明回路的选法可以自由挑，选哪个方便就用哪个。它和后面的"两点间电压与路径无关"是同一件事的两面。

随堂例题：KCL 求 I（含一条导线把两点连成一个节点）

解析：电路里某两处虽然中间有导线，但导线上没有元件，所以这两点是同一个节点，要合并。按 KCL：4 = I − 3，解得 I = 7。

（另一道同型小题：节点上由 I − 4 − 1 + 6 = 0 解得 I = −4。）

这一题在讲什么：反复考"什么算一个节点"——导线上没有元件时，导线两端的点是同一个节点，必须合并后再列方程。数错节点，后面 KCL 全错。

随堂例题：KVL 求 U（−8 + U + 10 = 0）

解析：选顺时针为绕行方向（在图上画出箭头）。沿回路列 KVL：−8 + U + 10 = 0，解得 U = −2。

老师特别强调这道题上学期考过，很多同学只写一个 U = −2 就拿不到分；标准写法必须先声明绕行方向，再写方程，最后给结果。

这一题在讲什么：KVL 的最简形态，主要考"格式"——绕行方向、方程、结果三步缺一不可。

随堂例题：KVL 求 U（含 6×2）

解析：仍选顺时针为绕行方向（一般让绕行方向与支路电流方向一致，正号多、少出错）。电阻上电压方向与电流方向相同，取 6 × 2 = 12；另有一处电压方向相反。列式：−U + 12 − 10 = 0，解得 U = 2。

这一题在讲什么：KVL 里电阻项怎么写——电阻的电压方向默认与电流参考方向一致，所以电阻项写成 I·R；电源项则看其电压方向与绕行方向是否一致决定正负。

例题 1.4.1（功率、额定电压、额定电阻）

解析：给出功率和额定电压，直接代 P = U²/R（或 R = U²/P）求出额定电阻即可，属于代入计算。

这一题在讲什么：电阻功率公式的直接应用，先把 P = UI = I²R = U²/R 三个等价形式用熟。

例题 1.4.2（写出电压电流关系式）

解析：题目要求写出某元件电压与电流之间的关系式。这实际就是列 KVL 方程，按回路写出 U = … + I 的形式。

这一题在讲什么：把"电压电流关系式"和"KVL 方程"接上——元件的关系式本质上就是回路上 KVL 的整理结果。

例题 1.4.3（电源发出功率 60 W、电压 20 V）

解析：分三步。

  1. 由电源发出功率 60 W、电压 20 V，得该支路电流 I = 60 / 20 = 3 A（转写中记为"3I"，指这条支路电流为 3 A）。
  2. 对节点列 KCL：流进 1 A，流出为该支路电流 3 A，故 Ix + 1 = 3，得 Ix = 2 A。
  3. 选一个闭合回路（转写中取逆时针为参考方向），列 KVL：−20 + 3×5 − U = 0 型方程，解得 U。

注意这条支路整条是 5 A 还是 3 A：老师强调它是一条支路，同一支路电流处处相等，别写成别的值。

这一题在讲什么：把"功率 → 电流 → KCL → KVL → 电压"串成一条完整链路，是本章综合题的标准套路。

没编号但讲了的知识点

上节复习：电路模型、参考方向与功率

  • 电路模型有三个基本环节：电源、负载、中间环节，再加上各元件的模型图。
  • 1.2 讲的是电流、电压的方向：计算电路前必须先设定参考方向，参考方向定了才能求解。
  • 功率分关联参考方向与非关联参考方向：关联时求吸收功率，非关联时求发出功率。

支路、节点、回路、网孔

这是本节四个最基础的术语，后面列 KCL/KVL 全靠它们：

  • 支路：一条支路是若干个元件串联成的一段线。同一支路上电流处处相等（因为它们串联）。
  • 节点：三条或三条以上支路的连接点。注意——导线上没有元件时，导线两端的点是同一个节点，可以合并成一个点。
  • 回路：任意闭合路径，只要能绕成一个圈就叫一个回路。
  • 网孔：平面电路中内部不含支路的回路。所有网孔都是回路，但回路不一定是网孔。
  • 计数关系：支路数 − 节点数 + 1 = 网孔数，即 b − n + 1。这是大量实验得出的结论，老师让写在书上（P10 下边）。
  • 判断一条线是不是支路：支路里至少要含一个元件；只有导线连接的两个点不算支路，它们是同一个节点。

KCL：基尔霍夫电流定律

  • 内容：电路中任意一个节点上，所有支路电流的代数和为零；等价说法是"流入的电流等于流出的电流"。
  • 直观理解：像水龙头这个节点，左边流进多少，右边就流出多少，体现电流的连续性。
  • 写方程时先选正方向：流入为正，则流出取负，代数和为零；也可以统一选流出为正。不管怎么选，式子最终都化简成"流入 = 流出"。
  • 独立方程数：N 个节点的电路只能列 N − 1 个独立的 KCL 方程（因为两个节点时只需列一个就能表达）。这条书上没写，老师要求写在 P10 下边。
  • 老师建议直接用"流入 = 流出"的写法，省去考虑正负号。

KCL 的推广：广义节点

  • KCL 不只用在一个节点，也可以用在任意假想的闭合面（包围部分电路）上：把整个包围面看成一个"大节点"，穿过这个面的所有电流的代数和仍为零。
  • 用途：复杂电路中只关心某一块与外界的电流交换时，把它圈起来整体当节点，一步求解。
  • 例子：一个闭合面里只有一条支路通入、没有流出，则这条支路电流必为零。

KVL：基尔霍夫电压定律

  • KCL 解决节点问题，KVL 解决回路问题。所以前面必须先弄清节点和回路。
  • 内容：沿任意绕行方向（顺时针、逆时针都行），回路中各元件电压降的代数和为零。
  • 步骤：① 先指定回路的绕行方向；② 确定各电压前的符号——电压参考方向与绕行方向一致取正，相反取负。
  • 选绕行方向的技巧：一般让绕行方向与回路里电流方向一致，这样正号多、不易错。
  • 关于电阻：电阻没有正负极性，其电压参考方向默认与电流参考方向相同（否则欧姆定律前要加负号）。
  • 独立方程数：有 B 条支路、N 个节点的电路，独立 KVL 方程数为 B − N + 1，也就是有多少个网孔就能列多少个独立 KVL 方程。老师让写在书上 P12 附近。
  • 三回路例子说明：任取两个回路方程就能推出第三个，所以只需列两个独立方程。

KVL 的推广与"两点间电压与路径无关"

  • KVL 也可以推广到任意假想回路：比如电路中 C、E 两点并未直接相连，但可以用一个假想的电压 U_BE 代表这两点间的电压，把它当成一条支路补进回路，照样列 KVL。
  • 由此可证：电路中任意两点间的电压，等于这两点间任意一条路径上各元件电压的代数和；也就是两点间电压与所选路径无关（本质是电位差）。
  • 求 U_AB 的两条路径：
    • 上路径（顺时针）：−U_AB + U₂ + U₃ = 0 ⇒ U_AB = U₂ + U₃；
    • 左路径（逆时针）：−U_AB + U_S1 + U₁ − U_S4 − U₄ = 0 ⇒ U_AB = U_S1 + U₁ − U_S4 − U₄。
    • 两条路径结果相等，正好验证了"与路径无关"。

无源元件与有源元件

  • 无源元件：在关联参考方向下，任意时刻吸收的能量始终 ≥ 0（总输入能量不为负），也就是消耗能量的元件，如电容、电阻、电感、二极管，通常作为负载。无源元件不具备能量的控制作用。
  • 有源元件：具有能量产生或控制作用的元件。独立源（发电机、电池）产生能量，受控源起控制作用。常见有源元件还有三极管、场效应管、运算放大器。
  • 后续主要讲无源元件，独立源和受控源也会讲，但都是讲模型图，不是实际电路。

电阻元件

  • 电阻元件的最大特点：以消耗电能为主。凡是消耗电能为主的器件都可以等效成电阻元件，如实验室的小电阻器、滑动变阻器、灯泡。
  • 线性电阻：任何时刻电压与电流成正比，伏安特性是一条过原点的直线；非线性电阻则不是直线。本课程现在接触的都是线性电阻。
  • 符号用 R，单位欧姆（Ω）。关联参考方向下满足欧姆定律：u = R·i。
  • 电导：G = 1/R = i/u，单位西门子（S）。电阻表示元件阻碍电流的能力，电导表示传导电流的能力，两者物理意义不同。前两章基本用不到电导，只有第三章节点电压法会用到；题目里写"几西门子"给的就是电导。
  • 若参考方向非关联，公式前加一个负号。
  • 线性电阻是无记忆的双向性元件。

电阻的功率

  • P = U·I；配合欧姆定律有 P = I²R = U²/R，都可用（关联参考方向下求的是吸收功率）。
  • 非关联参考方向时，吸收功率 = −U·I；也可写成"发出功率 = U·I"。
  • 结论：电阻元件在任意时刻总是吸收功率，是耗能元件，消耗的能量对功率积分得到。电能计算在电路里很少用，了解即可。

开路与短路

  • 开路：相当于电阻为无穷大（断开），此时 i = 0，但 u ≠ 0。
  • 短路：电阻为 0，相当于一根导线，此时 u = 0，但 i ≠ 0。
  • 判断口诀：电流为 0 → 开路；电压为 0 → 短路。〔转写此处口误说反，按前后文更正。〕

转写与术语

  • 「交互式定理」「切尔霍夫」→ 基尔霍夫（Kirchhoff）定律。
  • 「TCL 方程」→ KCL 方程（基尔霍夫电流定律）。
  • 「KPL / KPI」→ KVL（基尔霍夫电压定律）。
  • 「电脑」→ 电导。
  • 「网口」→ 网孔。
  • 「圆心元件」→ 一个元件（指支路里至少要含一个元件）。
  • 「中高频…主低频」→ 通高频、阻低频（电容）。
