11-11-相量复习与复阻抗
这节课在干什么
本次课由新任课老师接手讲授：前 55 分钟先串联 1–4 章主干并系统重温 5.2–5.3（复数象限定角、复指数取虚部推相量、KCL/KVL 与 R,L,C 相量伏安关系），后 30 分钟进入 5.4 无源单口网络的阻抗，将正弦交流电路中的元件统一抽象为复阻抗与导纳，进而改画相量模型求解。转写把「相量」听成「向量」、把「复阻抗」听成「负阻抗／自主抗」，详见文末「转写与术语」。


要会五件事：


    

  1. 复数极坐标与直角坐标互化时，先由实部、虚部正负判定象限再定辐角，加减用直角坐标、乘除用极坐标；
    2. 

  2. 理解有效值相量 I˙=I∠φ 来自复指数函数 2​Iej(ωt+φ) 取虚部并分离旋转因子 ejωt，因此只有同频率正弦量才能直接做相量加减；
    3. 

  3. 熟记三元件的相量替换与相位关系：电阻 R（同相）、电感 jωL（电压超前电流 90∘）、电容 jωC1​=−jωC1​（电流超前电压 90∘）；
    4. 

  4. 掌握无源线性单口网络的复阻抗 Z=U˙/I˙=R+jX=∣Z∣∠φz​、导纳 Y=1/Z，以及按 X（或 φz​）正负判别感性／容性／电阻性与最简串联等效电路；
    5. 

  5. 会把时域电路改画为相量模型，把微分方程化成复代数方程，并套用串并联与分压、分流公式化简网络。
    6.

题号条目
课堂复数举例（−3+j4 化极坐标形式）
解析：本例用于演示复数化极坐标时的象限定角机械步骤。


⚠ 转写将左端记号读作 A3，无法核实课件原写为 A 还是 A3​，以下按 −3+j4 演算。


    

  1. 先判象限：实部 a=−3<0 落在实轴负半轴，虚部 b=4>0 落在虚轴正半轴，故复数位于第二象限。
    2. 

  2. 计算模长：由直角三角形勾股定理（3-4-5 常见直角边比例），得模长为

    ∣A∣=(−3)2+42​=5
    3. 

  3. 计算参考锐角：先按正值取参考锐角 α=arctan34​≈53.1∘（大边对大角，4 对应 53.1∘；6-8-10 比例角度相同）。
    4. 

  4. 按象限折算辐角：复数辐角定义为与正实轴的夹角；因点在第二象限，辐角为

    θ=180∘−53.1∘=126.9∘
    5. 

  5. 写出结果：极坐标形式为 5∠126.9∘。
    6. 



这一题在讲什么：专门防「直接对 b/a 求 arctan 漏看象限」的错误——第二象限若漏用 180∘ 修正，角度会落进第四象限，相差 180∘。


5.4 模型对比（R、L 串联时域回路转相量模型）
解析：已知正弦电压源 uS​(t) 激励 L 与 R 串联回路，求电感电流 iL​(t) 的方程形式对比。


    

  1. 列写时域 KVL 方程：沿回路顺时针绕行，各元件电压满足 uL​(t)+uR​(t)=uS​(t)。
    2. 

  2. 代入时域伏安关系：将 uL​(t)=LdtdiL​(t)​ 与 uR​(t)=RiL​(t) 代入，得一阶非齐次线性微分方程

    LdtdiL​(t)​+RiL​(t)=uS​(t)
    3. 

  3. 改画相量模型：保持电路连接拓扑与电压电流参考方向不变，将瞬时源与响应改为有效值相量 uS​(t)→U˙S​、iL​(t)→I˙L​，电阻保留 R，电感 L 替换为复阻抗 jωL。
    4. 

  4. 列写相量 KVL 并求解：由相量形式 KVL U˙L​+U˙R​=U˙S​，代入相量元件关系得代数方程

    jωLI˙L​+RI˙L​=U˙S​⟹I˙L​=R+jωLU˙S​​
    5. 



这一题在讲什么：把同一回路的时域微分方程和相量代数方程并排写出，说明引入相量模型后，求导运算变成了乘以 jω，不必直接解微分方程。


5.4 例题①（已知 ω=105 rad/s，求 R,L,C 串并联输入阻抗 Z）
解析：本例演示如何先将电路元件换成复阻抗，再按电阻串并联规则化简求端口输入阻抗 Z。


⚠ 本题电路连接图、电阻阻值、L 与 C 原始标称值及最终数值结果在转写中缺漏，以下仅写口播确认的参数计算与化简步骤。


    

  1. 由角频率求感抗与容抗：题给 ω=105 rad/s，代入口播参数得

    XL​=ωL=100 Ω,XC​=ωC1​=100 Ω
    2. 

  2. 替换为复阻抗构建相量模型：「看山不是山」，不再将元件视作 R,L,C，统一换为复阻抗：

    ZR​=R,ZL​=jXL​=j100 Ω,ZC​=−jXC​=−j100 Ω
    3. 

  3. 划分支路并按串并联公式化简：按口播结构将一条含电阻与电容的串联支路记为 Z1​=ZR​+ZC​，另一并联支路记为 Z2​，先算并联阻抗 Z∥​=Z1​1​+Z2​1​1​，再与串联电阻 ZR​ 相加得端口输入阻抗

    Z=Z1​1​+Z2​1​1​+ZR​
    4. 

  4. 复数代数运算定值：按极坐标乘除、直角坐标加减法则化简为 Req​+jXeq​ 形式。
    5. 



这一题在讲什么：建立「相量模型下，复阻抗串并联结构与直流电阻完全一致」的做题手感——先全部换成带 j 的阻抗，再套公式做复数四则运算。


5.4 例题②（由端口 u(t),i(t) 求无源网络 N 的最简串联等效电路）
解析：本例已知端口电压 u(t)、电流 i(t) 以及串联在端口与无源网络 N 之间的外接 ZR​,ZL​，反求 N 的最简串联组合元件值。


⚠ 本题端口 u(t),i(t) 完整正弦式、外接 ZR​,ZL​ 数值与 ω 均在转写中缺漏，以下为教师口播的演算链条与数值片段。


    

  1. 瞬时式转相量并求端口总阻抗：由给定 u(t)、i(t) 写出有效值相量 U˙、I˙，按定义求串联总阻抗

    Z=I˙U˙​
    
（转写口播两相量模之比处提及 10 Ω）。
    2. 

  2. 串联关系相减求 ZN​：外接 ZR​、ZL​ 与网络 N 串联，由 Z=ZR​+ZL​+ZN​ 移项得

    ZN​=Z−ZR​−ZL​
    
化成直角坐标形式，转写口播结果为 ZN​=6−j2000 Ω（口播将 j 误听为 7）。
    3. 

  3. 判别最简串联结构：ZN​ 实部 RN​=6 Ω 为电阻分量；虚部 XN​=−2000 Ω<0，说明网络 N 呈容性，故最简串联等效为「电阻 RN​=6 Ω 与电容 C 串联」。
    4. 

  4. 由容抗反算电容值：令 XC​=ωC1​=2000 Ω，代入题给角频率 ω 即得 C=2000ω1​。
    5. 



这一题在讲什么：演示「先由端口电压电流比求总阻抗、扣除已知元件后看虚部正负定等效结构」的逆向建模流程。


没编号但讲了的知识点

正弦量物理背景与 5.2 复数／相量推导回顾
    

  • 为何产生正弦交流电：火电、水电、核电、生物质与光热发电等（除光伏直接发电外）均通过热能转化为机械能，驱动发电机导体旋转切割磁感线产生感应电动势；磁极附近磁感线密、外侧疏，旋转一周即呈周期性正弦曲线变化。三相系统采用互差 120∘ 的三组导体以提升效率，教材统一用 sin 函数描述。
    • 

  • 复数核心运算法则：
      

    • 直角坐标形式 a+jb（j2=−1）用于加减：实部与实部分别相加减、虚部与虚部分别相加减，实部与虚部互不交叉；
      • 

    • 极坐标形式 ∣A∣∠θ（对应指数形式 ∣A∣ejθ）用于乘除：相乘为模相乘、角相加；相除为模相除、角相减；
      • 

    • 换算：∣A∣=a2+b2​，θ 为复数与正实轴的夹角，计算 arctan(b/a) 时须先依象限修正角度。
      • 

    

    • 

  • 由复指数推相量（Im[⋅] 取虚部法）：
      

    • 构造随时间旋转的复指数函数 2​Iej(ωt+φ)=2​I[cos(ωt+φ)+jsin(ωt+φ)]，取其虚部恰与正弦电流一致：

      i(t)=2​Isin(ωt+φ)=Im[2​Iej(ωt+φ)]
      
（注：教材取虚部记号 Im 与电流幅值 Im​ 写法相近，阅读时须按位置区分）；
      • 

    • 分离含时间因子：2​Iej(ωt+φ)=(2​Iejφ)⋅ejωt，定义复常数有效值相量 I˙=Iejφ=I∠φ（幅值相量 I˙m​=2​I˙），后半部分 ejωt 称为旋转复数；
      • 

    • 同频率前提的来源：角频率 ω 保存在被抽离的 ejωt 中而不在 I˙ 内，故只有同频率正弦量才能保持一一对应并直接做相量运算。
      • 

    

    • 

  • 同频相量加减成立的依据：因复数加减中实部与虚部互不混淆，对两个同频复指数相加后再取虚部，与先分别取虚部再相加结果相同，故时域和 u1​(t)+u2​(t) 唯一对应相量和 U˙1​+U˙2​（减法同理）。
    • 



5.3 KCL/KVL 与三元件相量关系回顾
    

  • KCL 与 KVL 相量形式：在同频率正弦稳态电路中，任一节点满足 ∑I˙=0，任一闭合回路沿同一绕行方向满足 ∑U˙=0。
    • 

  • 三层记号区分：瞬时值用小写 u(t),i(t)，有效值用大写 U,I，相量用大写加点 U˙,I˙。
    • 

  • 电阻、电感、电容伏安与相量关系汇总（老师要求对照教材第 5 章元件关系汇总表熟记，转写口播页码为 150 页）：
    • 







元件时域关系有效值关系相量关系相量模型替换相位关系


电阻 Ru(t)=Ri(t)U=RIU˙=RI˙R电压与电流同相


电感 Lu(t)=Ldtdi(t)​U=ωLI=XL​IU˙=jωLI˙jωL电压超前电流 90∘

  • 电感与电容关键点：感抗 XL​=ωL 与容抗 XC​=ωC1​ 单位均为欧姆（Ω），物理上都表征阻碍电流的能力；电容相量式中的负号由 j1​=j2j​=−j 推导得出，因 ω>0,C>0 使 XC​ 恒正，故纯电容阻抗虚部恒为负。

5.4 无源单口网络的复阻抗、导纳与串并联
    

  • 为什么交流电路比直流复杂：直流稳态下电压电流恒定，由 iC​=Cdtdu​ 与 uL​=Ldtdi​ 得 iC​=0（电容等价于开路）、uL​=0（电感等价于导线）；正弦交流下电压电流随时间持续变化，iC​ 与 uL​ 均不为零，因此需要用阻抗统一表达 R,L,C 共同呈现的阻碍作用。
    • 

  • 复阻抗（简称阻抗）定义：对不含独立源的无源线性二端网络 N（本节不含受控源），取端口电压 U˙ 与电流 I˙ 为关联参考方向，定义复阻抗为

    Z=I˙U˙​=∣Z∣∠φz​=R+jX
      

    • 单位：欧姆（Ω），虚数单位 j 无量纲；
      • 

    • 阻抗模：∣Z∣=IU​=R2+X2​，等于端口电压与电流有效值之比；
      • 

    • 阻抗角：φz​=φu​−φi​=arctanRX​，等于端口电压与电流的相位差（须依 (R,X) 象限定角）；
      • 

    • 分量独立与抵消：实部 R 称电阻分量，虚部 X 称电抗分量（由感抗与容抗共同决定，可正可负）；实虚部之间在结构上不会互相混同，但感抗与容抗一正一负可相互抵消（这是后续功率因数提高与无功补偿的理论基础）。
      • 

    

    • 

  • 三类纯元件的复阻抗：
      

    • 纯电阻：ZR​=R（虚部为 0）；
      • 

    • 纯电感：ZL​=jωL=jXL​（实部为 0，虚部恒正）；
      • 

    • 纯电容：ZC​=jωC1​=−jωC1​=−jXC​（实部为 0，虚部恒负）。
      • 

    

    • 

  • 阻抗三角形：以 R、X 为直角边、∣Z∣ 为斜边、φz​ 为夹角的直角三角形（与后续电压三角形、功率三角形互为相似三角形，夹角同为阻抗角）。
    • 

  • 阻抗性质与最简串联等效电路：
    • 







电抗与阻抗角条件网络性质端口电压电流相位最简串联等效电路


X>0（φz​>0，有电阻时 0<φz​<90∘）感性电压超前电流电阻 R 与电感 L 串联


X<0（φz​<0）容性电流超前电压（电压滞后电流）电阻 R 与电容 C 串联


X=0（φz​=0）电阻性电压与电流同相单个电阻 R






    

  • 导纳 Y：阻抗的倒数，即 Y=U˙I˙​=Z1​，单位为西门子（S）；对应各元件记为 YR​,YL​,YC​，用于正弦交流电路的节点电压法（自导纳、互导纳）。
    • 

  • 复阻抗的串并联与分压、分流公式（形式与直流电阻相同）：
      

    • 串联（由 KVL）：Z=Z1​+Z2​；分压公式 U˙1​=Z1​+Z2​Z1​​U˙，U˙2​=Z1​+Z2​Z2​​U˙；
      • 

    • 并联（由 KCL）：Z=Z1​∥Z2​=Z1​1​+Z2​1​1​；分流公式 I˙1​=Z1​+Z2​Z2​​I˙，I˙2​=Z1​+Z2​Z1​​I˙（分子取另一条支路的复阻抗，阻抗越大分流越小）。
      •
