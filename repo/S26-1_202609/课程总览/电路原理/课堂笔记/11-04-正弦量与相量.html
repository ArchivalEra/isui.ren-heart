11-04-正弦量与相量
这节课在干什么
本次课前收第四章、后开第五章：开头先订正一张图（叠加定理的图，课本 4.2 那张才对）并交代习题册第四章计算题的答案已发群里，
接着把第五章的地图摊开，然后讲 5.1 正弦量的基本概念（三要素、有效值、相位差）与 5.2 的前半（复数的三种形式与相量表示）。


要会五件事：


    

  1. 说出正弦量的三要素（幅值、角频率、初相位），并说清每个量决定正弦量的哪一部分；
    2. 

  2. 认准瞬时值 / 幅值 / 有效值三个记号，会用 I=Im​/2​ 互算，并知道工程上说的「电压电流多大」指的是有效值；
    3. 

  3. 会求两个同频正弦量的相位差，并判断超前、滞后、正交、同相或反相；
    4. 

  4. 会把复数在代数形式与极坐标形式之间互转，定角时按象限定；
    5. 

  5. 会把一个正弦量写成相量（大写字母加点），并知道相量与正弦量是一一对应但不相等。
    6.

题号条目
例 5.1.1（求 U1​ 与 U2​、U1​ 与 I3​ 的相位差）
解析：相位差的求法有固定的五步，先按顺序走完，再回头读结论。


    

  1. 先确认同频率。频率不同的两个正弦量之间没有相位差可比，这是前提条件，不是结论。
    2. 

  2. 统一函数形式。本课统一用正弦。电流若给的是余弦，按

    cos(ωt+θ)=sin(ωt+θ+90∘)
    
化成正弦后再比；化成正弦后还要把原来的初相位一并带上。
    3. 

  3. 统一幅值符号。若一条曲线的幅值为负，把它画成同幅值的正幅值，相当于沿横轴移 180∘：
加 180∘ 或减 180∘ 都对；若选了加 180∘，末尾按下一步折回 ±180∘。
    4. 

  4. 相减取差。两个初相位相减即相位差。
    5. 

  5. 折回 ±180∘。差值大于 180∘ 就减 360∘，小于 −180∘ 就加 360∘，
使结果落在一个周期的一半以内，再读「谁超前谁、差多少」。
    6. 



⚠ 本题在转写里只有老师的这段方法提示（把 U2​ 的负 50∘ 画成正的 50∘ 再算、电流 I 化成 sin 形式再算），
题面与数值答案都没有出现；本页因此只写方法，不给结论数值。


这一题在讲什么：相位差不是「算出一个角度」就完事，前面有三个改写动作挡在中间——
函数形式不同、幅值符号不同、角度没折回 ±180∘。老师把这三步先讲成流程，例 5.1.1 只是这个流程的第一个套用对象；
以后遇到任何求相位差的题，都按这五步走，不要跳步。


例 5.2.1 与 5.2.2（复数的形式转换与复数运算）
解析：老师把这两个例题并称为「这两个类型」，课堂没有逐题演算，只讲了每类操作的机械做法。


    

  1. 形式转换这一类（老师点名 5.2.1 是「代数形式 ↔ 极坐标形式」的转换）：
      

    • 代数形式 → 极坐标形式：先取模 A=a2+b2​，再定角 φ=arctan(b/a)，角必须按所在象限定；
      • 

    • 极坐标形式 → 代数形式：a=Acosφ、b=Asinφ，直接代三角函数。
      • 

    

    2. 

  2. 复数运算这一类：
      

    • 加减用代数形式：实部与实部相加，虚部与虚部相加；
      • 

    • 乘除用极坐标形式：乘法是模相乘、角相加；除法是模相除、角相减；
      • 

    • 混合运算按「先乘除、后加减」：先把代数形式化成极坐标做乘除，再把结果化回代数形式做加减。
      • 

    

    3. 



⚠ 两个例题的题面数据与课堂算式都没有出现在转写里；老师只点了「这两种类型」并让学生自己看课本数据。本页只写两类操作的规则。


这一题在讲什么：复数运算之所以要先学「形式转换」，是因为加减和乘除各自认一种形式——
加减硬要用极坐标，就得退回图形法（平行四边形定则）才能求和；乘除硬要用代数形式，公式会复杂到算不动。
老师把「加减用代数、乘除用极坐标」定成规矩，后面所有复数计算题都按这条规矩走。

  • 无受控源：把独立源全部置零（电压源短路、电流源开路），看剩下网络的等效电阻。
    

    • 

  • 有受控源：两种方法——
    

      

    • 外加电压法：在端口外加电压求电流，外加电压时必须把独立源去掉，受控源保留；
      •

独立源保留（开路电压本来就要算），受控源也保留——两种方法的差别见
10-28 戴维南与诺顿 的对照表。

5.1 为什么要引入正弦量
    

  • 线性电路里的电源，提供的电压或电流是随时间变化的函数；直流电路里这些量大小、方向都不随时间变，交流电路里则周期性变化。
    • 

  • 选正弦（或余弦）的理由：同频率的正弦量做加减、微分、积分，结果仍是同频率的正弦量——
频率在运算中不变，电路的频率成分才不会在运算中跑掉。
    • 

  • 本书统一用正弦函数（有的书用余弦，道理相同：二者在 2π 范围内都是周期为 2π 的函数）。
    • 



5.1 正弦量的三要素
一个正弦量由三个量唯一确定，三者定下则函数定下：


    

  1. 幅值 Im​：正弦函数的最大值，最小值是 −Im​。它决定正弦量变化的幅度。
记号规则是大写字母加小写 m（Im​、Um​、电动势幅值），国际通用。
从 −Im​ 到 Im​ 的整个变化范围称为峰值，即 2Im​。
    2. 

  2. 角频率 ω：决定正弦量变化的快慢，ω 越大变化越快。

    ω=T2π​=2πf,f=T1​
    
f 的单位是赫兹，ω 的单位是弧度每秒。
我国电力系统的工频为 50 Hz，对应 ω=2π×50=314 rad/s。
    3. 

  3. 初相位 φ：t=0 时刻的相角，决定正弦量的起始位置（在纵轴正半轴还是负半轴）。
初相位与频率合称相位，相位反映正弦函数的变化进程。初相位一般取在 0∼±180∘ 之间。
    4. 



5.1 有效值
    

  • 为什么要引入：交流量逐时变化，研究某一个时刻的电流、电压很少见，一般研究的是一段时间内的变化；
而这段时间内的最大值、最小值代表不了整体效果，所以要用一个量来代表这段时间的平均效果——这就是有效值。
    • 

  • 定义：一个电阻通以交流电与通以直流电，若在同一段时间内消耗的能量相同，
则这个直流值就是这个交流电的有效值。它反映的是交流在一个周期内的平均效果。
    • 

  • 与幅值的关系（把交流代入正弦函数、按能量相等推导）：

    I=2​Im​​
    
电压同理：U=Um​/2​。
    • 

  • 正弦量的两种写法（一一对应）：

    i(t)=2​Isin(ωt+φ),u(t)=2​Usin(ωt+φ)
    • 

  • 三个记号必须分清：
      

    • 小写 i（或 u）：瞬时值，随时间变化的那一条曲线；
      • 

    • 大写 Im​（或 Um​）：幅值，正弦量的最大值；
      • 

    • 大写 I（或 U）：有效值。
      • 

    

    • 

  • 工程上用哪个：说的电压电流「多大」、铭牌上的标注、电压表与电流表的读数，全都是有效值；
只有绝缘水平上的耐压值这类场合才用幅值。所以有效值在后面各节里用得极多，幅值用得少。
    • 



5.1 初相位与相位差
    

  • 相位差：两个同频率正弦量的初相位之差。它是一个常数，与计时起点无关；
不同频率之间没有相位差可比。
    • 

  • 相位差用来干什么：判断两个量的超前 / 滞后 / 正交 / 同相 / 反相关系。
      

    • 电压超前电流 φ：电压的起始位置在电流之前；
      • 

    • 电流超前电压 φ：反过来；
      • 

    • 正交：一个达到最大值时另一个恰好为零；
      • 

    • 同相：两者同时到最大、同时到最小；反相：两者同时到最大、同时到最小但方向相反。
      • 

    

    • 

  • 求相位差的五步（与例 5.1.1 的解析同源）：
    • 







步做什么依据


1确认两边同频率不同频率无相位差


2统一函数形式（余弦化正弦加 90∘）cos(ωt+θ)=sin(ωt+θ+90∘)


3统一幅值符号（负幅值移 180∘）两边同向才可比


4初相位相减，结果折回 ±180∘大于 180∘ 减 360∘，小于 −180∘ 加 360∘


5读超前 / 滞后 / 正交 / 同相差值为正即前者超前






    

  • 两个容易漏的改写：
      

    • 函数形式不同：I1​=Asin(ωt−30∘) 与 I2​=Bcos(ωt+θ)，先把 I2​ 化成正弦得
I2​=Bsin(ωt+θ+90∘)，再与 I1​ 比。
转写里这一例的口播数字含混（「用这个 40 减去一个负 30 就是 70」），本页只保方法与结论——I2​ 超前 I1​。
      • 

    • 幅值符号不同：把负幅值换算成正幅值，等价于移相 180∘；加或减 180∘ 都成立，
若选了加 180∘，末尾按折回 ±180∘ 那一步处理。
      •

5.2 为什么要引入相量
    

  • 正弦量直接运算很麻烦：两个支路电流相加、电压除以电流求电阻，都是正弦函数之间的加减乘除，
而正弦函数相除没有好办法。
    • 

  • 正弦量求和只有两条路：用公式做等效变换，或者用图形方法；两条路都不省事。
    • 

  • 相量就是为省这一步而设的：把同频率正弦量换成相量后，加减乘除按复数规则做。
    • 



5.2 复数的三种形式
    

  • 代数形式（直角坐标形式）：a+jb，实部在横坐标、虚部在纵坐标。
    • 

  • 指数形式。
    • 

  • 极坐标形式：A∠φ，其中 A 是模，φ 是相角。
    • 

  • 电路运算里最常用的是代数形式与极坐标形式：加减用代数形式，乘除用极坐标形式。
    • 



5.2 形式互转：定角必须按象限（课堂演算）
课堂演算的例子是四个直角坐标形式的复数，实部与虚部分别取 ±3、±4 的四种符号组合，因此模全都相同：


    

  1. 先算模（只跟大小有关）：

    A=a2+b2​=32+42​=5
    2. 

  2. 再定象限（只跟符号有关）：
      

    • 3+4j：实部 >0、虚部 >0 → 第一象限；
      • 

    • 3−4j：实部 >0、虚部 <0 → 第四象限；
      • 

    • −3+4j：实部 <0、虚部 >0 → 第二象限；
      • 

    • −3−4j：实部 <0、虚部 <0 → 第三象限。
      • 

    

    3. 

  3. 再定角：先算出锐角 arctan(4/3)=53.1∘，再按象限配符号、加减 180∘：
      

    • 第一象限：φ=53.1∘；
      • 

    • 第四象限：φ=−53.1∘；
      • 

    • 第二象限：φ=180∘−53.1∘=126.9∘；
      • 

    • 第三象限：φ=53.1∘−180∘=−126.9∘。
      • 

    

    4. 

  4. 写成极坐标形式：5∠53.1∘、5∠(−53.1∘)、5∠126.9∘、5∠(−126.9∘)。
    5. 



反向转换（极坐标 → 代数）用 a=Acosφ、b=Asinφ。课堂演算用的数是 5∠(−32.15∘)，
口播给出实部为正、虚部算得 −2.66。


⚠ 反向转换演算例的口播数字（32.15∘、−2.66）在转写里含混，本页按口播登记。


这一段在讲什么：模由实部、虚部的大小决定，角由它们的符号决定——这是两件分开的事。
先算锐角、再按象限定角，就不会把 126.9∘ 误写成 53.1∘、也不会把第三象限的角写成正的。
四个数模都是 5、角各不相同，正好把四种象限一次走完。


5.2 复数运算的规矩




运算用哪种形式做法


加、减代数形式实部与实部相加，虚部与虚部相加


乘极坐标形式模相乘，角相加


除极坐标形式模相除，角相减






    

  • 为什么加减要用代数形式：两个极坐标形式的复数要相加，只能先用图形法（平行四边形定则）求和；
要拿到数值，还得再化成代数形式。既然最后总要化，不如一开始就化。
    • 

  • 为什么乘除要用极坐标形式：代数形式做乘除公式很复杂；只有实部为零、只有虚部时还算简单。
乘比除好记一些，除更难。
    • 

  • 混合运算：与数学运算一样先乘除、后加减——先把代数形式化成极坐标做乘除，再把结果化回代数形式做加减。
    • 

  • 计算器：这类运算基本都要用计算器（30∘、45∘、60∘ 好口算，其余不便）；
考试要带黑色科学计算器，不能用手机。
    • 



5.2 相量：与正弦量一一对应，但不相等
    

  • 前提条件是频率相同。同频率时三要素里频率已经固定，只剩幅值与初相位两项要处理；
幅值对应复数的模，初相位对应复数的相角，幅值又是有效值的 2​ 倍——
于是「用复数代替正弦量」这一步就成立。
    • 

  • 推导路径：把复数写成指数形式后，它的虚部就是正弦函数形式，实部就是对应的余弦函数形式，
所以正弦量与复数之间是一一对应的。
    • 

  • 在电路里，复数改称「相量」（老师口播里「向量」与「相量」混用），记号是大写字母上加一点：
I˙、U˙；加点的用意是把它与普通复数区分开。
    • 

  • 相量一般默认指「有效值相量」（设备上读出来的都是有效值）；幅值相量也可写，数值是有效值相量的 2​ 倍。
    • 

  • 相量与正弦量不是相等关系，理由有两条：
      

    • 正弦量是随时间变化的函数，本身携带频率信息；相量只有有效值与初相位两项，看不出频率与时间关系；
      • 

    • 正弦量有三个参数，相量只有两个参数。
      • 

    

    • 



5.2 相量的表示与互求（课堂演算）
    

  • 由幅值求有效值相量：把幅值除以 2​，再把初相位接上。
课堂例：幅值 141.4 A → 有效值 141.4/2​=100 A。
    

    ⚠ 该例的初相位数值没有在转写里出现，本页只保 141.4→100 这一步。
    

    • 

  • 由有效值相量写回瞬时表达式：幅值取 2​ 倍，角频率由频率换算。
课堂例：有效值相量 50∠15∘ A、频率 50 Hz →

    i(t)=502​sin(314t+15∘) A
    

    • 

  • 三个 220 V 的相量：有效值都是 220 V，初相位分别是 0∘、−120∘、120∘，即

    U˙a​=220∠0∘ V,U˙b​=220∠(−120∘) V,U˙c​=220∠120∘ V
    
幅值相量则为 2202​ 倍。
