11-09-相量运算与向量图
这节课在干什么
开头回顾 5.1 正弦量的三要素、有效值与 5.2 复数的四种形式；主体讲 5.2 后半的相量运算：同频率正弦量的加减、相量图与平行四边形定则、书写规范判断；后半进入 5.3，把 KCL、KVL 写成相量形式，并推导电阻、电感、电容元件的相量伏安关系。转写通篇把「相量」听成「向量」、把「KCL」听成「PCL」，详见「转写与术语」。


要会五件事：


    

  1. 先把题给的正弦量统一写成正弦标准式，再写成相量：默认有效值相量（模为有效值，角为初相位），写幅值相量时模取 2​ 倍有效值；
    2. 

  2. 相量加减先把极坐标形式化成代数形式，实部与实部分别相加、虚部与虚部分别相加，需要数值时再化回极坐标形式；
    3. 

  3. 相量图上按平行四边形定则合成；减法改成加上反向相量（反向延长线），只有同频率的相量才能画在同一张图上；
    4. 

  4. 由相量和反写正弦函数：幅值 =2​× 有效值模，角频率沿用本题同频条件，初相位沿用合成相量的角；
    5. 

  5. 分清瞬时值小写 i(t)、有效值大写 I、相量 I˙；相量与正弦函数之间是一一对应，不能画等号。
    6. 



行政与考核（有才写）
    

  • 下一次课：周三由朱老师上；本次课要把 5.3 讲完，老师因此把 5.3 讲得较快。
    • 

  • 课本与自学：课上留时间看课本 108–109 页的向量图例题，以及 111–112 页的推导；点名看例题 5.2.6、5.2.7、5.3.1。老师明确说 5.2.6、5.2.7 的微分、积分在课上没有推导，「记住就行」，要求下去自己推导、把课本上的例题与推导过程想一想。
    • 

  • 实验课：12 月找一个周日，与学委约时间；两个班分班、各用一个周日做，共 4 个实验，四份实验报告都要带去。老师当天把实验报告、实验指导书、电路图与实物图照片、参考数据传到钉钉群；先打印报告，把实验过程、设备、内容、注意事项等能写的先写好，做实验时只填数据，回去再写分析题。群里的参考数据不能直接抄成自己的数据，除非自己实测与参考值确实一致。
    • 

  • 实验成绩流程：做实验（含考勤）→ 交四份报告 → 老师批改给成绩 → 发回后每份拍成 PDF 交学委归档（学校存电子档，不存纸质档）→ 归档完成才能提交实验成绩；少一步都无法归档。
    • 

  • 习题册第五章：点名「选择题」第 1、4、6、9、12、15、17、20、21、24 题可以先写；有些题要等 5 章讲完再写。第 30 题题干说「如图所示」但图上缺图，老师当场改成「R 与 L 串联的正弦交流电路，求总电压」，按这个条件做单选，不必用原图。
    • 

  • 书写规范：老师说第五章「听起来简单、动手就容易错」，零散记号多，必须自己动手算；考试用向量图的时候不太多，主要用代数形式求和。
    • 



题号条目
课首例子①（U˙1​=6∠30∘，求 U˙1​ 与 U˙2​ 之和）
解析：这是推导「同频正弦量加减 = 相量加减」之后的第一道求和例。题面里 U˙2​ 的模与角、U˙1​ 的函数式、ω 的完整数值在转写中都没有口播清楚，能站住的只有 U˙1​ 的有效值 6、角 30∘，以及结果的有效值 9.67 和角频率 314 rad/s；因此这里只写每一步依据，不补造缺掉的题面数。


    

  1. 先确认同频率。同频率时频率在运算中不变，正弦量只剩幅值与初相位两项要处理；不同频率的正弦量不能这样合并。
    2. 

  2. 把每个正弦量写成相量。给定的是有效值时直接写 U˙=U∠φ；给定最大值 Um​ 时先按 U=Um​/2​ 换成有效值。转写这里报的是「有效值是 6，角度是 30」，即 U˙1​=6∠30∘。
    3. 

  3. 把极坐标形式化成代数形式（相量加减认代数形式）：U˙k​=ak​+jbk​，其中 ak​=Uk​cosφk​、bk​=Uk​sinφk​。
    4. 

  4. 实部与实部相加、虚部与虚部相加：U˙=(a1​+a2​)+j(b1​+b2​)。这就是同频正弦量求和的全部运算，依据是两个同频正弦量之和仍是同频正弦量，而相量与正弦量一一对应。
    5. 

  5. 把结果化回极坐标形式，U=a2+b2​、φ=arctan(b/a)（按象限定角）。转写口播给出的结果有效值是 9.67。
    6. 

  6. 反写回正弦函数：u(t)=2​Usin(ωt+φ)。转写口播里频率仍是 314，故写成 u(t)=2​×9.67sin(314t+φ)；φ 的数值未在转写中出现，保留符号。
    7. 



这一题在讲什么：两个正弦函数直接相加要动三角恒等式，写成相量后只是一次复数加法。老师特意先给「推导过程」再给「例子」，是要说明相量法的合法性来自同频条件，不是把符号换一换就完事。


课首例子②（U˙1​=141/2​∠(π/3)、U˙2​=70.5∠(−π/6)，画相量图）
解析：这是「画几个同频率正弦量的向量图」的例。转写里 U˙1​ 的分子读作「141」、U˙2​ 的模读作「70.5」，与「141/2​≈100」「100/2​≈70.7」的换算关系不一致，本页按口播原样登记两个模，不择一断言。


    

  1. 先把正弦函数写成相量：题给的是最大值（幅值），按 U=Um​/2​ 取有效值，初相位照抄。于是 U˙1​=(141/2​)∠(π/3)、U˙2​=70.5∠(−π/6)；模是有效值，角是初相位。
    2. 

  2. 选参考量：可以按直角坐标系的 X、Y 轴画，也可以选某一个相量作参考量，先画出它，再按其他正弦量与它的相位差依次画出其余相量。哪种方便用哪种。
    3. 

  3. 逐个画：相量的模画成长度、相角画成相对参考方向转过的角；U˙1​ 的角是 π/3，U˙2​ 的角是 −π/6，后者落在参考方向的另一侧。
    4. 

  4. 加减用作图法：求和时把两个相量按平行四边形定则合成；求差时把被减相量反向延长（等价于加上负相量），再作平行四边形。
    5. 

  5. 由合成相量反写正弦函数：合成相量的模是有效值，故幅值取 2​ 倍，角频率沿用本题同频条件，初相位取合成相量的角。
    6. 



这一题在讲什么：画相量图之前必须先完成「正弦函数 → 相量」这一步，老师把这一步称作第五章大题的第一步、非常关键；图只是把模与角画出来，不能替代写相量。


书写规范判断 第一组（正弦函数 → 有效值相量，漏相量点）
解析：判断对象是「给出一个正弦函数，写出它的相量形式」的几种写法。


    

  1. 先看数值：模取有效值、角取初相位，这两处都对。
    2. 

  2. 再看记号：大写 U 不加点的写法表示有效值（一个实数），不是相量；相量必须写成 U˙=U∠φ 或 U˙=Uejφ。故该写法错在漏了相量点，与数值无关。正确写法是给大写字母加上相量点，模与角保持原值。
    3. 

  3. 依据：相量是复数，有效值是实数，两者记号不能混用；相量与正弦函数一一对应但不相等，记号上必须能区分。
    4. 



这一题在讲什么：老师把「理解了但写不对」单列出来，说明本节的错误大多出在记号而不在计算：先看记号，再核对模与角。


书写规范判断 第二组（指数形式漏 j）
解析：判断对象是一个**幅值相量（振幅相量）**的指数形式写法。


    

  1. 先看模：幅值相量用最大值作模，这一处没有问题。
    2. 

  2. 再看指数：指数形式必须写成 Um​ejφ，指数上除角度外还有虚数单位 j；只把角度写在指数上等于丢掉了虚部，不再是相量。故该写法错在指数上漏 j，正确写法是 U˙m​=Um​ejφ。
    3. 

  3. 依据：ejφ=cosφ+jsinφ 才有实部与虚部；指数形式、三角形式、代数形式、极坐标形式写的是同一个复数。
    4. 



这一题在讲什么：指数形式在电路运算里用得不多，主要在推导时用；正因为不常写，漏 j 成了高频错误。老师要求把四种形式放在一起对照，看它们是不是同一个相量。


书写规范判断 第三组（有效值相量 → 瞬时表达式，漏 2​ 与 (t)）
解析：判断对象是「已知电流的有效值相量 I˙=I∠φ，写出时间函数」的写法。


    

  1. 由相量模反推幅值：有效值相量的模是 I，正弦函数的幅值应为 Im​=2​I。把 I 直接当幅值抄进正弦函数，少一个 2​，错。
    2. 

  2. 补自变量：瞬时值是随时间变化的函数，必须写成 i(t)，不能只写一个孤立的 i。故正确写法是

    i(t)=2​Isin(ωt+φ)
    3. 

  3. 依据：I=Im​/2​；小写带 (t) 的记号专指瞬时值。
    4. 



这一题在讲什么：这一组把「相量模是有效值」和「正弦函数前面是幅值」两个口径摆在一起，专治把相量的模直接抄成幅值。


书写规范判断 第四组（指数形式的有效值相量与正弦函数画等号）
解析：已知量是指数形式写出的有效值相量 I˙=Iejφ，判断对象是「I˙= 正弦函数」这类写法。老师先说「应该没什么问题」，随即自己改判「这个也不对」，两句话针对的是同一组。


    

  1. 先读出模与角：ejφ 里的指数只给角度，模是前面的系数 I，且是有效值；指数形式与极坐标形式写的是同一个相量，读法相同。
    2. 

  2. 核对反写动作：i(t)=2​Isin(ωt+φ)，幅值乘 2​，角频率沿用题给频率，初相位沿用 φ；这一步本身没有错。
    3. 

  3. 错在等号：相量只带模与初相位两项，不带角频率、不带时间；正弦函数是随时间变化的函数，带 ω 与自变量 t。两者是一一对应，不是相等，因此不能直接画等号。老师同时点出，瞬时值要写成小写带 (t) 的形式，不能写成一个不带自变量的字母。
    4. 

  4. 正确写法：用对应记号分开写，例如

    I˙=Iejφ=I∠φ ⟺ i(t)=2​Isin(ωt+φ)
    
左边两个是同一个相量的两种写法，右边是正弦函数；左右之间写「对应」而不是写等号。
    5. 



这一题在讲什么：这是本节最根本的一条口径。相量法之所以能把正弦量的加减变成复数加减，靠的是「同频条件下的一一对应」；把对应写成相等，等于把丢掉的 ω 又悄悄加回来了。指数形式只是相量的另一种写法，不因为形式不同就允许画等号。


书写规范判断 第五组（有效值 100 与负号）
解析：判断对象是「有效值相量的有效值是 100」以及紧接着一处的符号判断。


    

  1. 模的读法：有效值相量的模就是有效值，题给有效值为 100，写「有效值 =100」正确。
    2. 

  2. 符号：下一处该带负号（转写里学生插话「符号忘了」），按题目给定的方向取负号后写对；负相量等价于反向延长线，不能把负号悄悄丢掉。
    3. 

  3. 依据：相量的模非负，方向信息全部放在相角里；取负相量时角移 180∘（见后文「负相量」一节）。
    4. 



这一题在讲什么：数值对了不等于写法对了，符号与记号是同一层检查项；老师把这几组判断连着排，就是要练「一眼看出错在哪一层」。


作业例题（求 uAB​=uA​−uB​，代数法与相量图法）
解析：转写里称为「一道习题的作业」。题面只口播了 U˙A​=220∠0∘、U˙B​ 角为 −120∘，以及结果有效值 380、角 30∘；U˙B​ 的模、uA​ 与 uB​ 的完整函数式、单位与 ω 都没有口播清楚。下面写两条都能机械执行的方法，不补造缺数。


    

  1. 先写相量：题给有效值相量 U˙A​=220∠0∘；U˙B​ 的角为 −120∘，模按题面给的有效值记为 UB​。
    2. 

  2. 把减法改成加法：U˙AB​=U˙A​−U˙B​=U˙A​+(−U˙B​)，负相量就是把 U˙B​ 反向延长。
    3. 

  3. 代数法：两项分别化成代数形式，实部与实部相加、虚部与虚部相加，再化回极坐标形式得模与角。
    4. 

  4. 相量图法：U˙A​ 的角是 0∘，选它作参考量沿参考方向画；−U˙B​ 的角是 −120∘+180∘=60∘。两分量长度相等时平行四边形是对称的，合成相量平分 0∘ 与 60∘，得角 30∘（转写口播为「上面是 60，平分一下 30」）。
    5. 

  5. 反写正弦函数：uAB​(t)=2​UAB​sin(ωt+φAB​)，其中模与角取第 3 步或第 4 步的合成结果。转写口播的结果是有效值 380、角 30∘。
    6. 



这一题在讲什么：同一道题给出两条解法，说明相量图不是另一种理论，而是同一个复数加法的几何画法；当两个分量长度相等、夹角好分时，图法比代数法更快。老师也点明「用向量图还要更简单一些」。


例 5.2.6（已知 i1​、i2​ 求 i=i1​+i2​）
解析：老师带全班一起看课本例题。转写口播可确认的是 i1​ 的相量写作 I˙1​=3∠0∘，i2​ 原给余弦形式且前面带负号；i2​ 的幅值、和电流的结果数值都没有口播清楚，本页只写化简与求和链条。


    

  1. 统一函数形式：本课统一用正弦。把余弦化成正弦用

    cos(ωt+θ)=sin(ωt+θ+90∘)
    2. 

  2. 统一幅值符号：幅值前的负号移进相角，等价于角移 180∘（加或减 180∘ 均可）。余弦化正弦带来 +90∘，负号带来 ±180∘，合并后角变为 −90∘；所以 i2​ 的相量写成 I˙2​=I2​∠(−90∘)，模 I2​ 按 i2​ 的幅值除以 2​（或直接用题给有效值）。
    3. 

  3. 求和：把 I˙1​=3+j0 与 I˙2​=0−jI2​ 化成代数形式，实部与实部相加、虚部与虚部相加，得 I˙=3−jI2​，再化回极坐标形式。
    4. 

  4. 反写：i(t)=2​∣I˙∣sin(ωt+argI˙)。
    5. 



这一题在讲什么：题面给余弦、带负号，就是要逼出「先统一到正弦标准式再写相量」这一步；不统一就写相量，初相位会整体偏 90∘ 或 180∘。


例 5.2.7（串联电路的电压之和与微分、积分）
解析：老师在课上说这道例题「放在这里还有一点点早」，只交代了结构，没有推导。


    

  1. 串联用 KVL：各元件电压相加得总电压，写成相量形式就是 U˙=U˙R​+U˙L​+U˙C​。
    2. 

  2. 元件关系：电阻项 U˙R​=RI˙；电感项与电容项分别含对电流的微分、对电压的微分，代回时域关系会得到一个微分方程。
    3. 

  3. 相量化的作用：把求导、积分换成相量运算后，微积分关系变成比例关系，电路求解随之简化。老师明确「5.2.6 / 5.2.7 的微分和积分记住就行，在这里没有给大家推导」，推导留到后面电感、电容元件处。
    4. 



这一题在讲什么：它是 5.2 与 5.3 之间的桥——先看到「电压要相加」，才会需要「每个元件的电压怎么用电流表示」。


例 5.2.8（课本 109 页向量图，I˙1​=5∠0∘、I˙2​=10∠(−90∘)、I˙3​=10∠90∘，KCL 求总电流）
解析：老师说这道例题与课本 5.2.7「数值不一样，但道理完全一模一样」，并当场订正了自己对课本图的怀疑。


    

  1. 先写相量（题给有效值相量）：转写口播为

    I˙1​=5∠0∘,I˙2​=10∠(−90∘),I˙3​=10∠90∘
    
模是有效值，角是初相位。
    2. 

  2. 写 KCL 的相量形式：以流入节点为正，∑I˙=0，等价于「总电流等于各支路电流之相量和」，即 I˙=I˙1​+I˙2​+I˙3​。依据是正弦稳态电路里所有支路电流同频率。
    3. 

  3. 化成代数形式相加：I˙1​=5+j0（只有实部）、I˙2​=0−j10、I˙3​=0+j10；实部与实部相加、虚部与虚部相加，得 I˙=5+j0。I˙2​ 与 I˙3​ 模相等、方向相反，互相抵消。
    4. 

  4. 相量图核对：在直角坐标系里 I˙1​ 沿正实轴、I˙2​ 沿负虚轴、I˙3​ 沿正虚轴；先把后两者相加得零，再与 I˙1​ 按平行四边形定则合成，合成相量仍是 I˙1​。
    5. 

  5. 反写正弦函数：i(t)=2​×5sin(ωt+0∘)。转写末尾另报了一个「角度是 −40∘、有效值乘回 2​」的电流结果，与本组给定值不属于同一处演算，本页不把两个结果合并（见条件备注）。
    6. 



这一题在讲什么：三支路 KCL 在直流里是三个实数相加，在正弦交流里多两步——先把正弦函数化成相量、加完再变回正弦函数。老师拿它说明「为什么第五章求和必须用相量」：三个三角函数直接相加不现实。


课本 109 页图的订正：老师一度怀疑课本 5.2.6 的向量图角度写错，比对后确认「课本上的那个没有问题」。原因是课本那一处两个相量的模都是 5、角为 0∘ 与 90∘，合成相量才平分夹角得 45∘；另一处模分别是 3 与 4，模不相等，合成角就不是 45∘。模同为 5、角为 0∘ 与 90∘ 时，合成角平分两者得 45∘；换成 3 与 4 这种模不等的情形，合成角就不是 45∘，两者不能混用。


5.3 综合例题（已知 U˙2​、U˙3​ 与部分支路电流，求 U˙1​、U˙4​、I˙4​）
解析：这是 KCL/KVL 相量形式的综合应用。转写里电路图与大部分题面数值没有口播，能站住的只有几条关系链与零散数值（0.707、3.77、10、4.333、30∘、5、−150∘），彼此不能拼成完整题面；本页只写可复核的做法与依据。


    

  1. KCL 求 I˙4​：以流出节点为正，把各支路电流相量代数和写成 ∑I˙=0；每一项先化成代数形式（转写口播里有 3、0.707、0.707 这样的分量），实部与实部分别相加、虚部与虚部分别相加，再解出未知的 I˙4​。
    2. 

  2. KVL 求 U˙1​：沿闭合回路按参考方向写 ∑U˙=0。转写给出的回路式是 −U˙2​+U˙1​−U˙3​=0，由此 U˙1​=U˙2​+U˙3​。依据是任一回路各支路电压相量的代数和为零。
    3. 

  3. 分量求和：把 U˙2​、U˙3​ 各自写成 a+jb（用 a=Ucosφ、b=Usinφ，转写里出现 sin30∘、cos30∘ 的分量写法），实部与实部相加、虚部与虚部相加，再化回极坐标形式。
    4. 

  4. 由相反方向求 U˙4​：U˙4​ 与 U˙3​ 大小相同、方向相反，即 U˙4​=−U˙3​。若 U˙3​=5∠30∘，则

    U˙4​=−U˙3​=5∠(30∘−180∘)=5∠(−150∘)
    
不能写成 −5∠30∘ 再让模带负号。老师当场强调：把负号从模上移进相角，就是角移 180∘；写成正弦函数时 −5sin(ωt+30∘)=5sin(ωt+30∘−180∘)=5sin(ωt−150∘)。
    5. 

  5. 反写：把 U˙1​、U˙4​、I˙4​ 各自的模乘 2​ 作幅值，角频率沿用本题同频条件，初相位沿用各自相角，写成 u(t)、i(t)。
    6. 



这一题在讲什么：把「KCL/KVL 照抄成相量形式」和「负相量必须改角而不是改模」两件事放在同一道题里。前者是 5.3 的主结论，后者是整节课反复提醒的书写细节。


例 5.3.1（已知电感 L 与电流，求电感电压）
解析：老师只报了解题顺序，没有在课上展开例题数值。


    

  1. 先把题给电流写成相量：I˙=I∠φ，模取有效值、角取初相位。
    2. 

  2. 算感抗：XL​=ωL（单位欧姆）。
    3. 

  3. 代入相量关系：U˙=jXL​I˙=jωLI˙，即模乘 ωL、角加 90∘；于是电压有效值 U=ωLI，电压超前电流 90∘。

  4. 反写：u(t)=2​ωLIsin(ωt+φ+90∘)。

课堂例题（C=0.5 F，已知电流求电容电压）
解析：转写口播的电容值有 0.5 与 0.6 两处，角频率报的是 100，结果只报了「0.022​、sin100t、−120∘」这一串；本页按 0.5 F 登记，不择一断言，也不补造电流题面。


    

  1. 把电流写成相量：I˙=I∠φ，模取有效值。
    2. 

  2. 算容抗：XC​=ωC1​，单位欧姆。
    3. 

  3. 代入相量关系：U˙=−jXC​I˙=jωC1​I˙，即模除以 ωC、角减 90∘；电流超前电压 90∘。
    4. 

  4. 反写：u(t)=2​Usin(ωt+φU​)。转写口播的结果形式是 u(t)=0.022​sin(100t−120∘)。

5.3 元件关系判断（电阻、电感、电容三组对错）
解析：这是课末的一组判断，判断标准是等式两边必须属于同一层口径。


    

  1. 电阻：时域关系 u(t)=Ri(t)、有效值关系 U=RI、相量关系 U˙=RI˙ 都成立；把 R 与 I 写成随时间函数却不带微分/积分，或把时域式与有效值式混写，就错。老师点出「有效值对应有效值，这个式子一定要是对应的关系」。
    2. 

  2. 电感：时域关系是 u(t)=Ldtdi(t)​，其中没有感抗 XL​；把 XL​ 写进时域微分式就错。有效值关系 U=ωLI=XL​I、相量关系 U˙=jωLI˙ 正确；相量之比 U˙/I˙ 必须带 j，写成实数 ωL 就错。
    3. 

  3. 电容：时域关系是 i(t)=Cdtdu(t)​，是微分形式；有效值关系里 I=ωCU，因此 U=ωCI​=XC​I。用 U 表示电压时系数应写成 1/(ωC)，写成 ωC 的那一处错；相量关系 U˙=jωC1​I˙=−jXC​I˙ 正确。转写这一段的口播在「ωC」与「ωC 分之 1」之间来回，本页按可核对的有效值关系判定，不据口播择一断言课件原式。
    4. 



这一题在讲什么：第五章记号多（瞬时值、最大值、有效值、相量、感抗、容抗），错项几乎都是把两层口径拼在一个等式里。老师说「实在不知道就把这些公式都记住」，是先保住对应关系，再回头补推导。

5.1 / 5.2 回顾：三要素、复数四种形式、相量与正弦函数的对应
    

  • 5.1 正弦量三要素：角频率、振幅（最大值）、初相位；另讲有效值与相位差。工程上用得最多的是有效值，但题目给正弦函数时常给最大值，要会由 U=Um​/2​ 换算过去。
    • 

  • 5.2 复数的四种形式（本次课口播「复数四种形式」，上次课展开过）：
      

    • 代数形式（直角坐标形式）a+jb，实部在横轴、虚部在纵轴；
      • 

    • 三角形式 A(cosφ+jsinφ)；
      • 

    • 指数形式 Aejφ，指数上必须有 j；
      • 

    • 极坐标形式 A∠φ，A 是模、φ 是相角。
      • 

    • 常用的是代数形式与极坐标形式之间的转换：加减用代数形式，乘除用极坐标形式（模相乘角相加、模相除角相减）。
      • 

    

    • 

  • 相量与正弦函数的对应：同频率时频率固定，正弦量只剩幅值与初相位；幅值（或有效值）对应复数的模，初相位对应复数的相角，于是可用相量代表正弦量。相量一般默认有效值相量；幅值相量的模是有效值相量的 2​ 倍。记号是大写字母加一点 U˙、I˙。
    • 

  • 一一对应但不相等：相量不带角频率、不带时间，正弦函数是随时间变化的函数；两者之间写「对应」，不写等号。这条正是书写规范判断第四组的依据。
    • 



同频正弦量的相量加减：为什么可以这样算
    

  • 只有同频率的正弦量才能进行相量运算（也只有同频率的相量才能画在同一张相量图上）。同频相加后仍是同频正弦量，频率在运算中不参与变化。
    • 

  • 推导结论：若 u1​(t),u2​(t) 对应 U˙1​,U˙2​，则 u1​(t)±u2​(t) 对应 U˙1​±U˙2​。所以正弦函数的加减可以直接换成相量加减。
    • 

  • 正弦函数不能直接简单相加：不化成相量时，只能用三角恒等式或图示法；第五章里电压求和（KVL）、电流求和（KCL）都会碰到这一步。转写把 KCL 听成「PCL」，见「转写与术语」。
    • 

  • 机械顺序：① 统一成同频正弦标准式 → ② 每个量写相量（模、角）→ ③ 极坐标化代数 → ④ 实部、虚部分别相加 → ⑤ 代数化回极坐标 → ⑥ 反写正弦函数（幅值 2​ 倍、角频率沿用、角沿用）。
    • 

  • 这是变换思想：把时域（以时间为自变量的函数）变到频域（以频率为自变量、用相量表示）再分析，电压与电流都适用。相量法因此属于频率分析；只要掌握加减即可。
    • 



相量图：参考量选取、加减作图、超前滞后
    

  • 相量可以用图形表示：在复平面上把相量画成有向线段，长度是模（有效值），与参考方向的夹角是初相位。
    • 

  • 参考量的两种选法：① 直接以直角坐标系的 X、Y 轴为参考；② 选某一个相量作参考量，先画出它，再按其他正弦量与它的相位差依次画出其余相量。按题目需要选。
    • 

  • 只有同频率的相量才允许画在同一张相量图上，因为图上不画频率，频率必须全场相同。
    • 

  • 读超前滞后：把电压、电流画在同一张图上，比较相角；φu​−φi​>0 就是电压超前电流。图上看着「在前面」的那个相量相角更大。
    • 

  • 加用平行四边形定则：把 U˙1​、U˙2​ 首尾或共起点画出，按平行四边形求合成相量。
    • 

  • 减用反向延长线：U˙1​−U˙2​=U˙1​+(−U˙2​)，把 U˙2​ 反向延长后再按平行四边形合成。
    • 

  • 负相量：−U˙ 等价于把相量转 180∘（角加或减 180∘），不能写成负模再保留原角。写成正弦函数时把幅值前的负号移进相角，也是角移 180∘。
    • 

  • 模相等才平分夹角：两个相量模相等、夹角为 90∘ 时合成角是 45∘；模不等（如 3 与 4）时合成角不是 45∘。这是老师核对课本 109 页图时给出的理由。
    • 



书写规范：四层记号不能混




层记号含义写正弦函数时


瞬时值i(t)、u(t)随时间变化的函数必须带 (t)


最大值（幅值）Im​、Um​正弦量的最大值作三角函数前的系数


有效值I、U大写不加点，实数I=Im​/2​


相量I˙、U˙大写加点，复数模是有效值（默认），角是初相位






    

  • 相量与正弦函数一一对应但不相等，不画等号；
    • 

  • 有效值相量 → 瞬时表达式要乘 2​，并补 (t) 与 ω；
    • 

  • 指数形式相量的指数上要带 j；
    • 

  • 相量的模非负，负号一律移进相角（角移 180∘）；
    • 

  • 用最大值作模时要写明是幅值相量，用 Im​、Um​ 表示，别与有效值相量混。
    • 

  • 老师说第五章越听越糊涂，原因是「瞬时值小写、最大值大写带 m、有效值大写、相量加点」四类记号同时出现，加减又要化代数形式；必须自己动手算。
    • 



5.3 两类约束的相量形式
    

  • KCL 相量形式：任一点（直流里是任一节点）所有支路电流的相量代数和为零，∑I˙=0；以流入为正时即流入相量之和等于流出相量之和。依据是正弦稳态电路里所有支路电流同频率。
    • 

  • KVL 相量形式：任一回路各支路电压的相量代数和为零，∑U˙=0。
    • 

  • 与直流相比多的两步：先把随时间变化的函数写成相量，加完得到结果相量，再变回正弦函数。中间的计算仍是复数加法。
    • 

  • 老师说「基尔霍夫定律的相量形式就是相量运算，只不过赋予了电路的形式」，因此不难；难的是后面已知电流求电压那一类题。
    • 



5.3 元件伏安关系的相量形式与感抗、容抗




元件时域关系有效值关系相量关系相位


电阻 Ru(t)=Ri(t)U=RIU˙=RI˙同相


电感 Lu(t)=Ldtdi(t)​U=ωLI=XL​IU˙=jωLI˙电压超前电流 90∘


电容 Ci(t)=Cdtdu(t)​I=ωCU，U=ωCI​=XC​IU˙=jωC1​I˙=−jXC​I˙电流超前电压 90∘






    

  • 推导路线（三个元件同一套）：先给时域模型，把正弦电流（或电压）代进去，求导后把余弦化回正弦（角加 90∘），读出新函数的幅值与初相位，再写成相量；把相量式与电流相量对比，就得到相量关系。
    • 

  • 电阻：R 是常数，乘进三角函数后有效值变成 RI、角不变，所以时域、有效值、相量三层形式一致，电压电流同相。
    • 

  • 电感：求导多出因子 ω，cos 化 sin 多出 +90∘；写成相量时 j=1∠90∘=ejπ/2 承担这 90∘，即 U˙=jωLI˙。XL​=ωL 称感抗，单位欧姆，物理意义是电感元件限制电流的能力；L 一定时 XL​ 与频率成正比，ω=0 时电感相当于短路，ω→∞ 时阻碍作用趋于无穷。
    • 

  • 电容：为避开积分，题给电压、对电压求导得电流；I˙=jωCU˙，故 U˙=jωC1​I˙=−jXC​I˙。XC​=ωC1​ 称容抗，单位欧姆，物理意义是电容元件限制电流的能力；ω=0 时隔直流，ω→∞ 时容抗趋于零、相当于短路，即「通高频、阻低频」。
    • 

  • 向量模型图与向量图：分析 5.5 时第一步就是把时域模型图改画成相量模型图（电压、电流改写成相量形式，元件用阻抗表示）；再配一张相量图看相位关系。老师说 5.3 非常重要，因为整个电路分析都在解电压电流关系；引入相量后微积分关系变成比例关系，电路求解被简化。
    • 



5.2 收尾：微分与积分
    

  • 5.2 剩下的两块是相量的微分与积分；老师课上「没有给大家推导」，只要求记住结论，等学电感、电容元件时再推，课本上也直接给了结论。

  • 做法口径一致：对正弦函数求导或积分，也先化成相量形式再处理；求导后 cos 化 sin 是角加 90∘，这就是电感电压超前电流 90∘ 的来源。
