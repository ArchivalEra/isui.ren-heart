10-21-网孔电流法

这节课在干什么

本次课把第三章的两套「回路型」方法讲完：先讲 3.2 网孔电流法（概念、方程推导、标准形式、电流源与受控源的处理）， 再讲回路电流法（网孔法的推广，靠"选回路"减少方程数）。

要会五件事：

  1. 说清为什么网孔电流法只列 KVL——网孔电流在每个节点流入一次、流出一次，KCL 自动满足；
  2. 会从支路电流推出并直接使用标准形式 Rkk​IMk​+∑Rkj​IMj​=∑US↑​；
  3. 判互电阻的正负（看两网孔电流穿过公共电阻的方向是否相同），写对右端电压升；
  4. 处理理想电流源的两种位置（只在某个网孔边上 / 夹在两个网孔之间）与受控源（当独立源写 + 补充方程）；
  5. 用回路电流法挑回路，让每个电流源只落在一个回路里，从而少列方程。

行政与考核（有才写）

  • 习题册第二章里用到节点电压法的题先留着不做：选择题第 10 题、填空题第 6、9 题（教师口播时还提到填空题第 3 题，口径含糊）。
  • 下周一第 6、7 节补课（国庆冲掉的课）。原拟调到周三下午，因周三下午有党课，又调回周一第 6、7 节。
  • 考试口径：网孔法以往不单独出大题；本学期改成抽题后，大题与填空题里各有一两道。考研必考这一块。
  • 复习顺序：先把课本看懂，再做习题册；习题册的题要动笔写，看会不等于会写。

题号条目

课本 59 页例题（三个网孔，只含电阻与电压源）

解析：

  1. 三个网孔，网孔电流记 IA​、IB​、IC​（教师刻意不用 1,2,3，避免与支路电流混），全取顺时针。
  2. 网孔 A 的自电阻是 R1​+R2​；与网孔 B 的互电阻是公共电阻 R2​，两网孔电流穿过它方向相反，取负； 网孔 A 与网孔 C 无公共电阻，该项为 0。右端按顺时针绕行看电压升：过 US2​ 是降（取负），过 US1​ 是升（取正）：
    (R1​+R2​)IA​−R2​IB​=US1​−US2​
  3. 网孔 B：自电阻 R2​+R3​，与 A 的互电阻 −R2​，与 C 的互电阻 −R3​，右端为 US2​：
    −R2​IA​+(R2​+R3​)IB​−R3​IC​=US2​
  4. 网孔 C：与 A 无公共电阻（该项为 0），与 B 的互电阻 −R3​，自电阻 R3​+R4​，过 US4​ 是降：
    −R3​IB​+(R3​+R4​)IC​=−US4​
  5. 解出 IA​,IB​,IC​ 后回到支路：支路电流 = 相邻网孔电流的代数和，与支路参考方向同向的取正、反向的取负。

这一题在讲什么：这是标准形式的"最简情形"——只有电阻和电压源，没有电流源、没有受控源。 教师让学生先自己写第三个方程再对答案，就是要练"自阻全正、互阻看方向、右端看升降"这套动作固定下来。

课本 3.2.3 例题（理想电流源只在网孔边上）

解析：

  1. 电路是电阻、电压源加一个理想电流源；该电流源只属于一个网孔（在外侧支路上），所以那个网孔的电流被电流源定死。
  2. 取与电流源方向一致的绕行方向（教师取逆时针），于是 IM2​=2 A，这个方程不用列。
  3. 只对另一个网孔列式：
    50I1​+30×2=40
    解得 I1​=−0.4 A（负号表示实际方向与所设相反）。
  4. 两个网孔电流同向穿过 30Ω，故该项取正；该支路电流为两电流之和：2+(−0.4)=1.6 A。

这一题在讲什么：电流源"落在边上"是最省事的一种情形——它把一个未知量直接变成已知量。 教师顺带强调：取绕行方向时顺着电流源方向取，符号就全正，不容易错。

课本 3.2.3 例题二（理想电流源夹在两个网孔之间）

解析：

  1. 电流源是两个网孔的公共支路，它的电流不能同时等于两个网孔电流，所以不能把它当网孔电流用。
  2. 办法是先假设它两端的电压 U，把 U 当成一个新的未知量，两个网孔照常按标准形式写（电流源所在支路用 U 计电压）。
  3. 多了一个未知量，就补一个方程：两网孔电流穿过该支路的代数和等于电流源电流，即 I1​+I2​=−2（符号按教师所设方向）。
  4. 三个方程解三个未知量。

这一题在讲什么：网孔法的"代价"在这里露出来——中间支路上的电流源必须靠假设电压换未知量。 下次学回路法时会看到，选好回路就能把这一步整块省掉（本次课后半段正是这个对照）。

课本 3.2 例题（含受控电压源）

解析：

  1. 受控电压源按独立电压源写进方程，右端照常记它的电压；控制量暂时当已知。
  2. 网孔 A（无受控源）：4IA​−3IB​=2。
  3. 网孔 B：−3IA​+6IB​−IC​=−3U2​；网孔 C：−IB​+3IC​=3U2​。
  4. 补充方程把控制量用网孔电流写出来：U2​ 是 3Ω 上的电压，U2​=3(IB​−IA​)。
  5. 代回解三个网孔电流，再求各支路电流。

这一题在讲什么：受控源在所有列方程的方法里都是同一套动作（支路法、网孔法、节点法一致）： 先当独立源，最后补一个控制量方程。教师特别提醒一处易错点：受控源电压若写成"3U2​"， 而 U2​ 本身是某个电阻上的电压，那个电阻的电压已经在互电阻项里出现过，右端只写受控源自己的电压，不能再加一遍。

课本 61 页例题（回路电流法：挑大回路避开电流源）

解析：

  1. 电路里有多个理想电流源，且有电流源在中间（两个网孔的公共支路）。若用网孔法，每个这样的电流源都要假设电压 + 补方程。
  2. 改用回路电流法：选回路时让每个电流源只落在一个回路里，于是那几个回路的电流直接等于电流源电流，方程不用列。
  3. 剩下的未知量只用一个大回路 IA​ 表示，列一个方程：
    9IA​−4IB​−8IC​=20
    （9Ω 是该回路全部电阻之和；与相邻回路的公共电阻 4Ω、8Ω 取负；右端为绕行方向的电压升之和）。
  4. IB​、IC​ 已由电流源定死，代回即得 IA​，再由回路电流的代数和求各支路电流。

这一题在讲什么：回路法的唯一新增技能就是"选回路"。教师给的选法原则一句话： 让每个理想电流源只属于一个回路；这样网孔法里"设电压 + 补方程"的那一套全部消失。

没编号但讲了的知识点

网孔电流法为什么只列 KVL

  • 网孔电流是假想的、沿网孔闭合流动的电流。它沿闭合路径走，对每个节点都是流入一次、流出一次， 所以KCL 自动满足，不必再列。
  • KVL 本身就是"沿闭合回路各段电压代数和为零"，网孔正好是闭合回路，因此每个网孔列一个 KVL 方程即可。
  • 待求未知量数 = 网孔数 = 独立回路数 b−(n−1)（第一章讲过的计数公式）。

从支路电流推出标准形式

以两网孔电路为例（网孔一含 R1​、R2​、US1​、US2​，网孔二含 R2​、R3​、US2​，R2​ 为公共电阻）， 两网孔电流 IM1​、IM2​ 同取顺时针。先用支路电流写网孔一的 KVL：

R1​I1​+R2​I2​+US2​−US1​=0

再把支路电流换成网孔电流：I1​=IM1​，I2​=IM1​−IM2​（R2​ 上的支路电流是两网孔电流之差），整理得

(R1​+R2​)IM1​−R2​IM2​=US1​−US2​

网孔二同法（I3​=IM2​，I2​ 在该网孔里方向相反故取负）：

−R2​IM1​+(R2​+R3​)IM2​=US2​

教师强调：标准形式不是天上掉下来的，是从 KVL 推出来的；把电阻项留在左边、把电源项移到右边， 左边自然成为"电压降之和"、右边成为"电压升之和"。

标准形式与四条符号规则

N 个网孔就列 N 个方程，形式统一：

⎩⎪⎨⎪⎧​R11​IM1​+R12​IM2​+⋯+R1N​IMN​=∑US↑​R21​IM1​+R22​IM2​+⋯+R2N​IMN​=∑US↑​⋮​

  1. 自电阻 Rkk​：第 k 个网孔里所有电阻之和，恒为正。
  2. 互电阻 Rkj​：两网孔的公共电阻，看方向取号——两网孔电流穿过该电阻方向相同取正， 方向相反取负；两网孔没有公共电阻时该项为 0（不写）。
  3. 右端：沿该网孔绕行方向的电压升代数和——遇到电源是升取正、是降取负。
  4. 若所有网孔都取顺时针（或都取逆时针），任何相邻网孔的公共电阻上两电流方向必然相反， 所以互电阻项一律为负——这是可用来快速自查的口诀，但只在"全同向 + 真有公共电阻"时成立。

解题步骤

  1. 数网孔，标出每个网孔的电流及其参考方向（一般统一取顺时针）；
  2. 按标准形式逐个网孔列方程（自阻、互阻、右端电压升）；
  3. 解方程组得网孔电流；
  4. 用网孔电流的代数和求各支路电流，再按需要求电压、功率。

理想电流源的两种位置

  • 只在某个网孔边上（仅属于一个网孔）：该网孔的电流就是电流源电流， 取绕行方向与电流源方向一致时取正、相反时取负；这一个方程不列，未知量少一个。
  • 夹在两个网孔之间（公共支路）：不能当网孔电流用；假设它两端的电压 U 作为新未知量， 两个网孔方程照写，再补一个方程（两网孔电流穿过该支路的代数和 = 电流源电流）。 方程数不变（多一个未知量、多一个方程），但过程变长。

受控源的处理

  • 与第三章其他方法一致：受控源先按独立源写进方程，再补一个把控制量用网孔电流表示的方程。
  • 注意两处：① 受控源不能置零、不能当成短路或开路；② 受控源电压若由某个电阻上的电压表达， 该电阻的电压不要重复计入（它已在互电阻项里）。

网孔电流法与回路电流法

  • 回路电流法以回路电流为未知量，独立回路数同样是 b−(n−1) 个，列 N 个方程， 方程形式与网孔法完全一样（自电阻、互电阻、右端电压升之和）。
  • 网孔是回路的特例；网孔法只适用于平面电路，回路法可处理非平面电路（教师说后者在教材里很少见）。
  • 两种方法的差别只在"怎么选回路"，不在列式：
    • 有理想电流源时，选让电流源只落在一个回路里的回路，该回路电流直接已知；
    • 电流源越多、越在中间，回路法省下的方程越多。
  • 选用原则（教师给的对照）：独立回路少的电路用回路（网孔）法，独立节点少的电路用节点电压法； 只有两个节点时节点法最省（一个方程）。

学它干什么

  • 网孔法/回路法是第三章"标准形式"训练的一半（另一半是节点电压法）。教师反复说： 考试时即便不会解方程，也要把标准形式列出来——判卷按式子给分，10 分的题结果只占 2 分左右， 写对标准形式也能拿 2–3 分；网孔电流解出来 1 分、各支路电流再 1–2 分。
  • 网孔法的思想后面还在用：回路法的标准形式与它同构，节点电压法的标准形式也是同一套"自项正、互项负、右端源项"的记账法。

本篇没讲的

  • 节点电压法（3.3）：下次课才讲，本篇只提到"它比网孔法更常用"。
  • 非平面电路的具体例子：教师只说"很少见，教材上也不多"。

转写与术语

  • 「王红／网口／网红／完工／网补」→ 网孔（转写把"网孔"读成多种词，是本次课出现最频繁的错词）。
  • 「负电阻／负电组／负电脑」→ 互电阻（"互"被听成"负"；讲互电阻取号处尤多）。
  • 「自电组／自电阻」→ 自电阻（同句中两种写法混用）。
  • 「M1／M2」→ IM1​、IM2​（网孔电流，转写丢了 I 与下标）。
  • 「kpf／KA L／Kvm」→ KVL（列方程时的口播缩写）。
  • 「输出源／数控源／受众源」→ 受控源。
  • 「2O／3O／50 欧」→ 2Ω、3Ω、50Ω（欧姆符号被写成字母 O）。
  • 「1 2／1 3／5 3」→ 分数 1/2、1/3、5/3（口播"分之一"被转成空格加数字）。
  • 「母电电压法」→ 节点电压法（在比较两种方法时出现）。
