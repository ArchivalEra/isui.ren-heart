11-23-功率因数与谐振

这节课在干什么

本节收尾第五章正弦稳态电路：先接续上一道 R-L 串联算参题的结尾（00:00–01:55），再讲一道三支路并联正弦电路功率计算例题（01:56–12:38）；随后集中讲解功率因数的提高——意义、并联电容补偿原则、欠/全/过三种补偿状态及经济性比较、补偿电容公式推导与发电机带日光灯例题（14:54–52:38）；最后带过正弦交流电路最大功率传输（52:39–55:59），并略讲 5.7 电路的频率响应（55:59–60:45）与 5.8 正弦稳态电路的谐振（60:46–63:24）。

要掌握六件事：

  1. 功率计算两条路：求端口 U˙、I˙ 按定义算 P、Q、S，或按各支路有功守恒（∑Ik2​Rk​）与无功守恒（∑Ik2​Xk​）相加；
  2. 提高功率因数的两大意义：提升电源设备有功输出利用率，减小输电电流 I=P/(Ucosφ) 与线路热损耗 I2R；
  3. 补偿原则与方案：保持负载额定电压与有功功率不变，在感性负载两端并联电容（QC​<0 与感性无功局部互换），工程上因成本与容值精度选欠补偿；
  4. 并联补偿电容计算式：C=ωU2P​(tanφ1​−tanφ2​)，电容提供无功 QC​=Q2​−Q1​=P(tanφ2​−tanφ1​)<0；
  5. 交流最大有功功率传输：RL​,XL​ 独立可变时满足共轭匹配 ZL​=ZS∗​（Pmax​=4RS​US2​​），RL​,XL​ 成比例仅模可变时满足模匹配 ∣ZL​∣=∣ZS​∣；
  6. 网络函数 H(jω)=响应相量/激励相量 分出幅频与相频特性，四类滤波器概念，以及谐振时总电压与总电流同相（呈纯电阻性，串联谐振满足 ωL=ωC1​）。

没编号但讲了的知识点

1. 前题收尾与三支路并联电路功率例题（00:00–12:38）

  • 前题收尾（00:00–01:55，无题号，缺完整题干与电路原图）：录音自解题末尾切入，场景为已知有功功率与 cosφ=0.6、无功功率 Q=40 var（单位大写写为 var，勿写成小写）的 R-L 串联电路求元件参数。课堂总结三条等效求法：由 P=I2R、Q=I2XL​ 及 L=XL​/ω；由 P=UIcosφ 求 φ 与 Q=UIsinφ；或利用功率三角形与阻抗三角形相似，由斜边 Z 与 cosφ 直接求直角边 R、XL​。
  • 例题（无编号）：三支路并联正弦电路功率计算（01:56–12:38，缺原图及部分支路元件值）
    • 口述已知：电源电流相量 I˙s​=5∠0∘ A（有效值 I=5 A，φi​=0∘）；电路由三条并联支路组成——支路一为电流源 is​ 与电阻 R=2Ω 串联，支路二为 R-L 串联，支路三为 R-C 串联。具体 is​(t) 表达式与后两支路 R,L,C 数值仅在课件显示、未逐一读出。
    • 要求：电路吸收的有功功率 P、无功功率 Q、视在功率 S 及功率因数 cosφ。
    • 解法一（端口电压法）：将各元件转为相量模型，求电流源端口等效阻抗 Z=2+Z并​（转写在此处数字损坏），得端口电压相量 U˙s​=ZI˙s​（电流由上向下、端口电压上正下负，取关联参考方向）。课堂给出端口电压相角 φu​=6.34∘，故 φ=φu​−φi​=6.34∘，cosφ=cos6.34∘>0；再代入 P=UIcosφ、Q=UIsinφ、S=UI。因 Q>0（电感无功恒大于零、电容无功恒小于零），整体呈感性。
    • 解法二（功率守恒法）：2Ω 电阻电流即 I=5 A，其有功为 I2R；对后两条并联支路作相量分流求出各自支路电流有效值，分别按 Ik2​Rk​ 与 Ik2​Xk​ 计算各支路有功与无功（感性为正、容性为负），再各自求和得总 P、Q，最后得 S=P2+Q2​、cosφ=P/S。

2. 功率因数的提高（14:54–45:22）

  • 定义与行业标准：功率因数 λ=cosφ=SP​，与有功 P=UIcosφ、无功 Q=UIsinφ、视在功率 S=UI 构成功率三角形。教材第 135 页更新数据：一般工业企业要求 cosφ≥0.9，高压供电企业要求不低于 0.95；同一设备满载时功率因数高于空载。
  • 两大作用：
    1. 提高电源设备容量利用率：额定容量 S 固定时，cosφ 越大，输出有功 P=Scosφ 越大。
    2. 减小输电线路损耗：当负载有功 P 与端电压 U 一定时，线路电流 I=UcosφP​ 与 cosφ 成反比；提高 cosφ 可减小电流 I，从而降低线路电阻发热损耗 I2R 并减少导线截面需求。（顺带提及：长电源线或插排线勿绕圈使用，交流电下绕圈形成电感易发热起火。）
  • 原则与方法：保证原用电器额定电压 U 与所需有功 P 不变（不影响正常工作），在感性负载两端并联电容（串联会分压改变负载电压）。电容支路无功 QC​<0 与电感无功 QL​>0 在局部相互充放交换，减少无功在电源与负载间往返，总无功 Q 减小使 ∣φ∣ 变小、cosφ 增大。
  • 三种补偿状态对比：
补偿状态并联电容大小总无功与相角符号端口性质工程取舍与原因
欠补偿偏小Q>0, φ>0感性工程选用：与等 ∣φ∣ 过补偿 cosφ 相同但电容更小、成本更低
全补偿恰好抵消Q=0, φ=0纯电阻性理论最理想，但所需电容常需极高精度且难随负载匹配
过补偿偏大Q<0, φ<0容性不选：与等 ∣φ∣ 欠补偿相比增加电容容量与材料成本
  • 补偿电容公式推导：以端电压 U˙ 为参考相量，补偿前电流 I˙1​ 滞后角 φ1​，并联电容电流 I˙C​（IC​=ωCU，超前 U˙ 90∘）后总电流 I˙2​=I˙1​+I˙C​ 滞后角降为 φ2​。保持 P、U 不变，由垂直分量得：
    IC​=I1​sinφ1​−I2​sinφ2​=UP​(tanφ1​−tanφ2​)
    结合 IC​=ωCU，得并联电容：
    C=ωUIC​​=ωU2P​(tanφ1​−tanφ2​)

3. 无编号例题：交流发电机带日光灯补偿计算（45:23–52:38）

  • 已知条件：交流发电机额定容量 SN​=10 kVA，额定电压 U=220 V，电源频率 f=50 Hz（ω=2πf=100π rad/s）；所接日光灯负载总有功功率 P=8000 W，原功率因数 cosφ1​=0.6。
  • 第（1）问：负载电流是否超过发电机额定值？
    • 发电机额定电流：IN​=USN​​=22010000​≈45.5 A
    • 负载电流：I1​=Ucosφ1​P​=220×0.68000​≈60.6 A
    • 结论：60.6 A>45.5 A，超过额定值，不能正常工作。
  • 第（2）问：功率因数提高到 cosφ2​=0.9 应并联多大电容？
    • 由 cosφ1​=0.6、cosφ2​=0.9 求 φ1​,φ2​ 及正切值，代入公式：
      C=ωU2P​(tanφ1​−tanφ2​)=100π×22028000​(tanφ1​−tanφ2​)≈447μF
  • 第（3）问：提高到 0.9 后的线路负载总电流是多少？
    • I2​=Ucosφ2​P​=220×0.98000​≈40.4 A<45.5 A，低于额定电流，发电机尚有余力带其他负载。
  • 第（4）问：电容器提供的无功功率是多少？
    • 补偿前 Q1​=Ptanφ1​（一万多 var），补偿后 Q2​=Ptanφ2​（三千多 var），电容发出无功（吸收负无功）：
      QC​=Q2​−Q1​≈−6.8 kvar

4. 最大功率传输（52:39–55:59）

  • 将含源单口网络经戴维南等效为电压源 U˙S​ 与内阻抗 ZS​=RS​+jXS​ 串联，外接可变负载阻抗 ZL​=RL​+jXL​；最大功率指有功功率 P=I2RL​ 最大，分两种情形：
    1. 共轭匹配（RL​ 与 XL​ 可独立变化）：当 ZL​=ZS∗​，即 RL​=RS​ 且 XL​=−XS​（电抗互为相反数）时有功最大，
      Pmax​=4RS​US2​​
    2. 模匹配（RL​ 与 XL​ 保持固定比例、仅调整阻抗模长；课堂口述一度混说为「阻抗角 φ 可变、模不变」后又指明为 R,X 比例定值）：当 ∣ZL​∣=∣ZS​∣ 时取得最大有功功率。

5. 5.7 电路的频率响应（55:59–60:45，仅概念）

  • 频率特性与网络函数：电路响应随正弦激励频率 ω 变化的规律。网络函数定义为
    H(jω)=激励相量响应相量​=∣H(jω)∣∠θ(ω)
    只取决于电路结构与参数，与激励大小无关。模 ∣H(jω)∣ 随 ω 的变化为幅频特性，辐角 θ(ω) 随 ω 的变化为相频特性，合称电路的频率特性。
  • 滤波器分类：允许所需频段（通带）通过、抑制不需要频段（阻带）的电路。按幅频特性分为低通、高通、带通（保留中间某频段）、带阻（抑制中间某频段）四类。

6. 5.8 正弦稳态电路的谐振（60:46–63:24，仅概念与串联条件）

  • 谐振概念：在同时含有电感与电容的交流电路中，若端口总电压与总电流同相，电路处于谐振状态。此时端口呈纯电阻性，电源与电路间不再发生无功交换，无功仅在 L 与 C 内部互换（等效于全补偿）。分为串联谐振与并联谐振；工程上既用于无线电与电子测量选频，也需在一般电力网络中防止非预期谐振危害。
  • 串联谐振条件：电抗虚部完全抵消，即
    ωL=ωC1​
    并联谐振未展开推导即下课。
