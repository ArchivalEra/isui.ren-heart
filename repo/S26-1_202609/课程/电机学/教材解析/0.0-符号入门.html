电机学符号入门

这本书自己带了一张「主要符号表」（在目录之后、正文之前，两页），第一章开头就直接用其中的符号，而且一个都不解释——教材默认你已经认识。这一页把第一章会遇到的符号按族整理好，每个符号在正文里都能点：点到就出气泡，气泡里是一句话解释。

  • 正文里把符号写成 [tex]{#词条id} 令牌（如 [B]{#sym-B}）即可获得点击气泡；词条在下面围栏里维护，渲染时围栏被剥掉、不出现在页面上。围栏每行一个词条，格式 id | 标题 | 气泡文本；新增符号族 = 新面板（带 {#id}）+ 新词条行，两处 id 必须一致。
  • 符号表里只有"是什么"，没有"怎么用"。要会算，看各节解析；要背，看下面这张速查。
  • 下标与上标是本书的语法，不认它就等于读不懂公式：1 是定子侧/一次侧/基波，2 是转子侧/二次侧/二次谐波，N 是额定，st 是起动，σ（西格玛）是漏，* 是标幺值；上标 ′ 是归算值或瞬态值，″ 是超瞬态值，·（点）是相量。
  • 单位必须跟着符号走（第一章就靠这个分辨物理量）：BBB 用 T，Φ\PhiΦ 用 Wb，HHH 用 A/m，μ\muμ 用 H/m，FFF 与 UMU_MUM​ 用 A，LLL、MMM 用 H，eee 用 V，TTT 用 N·m。

一族一族的记法

磁场的三个基本量：B、H、μ

三个量，两句话：

  • [B]{#sym-B} 是磁通密度（也叫磁感应强度），描述"磁有多强"，是矢量；[H]{#sym-H} 是磁场强度，也是矢量，描述"外界激励有多强"；两者由 [μ]{#sym-mu} 联系起来：B=μHB=\mu HB=μH。
  • 谁跟介质有关：HHH 只看电流（激励），BBB 还要乘上介质的磁导率。所以同一个电流，铁心里的 BBB 比空气里大几千到上万倍——这一条在第一章会反复考（真空、铜、铝的 μ\muμ 都可以当成 μ0\mu_0μ0​）。
磁通与磁链：Φ、Ψ
  • [Φ]{#sym-Phi} 是磁通（穿过某面积的磁感应线根数，标量，Wb）；[Ψ]{#sym-Psi} 是磁链（NNN 匝线圈每匝的磁通加起来，Ψ=NΦ\Psi=N\PhiΨ=NΦ，本质是"磁通乘以匝数"）。
  • 一句话区分：Φ 是"几根线"，Ψ 是"几根线 × 几圈"。磁链变化才产生感应电动势，所以电机里论"变化"用 Ψ。
磁路三件套：F、U_M、R_m、Λ
  • [F]{#sym-F} 是磁动势（安匝数 NININI，单位 A——注意单位不是"安培·匝"）；[U_M]{#sym-UM} 是磁位差/磁压（∫H dl\int H\,\mathrm dl∫Hdl，单位也是 A）。
  • [R_m]{#sym-Rm} 是磁阻 Rm=l/(μS)R_m=l/(\mu S)Rm​=l/(μS)；[Λ]{#sym-Lambda} 是磁导 Λ=1/Rm=μS/l\Lambda=1/R_m=\mu S/lΛ=1/Rm​=μS/l。
  • 与电路一一对应：磁动势 ↔ 电动势，磁通 ↔ 电流，磁压 ↔ 电压降，磁阻 ↔ 电阻。第一章的整张类比表在小结与习题里。
电路与机电转换：L、M、e、F_e、T
  • [L]{#sym-L} 是电感（单位电流产生的磁链，ΛN2\Lambda N^2ΛN2）；[M]{#sym-M} 是互感（一个回路的电流在另一个回路里造出的磁链）。
  • [e]{#sym-e} 是感应电动势（e=−dΨ/dte=-\mathrm d\Psi/\mathrm dte=−dΨ/dt）；[Fe]{#sym-Fe} 是电磁力（Fe=BliF_e=BliFe​=Bli）；[T]{#sym-T} 是电磁转矩（T=BlirT=BlirT=Blir）。
  • 方向靠三个定则分工：右手螺旋（电流→磁场）、右手定则（运动→电动势）、左手定则（电流＋磁场→受力）。分工表见第三节解析。
材料与损耗：Br、Hc、p_Fe
  • [磁滞回线]{#sym-hysteresis} 的两个交点：[Br]{#sym-Br} 剩磁（撤掉外磁场后还剩的磁通密度）、[Hc]{#sym-Hc} 矫顽力（要把磁性消掉所需的反向磁场）。
  • [铁耗]{#sym-pFe} pFe=ph+pep_{Fe}=p_h+p_epFe​=ph​+pe​：磁滞损耗 + 涡流损耗，都发生在铁心里，与频率、磁通密度有关。
  • 记忆钩子：回线越胖（面积大）磁滞损耗越大；片子越薄、电阻率越高，涡流损耗越小。
储能与下标约定
  • [W_m]{#sym-Wm} 是磁场储能（能量密度 wm=12BHw_m=\frac12 BHwm​=21​BH，线性介质下 wm=B22μw_m=\frac{B^2}{2\mu}wm​=2μB2​）。旋转电机的磁场能量主要存在气隙里——第一章特别强调这一点。
  • [下标约定]{#sym-sub} 与 [上标约定]{#sym-prime} 是本书的语法，读公式前先认号。
