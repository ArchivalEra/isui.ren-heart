2026-10-10作业：逻辑函数化简、状态表与卡诺图（习题 7.9、7.10）

1. 来源与边界

  • 来源：学习通上的作业，平台页眉（任务名）逐字为「2026-10-10作业」；共 2 题，平台小节都写作「简答题」——第 1 题是教材习题 7.9（化简 + 状态表 + 逻辑图，3 小问，截图底部 1/2）、第 2 题是教材习题 7.10（卡诺图化简，4 小问，截图底部 2/2）。
  • 题面来源：用户提供的 1 张答题页截图；截图原件不入库，文件名与 SHA-256 登记在原始资料索引。题面已与教材第 7 章章末习题 7.9 逐字核对一致（该章原文档已归档；上划线归属按原文档公式对象逐项解析，见校对层）。
  • 三件事一起做：题目要求「化简 + 列出状态表 + 画出逻辑电路图」——三个都要交。

2. 依赖

7.9(1) 化简 + 三小问的状态表、逻辑图卡诺图化简法与无关项卡诺图排列（循环码）、相邻关系、画圈四原则、从圈读与项；把 A,B,CA,B,CA,B,C 各组合代进原式填状态表—
7.10 四小问（卡诺图化简）卡诺图化简法与无关项四变量卡诺图（行、列各两个变量，都按 00/01/11/10）、画圈四原则、从圈读与项—

怎么用这份作业：每题拆成「提示 → 完整解答 → 复盘」三层，默认全部收起——先自己动笔，卡住了再逐层展开。 本题型三件事的套路：① 化简——先看式子结构：有相同因子就用并项法提公因子，见「变量 × 含该变量的和」就用吸收律收掉，含反变量与项（X+X‾YX+\overline{X}YX+XY）就用消去法，括号乘积先展开成最小项之和再用 XX‾=0X\overline{X}=0XX=0 清理；都不顺手再填卡诺图圈组。② 状态表——把 A,B,CA,B,CA,B,C 的 8 种组合逐个代入原式填 YYY。③ 逻辑图——用与门/或门/非门把最简式画出来。

一、习题 7.9(1)（含嵌套取反，化简到一项）

化简 Y=AC+A‾BC‾+B‾C+ABC‾‾Y = \overline{\overline{AC + \overline{A}BC} + \overline{B}C + AB\overline{C}}Y=AC+ABC​+BC+ABC​，并列出状态表、画出逻辑电路图。

提示

这个式子有两层横线，逐层算、别心算整式 ① 最外层一条长横线盖住整个括号内三项之和；内层 AC+A‾BCAC+\overline{A}BCAC+ABC 上还有一条，只盖这一项。 ② 列状态表时把每一层单独写成列：先算内层和 → 再算内层取反 → 再算三项之或 → 最后取反。 ③ 状态表算完，把 Y=1Y=1Y=1 的行挑出来（本题只有 011 与 111 两行）；两行里 AAA 一个取 0 一个取 1，BBB、CCC 都取 1——相同的变量留下（BCBCBC）、相异的变量消掉（AAA），即得最简式。

二、习题 7.9(2)（吸收律：三项归一项）

化简 Y=A(A+B+C)+B(A+B+C)+C(A+B+C)Y = A(A+B+C) + B(A+B+C) + C(A+B+C)Y=A(A+B+C)+B(A+B+C)+C(A+B+C)，并列出状态表、画出逻辑电路图。

提示

每一项都长成「变量 × 含该变量的和」 ① 三项的括号都是同一个 (A+B+C)(A+B+C)(A+B+C)，别看成一整块去提公因子——逐项分开看。 ② 每项都是 A⋅(A+B+C)A\cdot(A+B+C)A⋅(A+B+C) 这种「变量 × 含该变量的和」形状，正好是吸收律 X(X+Y)=XX(X+Y)=XX(X+Y)=X 的样子，逐项收掉。

完整解答

第一步：逐项用吸收律收掉

三项分别是 A⋅(A+B+C)A\cdot(A+B+C)A⋅(A+B+C)、B⋅(A+B+C)B\cdot(A+B+C)B⋅(A+B+C)、C⋅(A+B+C)C\cdot(A+B+C)C⋅(A+B+C)，都形如「变量 × 含该变量的和」。

按吸收律 X(X+Y)=XX(X+Y)=XX(X+Y)=X（取 X=AX=AX=A、Y=B+CY=B+CY=B+C）：

A(A+B+C)=A,B(A+B+C)=B,C(A+B+C)=CA(A+B+C)=A,\qquad B(A+B+C)=B,\qquad C(A+B+C)=CA(A+B+C)=A,B(A+B+C)=B,C(A+B+C)=C

（三项的括号都是同一个 (A+B+C)(A+B+C)(A+B+C)，各自的系数又都出现在括号里，所以每一项都被自己的系数吸收。）

第二步：三项相加

Y=A+B+CY = A + B + CY=A+B+C

（只有 A=B=C=0A=B=C=0A=B=C=0 时 Y=0Y=0Y=0，其余全 1——这正是"或"的定义。）

答案：最简式 Y=A+B+CY = A + B + CY=A+B+C。

逻辑电路图（三输入或门）：

吸收律 A(A+B+C)=AA(A+B+C)=AA(A+B+C)=A 是本题的一步杀 形如 A(A+B+C)A(A+B+C)A(A+B+C) 的项，括号里只要有 AAA 本身，整项就被 AAA 吸收（AAA 已经蕴含了它）。 三项各自吸收后直接相加，得 A+B+CA+B+CA+B+C。看到"变量 × 含该变量的和"，第一反应就是吸收律。

三、习题 7.9(3)（展开后逐项清理，化简到一项）

化简 Y=(A+B)(A‾+B‾)B‾Y = (A+B)(\overline{A}+\overline{B})\overline{B}Y=(A+B)(A+B)B，并列出状态表、画出逻辑电路图。

提示

先展开、再用 XX‾=0X\overline{X}=0XX=0 清理 ① 把前两个括号相乘展开（分配律）——得到四项，其中 AA‾A\overline{A}AA 与 BB‾B\overline{B}BB 用互补律直接划掉。 ② 剩下的两项乘上最后那个 B‾\overline{B}B，再清理一次：B‾ B‾\overline{B}\,\overline{B}BB 用重叠律留成 B‾\overline{B}B，BB‾B\overline{B}BB 用互补律归零。 ③ 算完可用状态表复核：式末乘了 B‾\overline{B}B，所以 B=1B=1B=1 的两行 YYY 必为 0；状态表里只有 B=0B=0B=0 的取值可能为 1，与结果相符即通过。

完整解答

第一步：展开前两个括号（分配律 (X+Y)(Z+W)=XZ+XW+YZ+YW(X+Y)(\htmlData{term=sym-Z}{Z}+W)=XZ+XW+YZ+YW(X+Y)(Z+W)=XZ+XW+YZ+YW）

(A+B)(A‾+B‾)=AA‾+AB‾+BA‾+BB‾(A+B)(\overline{A}+\overline{B}) = A\overline{A} + A\overline{B} + B\overline{A} + B\overline{B}(A+B)(A+B)=AA+AB+BA+BB

第二步：逐项清理（互补律 XX‾=0X\overline{X}=0XX=0）

=0+AB‾+A‾B+0=AB‾+A‾B= 0 + A\overline{B} + \overline{A}B + 0 = A\overline{B} + \overline{A}B=0+AB+AB+0=AB+AB

（这是异或 A⊕BA\oplus BA⊕B。）

第三步：乘上 B‾\overline{B}B 并再清理

Y=(AB‾+A‾B)B‾=AB‾ B‾+A‾BB‾Y = (A\overline{B} + \overline{A}B)\overline{B} = A\overline{B}\,\overline{B} + \overline{A}B\overline{B}Y=(AB+AB)B=ABB+ABB

用重叠律 X⋅X=XX\cdot X=XX⋅X=X 得 AB‾ B‾=AB‾A\overline{B}\,\overline{B}=A\overline{B}ABB=AB；用互补律 BB‾=0B\overline{B}=0BB=0 得 A‾BB‾=0\overline{A}B\overline{B}=0ABB=0。所以

Y=AB‾+0=AB‾Y = A\overline{B} + 0 = A\overline{B}Y=AB+0=AB

答案：最简式 Y=AB‾Y = A\overline{B}Y=AB。

小结：这份作业要带走的东西

  1. 两条路，看式子结构选：① 公式法——式子有公因子/反变量与项/括号乘积时最快（并项、吸收、消去、展开清理）； ② 卡诺图——式子已化成最小项、或公式法看不出规律时，填图圈组最稳。 ③ 逐行代入状态表最慢，嵌套取反时极易错，只适合做校验（本题 7.9(1) 的状态表就把各层单独列成列）。
  2. 吸收律是"一步杀"：A(A+B+C)=AA(A+B+C)=AA(A+B+C)=A、A+AB=AA+AB=AA+AB=A——凡"变量 × 含该变量的和"或"变量 + 含该变量的积"，直接吸收（7.9(2) 三顶归一项就靠它）。
  3. XX‾=0X\overline{X}=0XX=0 清理法：把式子展开成最小项之和，凡出现"同一变量正反相乘"的项直接划掉（7.9(3) 就靠这一步）。
  4. 三件事一起交：化简式、状态表、逻辑图——状态表是化简结果的独立校验（两者必须一致）。
  5. 逻辑图符号（本课约定）：与门写 AND、或门写 ≥1、非门是带小圆圈的方框。
  6. 四变量卡诺图：行、列各两个变量都按循环码；"整行全 1"能圈 8 格大圈（消 3 个变量），"四个角"也是相邻的一圈。
