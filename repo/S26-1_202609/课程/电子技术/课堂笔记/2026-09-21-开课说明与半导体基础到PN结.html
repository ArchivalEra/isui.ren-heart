电子技术 2026-09-21：开课说明与半导体基础到 PN 结

这节课在干什么（第一次课）：前一段讲这门课怎么考、怎么用工具（本课成绩一半来自过程，而过程规则相当具体）， 然后进第一章：什么是电子技术（两分支、四种处理方式）→ 半导体基础（本征半导体 → 掺杂 → P 型／N 型 → 多子少子）→ PN 结的形成 → PN 结的单向导电性。教师说 PN 结的单向导电性 是第一章最重要的特性，也是后面所有应用的铺垫。

没编号但讲了的知识点

课程地图与第一章重点

  • 第一章的地位：教师说是「最最基础的也是最重要的」一章，是后面几章的知识铺垫。
  • 学习顺序（由浅入深）：半导体基础知识 → 半导体器件——二极管 → 特殊二极管 → 晶体管 → 场效应管 → 光电类器件。
  • 第一章重点：① PN 结的工作原理与单向导电性；② 三极管的电流分配与电流放大作用；③ 二极管、稳压管、三极管、场效应管的构造、工作原理、特性曲线与主要参数的意义；④ 学会分析含二极管的电路。
  • 教材的性质与局限：本课教材把模拟电子技术与数字电子技术合成一门，「讲的课时也有限，水平能力也有限，不可能方方面面都讲得很深」。打算考研考电子方向的同学要另找经典教材、慕课与在线平台（教师也提到 B 站）。
  • 教师知道《电路原理》同步开设，说讲到需要时会「把电路的一些知识穿插一点进来」。

什么是电子技术

定义（教师说取自百度百科，属引用）：根据电子学的原理，运用电子元器件来设计和制造具有某种特定功能的电路，以解决实际问题。四个要素：原理（依据）、元器件（用什么搭）、特定功能的电路（做出什么）、解决实际问题（为了什么）。

两大分支：

  • 信息电子技术（典型应用是手机）再分两支：模拟电子技术处理模拟信号（连续变化，电路里的信号多以电压电流波形出现）；数字电子技术处理数字信号（只有高低电平两种状态，对应计算机里的 0 和 1）。教师说低电平例如 0.7 V 以下（同段又说「或者说 0.3 V 以下」，两个数字都记）。
  • 电力电子技术处理电能形式转换：多数输电线路传交流电，只有特高压直流输电这类极个别线路是直流；而手机用的是直流电（电池）——把交流变直流、直流变交流，就要用电力电子技术。

一句话：电子技术主要是对电子信号进行处理的技术。

四种主要的处理方式：

处理方式 教师讲的道理与例子
信号的产生（发生） 要先有信号。打电话拨号后先产生一个信号去呼叫（发到转接中心）；这个信号在手机内部刚产生时很微弱
放大 信号传输中会衰减，要传得远、传得久就得放大。电力电子领域里相当于升压或增大电流，信息电子里是增强信号能量
滤波 接收端信号含很多杂波，要滤出所需信息；电力电子里交流变直流后也要滤波，作用是把抖动的信号变平稳
转换 模拟与数字信号常要互相转换。麦克风讲话产生连续的模拟信号，计算机要用就做模数转换，存内存、存存储器；播放时读出数据经扬声器（一层膜随不同电流震动发出连续的声音）

应用领域与基本单元：电力系统、工业（「但凡带有控制设备、信号设备的都离不开电子技术」）、交通、医疗、广播等；要组成庞大的控制系统，最基本的单元就是元器件——二极管、三极管（以及场效应管一类），这些是本课程的主要内容。

从单体器件到集成芯片（课程动机）

  • 现实中单体器件用得比较少，实际系统里的器件基本都做成了集成芯片：在一块硅片上用光刻机刻出 MOS 管的沟道。
  • 特征尺寸：高端芯片目前可做到 3 纳米以下（教师估计）；指的是半导体工艺中最小的尺寸，也就是 CMOS 工艺里沟道的长度。尺寸越小 → 集成度越高 → 单位面积里的晶体管越多 → 处理与存储能力越强。
  • 产业背景（教师课堂叙述，未核实）：美国对我国芯片封锁主要卡光刻机；华为 Mate 40 之后 5 nm 以下芯片被断供；真正能做小特征尺寸的还不是大陆企业，最大代工厂是台积电，全球集成电路厂排前面的以欧美企业为主。教师的动员：学这门课不一定立刻改变现状，但可以在配套的生产与研发岗位上起作用。

半导体基础（一）：本征半导体

  • 半导体的电阻率介于导体与绝缘体之间：某些条件下扮演导体，条件改变又可能呈现绝缘体状态。
  • 本征半导体的定义（书上）：完全纯净的、具有晶体结构的半导体。两个关键词缺一不可（教师反复强调）：完全纯净、具有晶体结构（原子核与电子排列成立体的、整齐有规律的结构）。
  • 教材讲到的材料教师提到硅与砷化镓等，常用的是硅；硅是四价元素（外层四个电子）。
  • 共价键：相邻两个硅原子各出一个电子、两两配对，每个硅原子与周围四个硅原子以共用两个电子的形式结合。共价键「在学化学的时候是相当牢固的」，要破坏需要很大的能量。结构上每个原子处于一个四面体的中心，四个相邻原子在顶点。
  • 本征激发：给价电子提供能量（光照或加热），价电子挣脱共价键跑出来。跑出来的叫自由电子（带负电），它留下的空位带正电，叫空穴。

    教师明确说这里是考点：半导体中自由电子带负电荷、空穴带正电荷——后面讲单向导电性都要用。

  • 自由电子的活跃度与温度成正比 → 本征半导体具有热敏性与光敏性（半导体三大特性中的两个）。
  • 载流子的运动与电流方向：没有外电场时自由电子做杂乱无章的运动；加外电场后，空穴靠相邻价电子 来填补空位而等效地移动，自由电子沿一定方向移动。半导体的电流由两部分组成（电子 + 空穴）。 最容易糊涂的一点：两者移动方向相反，但电流方向相同——因为规定正电荷移动方向为电流的参考正方向， 所以自由电子的移动方向与电流方向相反。具体分析电路时先假设参考方向，算出的代数值为负说明假设反了。

半导体基础（二）：掺杂半导体与载流子

半导体的三大特性至此讲全：热敏性、光敏性、掺杂性。

  • 为什么必须掺杂：实际用的半导体一般不用本征半导体——它的导电特性太弱（教师也说「带负载的能力太弱」）。做法是掺入微量的其他元素，整体仍呈现本征半导体的特性，只是提高了导电性能。
  • P 型半导体（掺三价元素，教师举例硼）：三价元素最外层只有 3 个电子，比硅少一个 → 相当于多了一个空穴，即「掺了空穴」。以空穴为主的叫 P 型（P 取 positive 之意，因为相对 N 型它相当于带正电）。

    重要澄清：半导体材料本身呈电中性——没有外加电场时不带电荷（原子核与电子数仍一一配对）。「带正电」只是相对本征半导体、相对 N 型的说法。

  • N 型半导体（掺五价元素，教师举例磷）：五价元素最外层 5 个电子，比硅多一个 → 电子偏多，叫 N 型（negative）。N 型里的空穴来自本征激发（受光受热仍会产生少量空穴）。
  • 载流子、多子与少子（教师点明是考点）：载流子＝运输正负电荷的微粒（空穴带正电、自由电子带负电）。掺杂半导体里两种载流子数量不对等：
半导体 多数载流子（多子） 少数载流子（少子） 少子从哪来
P 型 空穴（掺杂掺进来的） 自由电子 本征激发
N 型 自由电子 空穴 本征激发

PN 结的形成

  • 为什么要做 P 型和 N 型：目的是形成单向导电的效果——把 N 型与 P 型接触在一起，形成一个交界面。

  • 形成过程（五个环节）：

    1. 多子扩散：交界面左边 P 型（多空穴）、右边 N 型（多自由电子），「异性相吸」——左边空穴往右跑、右边自由电子往左跑，这叫多子扩散运动。
    2. 复合耗尽：跑到对面的载流子相遇，电荷相反而成双成对地复合（互相抵消）。
    3. 形成内电场：复合后留下不能移动的原子核离子——N 侧带正电、P 侧带负电，内部形成内电场，方向由正指向负，即从 N 侧指向 P 侧。
    4. 少子漂移：内电场又促进少子的漂移运动（N 区少子空穴往左、P 区少子自由电子往右）——漂移方向与多子扩散方向相反。
    5. 动态平衡：多子扩散的量与少子漂移的量最终相等，成为动态平衡；此时该区域没有净的电荷运动，空间电荷区宽度固定不变。

  • 名称：这一段区域叫 PN 结，也叫空间电荷区或耗尽层。

  • 两条方向（务必记牢）：多子扩散使空间电荷区加宽、内电场增强；少子漂移使其变窄。

  • 内电场的作用：阻碍 P 区空穴、N 区电子向对方扩散；促进少子漂移。空间电荷区里没有载流子（已耗尽）。

  • 不加外加电压时：虽然内电场促进少子漂移，但少子量很小，漂移电流几乎为零 → PN 结形成后对外呈现不导电的状态。

PN 结的单向导电性（本节最重要的特性）

正向偏置（加正向电压）→ 导通：外接电源正极接 P 区、负极接 N 区，外电场由 P 指向 N，与内电场（N→P）方向相反：

环节 变化
内电场 被外电场削弱
多子扩散运动 被促进，扩散电流增大
空间电荷区（耗尽层） 变窄（变薄）
电阻 正向电阻变小
状态 正向导通，形成较大的正向电流

教师补充两点：① 当外电场大过内电场时，「耗尽层相当于不存在了」，电流可畅通通过；② 外电压从零逐渐增大时必须增大到内电场的强度，导通才明显——这对应一个死区电压的概念（下节课讲伏安特性曲线时体现）。

反向偏置（加反向电压）→ 截止：外接电源正极接 N 区、负极接 P 区，外电场仍由 N 指向 P，与内电场同向叠加：

环节 变化
内电场 被加强
多子扩散运动 被狠狠抑制
少子漂移运动 被加强，但少子量很少，形不成大电流
空间电荷区（耗尽层） 变宽
电阻 反向电流很小、电压一定时反向电阻很大
状态 截止

这个特性有什么用：改变加在 PN 结两端的电压就能改变电路的通断状态——既可用于数字开关，也可用于模拟信号的滤波、斩波。教师强调「这个部分务必请大家静下心来捋一遍」，因为这个特性不掌握，后面学起来会更吃力。
