★ 通关攻略

这是什么：一条从零开始、走完就能掌握本章的学习路线。不要求你读过教材或本仓的任何解析文件——每个概念在需要时当场讲清楚。

怎么用：每个面板的写法是 「跟着算一遍」→「要点」→「最容易错的点」→「过关题」。 先把「跟着算一遍」那道例题从题面到答案走一遍（每步都写了依据），再回头看要点，最后自己做过关题。 全部独立完成 = 本章通关。

3.0 不是教材的小节：教材第 3 章只有 3.1–3.5 五节，这一页是给整章做的导航与验收页。

开始之前：前置检查

本章依赖第 1、2 章——不是泛泛的「先学完」，而是具体三条：

  • 会算行列式（第 1 章）：定理 3.2 判线性相关，判据就是「nnn 阶行列式是否为 0」。 不会算行列式，这个判据用不了。先过掉第 1 章通关攻略。
  • 会用初等行变换（2.3 节）：本章求秩、求极大无关组、求坐标，全部靠行变换。 这是本章唯一的重型工具。不熟就先过掉2.3 节攻略。
  • 会求矩阵的秩（2.4 节）：3.3 节的秩是「向量组的秩」，与矩阵的秩是同一个数（定理 3.3）。

本章相对独立的一点：3.1、3.2 两节的运算都很轻（只有加法、数乘）， 即使第 2 章学得不好也能跟上；难点集中在 3.3 节——秩的算法。

预计用时：初学 4–6 小时（含做题）。

3.1 n 维向量（原书 p52–p53）

跟着算一遍：解 α+3γ=β（教材例 3.1）

已知 α=(−3,3,6,0)\boldsymbol{\alpha}=(-3,3,6,0)α=(−3,3,6,0)，β=(9,6,−3,18)\boldsymbol{\beta}=(9,6,-3,18)β=(9,6,−3,18)，求 γ\boldsymbol{\gamma}γ。

第 1 步：把未知量孤立到一边。 由 α+3γ=β\boldsymbol{\alpha}+3\boldsymbol{\gamma}=\boldsymbol{\beta}α+3γ=β，两边同减 α\boldsymbol{\alpha}α：

3γ=β−α3\boldsymbol{\gamma}=\boldsymbol{\beta}-\boldsymbol{\alpha}3γ=β−α

第 2 步：右边做减法（逐分量）。

β−α=(9−(−3), 6−3, −3−6, 18−0)=(12,3,−9,18)\boldsymbol{\beta}-\boldsymbol{\alpha}=(9-(-3),\ 6-3,\ -3-6,\ 18-0)=(12,3,-9,18)β−α=(9−(−3), 6−3, −3−6, 18−0)=(12,3,−9,18)

γ=13(12,3,−9,18)=(4,1,−3,6)\boldsymbol{\gamma}=\frac{1}{3}(12,3,-9,18)=(4,1,-3,6)γ=31​(12,3,−9,18)=(4,1,−3,6)

要点

  • 一切运算都是逐分量的：加法、数乘、相等判定，全部按位置一个一个做。
  • 行向量 ≠ 列向量：(1,2,3)(1,2,3)(1,2,3) 与 (1,2,3)T(1,2,3)^T(1,2,3)T 在本课程里是两种不同对象，不能相加。做题先看题面写的是哪种。
  • 「向量 = 特殊矩阵」是工具不是修辞：后面求秩、求坐标，都是把向量当列拼成矩阵来算。

最容易错的点

  • 把未知量留在两边就代数字。像例 3.2 那样 β\boldsymbol{\beta}β 在等式两边都出现时，必须先归并（按普通代数整理），再代数字。一上来就代数字会让中间步骤全乱。
  • 忽略系数：求出的 3γ3\boldsymbol{\gamma}3γ 要再除以 3，别忘了。

3.3 向量组的秩（原书 p58–p60）

跟着算一遍：求秩与极大无关组（教材例 3.7 第 (1) 小题）

已知 α1=(1,1,0,0)\boldsymbol{\alpha}_1=(1,1,0,0)α1​=(1,1,0,0)、α2=(1,0,1,1)\boldsymbol{\alpha}_2=(1,0,1,1)α2​=(1,0,1,1)、α3=(2,−1,3,3)\boldsymbol{\alpha}_3=(2,-1,3,3)α3​=(2,−1,3,3)，求秩与一个极大无关组。

第 1 步：竖着当列拼矩阵。（不是横着当行！）

A=(11210−1013013)A=\begin{pmatrix}1&1&2\\1&0&-1\\0&1&3\\0&1&3\end{pmatrix}A=​1100​1011​2−133​​

第 2 步：化行最简形（不是行阶梯形——要读表示系数必须最简形）。 书上用四步行变换，最终得到

第 3 步：数非零行 = 秩。 2 个非零行 ⇒ R=2R=2R=2。

第 4 步：主元列 → 极大无关组。 主元在第 1、2 列 ⇒ α1,α2\boldsymbol{\alpha}_1,\boldsymbol{\alpha}_2α1​,α2​ 是一组极大无关组。

第 5 步：读非主元列得表示系数。 第 3 列是 (−13)\begin{pmatrix}-1\\3\end{pmatrix}(−13​) ⇒ α3=−α1+3α2\boldsymbol{\alpha}_3=-\boldsymbol{\alpha}_1+3\boldsymbol{\alpha}_2α3​=−α1​+3α2​。

验算：−α1+3α2=−(1,1,0,0)+3(1,0,1,1)=(2,−1,3,3)=α3-\boldsymbol{\alpha}_1+3\boldsymbol{\alpha}_2=-(1,1,0,0)+3(1,0,1,1)=(2,-1,3,3)=\boldsymbol{\alpha}_3−α1​+3α2​=−(1,1,0,0)+3(1,0,1,1)=(2,−1,3,3)=α3​ ✓

要点

  • 一个动作管三种问法：求秩、求极大无关组、其余向量用其表示——全在行最简形里。
  • 秩 = 非零行数 = 极大无关组的向量个数。
  • 主元列（行最简形里每行首个非零元所在的列）对应原矩阵的同号列，那几个原向量构成一组极大无关组。
  • 非主元列的数 = 表示系数，这是行最简形独有的信息，行阶梯形读不出来。

最容易错的点

  • 横着拼。横着拼也能算出秩（行秩=列秩），但读不出哪几个原向量构成极大无关组，也读不出表示系数。
  • 只化到行阶梯形就停。行阶梯形能数秩，但不能读系数。
  • 读系数时读错列。非主元列的数是「作为主元列的那些向量的组合系数」，顺序按主元列从左到右排。
  • 应用题忘了检查「系数不能为负」（例 3.9 调味品配制就是这个坑）：行最简形给出的表示可能有负系数，实际题里要换成等价的非负表示。

3.4 向量空间（原书 p61–p62）

跟着算一遍：验证是基并求坐标（教材例 3.14）

要点

  • 查「是不是向量空间」只查两条：非空 + 对加法封闭 + 对数乘封闭。不用验 10 条性质（自动继承）。 最快的否证：集合里没有零向量 ⇒ 一定不是（因为取 k=0k=0k=0 必有零向量）。
  • 基 = 极大无关组，维数 = 秩。3.3 的算法原样搬过来。
  • 验证「是基」只需证无关（维数已知时）：rrr 个无关向量在 rrr 维空间里自动构成基。
  • 坐标依赖基：同一个向量换一组基，坐标就变。答题必须写「在哪个基下的坐标」。

最容易错的点

  • 把「坐标」当成「分量」。只有标准基下坐标才等于分量。
  • 行变换时右边忘了同步做。(A∣B)(A\mid B)(A∣B) 是一个整体，左边怎么变右边也要怎么变。
  • 验证封闭性时只举一个例子。要任取一般元素（带约束条件写出来）来验证，或举出一个明确的反例来否证。

>> A = [1 1 2; 1 0 -1; 0 1 3; 0 1 3]    % 三个向量竖着当列
>> rank(A)                                % 秩 = 2

要点

  • a:step:b — 等差数列，终点是上界不保证取到（1:2:7 与 1:2:8 结果相同）
  • linspace(a,b,n) — 从 a 到 b 共 n 个点（n 是点数不是步长，两端都含）
  • logspace(a,b,n) — 从 10a10^a10a 到 10b10^b10b 共 n 个点的等比数组
  • rank(A) / rref(A) / A\B — 秩 / 行最简形 / 解矩阵方程
  • 行向量 [1 2 3]，列向量 [1;2;3] 或 [1 2 3]'

最容易错的点

  • linspace 的第三个参数当步长用。它是点数。
  • 行列向量搞混。3×1 乘 3×1 不合法，会直接报错。
  • 以为 1:2:8 能取到 8。它只到 7。
